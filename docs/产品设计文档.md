# 产品设计文档

> 二手交易平台分析系统

## 一、产品概述

### 1.1 一句话定位

一个面向二手交易领域的**平台类竞品分析工具**，帮助使用者系统性地收集、结构化、对比和跟踪各类线上二手交易平台（C2C 闲置交易、回收置换、质检转卖等）的信息。

### 1.2 背景与目标

二手交易是一个信息相对分散、平台众多、模式差异大的垂直领域。从业者、研究者或运营人员想要横向了解各家平台的定位、功能、定价与服务差异，往往需要逐个平台翻找、手工整理，效率低且难以沉淀。

本系统目标：

- 把「竞品调研」这件事**结构化、流程化**，减少重复劳动；
- 用**半自动采集 + AI 信息提炼**降低信息整理成本；
- 提供**多竞品横向对比**能力，快速看清各家差异；
- 形成可长期维护、可追踪的竞品情报库。

### 1.3 目标用户

- 首要：产品/运营/研究人员（做领域内竞品调研）
- 次要：二手交易从业者、普通用户（想了解各平台差异）

> 当前阶段为个人项目，以跑通完整链路、展示能力为主要目标，暂不涉及多用户与账号体系。

## 二、核心价值与方向

- **数据沉淀**：把零散的竞品信息统一成结构化数据，一次录入/采集，长期复用。
- **降本增效**：抓取 + AI 提炼，把「人工翻找→手工整理」变成「机器初筛→人工校对」。
- **直观对比**：一个页面看清多家平台在关键维度上的差异，辅助决策。
- **可追踪**：记录竞品的更新变化，形成动态情报而非一次性快照。

## 三、主要功能

### 3.1 竞品信息管理

- 竞品条目的**新增、查看、编辑、删除**（手动录入为主）。
- 每条竞品包含**通用分析维度**：
  - 基础信息：名称、平台类型、定位、官网、上线状态
  - 功能与业务：核心功能、目标用户、业务模式
  - 商业信息：定价/收费方式、优势、不足
  - 其他：备注、标签、关联链接

### 3.2 半自动采集 + AI 提炼

- 输入目标网址，自动抓取页面内容；
- 用 AI 从抓取内容中**提炼结构化字段 + 生成摘要**；
- 提炼结果进入「**待校对**」状态，由人确认或修正后才正式入库；
- 抓取或提炼失败时，可**降级为手动录入**，不影响主流程。

### 3.3 多竞品对比

- 选定多个竞品，生成**对比表格**；
- 以**雷达图**直观呈现各竞品在多个维度上的差异；
- 对比维度可配置（默认使用通用维度）。

### 3.4 （后续）动态监控与报告

- 定期更新竞品动态，记录版本/功能变化；
- 导出 Markdown / HTML 形式的分析报告。

> 3.4 为 MVP 之后的可选能力，不纳入首版范围。

## 四、产品范围

### 4.1 首版（MVP）包含

1. 竞品信息的增删改查（手动录入为主）
2. 通用分析维度字段
3. 单页多竞品对比（表格 + 雷达图）
4. 一个抓取试点：抓取 → AI 提炼 → 人工校对入库
5. 简单前端页面（列表页 + 对比页 + 录入表单）

### 4.2 首版（MVP）不包含

- 用户登录 / 权限管理
- 自动定时监控
- 复杂报表导出
- 多租户 / 多人协作
- 云端部署、移动端

## 五、关键业务流程

### 5.1 竞品录入流程（手动）

```
人工填写表单 → 校验 → 入库 → 列表可见
```

### 5.2 竞品采集流程（半自动）

```
输入网址 → 抓取页面 → AI 提炼 → 待校对 → 人工确认/修正 → 入库
                                    └─ 失败则降级为手动录入
```

### 5.3 竞品对比流程

```
选择多个竞品 → 系统汇总维度 → 生成对比表 + 雷达图 → 查看/导出
```

## 六、核心概念与数据维度

| 维度类别 | 字段举例 |
|----------|----------|
| 基础信息 | 名称、平台类型、定位、官网、上线状态 |
| 功能业务 | 核心功能、目标用户、业务模式 |
| 商业信息 | 定价方式、优势、不足 |
| 元信息 | 标签、备注、关联链接、更新时间 |

- **平台类型**：C2C 闲置交易、回收置换、质检转卖、资讯社区等（可扩展）。
- **扩展字段**：针对不同平台类型，可附加专属字段，保证通用框架可扩展。

## 七、非功能需求（方向性）

- **易用性**：录入和对比操作简单直观，无需培训即可上手。
- **可维护性**：数据维度可扩展，新增平台类型无需重构。
- **可靠性**：采集/AI 失败不影响已有数据，可降级人工处理。
- **安全性**：密钥等敏感配置不进入版本库。

## 八、后续规划方向

1. 定时监控竞品动态与变化提醒
2. 更丰富的分析维度与自定义字段
3. 报告导出与分享
4. 多用户 / 团队协作
5. 云端部署与移动端适配
