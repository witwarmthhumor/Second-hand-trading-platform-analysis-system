# ID锁未退出客服处理话术

## 1. 适用范围与触发条件

本 SOP 适用于买家收到手机等带账号锁的设备后，发现 ID 锁（激活锁）未退出、无法正常使用的全部工单。此类工单买家情绪浓度高，容易误认为买到盗抢设备，处理遵循三条原则：先安抚再核实；一切以质检报告与卖家发货前影像为证据；判责前不承诺任何赔付口径。触发条件包括：买家反馈设备激活时提示绑定他人账号、卖家无法或拒绝配合退出账号、设备疑似盗抢、商品页对账号锁状态披露不清。

## 2. 处理流程

| 步骤 | 动作 | 责任人/角色 | 系统操作 |
|------|------|-------------|----------|
| 1 | 安抚买家情绪，指导其停止任何解锁尝试、保留设备原样 | 一线客服 | 工单系统-接单并标记 ID 锁类 |
| 2 | 调取质检报告、商品页快照与卖家发货前影像，核对锁状态与披露记录 | 一线客服 | 质检系统、订单快照存档 |
| 3 | 通知卖家在约定时限内提交关机录屏与账户退出截图 | 一线客服 | 聊天工具-发送举证模板 |
| 4 | 按情形分类处置：配合解锁、按披露口径处理或升级 | 一线客服/主管 | 工单系统-分类打标 |
| 5 | 疑似盗抢或卖家超时不举证的，冻结交易资金并升级专组 | 主管/安全专组 | 资金冻结、升级流转 |
| 6 | 出具结论并向双方同步，禁售类设备按禁售规则收尾 | 仲裁组 | 工单系统-结案归档 |

常见情形处置要点如下：质检报告未涉及 ID 锁的，先致歉并说明会核查发货影像，不直接认定卖家有问题；卖家申报过账号异常的，引导买家查看商品页披露记录并按披露口径处理；疑似盗抢机的，引导买家停止操作、立即冻结交易资金，不让买家继续尝试解锁；卖家愿意配合解锁的，设定配合时限、超时按失联升级，不接受卖家"远程指导买家解锁"的方案。

## 3. 判责/分级标准

| 情形 | 判定方向 | 依据 |
|------|----------|------|
| 卖家发货前影像显示已退出账号、买家收货后被远程上锁 | 结合锁状态变更记录核查，非卖家原因的不贸然定责 | 发货前影像、账号锁日志 |
| 卖家无法提供退出账户证明，商品页承诺无锁 | 卖家责任，按描述不符处理 | 商品页快照、举证缺失 |
| 商品页已披露账号异常、买家下单前可见 | 按披露口径划分责任 | 商品页披露记录 |
| 设备疑似盗抢 | 冻结交易资金，转安全专组与平台介入 | 锁状态、设备来源核查 |
| 卖家愿在约定时限内配合退出 | 暂不定责，超时未完成再按失联升级 | 工单时限记录 |

判责所需证据及用途如下：质检报告来自验机仓，用于确认锁状态是否被记录；发货前影像来自卖家，用于判定发货时设备状态；聊天记录来自双方，用于核对卖家是否承诺过可解锁；商品页快照来自平台，用于核对披露内容。证据不足时不定责，先补齐再判。

## 4. 标准话术

**买家版**

您好，非常理解您的心情。ID 锁问题我们会优先核查卖家的发货前影像与商品页披露记录，核查期间您的资金仍在平台托管中，不会有损失。麻烦您先不要尝试任何解锁操作、保留设备原样，我们会尽快给您结论。

**卖家版**

您好，买家反馈设备存在 ID 锁未退出的情况，请您在工单内提交发货前的关机录屏与账户退出截图；如果确实遗漏，主动配合处理会对判责结果有利。

**升级告知版**

您好，经初步核查卖家的发货影像存在疑点，工单已升级专组处理，处理期间资金保持托管，结论会以工单形式同步给您和卖家双方。

## 5. 升级条件与升级路径

满足下列任一条件即升级：卖家超过约定时限不举证或失联；设备疑似盗抢；买家情绪激动并提及报警或媒体；卖家与买家就账号是否已退出各执一词且证据冲突。

升级路径为：一线客服先安抚并固定证据 → 无法在一线化解的转主管 → 疑似盗抢或涉禁售设备的，由主管转仲裁组与安全专组 → 资金在核查期间保持冻结、托管 → 结论出具后逐节点向买家同步，禁售类设备按平台禁售规则处理交易并向买家说明后续保障。判责前不得向任何一方承诺赔付或定责口径。
