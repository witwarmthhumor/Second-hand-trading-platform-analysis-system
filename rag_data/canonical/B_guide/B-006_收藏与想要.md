# 收藏与想要

## 什么时候看这篇

你在回流二手（RAGreflow）上刷到一件商品，暂时没想好买不买，或者想等卖家降价再出手——这时候就该用「收藏」和「想要」。两个功能都免费，区别在于：收藏是给自己看的清单，想要是给卖家看的信号。

## 操作步骤

1. 打开商品详情页，找到价格下方的一排按钮。左侧是「收藏」图标（心形），右侧是「想要」按钮（铃铛形）。点一下即完成操作，不需要确认弹窗。

2. 收藏后，商品会进入「我的-我的收藏」列表。列表按收藏时间倒序排列，最新收藏的排在最上面。点进任意一件商品，可以看到当前价格和剩余库存。

3. 点「想要」后，系统会提示你选择期望价位。你可以直接选「按当前价提醒」，也可以手动输入一个低于现价的数字。这个动作会推送给卖家端。

4. 设置降价提醒：在点「想要」时勾选「降价通知我」，当卖家改价且新价格不高于你填的期望价时，你会收到站内信和 App 推送。若卖家未改价，提醒不会触发，也不会有任何扣费。

5. 管理你的列表：在「我的-我的收藏」页面，左滑任意商品可取消收藏；点右上角「管理」可批量删除。已点「想要」的商品如需取消，进入商品详情页再点一次铃铛按钮即可。

6. 查看谁想要你的商品（如果你是卖家）：在「我的-在售商品」点开某件商品，切到「想要的人」标签页，能看到人数和他们的期望价位分布。你可以据此决定是否调价。

## 关键规则

- 收藏和想要均不产生任何费用，不占用信用额度，也不会影响你的买家信用分（初始信用分 800 分，范围 350-950，见 RL-201）。
- 点「想要」不等于下单，不触发 24 小时未付款自动取消规则（RL-104）；卖家不会因此获得你的联系方式。
- 降价提醒只在卖家主动改价且新价 ≤ 你的期望价时触发一次。若卖家改价后仍高于期望价，你不会收到通知。
- 同一件商品只能设一个期望价，修改次数不限，以最后一次保存为准。修改路径：商品详情页-「想要」按钮-「修改期望价」。
- 卖家端看到的是「想要人数」和价格区间分布，看不到具体是谁、头像或昵称，隐私保护与平台页面公示规则一致。
- 收藏和想要记录在商品下架或售出后自动失效，不会保留历史记录。若商品重新上架，需重新操作。

## 常见问题

**「收藏和想要能同时点吗？」**
能。两者互不冲突，收藏进清单，想要同时给卖家发信号。

**「我点了想要，卖家会不会来砍我？」**
不会。卖家只能看到人数和价格区间，看不到你的身份。平台不向卖家展示买家个人信息。

**「降价提醒准不准？会不会漏？」**
只要卖家改价且新价 ≤ 你的期望价，系统会推送一次。若卖家直接编辑价格而非重新发布，提醒同样触发。

**「我收藏的商品降价了会通知我吗？」**
不会。收藏不带降价提醒功能，只有点「想要」并设置期望价才会触发通知。

**「不想要了怎么取消？会不会扣分？」**
随时可取消，不扣分不影响信用。取消路径：商品详情页再点一次铃铛按钮。

## 风险与避坑

- 期望价别填得太低。填一个远低于市场价的数字，卖家大概率不会改价，提醒也就永远不会触发——你等来的只有商品被别人买走。
- 收藏不等于锁货。心仪的商品如果只剩一件，别指望收藏能帮你占住，该下单时就下单，犹豫的工夫可能就没了。
- 别把「想要」当砍价工具反复改价试探。虽然修改次数不限，但每次改动都会重新推送给卖家端，频繁操作容易让卖家觉得你不是诚心买家。
- 商品下架或售出后，收藏和想要记录会直接失效，不会提前通知你。重要的商品建议截图留存价格和成色描述，方便之后对比。
- 收到降价提醒后先核对商品状态再下单，确认是否已被别人拍下、成色描述有无改动，避免空欢喜一场。
