# 仅退款与退货退款区别

## 什么时候看这篇

商品出了问题，你打开退款页面对着两个选项发懵：仅退款还是退货退款？选错会被驳回一次，浪费好几天，这篇帮你三分钟选对。

## 两种退款的本质区别

仅退款是"钱退回来，货不用寄回去"，适用于货没到、或者问题小到寄回去都不划算的场景；退货退款是"货寄回去，钱退回来"，适用于东西本身要退掉的场合。一句话：还想要货就选仅退款，不想要货就选退货退款。

## 怎么选：对号入座

| 你的情况 | 该选哪个 | 理由 |
| 付款后卖家一直不发货 | 仅退款 | 没有货可退 |
| 包裹丢件、显示签收但没收到 | 仅退款 | 先止损，找物流是平台和卖家的事 |
| 收到商品与描述不符，不想要了 | 退货退款 | 退回商品再拿全款 |
| 小配件缺失、轻微瑕疵，可以接受 | 仅退款，申请部分退款 | 折价补偿比来回寄更省事 |
| 功能故障、假货 | 退货退款，并可要求赔偿 | 按售后流程举证 |

## 操作步骤

1. 订单页点「申请退款」，选类型；
2. 退款原因照实选，描述不符就选描述不符，不要随手选无理由；
3. 上传证据：订单快照截图、商品图片视频、聊天记录；
4. 等卖家响应，卖家拒绝不要慌，申请平台介入。

## 关键规则

- 确认收货后 15 天内是售后窗口，过期就难办了（来源：trade.after_sale_window_days，RL-A-047）；
- 卖家拒绝后可申请平台介入，介入有处理时限，复杂情形按仲裁流程走（来源：arbitration.platform_intervene_deadline_hours，RL-A-141）；
- 举证材料认这几样：订单快照、商品图片视频、聊天记录、物流凭证、质检报告、付款凭证（来源：arbitration.evidence_types）。

## 风险与避坑

- 仅退款用在小问题上没问题，恶意滥用会被记录，影响你后续维权可信度；
- 退货退款先把寄回物流单号填好再寄，别裸寄贵重物品；
- 描述不符的争议，下单前聊天里卖家承诺的内容要截图，空口无凭。
