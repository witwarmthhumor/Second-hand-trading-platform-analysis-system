# 司法协助配合规则

> 制度编号：RL-A-233　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

平台依法配合司法机关的调查取证。本章规定协助的范围、程序与用户权利，依据《个人信息使用规则》（RL-A-183）制定。

## 第二章 正文条款

第1条 协助范围：依法定手续调取的交易记录、账户资料、日志数据。

第2条 程序要求：调取须附法定文书，平台核验文书后执行；无手续的调取请求一律拒绝。

第3条 用户权利：被调取信息的用户在案件允许的范围内享有知情权；不实指控的用户有权提交反驳材料。

第4条 数据安全：调取过程留痕，数据仅用于案件用途，用途外的使用由调取方负责。

## 第三章 协助口径对照表

| 情形 | 平台动作 |
| 法定文书调取 | 核验后依法提供 |
| 律师调查（有手续） | 依法定范围提供 |
| 个人声称执法要求 | 拒绝并核实 |
| 协查函件 | 按函件范围提供 |

补充说明：司法协助还有一个用户高频咨询的场景：我自己起诉卖家，需要平台提供交易记录作为证据。这种情况的处理路径是：向平台提交你已有的受理证明，平台按程序提供与案件相关的记录副本。自助渠道里可以导出的归档文件（RL-A-188）在多数场景下已经够用，先自助导出再决定是否申请协助，能节省大量时间。

补充说明：司法协助的用户权利还有一个容易被忽略的面向：你有权知道你的哪些数据被调取了。法定手续范围内的调取，平台会按程序告知受影响的用户（法律禁止告知的情形除外）。这个知情权让你有机会在司法程序中行使自己的辩护权利。数据被调取不等于你有什么问题，知情是为了让你准备应对，而不是让你恐慌。

补充：协助调取的数据范围以文书记载为准，超出文书记载范围的数据即使平台有也不会提供。

补充：司法协助的用户知情权还有一个保护性设计：涉及国家安全、恐怖活动等特殊案件的调取依法可以不通知当事人，这是法律的明文规定，平台照办。一般民商事案件的调取则通知不受限。两类情形的区分由执法机关在手续中载明，平台按手续执行，不做额外判断。用户对调取有异议的，异议对象是调取机关而不是平台。

## 第四章 违规处理与责任

伪造司法文书骗取数据的，永久封禁并移交执法部门；平台内部配合伪造的顶格追责（来源：penalty 节点）。
