# 合并付款规则

> 制度编号：RL-A-025　版本：v3.2　生效日期：2026-06-01　适用对象：买家

## 第一章 总则

合并付款便于买家一次结清多个待付订单。本章规定可合并的范围、失效规则与资金口径，依据《商品下单规则》（RL-A-022）制定。

## 第二章 速查要点

- 同一买家名下、同一结算周期内的未付款订单可合并付款；
- 合并以购物车内勾选为准，支付成功后按单独立账、逐单生效；
- 任一订单因卖家改价、下架导致金额变化的，仅该单失效，其余订单继续支付流程；
- 未付款订单的关闭时限仍为 24 小时（来源：trade.buyer_cancel_unpaid_hours），合并状态不延长时限；
- 合并支付发生部分退款时，按各订单实付金额占比拆分退回，均原路退回（来源：RL-A-068）。
- 合并付款的订单各自独立计算发货时限（来源：trade.seller_ship_deadline_hours）；
- 合并支付成功后不可拆分撤单，只能逐单走取消或售后流程；
- 合并付款的发票按各订单金额分别开具（参照 RL-A-070）。

## 第三章 常见情形对照

| 情形 | 处理口径 |
| 其中一单被卖家取消 | 已付款项按占比退回该单部分 |
| 合并支付用了优惠券 | 优惠按比例摊到各单，退款按摊后金额退 |
| 支付中断 | 全部订单保持未付款，重新发起即可 |
| 支付中断 | 全部订单保持未付款，重新发起即可 |
| 使用余额与通道混合支付 | 按各通道实付拆分记录，退款原路对应 |
| 合并中卖家改价 | 改价单退出本次合并，其余单据继续 |

- 单次合并付款的订单数以支付页展示为准，超出部分分次支付；
- 跨类目订单可合并，费率仍按各单商品所属品类分别计算（来源：fee.rates_by_category）；
- 合并付款中含验货订单的，各单独立走验货流程，互不影响。

执行提示：使用合并付款前，先确认每笔订单的商品状态与卖家在线情况，避免其中一单因下架导致整体流程中断。合并付款成功后，各订单在「我的-订单」中仍逐单展示，发货、售后、评价互不牵连。需要发票的买家，合并付款不影响按单开票；对金额有疑问的，以账单明细的逐笔拆分记录为准，账单口径与支付渠道流水一致。

## 第四章 违规处理与责任

利用合并付款规则拆单套取优惠或干扰结算的，按《价格违规治理》（RL-A-139）与扣分阶梯处理。
