# 账号注销与信息删除

> 制度编号：RL-A-190　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

注销是用户对个人信息的终极控制权。本章规定注销的条件、信息删除的范围与保护期机制，依据《个人信息使用规则》（RL-A-183）制定。

## 第二章 正文条款

第1条 注销前提：无在途交易、无未结清的判责与赔付款、无未提现余额（余额须先行处理）。

第2条 注销设保护期：保护期内重新登录可撤销注销；超过保护期的账户与数据不可恢复。

第3条 信息删除范围：账户资料、设备标识绑定、个性化数据即时删除或匿名化；交易记录按留存规则脱敏存档（RL-A-187）。

第4条 注销不影响已完成的交易的法律效力，历史交易的责任与权利不因注销消灭。

## 第三章 注销与保留对照表

| 数据类别 | 处理方式 |
| 账户资料与绑定 | 即时删除 |
| 个性化与推荐数据 | 即时删除或匿名化 |
| 交易与资金记录 | 脱敏存档至留存期满 |
| 已产生的评价 | 保留但脱敏展示 |

补充说明：注销保护期的设计还有一个常被问到的问题：保护期有多长。保护期的长度以注销页面的公示为准，设计的考量是平衡两类需求：给冲动的注销决定留反悔余地，同时不让反悔机制被用来规避治理。保护期内账户处于冻结状态，不能交易但可以恢复。真正想离开的用户，保护期结束后数据删除会自动执行，不需要额外操作。

补充说明：注销后的账户名释放还有一个细节：原昵称与账户名会进入一段冷却期后重新开放，防止有人利用刚注销的账户名冒充原用户。这个设计保护的是注销用户的社会关系网络，避免有人借旧名行骗。如果你的好友列表里有账户显示已注销，请谨慎对待以该身份重新出现的同名账户，先通过其他渠道核实身份。

补充：保护期内撤销注销是即时生效的，账户功能立即恢复，数据完整如初，撤销操作本身不产生任何费用或限制。

## 第四章 违规处理与责任

以注销逃避未结清判责的，注销申请不予受理；已发现规避行为的按主体关联追责（RL-A-149）。
