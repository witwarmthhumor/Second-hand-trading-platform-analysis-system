# 黑客与作弊器材禁售细则

> 制度编号：RL-A-101　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

本章规定黑客工具与作弊器材的禁售口径，依据《禁售商品管理总纲》（RL-A-076）制定。此类商品的流通直接危害网络秩序与考试、竞技公平，平台从严管理。

## 第二章 禁售范围明细表

| 类别 | 典型商品 | 说明 |
| 网络攻击工具 | 木马程序、DDoS 压测服务、钓鱼套件 | 含源码与部署服务 |
| 数据窃取 | 监听程序、爬虫绕过服务、凭据提取工具 | 不论是否交付源码 |
| 考试作弊 | 隐形耳机、作弊通信设备 | 含代考服务信息 |
| 竞技作弊 | 游戏外挂、代练打手服务 | 含成品与定制 |

## 第三章 正文条款

第1条 以"安全研究""渗透测试"名义发布的攻击工具，无合法资质与场景证明的按禁售处理。

第2条 普通网络安全书籍、硬件防火墙等合法商品正常流通，描述中不得附带攻击服务引导。

第3条 违规商品下架并按累计扣分阶梯从重记分；为作弊提供组织化服务的永久封禁（来源：penalty 节点）。

补充说明：黑客工具交易的参与者往往抱着技术交流的心态，但工具一旦交付就脱离了发布者的控制，造成的实际损害在法律上可能追溯到提供方。平台对安全研究的豁免仅面向有资质的安全企业与实名研究员，个人发布者不在此列。合法的安全服务请在具备资质的平台上承接，二手平台的流通环境不适合承载这类交易。

补充说明：考试与竞技作弊器材的另一个风险是受骗。购买作弊设备的学生与玩家本身就是黑产的目标，付款后被拉黑的案例远多于实际用上的案例。平台治理这类信息不只是维护公平，也是在保护潜在受害者。发现此类信息，举报时标注具体用途场景，可以帮助治理人员更快定性。

最后提示：安全研究的合法承接渠道是有资质的企业与机构，二手平台不在其列。

## 第四章 违规处理与责任

利用平台发布黑客工具造成实际损害的，平台配合执法部门追溯，交易记录作为证据提供。
