# 个人信息查询与复制

> 制度编号：RL-A-188　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

查询与复制个人信息是用户的法定权利。本章规定行使路径与响应口径，依据《个人信息使用规则》（RL-A-183）制定。

## 第二章 正文条款

第1条 可查询与复制的范围：本人账户资料、订单与售后记录、信用与违规记录、授权与同意记录。

第2条 行使路径：「我的-设置-隐私-个人信息下载」，提交申请后系统生成带签名的归档文件。

第3条 响应节奏以页面公示为准，归档文件包含数据范围说明与格式说明。

第4条 复制的次数不限，但频次异常（短时间高频申请）的会触发安全核验，防止数据被批量爬取。

## 第三章 查询范围对照表

| 数据类别 | 可查 | 可复制归档 |
| 账户资料 | 是 | 是 |
| 订单与售后 | 是 | 是 |
| 信用与违规记录 | 是 | 是 |
| 他人信息 | 否 | 否 |

补充说明：个人信息归档文件还有一个重要的使用场景：更换平台或留存证据。归档文件包含你的账户资料、交易记录与授权记录，带签名可验证真伪。当你需要证明自己与某笔交易的关系、或者需要迁移数据到其他服务时，这份归档就是官方背书的凭证。建议重要交易较多的用户定期导出一次归档，成本低但价值高。

补充说明：归档文件还有一个技术细节值得说明：文件里的数据格式是可读的结构化格式，附有字段说明文档，用户不需要专业工具就能看懂自己的数据。这个设计针对的是数据可携带权的真实可用性——如果导出的数据只有机器能读，那权利就打了折扣。看得懂、带得走、可验证，是归档功能的三个设计锚点。

补充：归档申请的处理进度在隐私中心可见，生成完成后有通知，归档文件保留一段下载窗口，逾期需重新生成。

补充：归档文件的字段说明会随数据范围的调整同步更新，旧版归档文件的说明文档也会在归档页保留历史版本，对照阅读可以理解字段变化的原因，这些细节让归档功能在长期使用中始终保持可解释性，这也是数据权利行使场景里最容易被忽视但最有价值的一部分。

## 第四章 违规处理与责任

利用查询复制功能批量获取他人信息的，永久封禁并移交执法部门（来源：penalty 节点）。
