# 回收诈骗专项治理

> 制度编号：RL-A-203　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

回收诈骗是二手数码领域高发的骗局：骗子以高价回收为饵，诱导卖家邮寄设备后压价或失联。本细则为该骗局的专项治理安排，依据《站外引流处罚规则》（RL-A-132）与反诈体系制定。

## 第二章 诈骗链路拆解

| 环节 | 骗子话术 | 破绽 |
| 引流 | 高价回收，高于平台行情 | 价格明显高于市场 |
| 取信 | 谎称正规公司，出示伪造资质 | 资质无法在官方渠道核验 |
| 收货 | 诱导绕过平台直接邮寄 | 脱离担保交易 |
| 压价 | 收到后挑毛病砍价，或直接失联 | 拒绝平台介入 |

## 第三章 正文条款

第1条 治理期内，商品描述与聊天中出现高价回收话术的账号进入重点监控。

第2条 受害卖家的报案信息纳入反诈保护体系（RL-A-195），举报渠道保持畅通。

第3条 认定为回收诈骗的账号顶格处罚，涉案设备线索协助警方追缴。

补充说明：回收诈骗的受害者还有一个常见的二次伤害：骗子在压价阶段会用检验报告吓唬卖家，声称设备有各种专业问题所以只值废品价。这些所谓的报告多为伪造，普通卖家难以辨别。平台治理提示很简单：脱离平台担保的任何检验结论都不具备判责效力，真正的损失确认只能通过平台验货流程。记住这一点，压价话术就失去了杀伤力。

回收诈骗的高发对象还有一个特征值得警惕：刚在平台卖出一台数码设备的新卖家。骗子会通过成交记录锁定这些卖家，以同样的设备型号、更高的回收价发起接触。识别方法也很简单：真正的买家关心的是商品状态与价格，回收骗子开口就谈他们的回收流程与打款速度。两个场景的话术差异非常明显，多留意一眼就能分辨。

平台在治理期内还加强了回收类商品发布的信息要求：宣称提供回收服务的账号必须提交经营资质并公示回收流程，资质与流程的核验结果在账号页展示。买家在选择回收服务时，先看核验标识，再看报价，最后坚持走平台流程寄送。三步走完，回收诈骗的生存空间就被压缩到零。任何不愿意走这三步的回收商，直接放弃就好。

## 第四章 违规处理与责任

组织化回收诈骗、跨平台连续作案的，永久封禁并配合执法部门追查（来源：penalty 节点）。
