# 个人信息使用规则

> 制度编号：RL-A-183　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

本章规定已收集个人信息的使用规则，依据《个人信息收集范围》（RL-A-182）制定。使用的原则是目的限定：收集时说明的用途就是使用的边界。

## 第二章 正文条款

第1条 账户与实名信息用于身份核验、交易确认与资金安全，不用于任何营销场景。

第2条 交易与物流信息用于履约、售后与争议举证，聊天记录的使用限定于纠纷举证与安全审查（RL-A-186）。

第3条 设备与日志信息用于风控模型与故障排查，不做用户画像的商业化输出。

第4条 浏览与搜索行为用于个性化推荐，用户关闭推荐开关后，相关数据仅保留安全用途。

第5条 任何使用场景超出收集时说明目的的，须重新取得用户同意。

## 第三章 使用边界清单

| 边界 | 说明 |
| 不出售 | 任何形式的个人信息买卖 |
| 不共享 | 营销目的的第三方共享 |
| 不画像 | 用于歧视性定价的用户画像 |
| 不留存 | 超出必要期限的原始日志 |

补充说明：目的限定原则在实践中有两个容易混淆的场景需要说明。第一个是安全用途的边界：风控模型确实需要分析行为数据，但分析结果只能用于风险决策，不能反哺营销。第二个是聚合统计的边界：脱敏后的聚合统计（比如品类交易规模）不属于个人信息范畴，可以使用；但能反推到个人的分析就触碰了边界。这两个场景的区分标准是能否识别到特定个人。

扩展说明：使用规则的执行还有一层技术保障叫用途绑定，数据在系统内按用途标签流转，营销系统的数据接口无法访问风控专用的数据集，反之亦然。这种技术隔离比人工审批更可靠，因为越权访问在系统层面就不存在路径。用户看到的隐私设置与后台的数据流转是同一套规则的两种呈现，设置里关掉的，数据流就真的断了。

## 第四章 违规处理与责任

内部越权使用个人信息的，按《信息安全事件处置》（RL-A-193）顶格追责（来源：penalty 节点）。
