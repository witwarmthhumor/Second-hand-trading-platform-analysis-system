# 交易对手信用查看指南

> 制度编号：RL-A-179　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

交易前查看对方信用是平台的免费保障工具。本章规定查看的范围、口径与使用边界，依据《信用分体系总则》（RL-A-156）制定。

## 第二章 查看口径明细表

| 信息项 | 买家可见（看卖家） | 卖家可见（看买家） |
| 信用等级 | 展示 | 展示 |
| 历史成交规模 | 展示区间 | 展示区间 |
| 好评率 | 展示 | 展示 |
| 具体扣分事件 | 不展示 | 不展示 |
| 身份信息 | 不展示 | 不展示 |

## 第三章 正文条款

第1条 查看入口在商品页与订单页，无需对方同意。

第2条 信用信息的使用限于交易决策，不得用于歧视性筛选、站外骚扰或信息倒卖（RL-A-090）。

第3条 信用等级仅作参考，交易决策还应结合商品描述、验货服务与沟通记录综合判断。

补充说明：查看对方信用不需要对方同意，这个设计曾经有争议，但数据证明透明的信用环境让欺诈成本大幅上升，交易的摩擦反而下降了。

补充说明：信用信息的展示还有一个时间维度：等级是实时的，但好评率是周期滚动的。一个刚发生纠纷的卖家，等级还没变但好评率的趋势已经反映出来。看信用信息时同时看两个时间尺度的数据，是比只看等级更成熟的用法。数据的意义在于对比，单一时点的快照信息量总是有限的。

另外，信用信息的查询不产生任何通知，对方不会知道你查看了他的信用，这一点可以放心使用。

补充说明：查看信用时的另一个建议是结合评价内容交叉验证。信用等级是量化数据的汇总，而评价内容是细节故事的呈现，两者结合才能形成完整的判断。一个信用等级中等的卖家，如果评价里全是认真包装、按时发货、售后爽快的细节，可信度其实高于一个等级更高但评价空泛的对手。信用信息是工具，不是判决书，如何使用取决于每个交易者自己的判断框架。

## 第四章 违规处理与责任

批量采集、倒卖信用信息的，永久封禁（参照 RL-A-090 隐私口径）。
