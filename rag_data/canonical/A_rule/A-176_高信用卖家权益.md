# 高信用卖家权益

> 制度编号：RL-A-176　版本：v3.2　生效日期：2026-06-01　适用对象：卖家

## 第一章 总则

本章规定高信用卖家可享有的权益清单，依据《信用等级与权益》（RL-A-159）制定。权益设计的目标是让守规矩的人得到看得见的回报。

## 第二章 权益明细表

| 权益 | 内容 | 适用等级 |
| 客服快线 | 专属客服通道优先接入 | 高等级以上 |
| 活动优先 | 平台活动报名优先审核 | 高等级以上 |
| 流量扶持 | 符合条件的商品曝光加成 | 高等级以上 |
| 保证金优惠 | 符合条件的专业卖家保证金减免评估 | 极高等级 |
| 争议加速 | 卖家申诉的处理加速 | 极高等级 |

## 第三章 正文条款

第1条 权益的取得与维持以信用等级实时映射为准，等级下降权益即收回。

第2条 保证金减免为评估制，减免不豁免扣罚责任（RL-A-129）。

第3条 权益清单动态调整，调整提前公告，不追溯已享受权益。

补充说明：权益的展示是自动的，高信用标识在商品页与聊天页都有角标，买家据此可以快速识别履约记录良好的卖家，这比任何自我介绍都有说服力。

补充说明：权益的自动生效机制还有一个细节：权益状态在等级切换的当天即生效，不需要等到次日更新。即时生效的权益与日更的分值不同步，偶尔会让用户产生『分已经涨了为什么权益还没变』的疑问，答案是权益跟等级走、等级跟分值走、分值日更，权益的生效时点以等级切换时间为准。

另外，权益的使用明细在权益中心有流水记录，每一项权益的使用与失效都有据可查。

补充说明：高信用权益的适用还有一个常见疑问：权益是否可以转移给他人使用。答案是否定的，所有权益都与信用主体绑定，主体资格不可转移，权益自然也不可转移。这个限定保护了权益体系的完整性，也让信用分的价值保持在行为本身上。试图通过账号买卖转移权益的行为，会同时触发账号交易与信用欺诈两条治理线。

## 第四章 违规处理与责任

权益期间发生违规的，按违规处理并同步评估权益保留（RL-A-148 累犯口径）。
