# 反诈信息保护规则

> 制度编号：RL-A-195　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

本章规定反诈工作中个人信息保护的口径，依据《个人信息使用规则》（RL-A-183）制定。反诈需要数据，但数据使用必须有边界。

## 第二章 正文条款

第1条 风险标记的使用限定于交易拦截、提醒推送与治理处置，不用于任何商业场景。

第2条 反诈协查的数据提供依法执行，配合执法部门的调取须有法定手续（参照 RL-A-233）。

第3条 用户的被骗报案信息严格保密，报案记录不进入对用户的任何负面评估。

第4条 反诈提醒的推送频次受控，避免以反诈为名的过度打扰。

## 第三章 保护边界对照表

| 边界 | 说明 |
| 不公开 | 风险标记名单的对外公示 |
| 不歧视 | 被骗记录不影响信用评估 |
| 不滥用 | 反诈数据的商业分析 |
| 不越权 | 无手续的数据调取 |

补充说明：反诈数据保护的另一个维度是防二次诈骗。被骗用户在报案后会频繁接到自称能追回损失的私信或电话，这些几乎全是二次诈骗。平台侧的反诈提醒会明确告知：官方不会以任何形式私信联系受害者，追回损失的唯一途径是执法机关。把这条信息记牢，等于给自己的报案信息上了第二道锁。

补充说明：反诈信息的保护还有一个容易被忽略的场景是善意提醒的边界。用户发现好友可能被骗，在平台上提醒对方是正常的，但如果通过站外渠道反复联系对方施压，就可能越界构成骚扰。善意提醒一次即止，反复的提醒会给双方都带来困扰。平台的风险提醒系统会在风险事件发生时自动触达，不需要用户承担提醒义务。

补充：反诈提醒的内容也接受用户反馈，提醒话术过于频繁或不当的，反馈后会调整推送策略。

补充：反诈提醒的触达记录用户可以在安全中心查看，每次提醒的类型、时间与关联事件都有记录，这些记录帮助用户复盘自己接触过的风险场景，也是平台评估提醒策略有效性的数据来源，提醒系统本身也在用户的反馈中持续优化。

## 第四章 违规处理与责任

泄露报案人信息的，按《信息安全事件处置》（RL-A-193）顶格追责（来源：penalty 节点）。
