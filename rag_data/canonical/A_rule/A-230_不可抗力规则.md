# 不可抗力规则

> 制度编号：RL-A-230　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

不可抗力指不能预见、不能避免且不能克服的客观情况。本章规定不可抗力的范围、认定与后果，依据《交易主体权利义务》（RL-A-228）制定。

## 第二章 情形对照表

| 类别 | 典型情形 | 是否不可抗力 |
| 自然灾害 | 台风、洪水、地震导致的物流中断 | 是 |
| 政府行为 | 管控措施、交通管制 | 是 |
| 平台故障 | 系统级故障导致的功能不可用 | 是（平台侧责任另计） |
| 快递爆仓 | 高峰期时效变慢 | 否（可预见的商业风险） |
| 个人原因 | 生病、出差、忘记 | 否 |

## 第三章 正文条款

第1条 主张不可抗力的，须提供可核验的客观证据（官方公告、物流通报等），口头主张不予认定。

第2条 不可抗力期间的义务中止履行，影响消除后继续履行；合同目的因此不能实现的，可解除且互不追责。

第3条 不可抗力不影响已产生的举证义务：受影响方仍应留存证据并及时通知对方。

补充说明：不可抗力的认定还有一个灰色地带需要说明：平台系统故障是否属于不可抗力，区分故障的层级。区域性系统故障导致功能不可用的，属于平台侧的履行障碍，受影响订单按平台责任处理，这实际上比不可抗力的互不追责对用户更有利；而用户侧的网络问题、设备问题，从来不属于不可抗力。两层区分的逻辑是：谁的范围内的问题，谁承担。

补充说明：不可抗力还有一个举证的实务建议：受影响方在不可抗力发生时就应保存证据，比如物流公司的延误公告截图、官方发布的交通管制通知。事后补证的最大问题是这些公告的链接会失效、页面会下线。不可抗力发生后第一时间截图存档，是对自己最便宜的保护。主张者的举证义务不因不可抗力而免除，只是举证的对象变成了不可抗力本身。

补充：不可抗力的认定与物流公司的不可抗力公告联动，官方公告是物流类不可抗力的首选证据。

补充：不可抗力的后果分配还有一个细节：受影响方的通知义务。不可抗力发生后，受影响方应当在合理时间内通知对方，因为对方也有减少损失的需要（比如买家可以取消订单改买其他渠道）。未及时通知导致对方损失扩大的，扩大部分的损失不能援引不可抗力免责。通知义务是诚实信用原则在不可抗力场景下的具体化。

## 第四章 违规处理与责任

虚构不可抗力逃避履约的，按虚假发货口径（RL-A-028）从重处理。
