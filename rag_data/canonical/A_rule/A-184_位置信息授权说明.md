# 位置信息授权说明

> 制度编号：RL-A-184　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

本章说明位置信息的授权场景与使用口径，依据《个人信息使用规则》（RL-A-183）制定。位置是典型的可选授权信息，拒绝授权不影响任何核心交易功能。

## 第二章 正文条款

第1条 授权场景仅限两类：附近质检仓与服务点展示、同城面交的匹配推荐。

第2条 精度口径：仅使用模糊位置（城市级），不采集精准定位轨迹。

第3条 授权的开启与关闭都在「我的-设置-隐私」内可随时操作，关闭后相关功能退化为手动选择城市。

第4条 位置信息不与其他用户共享，同城推荐只呈现商品，不暴露任何一方的具体位置。

## 第三章 使用边界清单

| 边界 | 说明 |
| 不记录 | 位置轨迹的历史留存 |
| 不共享 | 向其他用户展示具体位置 |
| 不关联 | 位置与营销画像的关联分析 |
| 不强制 | 以任何形式引导开启授权 |

补充说明：模糊位置的技术实现是地理围栏的粗粒度化：系统只知道你在某个城市级区域，不知道你的街道与楼栋。这个精度对于附近质检仓展示完全够用，对于想通过位置信息推断个人生活规律的行为则是釜底抽薪。位置信息还有一个用户常问的问题：开启授权后历史轨迹是否被记录，答案是否定的，授权期间仅提供当前的区域判断，不做轨迹留存。

扩展说明：位置授权的另一个用户疑问是关闭后已有推荐的变化速度。关闭授权后，基于位置的推荐内容会在下一次刷新时切换为手动城市版本，不会有残留的基于旧位置的推荐长期存在。数据的删除与功能的降级是同步的，不会出现授权关闭了但系统还在用旧位置数据的滞后状态。这种即时性是可选授权类信息的统一标准。

补充：位置授权的状态在隐私中心有独立的开关与说明页，所有与位置相关的功能表现都会在说明页列明，用户可以对照自查。

## 第四章 违规处理与责任

利用位置信息实施线下骚扰或跟踪的，按《骚扰与言语违规处理》（RL-A-135）顶格处理并移交执法部门。
