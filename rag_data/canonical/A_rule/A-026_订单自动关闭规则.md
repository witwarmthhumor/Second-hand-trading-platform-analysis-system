# 订单自动关闭规则

> 制度编号：RL-A-026　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

自动关闭用于释放长期未付款占用的交易名额。本章规定触发条件、关闭后的货品处理与恢复口径，依据《商品下单规则》（RL-A-022）制定。

## 第二章 速查要点

- 下单后未付款的订单，24 小时后自动关闭（来源：trade.buyer_cancel_unpaid_hours）；
- 关闭不扣分、不影响信用，商品自动恢复可售；
- 关闭前平台推送一次提醒，买家可付款续住；
- 关闭后仍想要该商品的，重新下单即可，价格以新页面为准；
- 卖家侧不承担未付款订单的发货义务，也无权要求买家赔付。
- 自动关闭只针对未付款订单，已付款订单的取消走《交易取消规则》（RL-A-036）；
- 买家在关闭前主动取消的，不计入任何频次统计；
- 关闭后商品库存与发布状态即时恢复。

## 第三章 特殊情形

| 情形 | 口径 |
| 付款动作进行中到达时限 | 以支付渠道受理时间为准，受理成功不关闭 |
| 订单含定制约定 | 时限不延长，双方可重新约定后另行下单 |
| 自动关闭遇平台故障 | 系统补单恢复，记录以日志为准 |

- 自动关闭前买家已进入支付流程的，以支付渠道受理结果为准，成功则订单继续；
- 关闭订单占用过的优惠券，在券有效期内自动退回账户；
- 卖家不得以自动关闭为由催促买家脱离平台付款，违者按 RL-A-132 处理；
- 合并付款中单笔订单触发关闭的，仅该笔退出合并，其余订单继续计时。

执行提示：买家应把自动关闭当作购物车的清理机制而不是占货工具，拍下前确认型号、成色与价格，拍下后尽快付款。对价格敏感的买家可以先收藏并开启降价提醒，等真正决定购买时再下单，这比反复拍下再关闭更有利于卖家侧的库存判断。卖家遇到高频拍下关闭的买家，可通过举报入口反馈，平台核实后按骚扰与恶意行为口径处理，不需要卖家自行对峙。

## 第四章 违规处理与责任

卖家以订单即将自动关闭为由诱导买家脱离平台付款的，按《站外引流处罚规则》（RL-A-132）处理。
