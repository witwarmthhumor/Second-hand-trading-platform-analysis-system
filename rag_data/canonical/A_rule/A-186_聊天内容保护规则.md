# 聊天内容保护规则

> 制度编号：RL-A-186　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

聊天记录是二手交易的核心证据场。本章规定聊天内容的保护范围与使用边界，依据《个人信息使用规则》（RL-A-183）与《聊天记录作为凭证规则》（RL-A-042）制定。

## 第二章 正文条款

第1条 聊天内容对交易双方可见，对其他用户不可见；平台侧仅用于纠纷举证与安全审查两个用途。

第2条 聊天内容不作个性化推荐的数据来源，不做广告定向的依据。

第3条 聊天记录的留存期限与交易纠纷的时效匹配，届期后按脱敏存档处理。

第4条 一方单方面删除聊天不影响对方侧的记录与平台留存， deletion 不能消除证据效力。

## 第三章 使用边界清单

| 边界 | 说明 |
| 不展示 | 聊天内容向第三方展示 |
| 不分析 | 聊天情绪与倾向的商业化分析 |
| 不导出 | 内部人员的批量导出（需审批） |
| 不删除 | 用户删除不消除平台留存的举证效力 |

补充说明：聊天记录的证据效力与保护边界是同一件事的两面。作为证据，聊天记录的完整性由平台侧保障，用户删除不影响举证效力，这保护的是受害方；作为隐私，聊天内容的使用被限定在举证与安全两个场景，这保护的是所有方。理解了这个双重设计，就能明白为什么平台不支持单方面删除聊天：举证的公平性要求双方看到同一份记录。

扩展说明：聊天内容保护还有面向未来的一个设计考量：随着技术演进，新的分析能力可能不断出现，但使用边界的规则是先于能力存在的。任何新技术的引入都必须先回答它是否符合聊天数据的既有使用边界，答案是否定的就不引入。规则先行的意义在于，用户不需要担心技术的灰色地带会悄悄侵蚀隐私边界。

补充：聊天内容在双方设备上的本地缓存，由各端自行管理，卸载应用即清除本地缓存，平台侧留存按本规则执行。

## 第四章 违规处理与责任

内部人员越权查阅聊天记录的，按《信息安全事件处置》（RL-A-193）顶格追责（来源：penalty 节点）。
