# 永久封禁认定标准

> 制度编号：RL-A-128　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

永久封禁是平台最高级别的处罚。本章规定适用标准与复核边界，依据《违规节点与处罚阶梯》（RL-A-123）制定，认定从严、程序从慎。

## 第二章 认定标准速查表

| 情形 | 认定口径 |
| 累计扣分达 48 分 | 阶梯顶格，自动生效 |
| 盗抢设备交易 | 不论首次，直接顶格 |
| 涉赌涉诈组织行为 | 不论金额，直接顶格 |
| 冒充平台工作人员 | 造成损失即顶格 |
| 未成年人保护类重违 | 情节严重即顶格 |

## 第三章 正文条款

第1条 除阶梯顶格外，单次行为危害特别严重、影响特别恶劣的，平台可依据对应细则直接适用永久封禁。

第2条 顶格认定前须完成证据固定与复核程序，复核由超出原处理人的层级执行。

第3条 永久封禁的申诉通道保持开放，误判的经复核撤销并恢复账号（RL-A-144）。

补充说明：永久封禁的复核程序是防止误伤的最后防线，复核层级的设置保证了结论不由同一批人重复确认。历史上被撤销的永久封禁案例，几乎全部源于主体信息被冒用或证据链断裂，这类误判的共同特征是当事人从未实际参与过违规交易。如果你属于这种情形，把身份被冒用的证明材料整理充分，复核通过的把握是很大的。

补充说明：顶格处罚对关联账号的穿透力也需要正确理解。平台按设备、支付、行为特征做主体关联认定，标准是证据充分，而不是猜测关联。正常的家庭成员各自使用自己的账户交易，只要行为独立、资料真实，不会被牵连。关联规则的打击对象是刻意规避，不是正常生活。

补充：复核期间用户可提交一次补充陈述，材料以事实与证据为主，情绪化表达无助于结论。

补充：永久封禁名单不对外公示，以保护当事人隐私，但名单信息会在主体关联认定时内部使用。

## 第四章 违规处理与责任

永久封禁用户以亲属或他人信息重新注册经营的，按主体关联认定，关联账号一并处理（RL-A-149）。
