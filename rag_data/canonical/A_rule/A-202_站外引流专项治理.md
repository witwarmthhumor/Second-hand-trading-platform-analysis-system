# 站外引流专项治理

> 制度编号：RL-A-202　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

本细则为站外引流的专项治理安排，依据《站外引流处罚规则》（RL-A-132）制定，治理聚焦三个高发形态：商品图片嵌码、聊天自动回复带联系方式、售后话术诱导转账。

## 第二章 治理手段明细表

| 高发形态 | 治理手段 | 处置 |
| 图片嵌码 | 图像识别扫描二维码与水印 | 下架整改 |
| 自动回复引流 | 开场白模板抽检 | 清除话术并警告 |
| 售后诱导转账 | 判责案例回溯 | 从重记分 |
| 谐音变体 | 变体库持续更新 | 识别即清除 |

## 第三章 正文条款

第1条 治理期内识别技术升级为双通道：图像与文本并行扫描，变体话术入库时效缩短。

第2条 被处罚卖家的话术整改建议随处罚通知下发，整改验收通过方可恢复曝光。

第3条 买家侧的引流接触记录会触发安全提醒推送，提醒内容包括典型话术样本。

补充说明：引流的变体形态有一个规律可循：话术会变，但脱离平台的意图不会变。治理团队把识别的重心从关键词匹配转移到意图识别上，比如一段对话虽然没有出现任何敏感词，但行为模式是在试探性地引导交易搬家，这种对话同样会进入治理视野。用户举报这类对话时，把完整的对话截图交上来，比只截敏感词那一屏有价值得多。

引流的识别还有一个用户可以参与的机制是话术样本提交。如果你收到了新型的引流话术——比如某种新的谐音包装或者新的脱平台理由——可以通过安全中心的样本提交入口上报，治理团队的暗语库会快速收录这些样本。样本提交是匿名的，不会暴露你接触过的卖家信息。每一份样本都在帮助下一个用户避免同样的接触。

对卖家来说，还有一个需要注意的灰色地带是线下活动的引流边界。线下市集、摆摊场景中交换联系方式本身不违规，但如果线上商品页的目的就是把用户导向线下再绕开平台交易，那性质就变了。判断的标准是交易是否享受平台的担保与保障，脱离担保的交易无论以什么形式发生，都不在平台的保护范围内。

## 第四章 违规处理与责任

治理期内重复引流直接顶格处理；引流伴随诈骗线索的移交执法部门（来源：penalty 节点）。
