# 恶意评价认定

> 制度编号：RL-A-170　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

恶意评价的认定是评价体系里最需要审慎的环节。本章规定认定标准与程序，依据《评价发布规则》（RL-A-166）制定，既要保护卖家不受要挟，也不寒了真实差评的心。

## 第二章 认定标准速查表

| 认定情形 | 核心特征 |
| 无交易背景 | 评价人与交易无对应关系 |
| 要挟型 | 评价内容与索要利益挂钩 |
| 无关内容 | 评价指向与商品完全无关的事项 |
| 恶意攻击 | 内容以侮辱诽谤为主体 |
| 竞争攻击 | 同行身份且批量特征明显 |

## 第三章 正文条款

第1条 认定程序：卖家提交举报并附证据，平台结合交易数据与内容特征综合判断。

第2条 认定成立的评价按情节做折叠或删除处理，评价人按累计扣分阶梯记分（来源：penalty 节点）。

第3条 认定不成立的评价正常展示，卖家的申诉不构成对评价人的二次伤害。

补充说明：恶意评价认定的申诉保护还有一个对称设计：卖家举报恶意评价不成立的，评价人可以查看举报已被驳回的结果，但看不到举报人的申诉材料细节。这个设计避免了双方在申诉环节的二次对抗。评价生态的治理目标不是消灭差评，而是让每一条展示出来的评价都值得被信任，无论好评差评。

补充说明：卖家面对疑似恶意评价时还有一个常见误区：立即联系评价人要求删除。这个动作容易被解读为干扰评价权，甚至引发二次冲突。正确的顺序是先举报认定、后沟通删除，平台的认定结论会为后续沟通定下基调。顺序错了，有理的事也会变得被动。

另外，认定结论的申诉与 RL-A-141 的通用申诉流程共用时效规则，注意在时效内完成材料补充。

## 第四章 执行提示

差评与恶意评价的边界可以用一句话概括：评价是否围绕交易事实。买家给差评说成色与描述不符，哪怕说得尖锐，只要基于真实体验就不是恶意；买家说卖家是骗子并附上索要赔偿的聊天记录，这就进入了恶意认定的射程。卖家收到差评先复盘再举报，把每一次差评当成商品信息校准的机会。

## 第四章 违规处理与责任

伪造聊天记录构陷他人恶意评价的，按妨害治理顶格处理（RL-A-141）。
