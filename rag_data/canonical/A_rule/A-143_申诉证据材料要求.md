# 申诉证据材料要求

> 制度编号：RL-A-143　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

证据质量决定申诉成败。本章规定申诉材料的类型、形式与组织要求，依据《申诉总则与时效》（RL-A-141）制定，与《聊天记录作为凭证规则》（RL-A-042）的取证口径衔接。

## 第二章 有效证据类型明细表

| 证据类型 | 形式要求 | 证明力要点 |
| 聊天记录 | 平台内原文完整截图 | 保留上下文不断章 |
| 图片视频 | 原件不压缩 | 含时间信息最佳 |
| 物流凭证 | 官方轨迹截图 | 与运单号对应 |
| 质检报告 | 平台出具版 | 报告编号可查 |
| 支付凭证 | 渠道官方账单 | 与订单金额对应 |

## 第三章 正文条款

第1条 材料组织遵循对应原则：每一份材料对应结论中的一项认定依据，形成反驳闭环。

第2条 材料真实性的责任由提交方承担，造假按妨害治理处理（RL-A-141）。

第3条 材料超出申诉所需的部分不强制提交，但涉及完整语境的关键页不得裁剪。

补充说明：证据的组织比证据的数量更重要。一个常见的反例是把二十张截图按时间顺序平铺上传，处理人需要自己从图堆里找关键信息；而高效的提交方式是按结论里的认定依据逐条配证，每条配证附一句说明。处理人的复核工作量减半，申诉人的通过率翻倍，这是一件双赢的小事。

补充说明：证据的真实性审查还包括来源审查。平台内产生的聊天记录、订单信息属于平台可直接核验的证据，证明力最强；渠道方出具的账单属于可核验的第三方证据；自己拍摄的图片视频需要保留原件，以便核对压缩与编辑痕迹。三类证据的证明力排序，决定了申诉材料准备的优先级。

补充说明：材料的时间属性经常被忽视。聊天记录要能看出对话发生的日期，图片视频要带着拍摄时间信息，物流截图要有查询时间。没有时间戳的证据在对抗性场景里会被质疑为事后伪造，而有完整时间线的证据几乎无法被质疑。养成随手记录带时间习惯的用户，在所有争议中都占便宜。

补充说明：证据链的完整性还有一个验证方法：把自己的材料交给一个不了解案情的朋友看，看他能否仅凭材料还原事件经过。能还原的，说明材料自洽完整；还原不了的，找出断点补齐。这个十分钟的自测，胜过申诉被驳回后再补材料的一周折腾。

## 第四章 违规处理与责任

诱导他人出具虚假证明材料的，与材料造假同责。
