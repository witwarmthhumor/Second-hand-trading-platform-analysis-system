# 团伙作弊认定规则

> 制度编号：RL-A-149　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

团伙作弊以多账号协同规避治理，危害远大于单账号违规。本章规定团伙的认定标准与处置口径，依据《违规行为分类总则》（RL-A-121）制定。

## 第二章 正文条款

第1条 认定要素（满足两项即可立案）：设备与环境高度重合、支付与收款路径交叉、行为节奏协同、违规形态同源。

第2条 认定范围包括主号与小号、实际控制人与名义持有人、组织者与参与者。

第3条 处置：主号从重处罚，小号一并处置；组织者顶格处罚，参与者按贡献度分层记分。

第4条 团伙案件全程录像留证，涉及黑产的移交执法部门。

## 第三章 认定证据类型

| 证据 | 说明 |
| 设备指纹 | 多账号同设备登录操作记录 |
| 资金链路 | 收付款账户的交叉往来 |
| 行为同步 | 上架、改价、刷单的协同节奏 |
| 资料同源 | 注册信息的复用痕迹 |

补充说明：团伙认定的证据门槛设定为两项要素，是为了平衡打击精准与误伤控制。单一要素（比如同一台电脑登录两个账号）在家庭、合租场景里很常见，不足以定性；两项要素交叉（比如同设备且资金互转）才具有指向性。用户理解这个门槛，就知道正常共用环境不会出事，刻意协同才会被抓。

补充说明：分层处置是团伙案件里最容易被误解的部分。参与者常觉得自己罪轻不该被牵连，但团伙案件的整体性决定了参与即获益、获益即担责。真正想把责任摘出去的路径只有一条：证明自己被冒名或者被胁迫，并配合提供团伙的其他线索。平台对配合调查者的处理历来有从宽先例。

补充：团伙认定的申诉需提交设备与资金独立性的证明，普通截图不足，建议提供渠道方出具的对账单。

补充：团伙案件的量刑参考还包括涉案商品数量与持续时间，这两个变量在认定结论中会明确列出。

## 第四章 违规处理与责任

被认定为团伙的，全部关联账号的处置合并执行，任一账号的申诉不解除其他账号的处罚。
