# 价格违规治理

> 制度编号：RL-A-139　版本：v3.2　生效日期：2026-06-01　适用对象：卖家

## 第一章 总则

价格违规扰乱比价环境与交易诚信。本章规定价格类违规的认定与治理，依据《违规行为分类总则》（RL-A-121）制定，覆盖虚高标价、虚假优惠、诱导性价格表述三类问题。

## 第二章 认定标准明细表

| 违规形态 | 认定要点 |
| 虚高标价 | 标价远超商品实际价值且无合理说明 |
| 虚假优惠 | 划线价虚构、先涨后降的假促销 |
| 低价引流 | 以不存在的低价商品吸引点击后推销其他商品 |
| 价格歧义 | 描述与标价故意错位制造误解 |

## 第三章 正文条款

第1条 价格治理以订单快照与商品页历史记录为证据，卖家修改价格的行为轨迹可追溯。

第2条 认定成立的，纠正价格表述，情节严重的下架商品并记分。

第3条 诱导脱离平台交易的价格话术按站外引流（RL-A-132）合并处理。

补充说明：价格违规的治理需要平衡两个价值：打击欺诈与保护定价自由。卖家有权给自己的商品定任何价格，哪怕明显高于行情，这是定价自由；但虚构划线价、制造虚假的降价感知，就是对买家决策的操纵，这是欺诈。平台的治理瞄准后者，从不干预前者，理解了这个边界，卖家就不用提心吊胆地定价。

补充说明：买家侧识别价格欺诈有一个实用技巧：把商品价格与历史成交对比，把划线价与商品描述的成色对比。明显成色不符的低价、从未真实成交过的划线高价，都是风险信号。平台的价保与快照机制提供了兜底，但买家的基本判断力永远是第一道防线。

补充说明：虚假优惠的判定有一个时间维度的证据——商品的历史价格曲线。平台记录了商品的价格变动轨迹，先涨后降的操作在曲线上一目了然。卖家用真实降价做活动完全没有问题，担心被误判的可以在活动说明里写清原价的构成，透明是这一类目最好的合规策略。

## 第四章 违规处理与责任

以价格违规配合刷单、欺诈的，按合并处理规则从重（RL-A-140）。
