# 刷单炒信认定与处罚

> 制度编号：RL-A-130　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

刷单炒信伪造交易数据，破坏信用体系的根基。本章规定认定标准与处罚口径，依据《违规行为分类总则》（RL-A-121）制定，是平台信用治理的支柱细则之一。

## 第二章 认定标准速查表

| 行为形态 | 认定要点 |
| 虚假交易 | 无真实商品交付的订单流转 |
| 互换好评 | 双方约定互给好评的对单行为 |
| 代刷服务 | 帮他人刷量并收取费用 |
| 数据造假 | 粉丝、销量、评价的批量伪造 |

## 第三章 正文条款

第1条 认定综合物流真实性、资金流向、行为模式三方面证据，物流信息与交易场景明显脱节的即可立案。

第2条 处罚：虚假数据清零，商品与店铺降权，卖家按累计扣分阶梯记分；组织化刷单的适用顶格处罚。

第3条 参与刷单的买家账号一并记分，刷单所得佣金不予保护。

补充说明：刷单认定的三证据框架（物流、资金、行为模式）是理解整个治理体系的钥匙。刷单产业链可以伪造物流单号，可以拆分资金流，但三者的匹配关系很难同时伪造到位——发货地与收货地的真实物流、资金回流的时间差、短周期内高频的交易模式，总有一环会露馅。理解了这个框架，就能明白为什么平台的识别越来越准。

补充说明：被卷入刷单的另一个场景是熟人求助。朋友开店铺求你下一单，你出于好意下了，这一单如果没有真实商品交付，就是一笔标准的虚假交易，你的账号也会记分。帮助朋友的方式有很多，真实的购买、真诚的转发都可以，唯独刷单不要碰，这是对双方的保护。

补充：刷单认定的申诉与虚假交易治理共用同一通道，材料一次备齐即可。

补充：平台识别刷单的行为模型会随产业链形态持续迭代，历史上试图通过控制发货地、拆分资金流绕过识别的手法，目前均已纳入特征库，模型在攻防中始终保持着领先半步的位置。

## 第四章 违规处理与责任

以刷单为业、发展下线的，永久封禁并保留向执法部门移交的权利（参照 RL-A-149）。
