# 黑名单与屏蔽规则

> 制度编号：RL-A-196　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

本章规定用户侧的黑名单与屏蔽功能口径，依据《个人信息使用规则》（RL-A-183）制定。屏蔽是用户的自主防御工具，规则保障其有效且不被滥用。

## 第二章 正文条款

第1条 屏蔽功能：用户可将任意对象加入黑名单，屏蔽后双方聊天、交易、评价互动全部阻断。

第2条 屏蔽数量不设上限，屏蔽名单仅本人可见，被屏蔽方不会收到通知（避免激化）。

第3条 屏蔽不影响已完成的交易与在途订单的处理，售后流程照常。

第4条 换号规避屏蔽的，按主体关联处置（RL-A-149），关联账号一并屏蔽。

## 第三章 屏蔽功能边界表

| 功能 | 效果 |
| 聊天阻断 | 双向不可发送 |
| 商品屏蔽 | 对方商品不展示 |
| 交易阻断 | 不可互相下单 |
| 记录保留 | 历史交易记录保留 |

补充说明：屏蔽功能还有一个进阶用法：交易前的预防性屏蔽。如果你在某次浏览中发现某个卖家的行为风格让你不适，可以先屏蔽再决定是否继续接触，屏蔽不影响你后续解除。防御性使用屏蔽功能不需要理由，也不需要向任何人解释，这是你对自己交易环境的自主管理权。

补充说明：屏蔽与举报是两个功能不是替代关系：屏蔽解决的是不想再接触，举报解决的是对方的行为违规。被屏蔽的对象如果行为确实违规，举报让治理介入；如果只是合不来，屏蔽就足够了。把两个功能用在正确的场景里，既不过度治理，也不放任违规，这是用户与治理体系配合的正确姿势。

补充：屏蔽名单支持批量管理，定期清理不再需要屏蔽的对象，保持名单的准确性。

补充：屏蔽名单的管理还有一个细节值得说明：屏蔽是单向的，你屏蔽了对方，不代表对方也屏蔽了你，所以你可能仍然能在公共区域看到对方的活动痕迹，这是正常现象。屏蔽只保证你们之间的直接互动通道被切断，公共区域的展示规则对所有用户一视同仁，理解这一点可以避免很多不必要的困惑。

## 第四章 违规处理与责任

利用屏蔽功能逃避已成立的判责义务的，屏蔽不影响义务执行，判责照常进行。
