# 处罚复核规则

> 制度编号：RL-A-144　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

复核是申诉处理后的二次审查机制，由独立于原处理的层级执行。本章规定复核的触发、程序与效力，依据《申诉总则与时效》（RL-A-141）制定，是程序正义的最后一道闸。

## 第二章 正文条款

第1条 复核触发：第一次申诉被驳回后，用户在时效内提交新材料的；或平台自查发现原结论存在疑点的。

第2条 复核由未参与原处理的资深人员执行，必要时引入跨团队评估。

第3条 复核结论三种：维持原结论、调整处罚幅度、撤销原结论并恢复权益。

第4条 复核结论为终局结论，双方均应执行；复核中发现新违规线索的，另案处理。

## 第三章 程序要点

| 环节 | 要求 |
| 受理 | 新材料审查先行 |
| 审查 | 原结论与新材料逐条比对 |
| 结论 | 说明维持或撤销的理由 |
| 执行 | 撤销的恢复权益并消除影响 |

补充说明：复核与申诉最大的区别在于复核是主动审查而非被动回应。复核人员会把原结论、第一次申诉、新材料三方放在一起比对，寻找的是结论是否依然站得住，而不是替原结论辩护。这种立场设计保证了复核不是走过场，历史上复核改判的案例中相当一部分是复核人员主动发现了原处理的逻辑断点。

补充说明：跨团队评估的引入是为了处理专业壁垒高的案件，比如涉及质检标准的判责复核会请质检专家参与，涉及价格治理的会请运营口参与。专业视角的加入让复核结论在技术层面也站得住，而不仅仅停留在程序层面。用户在复核材料里可以包含技术性说明，这是复核阶段特有的加分项。

补充：复核期间原处罚继续执行的原则有一个例外，即执行会造成不可逆后果的（如商品删除），复核受理时先行冻结执行动作。

补充：复核处理人员的名单每半年轮换一次，轮换期间在途案件由交接双方共同完成，保证结论连贯。

## 第四章 违规处理与责任

复核人员在复核中发现原处理存在程序瑕疵的，按内部质控流程追因改进；用户侧伪造材料的按妨害治理处理（RL-A-141）。
