# 卖家规则速查手册

> 制度编号：RL-A-236　版本：v3.2　生效日期：2026-06-01　适用对象：卖家

## 第一章 总则

本手册把卖家最常用的规则要点压缩成一页速查，条款细节见各对应细则。

## 第二章 速查表

| 事项 | 口径 | 细则 |
| 发货时限 | 付款后 48 小时内 | RL-A-027 |
| 货款结算 | 确认收货后 T+1 | RL-A-063 |
| 提现到账 | T+1 | RL-A-066 |
| 服务费 | 按品类 0.010~0.030，最低 0.1 元 | RL-A-051 |
| 保证金 | 专业卖家 500 元 | RL-A-073 |
| 强制验货品类 | 九大品类详见清单 | RL-A-034 |
| 售后责任 | 描述不符卖家担责 | RL-A-133 |
| 违规阶梯 | 12/24+7天/36+30天/48分 | RL-A-123 |
| 禁售 | 总纲加分册 | RL-A-076 |
| 站外引流 | 禁止 | RL-A-132 |

## 第三章 使用说明

第1条 速查表只列高频要点，完整规则以各细则为准。

第2条 速查表与细则不一致时，以细则为准并反馈修正速查表。

补充说明：卖家速查手册的另一个用法是新人培训：新入行的卖家把这十行速查表当成经营检查清单，每接一单对照一遍，一个月后这些规则就会内化为习惯。历史上因为不熟悉发货时限与售后责任而吃亏的新卖家，占了新卖家纠纷的大头。速查手册的价值不在全，而在关键时刻能想起来。

补充说明：卖家速查手册还有一个使用建议：把它打印出来贴在工作台旁。速查表的十个事项覆盖了卖家日常经营的绝大多数规则触点，从发货时限到违规阶梯，从服务费到禁售边界。新卖家上架第一件商品前对照一遍，老卖家在遇到不常见场景时翻一眼，这本小册子就能避免大多数的无心违规。

补充：速查表定期更新，更新记录在表格底部标注，对照速查表与细则的时效以细则为准。

补充：卖家速查手册还有一个与新手任务的联动建议：平台的新手引导任务中包含规则学习的环节，把速查手册的十个事项与新手指引的步骤对照学习，一遍下来规则的框架就建立起来了。老卖家在规则修订后，也建议用速查手册做一次快速的增量核对，看看自己熟悉的口径有没有变化。

## 第四章 违规处理与责任

以速查表替代细则主张权利的，不获支持；速查表是入口，不是依据本身。
