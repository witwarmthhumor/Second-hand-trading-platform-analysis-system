# 线上申诉操作规则

> 制度编号：RL-A-142　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

本章规定申诉的线上操作流程，依据《申诉总则与时效》（RL-A-141）制定。线上通道是申诉的唯一正式入口，线下沟通不产生申诉效力。

## 第二章 操作步骤

1. 进入「我的-规则中心-违规记录与申诉」，找到目标结论；
2. 点「发起申诉」，选择申诉理由分类；
3. 按理由分类的提示上传对应材料，逐条对应结论中的认定依据；
4. 提交后记录申诉编号，处理进度在同页可见；
5. 对处理结果不满意的，在时效内凭新材料发起第二次申诉。

## 第三章 操作要点

| 环节 | 要点 | 常见错误 |
| 分类选择 | 按结论类型选 | 选成咨询 |
| 材料上传 | 原图不裁剪 | 截图断章取义 |
| 说明文字 | 事实加时间线 | 情绪化长文 |
| 时效管理 | 见通知页倒计时 | 逾期才发现 |

补充说明：线上申诉入口的另一个价值是全程留痕。每一次申诉的分类选择、材料清单、处理意见都在系统里可查，这既是用户追溯自己案件的依据，也是平台治理质量抽检的数据来源。历史上有过申诉处理不公的投诉，最终都是靠这份全程记录还原了真相。数字化流程的最大受益者，恰恰是最需要程序正义的普通人。

补充说明：申诉分类的选择看起来是小事，选错会导致案件流入错误的处理队列，白白多等一个周期。如果对自己的案件属于哪一类拿不准，宁可先选一个接近的提交，在说明文字里写清楚自己的理解，处理人员会做一次分类校正，这比因分类纠结而错过时效要好得多。

补充说明：申诉编号的格式里隐含了案件类型与受理队列的信息，熟练的用户看编号就知道自己的案件进了哪条线。普通用户不需要研究编号规则，但一定要保存好编号本身，查询进度、补充材料、反馈偏差，所有后续操作都以编号为锚点。丢编号的补查流程很麻烦，截图存档是最简单的自保。

补充说明：线上申诉还有一个隐藏优势是处理人员的评审记录也可追溯。用户看到的是结论，结论背后每一步的审查意见都在系统里留存，出现争议时这些内部记录会被调出来复盘。流程的全程数字化让暗箱操作没有生存空间，这是线上申诉比线下沟通更值得信赖的根本原因。

## 第四章 违规处理与责任

利用申诉入口批量骚扰、提交无关材料的，限制申诉功能并按骚扰口径处理（RL-A-135）。
