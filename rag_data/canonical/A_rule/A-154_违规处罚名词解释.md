# 违规处罚名词解释

> 制度编号：RL-A-154　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

本篇汇总违规处罚体系的常用名词，作为 A5 系列细则的配套词典。名词的定义以本篇为准，各细则引用时含义一致。

## 第二章 名词表

| 名词 | 解释 |
| 记分 | 对违规行为按分值计入周期账户的行为 |
| 周期 | 累计扣分的计算时段，365 天滚动清零 |
| 阶梯 | 记分达到节点后触发的处罚序列 |
| 限流 | 降低账号与商品曝光的功能限制 |
| 封禁 | 暂停账号交易与发言功能的处罚 |
| 永久封禁 | 不设期限的账号封禁 |
| 判责 | 对交易纠纷划定责任归属的程序 |
| 举证 | 提交证据材料支持自己主张的行为 |
| 申诉 | 对结论提出异议并要求复查的程序 |
| 复核 | 申诉驳回后的二次审查机制 |
| 主体关联 | 通过设备、资金、行为认定多账号同一控制 |
| 顶格 | 适用细则允许的最高处罚档 |
| 从轻 | 在标准处罚基础上降低幅度 |
| 妨害治理 | 伪造证据、干扰核查等阻碍治理的行为 |

## 第三章 使用说明

第1条 各细则引用名词时不再重复定义，以本篇为统一口径。

第2条 名词的增补与修订随规则版本更新发布。

补充说明：名词表是细则体系的配套词典，它的存在解决了一个长期问题：同一概念在不同细则里的表述漂移。比如限流在旧版细则里有时叫降权、有时叫曝光限制，用户容易混淆。名词表统一定义后，各细则引用时含义强制一致，用户查一个词就能贯通全部相关条款。阅读细则遇到不认识的词，先查本篇。

补充说明：名词的增补机制是开放的，用户在使用中发现表述歧义，可以通过规则中心提交增补建议。被采纳的建议会在版本更新记录里署名致谢。词典的准确性依赖使用者共同维护，这是规则共建的又一个具体场景。

补充：名词表按拼音排序检索，Ctrl+F 搜索是更快的用法，全部名词不超过一屏。

补充说明：名词表会随细则演进持续增补，已收录的名词定义也可能修订。重大修订会通过规则中心的版本公告提示，普通修订在版本记录里可查。建议长期经营的卖家把名词表加入书签，沟通时引用统一的名词口径，能显著降低与客服、仲裁之间的理解偏差。

## 第四章 违规处理与责任

恶意利用名词歧义规避规则的，按实质重于形式原则认定（参照 RL-A-121）。
