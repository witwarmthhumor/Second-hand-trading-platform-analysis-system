# 恶意退款治理规则

> 制度编号：RL-A-133　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

恶意退款侵蚀卖家经营信心，也挤占正常售后的处理资源。本章规定恶意退款的认定、处置与卖家应对指引，依据《违规行为分类总则》（RL-A-121）制定。

## 第二章 认定标准明细表

| 行为形态 | 认定要点 |
| 仅退款滥用 | 无理由拒退货物且拒不沟通 |
| 掉包退货 | 退回商品与发出商品不一致且有影像佐证 |
| 伪造凭证 | 举证材料存在明显编辑痕迹 |
| 高频异常 | 周期内多单退款且败诉率高 |

## 第三章 正文条款

第1条 认定综合退款理由、举证质量、历史记录综合评估，单一败诉不构成恶意认定。

第2条 认定成立的，卖家已收货款不受影响，买家按累计扣分阶梯记分；情节严重的限制下单功能。

第3条 掉包退货查实的，除记分外要求买家承担商品损失赔偿。

补充说明：恶意退款治理的难点在于区分真实消费纠纷与职业化薅羊毛。平台不预设买家有罪，但会通过退款频次、理由分布、举证质量的行为画像做风险评估。正常买家偶尔的一次失败退款不会触发任何机制，连续多单的异常模式才会进入治理视野。这个设计保证了普通用户无感，也让职业玩家无处遁形。

补充说明：卖家在售后沟通中最容易犯的错误是情绪先行，一句气话被截图后，自己在判责里反而从受害者变成加害者。所有售后沟通都建议遵循一个模板：先复述买家的诉求，再陈述自己的事实，最后给出方案。不带情绪的表达既显专业，也是仲裁时的极佳证据材料。

补充说明：仅退款滥用的治理还有一个前置环节是原因选择。部分买家把仅退款当成无理由试错工具，理由随手选，被驳回后再换理由重来。平台把退款原因的选择轨迹纳入了评估，反复更换矛盾理由的行为会显著提高风险评级。买家在申请前想清楚理由，一次选对，既提高通过率，也保护自己的记录。

## 第四章 卖家应对指引

卖家遭遇疑似恶意退款时，正确的动作是：保全发货影像与签收记录，退货环节录制拆箱视频，沟通留痕不进行人身指责，然后提交平台判定。与买家在聊天里对骂、拉黑拒收，只会让自己的证据链出现断点。
