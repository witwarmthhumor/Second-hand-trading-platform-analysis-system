# 信用体系名词解释

> 制度编号：RL-A-180　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

本篇汇总信用体系的常用名词，作为 A6 系列的配套词典，定义以本篇为准。

## 第二章 名词表

| 名词 | 解释 |
| 信用分 | 量化用户交易可信度的分值，区间 350–950 |
| 初始分 | 新用户注册时获得的起始分值 |
| 信用等级 | 信用分对应的档位划分 |
| 店铺分 | 卖家经营质量的综合评分 |
| 四维度 | 商品质量、服务态度、物流履约、纠纷率 |
| 纠纷率 | 介入判责订单占总订单的比例 |
| 好评率 | 好评数占可计入评价总数的比例 |
| 回复率 | 首次消息获回复的占比 |
| 追评 | 基础评价后的后续体验评价 |
| 折叠 | 降低评价展示权重的处理 |
| 信用修复 | 处罚完毕后回升信用分的路径 |
| 等级映射 | 分值到等级的实时对应关系 |

## 第三章 使用说明

第1条 各细则引用名词时不再重复定义，以本篇为统一口径。

第2条 词语的增补修订随版本更新发布，与《违规处罚名词解释》（RL-A-154）互为补充。

补充说明：名词表的检索习惯建议是按系列查，信用体系的名词集中在 A6 系列，跨系列引用的名词在 A-154 违规处罚词典里也有收录。

补充说明：名词解释还有一个使用建议：遇到细则之间的表述冲突时，先查名词表确认概念定义，再对照细则的适用条款。大部分表面的冲突其实是概念理解的偏差，同一名词在两份细则里的定义是一致的。查完仍有疑问的，走规则中心的反馈入口，不要自行脑补口径。

另外，名词表支持纠错反馈，发现解释与实际使用不一致的，提交反馈后由规则委员会复核修订。

补充说明：名词表的另一个使用场景是阅读细则时的快速参照。细则条文为了表述精确，不可避免地使用术语，初次阅读的流畅度会受影响。建议的做法是先通读一遍名词表建立概念框架，再进入各细则正文，阅读效率会提升明显。名词表也会随细则修订同步更新，遇到新增名词不要惊讶，查一下定义就好。

## 第四章 违规处理与责任

利用名词歧义规避规则的，按实质重于形式原则认定（RL-A-121）。
