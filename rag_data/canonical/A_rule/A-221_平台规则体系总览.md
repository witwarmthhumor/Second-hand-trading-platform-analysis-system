# 平台规则体系总览

> 制度编号：RL-A-221　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

本章是平台规则体系的地图。规则数量多，但结构清晰：按主题分为九个子系列，按效力分为总纲与细则两级。本篇回答的问题是——你想找的规则在哪、它与别的规则是什么关系。

## 第二章 规则体系架构表

| 子系列 | 主题 | 覆盖内容 |
| A1 账户与入驻 | 账户生命周期 | 注册、实名、认证、注销 |
| A2 交易基础规则 | 交易流程 | 下单、发货、收货、取消、售后窗口 |
| A3 费用与结算 | 资金规则 | 费率、结算、提现、发票 |
| A4 禁售与限售 | 商品边界 | 禁售清单、限售资质 |
| A5 违规处罚与申诉 | 治理体系 | 记分、阶梯、申诉、复核 |
| A6 信用与评价 | 信用体系 | 信用分、店铺分、评价规则 |
| A7 信息安全与隐私 | 数据权利 | 收集、使用、删除、事件处置 |
| A8 专项治理 | 阶段行动 | 各类专项的治理安排 |
| A9 综合规则 | 体系本身 | 本章及以下综合条款 |

## 第三章 正文条款

第1条 规则的适用顺序：专项细则优先于总纲，总纲优先于本篇；细则之间冲突的，按《规则解释权与适用顺序》（RL-A-226）裁定。

第2条 规则的修订与版本管理按 RL-A-223 执行，所有规则文本以规则中心发布的现行版本为准。

第3条 用户对规则体系的建议，通过规则中心的反馈入口提交，纳入版本评估。

补充说明：九个子系列的阅读顺序也有讲究。新用户建议从 A2 交易基础规则读起，它覆盖了你即将经历的每一个交易环节；准备开店的用户先读 A1 账户与入驻；对资金敏感的用户优先读 A3 费用与结算。规则不需要一次读完，按需查阅才是这套体系的正确打开方式。把本篇的架构表当作目录来用，遇到具体问题再进入对应的子系列。

补充说明：规则体系的演进历史本身就是平台价值观的记录。早期的规则更侧重处罚，近年的修订明显增加了权益与修复的内容——信用修复、误判撤销、主动报备这些机制都是后来才有的。阅读规则时留意这个演进方向，你会理解平台治理的哲学：惩罚只是手段，让守规者得到公平环境才是目的。理解了这个哲学，很多条款的设计逻辑就豁然开朗。

补充：子系列的架构表支持从本篇跳转到各子系列的首篇细则，跳转路径在规则中心有快捷链接，不用手动搜索。

## 第四章 违规处理与责任

以不熟悉规则为由主张免责的，不予支持；规则的公示即视为送达（参照 RL-A-227 用户协议要点）。
