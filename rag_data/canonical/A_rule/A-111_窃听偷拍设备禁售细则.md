# 窃听偷拍设备禁售细则

> 制度编号：RL-A-111　版本：v3.2　生效日期：2026-06-01　适用对象：全体

## 第一章 总则

本章规定窃听窃照专用器材的禁售口径，依据《禁售商品管理总纲》（RL-A-076）制定。此类器材直接危害他人隐私与人身安全，平台零容忍。

## 第二章 禁售范围明细表

| 类别 | 典型形态 | 说明 |
| 专用窃听器材 | 针孔拾音器、隐蔽录音植入件 | 不论是否工作 |
| 专用偷拍器材 | 隐蔽摄像模块、伪装摄像头组件 | 含改装服务 |
| 反检测组合 | 与器材配套的屏蔽、探测规避装置 | 按套装认定 |
| 信息服务 | 安装、定位跟踪服务信息 | 信息亦禁售 |

## 第三章 正文条款

第1条 具备录音录像功能的普通消费电子（手机、行车记录仪、运动相机）正常流通，但描述不得突出隐蔽偷拍用途。

第2条 家用安防摄像头须为可视可告知的常规形态，伪装成日常物品的微型摄像设备禁售。

第3条 违规商品下架并顶格记分；安装服务类信息一并清除（来源：penalty 节点）。

补充说明：隐私器材治理的复杂性在于普通设备与专用器材的边界。手机可以录音，行车记录仪可以录像，这些是大众化功能，平台不禁；但把摄像头装进矿泉水瓶、把麦克风藏进插座，性质就完全不同了。判断标准可以概括为一句话：设备形态是否以隐蔽采集为目的。发布者用这个标准自查，举报者用这个标准定性，边界就清晰了。

补充说明：被偷拍偷录的受害者往往不知所措，这里给出基本路径：发现器材后立即报警并保留现场，不要自行拆除破坏证据；涉及网络传播的，向平台与警方同时投诉。平台对涉及隐私侵犯的账号会立即冻结并配合调查。隐私权的保护需要每个人的参与，一次举报可能就终止了一场持续的侵害。

补充：普通音频视频设备的进出口与流通，遵循一般商品规则即可，不需要额外的许可证明，这是与专用器材的本质区别。

## 第四章 违规处理与责任

利用此类器材侵犯他人隐私的，永久封禁并配合执法调查。
