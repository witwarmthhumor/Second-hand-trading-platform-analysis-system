# Chanel质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于所有送检的 Chanel 箱包，涵盖 Classic Flap、Le Boy、2.55、Gabrielle、19 Bag 等主流系列，以及中古款与当季款。检测目标不是简单判断新旧，而是对真伪、成色、功能、维修史四个维度给出可追溯的结论。

验机仓签收后按以下六步执行，全程录像：

1. **收件核验与登记**（30 分钟内完成）。拆箱前先拍外包装与运单，核对送检单上的型号、尺寸、颜色是否与实物一致。发现货不对板立即停检并上报。
2. **外观分级拍照**（≥8 张，含五金特写）。正面、背面、底部、内里、四角、五金件、身份卡各至少 1 张，镭射标必须微距拍摄。
3. **身份卡/序列号/镭射标核验**。三码比对，缺一不可。此步不通过直接走必拒流程，不再进入后续检测。
4. **五金与皮质逐项检测**。按第三部分明细表逐项打勾，异常项拍照留证并记录位置。
5. **真伪综合判定（双人复核）**。主检人初判后，由第二位鉴定师独立复核。两人结论不一致时提交组长仲裁。
6. **出报告**（签收后 48 小时内）。报告需包含全部照片、检测项结果、成色判定及必拒/通过结论。送检方对结果有异议的，可在 72 小时内申请复检。

## 二、检测工具与环境

- **光源**：色温 5000K 左右的标准光源，避免暖黄光掩盖皮质氧化与蜜色差异。
- **放大设备**：10 倍以上放大镜或微距镜头，用于镭射标、五金刻字、菱格走线的工艺比对。
- **紫外灯**：辅助观察补色、胶水残留与涂层修复痕迹。
- **标准比对样**：同型号正品五金件与皮质样本各一套，用于对版比对。
- **环境要求**：检测台面平整、洁净，操作人员佩戴白手套。不得在阳光直射或暗光环境下判定成色。
- **称量与量具**：软尺用于测量包身尺寸，与官方数据比对；如有明显偏差需在报告中记录。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 镭射标贴 | 字体清晰、边缘锐利，序号与身份卡一致 | 微距拍摄后放大比对 | 模糊/脱落/序号不一致→必拒 |
| 身份卡编号 | 与镭射标、内标烫金完全一致 | 三码交叉核验 | 任一不一致→必拒 |
| 五金电镀工艺 | 镀层均匀，刻字底部平整无气泡 | 放大镜观察 + 与比对样对版 | 镀层起皮/刻字发虚→按 B/C 降级，断裂→必拒 |
| 菱格走线 | 针距均匀，菱格饱满，无跳线/浮线 | 目测 + 手指触摸饱满度 | 局部跳线→C 级披露；多处塌陷→降 D |
| 皮质划痕/磨白 | 轻微痕迹不露底 | 分区目测，记录面积 | 单处磨白≤2cm 可 A/B；露料→C 以下 |
| 四角磨损 | 无露料或仅极轻微磨白 | 重点观察四角边缘 | 磨白可 B/C；露料→C/D 必披露 |
| 内衬污渍与异味 | 内衬干净，无霉味/烟味 | 目测 + 嗅觉判断 | 可去除污渍→C 披露；不可去除异味→必拒 |
| 拉链顺滑度 | 拉动顺滑无卡顿，拉头完整 | 全程开合 3 次 | 卡顿可修复→C/D；拉头断裂→必拒 |
| 手柄/肩带汗渍变色 | 无深色汗渍渗透 | 侧光观察 + 紫外灯辅助 | 轻微变色→B/C 披露；渗透皮质→C 以下 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 全套包装膜未撕，身份卡信封未开 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅试背过一两次，五金无划痕 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 包底有极轻微放置痕，五金有细微发丝纹 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 四角轻微磨白，内衬无污渍 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 手柄汗渍变色，五金镀层局部氧化 |
| D（7成新及以下） | 较重磨损/局部功能瑕疵，必须显著披露 | 四角露料、拉链卡顿但可修复、内衬明显污渍 |

成色判定需结合皮质老化与护理评估。做过补色或涂层修复的包，无论效果多好，护理史必须写入报告，且成色不得高于 B。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 五、必拒情形

出现以下任一情形，直接判定为必拒，不出成色结论：

- **判定为仿品**。镭射标、身份卡、五金工艺任一环节与正品对版不符且无法合理解释。
- **主料破损**。面料破洞或开裂贯穿皮质，非表面划伤。
- **五金断裂无法修复**。如链条节断裂、转锁机构损毁且配件无法替换。
- **强烈不可去除异味**。霉味或烟味超出常规通风可处理范围。
- **序列号与品牌数据库逻辑矛盾**。如序列号对应年份与该包型生产周期不符，或镭射标序号格式与当年工艺特征冲突。

必拒结论需双人复核签字，并在报告中附完整照片证据链。

## 六、报告字段与拍照取证要求

报告至少包含以下字段：送检单号、品牌系列与型号、身份卡编号、镭射标编号、内标编号、外观检测逐项结果、功能检测逐项结果、成色判定（N/S/A/B/C/D）、维修史与护理史、必拒/通过结论、检测人与复核人签名、报告日期。

拍照取证不少于 6 张，实际执行按外观分级拍照要求不低于 8 张。取证口径如下：

- **全景照**：包身正面、背面、底部各 1 张，光线均匀，不得遮挡瑕疵。
- **五金特写**：转锁、链条、刻字处微距拍摄，镀层脱落与氧化必须清晰可见。
- **镭射标与身份卡**：微距拍摄镭射标全貌，身份卡正反面各 1 张，编号需放大可读。
- **瑕疵定位照**：每处降级或异常项单独拍照，附比例尺或手指参照，标明位置。
- **内里与四角**：内衬污渍、四角磨损分别拍摄，侧光下呈现磨白与露料程度。

照片命名规则：送检单号_检测项_位置_序号。所有照片须在签收后 48 小时内随报告一并交付，缺失关键取证照片的，报告退回补拍。

## 七、常见争议与判定口径

**争议一：镭射标轻微磨损但身份卡清晰，是否影响真伪判定。**
判定口径：镭射标磨损属物理老化，不影响真伪结论，但磨损程度须拍照留证并在报告中披露。若镭射标被整体揭除或更换，则按序列号核验不通过处理，直接必拒。依据：镭射标是 Chanel 真伪核验的核心要素，缺失即失去比对基础。

**争议二：五金氧化是否必然降级。**
判定口径：氧化程度决定成色档位，轻微氧化可在 B 级披露，镀层起皮或刻字发虚降至 C 级，氧化导致五金断裂则进入必拒流程。护理后五金恢复光亮的，护理史必须写入报告，成色不得高于 B。依据：五金电镀工艺是 Chanel 对版要点之一，修复痕迹影响原装性判断。

**争议三：送检方不认可 C 级以下成色结论。**
判定口径：以照片证据链为准，送检方可在 72 小时内申请复检，复检由未参与初判的鉴定师执行。复检结论仍为 C 级以下的，维持原判并出具书面说明。依据：成色判定以客观痕迹照片为据，不以送检方主观描述为据。

**争议四：内衬异味经通风处理后是否可撤销必拒。**
判定口径：异味是否可去除在收件检测时一次性判断。霉味或烟味超出常规通风可处理范围的，当场判定必拒，不因送检方后续自行处理而改变结论。依据：必拒清单以收件时状态为准，避免送检方事后干预检测结果。
