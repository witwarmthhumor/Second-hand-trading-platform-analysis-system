# realme质检分册：检测要点与典型问题

## 一、检测范围与流程

realme 机型按七步走。验机仓签收后 48 小时内必须出报告，买家异议可在 72 小时内申请复检。

1. 收件核验与防拆封登记（30 分钟内）——核对序列号与运单、机身、系统三处一致，不一致直接进必拒流程。
2. 外观分级拍照——正面、背面、四边、接口共 ≥6 张。
3. 进水标检查——SIM 槽、充电口、耳机口如有进水标，逐一查看。进水标变色即判定进水，不论功能是否正常。
4. 功能逐项检测——按第三节表格逐项过。
5. 电池健康与循环次数读取——S≥90%，A 80–89%，<80% 必须明示，<60% 必拒。
6. ID 锁/账户锁退出验证——真我 UI 激活状态必须为"已激活且无账号绑定"，退出后重启再确认一次。
7. 出报告——签收后 48 小时内提交。

## 二、检测工具与环境

- 光源：可调角度台灯，强光侧照用于屏幕划痕分级。
- 拍照设备：不低于 1200 万像素，保留 EXIF 信息，不得裁剪关键区域。
- 读电池工具：realme 官方工程模式或厂商授权诊断工具，第三方工具读数仅作参考。
- SIM 取卡针、防静电手套、显微镜（观察进水标与主板维修痕迹时用）。
- 工作台铺防静电垫，检测全程录像，录像不少于 15 秒且覆盖开机、解锁、摄像头调用三个动作。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 账号锁/真我 UI 激活 | 无账号绑定，激活状态正常 | 设置-账户-查看绑定；重启后再次确认 | 有账号未退出即必拒 |
| 屏幕划痕 | 显示区无划痕；≤2 条发丝纹且不在显示区可计 A 级 | 强光侧照，30°–45° 扫视 | 显示区划痕降 1 级；深划痕计 C 级 |
| 屏幕坏点/触摸 | 无坏点、色斑，触摸无断触 | 网格法全屏 12 区域逐区滑动 | 单区断触降 1 级；多区断触必拒 |
| 边框磕碰 | 无露底金属磕碰 | 目测 + 微距拍照 | 露底金属即降 1 级；掉漆面积 >5mm² 计 C 级 |
| 背板裂纹 | 无任何裂纹 | 目测 + 强光透照 | 任何裂纹计 D 级并显著披露 |
| 摄像头镜片 | 镜片无中心区划痕 | 强光下斜视 | 中心区划痕降 1 级 |
| 电池健康 | S≥90%，A 80–89% | 工程模式读取健康度与循环次数 | <80% 必须明示，<60% 必拒 |
| 面容 ID/指纹 | 录入后解锁正常 | 录入两组生物信息，各解锁 5 次 | 完全不可用必拒 |
| ID 锁/激活锁 | 必须为关闭状态 | 设置-账户-退出后重启验证 | 未退出即必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封盒装，封条完整，首次开机引导 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅充电口轻微插拔痕迹，屏幕无划痕，电池健康 ≥90% |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 边框一处 ≤2mm 不露底金属的细微磕碰，屏幕无划痕，电池 80–89% |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 背板细微划痕但不裂，边框 ≤2 处轻微磕碰未露底 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 掉漆面积 >5mm²，屏幕 ≤2 条发丝纹且不在显示区 |
| D（7成新及以下） | 较重磨损/局部功能瑕疵，必须显著披露 | 背板裂纹、屏幕显示区划痕、电池 <80% 但 ≥60% |

电池健康 <80% 必须在报告中显著标注，循环次数超过 500 次也必须显著标注。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 五、必拒情形

出现以下任一情形，直接拒收并出具说明，不做降级处理：

- ID 锁/账户锁未退出——真我 UI 账号未注销，重启后仍提示激活锁。
- 电池健康 <60%——工程模式读数低于 60%。
- 主板维修史未申报——拆机发现主板有维修痕迹且寄售方未申报。
- 进水标变色且功能异常——进水标变色即判定进水，功能异常直接必拒；变色但功能正常也需显著披露并降级。
- 机身弯曲变形（>1mm）——平放桌面翘起超过 1mm。
- 序列号与机身/系统不一致——运单、机身标签、系统关于本机三处对不上。

## 六、报告字段与拍照取证要求

报告字段：序列号、机型与存储版本、成色等级、电池健康度、循环次数、进水标状态、拆修史（有/无）、账号锁状态、功能检测逐项结果、外观瑕疵描述、异常项照片索引。

拍照取证：外观分级拍照 ≥6 张，覆盖正面、背面、四边、接口。屏幕划痕用强光侧照拍，边框磕碰用微距拍，背板裂纹需透光照。进水标变色、主板维修痕迹必须单独微距取证。所有异常项加拍局部特写，照片与报告字段一一对应，编号规则为"序列号后四位+序号"。

## 七、常见争议与判定口径

**循环次数高但电池健康还行，能算 A 吗？**

不能。循环次数与电池健康是两个独立披露项：循环超过 500 次必须显著标注，健康度在 80–89% 区间可计 A 级，但两者同时出现时，报告必须把循环次数异常写清楚，由买家自行判断。成色等级按健康度区间定，循环次数只做披露、不直接降级，隐瞒不标即视为报告不实。

**进水标变色但功能全好，买家说没事，能不能不披露？**

不能。进水标变色即判定进水，不论功能是否正常。功能正常时不做必拒，但必须在报告中显著披露并降级处理。买家签收后拿进水标说事，以报告披露为准——披露了就不算隐瞒，没披露就是质检责任。

**卖家说"只是换过电池，没动主板"，怎么认定拆修史？**

拆修史以拆机观察为准，不只听卖家申报。换电池必然留下拆机痕迹，只要拆过就属于拆修史，必须写入报告。主板有维修痕迹且未申报即必拒；仅换电池但已申报的，如实写入"有拆修（换电池）"，成色按对应规则降级，不隐瞒即可流通。

**买家对成色有异议，复检怎么判？**

买家可在 72 小时内申请复检。复检以原始照片和录像为据，逐项核对报告字段与取证编号是否对应。外观类争议以首次检测的强光侧照照片为准，功能类争议以录像覆盖的开机、解锁、摄像头调用三段动作为准。照片或录像缺失的争议项，按对买家有利的口径处理。
