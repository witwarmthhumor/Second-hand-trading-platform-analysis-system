# 三星质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于三星品牌手机（含折叠屏机型）的回收质检与成色判定。验机仓签收后 30 分钟内完成收件核验与防拆封登记，核对机身序列号与系统 IMEI 一致后方可进入检测。签收后 48 小时内必须出具完整质检报告；任一方有异议的，可在报告出具后 72 小时内申请复检。

检测流程按以下步骤执行：

1. 收件核验与防拆封登记（30 分钟内完成）；
2. 外观分级拍照（正面、背面、四边、接口，合计不少于 6 张）；
3. 进水标检查（SIM 槽、充电口，耳机口如有）；
4. 功能逐项检测（详见第三节明细表）；
5. 电池健康与循环次数读取；
6. ID 锁/账户锁退出验证；
7. 出报告（签收后 48 小时内）。

折叠屏机型在常规流程之外追加铰链阻尼、折痕深度、内屏触控分区、屏幕胶合状态四项专项检测，顺序排在电池读取之前。

## 二、检测工具与环境

检测工位要求照度均匀，配备强光手电与桌面放大镜用于外观分级。屏幕划痕检测需在强光侧照条件下进行。电池健康与循环次数通过系统内置诊断页读取，不得仅凭第三方软件估算。折叠屏铰链检测使用专用开合治具，避免徒手反复开合造成二次损耗。SIM 卡槽弹出针、防静电手环、气吹与无尘布为工位标配。拍照背景板为中性灰，不得使用滤镜。所有检测数据实时录入系统，禁止事后补录。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 屏幕划痕 | ≤2 条发丝纹且不在显示区可计 A 级 | 强光侧照，目视加放大镜 | 显示区划痕或超过 2 条降 1 级 |
| 边框磕碰 | 无露底金属 | 目视加触感确认 | 露底金属降 1 级；掉漆面积 >5mm² 计 C 级 |
| 背板裂纹 | 无任何裂纹 | 强光下目视 | 任何裂纹计 D 级并显著披露 |
| 摄像头镜片划痕 | 镜片无中心区划痕 | 强光侧照 | 中心区划痕降 1 级 |
| 屏幕坏点/断触 | 无坏点、无断触 | 网格法全屏 12 区域逐区触控 | 任一区域断触计功能异常 |
| 面容 ID/指纹解锁 | 录入与解锁均正常 | 实际录入并解锁 3 次 | 失败即计功能异常 |
| 电池健康 | S 级 ≥90%，A 级 80–89% | 系统诊断页读取 | <80% 必须明示；<60% 必拒 |
| 电池循环次数 | 无硬性阈值 | 系统诊断页读取 | 超过 500 次必须在报告中显著标注 |
| 充电口/扬声器/振动/听筒/麦克风 | 全部正常 | 逐一实测 | 任一异常按功能缺陷记录 |
| 前后摄像头对焦与闪光灯 | 对焦迅速、闪光灯正常 | 实拍远近各 1 张 | 对焦失败或闪光灯不亮计异常 |
| 传感器（陀螺仪/指南针/距离感应） | 响应正常 | 系统诊断模式实测 | 无响应或漂移严重计异常 |
| ID 锁/激活锁 | 必须为关闭状态 | 设置内核对 | 未退出即必拒 |
| Knox 熔断状态 | 未熔断 | 设置 > 关于手机 > 状态信息 | 熔断即降级并显著披露 |
| 国行/港版/海外版鉴别 | 型号与销售地一致 | 核对型号尾缀与系统区域 | 不一致须在报告中注明 |
| 折叠屏铰链阻尼与异响 | 开合顺滑无异响 | 专用治具开合 10 次 | 异响或阻尼异常计功能缺陷 |
| 折叠屏折痕深度 | 息屏强光下不明显 | 强光侧照目视 | 明显折痕降 1 级 |
| 折叠屏内屏触控分区 | 全分区响应正常 | 网格法分区触控 | 任一区失灵计功能异常 |
| 折叠屏屏幕胶合 | 无开胶、无翘边 | 目视加指腹滑过边缘 | 开胶即计 D 级并显著披露 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封盒装，封条完整 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅拆封激活，机身无可见划痕 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | ≤2 条发丝纹且不在显示区，电池健康 80–89% |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 细微磕碰未露底，屏幕细纹在显示区外 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 掉漆面积 >5mm²，边框露底金属 |
| D（7成新及以下） | 较重磨损或局部功能瑕疵，必须显著披露 | 背板裂纹、内屏分区失灵、Knox 熔断 |

电池健康为独立于外观的判定维度：外观达 S 但电池健康 80–89% 的，整机成色按 A 级出；电池健康 <80% 的无论外观多新，必须在报告中明示具体数值。循环次数超过 500 次同样在报告中显著标注，但不单独触发降级。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 五、必拒情形

以下情形出现任一即拒收，不进入议价环节，由质检员在系统内勾选拒收原因并附取证照片：

| 拒收情形 | 判定要点 | 处理口径 |
|---|---|---|
| ID 锁/账户锁未退出 | 设置内仍处激活锁或账户锁定状态 | 拒收并告知卖家自行解锁后重新送检 |
| 电池健康 <60% | 系统诊断页读取值低于阈值 | 拒收，不参与任何成色定级 |
| 主板维修史未申报 | 拆机痕迹明显或主板序列号与机身不符 | 拒收；隐瞒拆修史按违规处理 |
| 进水标变色且功能异常 | 进水标变色即判定进水，不论功能是否正常 | 功能异常即拒收；仅变色而功能正常须显著披露 |
| 机身弯曲变形 >1mm | 平置桌面晃动或目视可见弧度 | 拒收，按严重结构损伤记录 |
| 序列号与机身/系统不一致 | 机身标签、系统 IMEI、外包装三者比对 | 拒收并标记为来源存疑 |

进水标变色但功能正常的，不直接拒收，但整机成色最高按 C 级出，报告中显著披露进水史。

## 六、报告字段与拍照取证要求

质检报告须包含以下字段：机身序列号与 IMEI、销售版本（国行/港版/海外版）、Knox 熔断状态、外观成色、电池健康与循环次数、功能检测结果逐项、进水标状态、拆修史声明、拒收原因（如有）。报告出具时限为签收后 48 小时内，超时须在系统内说明原因。

拍照取证不少于 6 张，覆盖正面、背面、四边与接口。划痕、磕碰、裂纹等瑕疵须在对应部位单独加拍特写，强光侧照下取景。进水标状态单独拍摄，确保变色区域清晰可辨。照片须与报告编号关联存储，禁止替换或补拍后覆盖原图。折叠屏机型另拍展开与折叠两态各一张，铰链区域单独取景。视频证据按需录制，时长不少于 15 秒，用于争议复检时调阅。

## 七、常见争议与判定口径

**争议一：卖家称"只拆封未使用"，但电池循环次数已较高。** 判定口径：循环次数超过 500 次必须在报告中显著标注，成色按实际使用痕迹定级，不以卖家描述为准。依据：循环次数是客观使用证据，高于口头陈述。

**争议二：进水标轻微变色但功能全好，买家要求按进水机退货。** 判定口径：进水标变色即判定进水，不论功能是否正常；功能正常的不拒收，但成色最高按 C 级并显著披露。依据：进水标变色是物理事实，功能正常不改变进水史的存在。

**争议三：边框磕碰露底但面积很小，卖家认为不该降级。** 判定口径：磕碰露底金属即降 1 级，不论面积大小；掉漆面积 >5mm² 的另行计 C 级。依据：露底与掉漆是两项独立判据，面积阈值只约束掉漆定级。
