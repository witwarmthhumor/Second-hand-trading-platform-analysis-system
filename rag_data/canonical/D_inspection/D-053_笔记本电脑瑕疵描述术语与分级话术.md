# 笔记本电脑瑕疵描述术语与分级话术

## 一、检测范围与流程

本手册适用于所有进入 RAGreflow 流转的笔记本电脑，覆盖外观、功能、电池、账户安全四个维度。验机仓签收后 48 小时内必须出报告；买卖任一方有异议，可在报告出具后 72 小时内申请复检，复检以第三方工程师复核结论为准。

流程共七步：收件核验与防拆封登记（签收后 30 分钟内完成）、外观分级拍照（A/C/D 面各 ≥2 张）、拆底盖核验（须先征得卖家同意，查硬盘/内存原装性、进水痕迹、螺丝动过痕迹）、功能与压力检测、电池循环与健康读取、账户/BIOS 锁退出验证、出报告。检测中发现的任何拆修史必须写入报告，隐瞒拆修即必拒。进水标变色即判定进水，不论功能是否正常。

## 二、检测工具与环境

检测在恒温恒湿的验机工位进行，避免反光影响外观判定。拍照使用统一校准色温的设备，关闭美颜与滤镜。拆机使用防静电螺丝刀套装，扭矩以不损伤螺丝为限。电池健康读取使用 AIDA64、battery-report 命令或厂商诊断工具，读数不一致时以厂商工具为准。压力测试使用 FurMark 与 AIDA64 系统稳定性测试组合，全程记录 CPU/GPU 温度曲线。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| A 面外观（顶盖） | 无深度划痕、无凹陷 | 目视 + 侧光检查，拍照 ≥2 张 | 可见凹陷或长划痕，降 C 级及以下 |
| C 面键帽与触控板 | 键帽无缺失、无连击 | 全键逐键敲击 + 触控板手势测试 | 键帽缺失或连击 ≥2 键，降 C 级；触控板漂移降 D 级 |
| D 面脚垫与螺丝 | 脚垫无缺失、螺丝无滑丝 | 目视 + 螺丝刀试拧 | 脚垫缺失 ≥2 处或螺丝滑丝，降 C 级并备注 |
| 转轴阻尼与异响 | 开合顺畅无异响 | 开合 20 次测试，翻转本重点查转轴区 | 异响或阻尼异常降 C 级；转轴区裂纹直接必拒 |
| 屏幕显示 | 无亮/坏点、亮度均匀 | 纯色 5 色测试（黑/白/红/绿/蓝） | 坏点 ≤5 个降 B 级；>5 个或漏液，必拒 |
| 电池健康与循环 | S 级 ≥90%，A 级 80–89% | 厂商工具读取健康度与循环次数 | 健康 <80% 必须明示；循环 >500 次显著标注 |
| 接口与无线 | 全接口插拔正常 | USB/HDMI/音频/读卡器逐一插拔 + WiFi/蓝牙连接测试 | 任一接口或无线功能失效，降 C 级 |
| 高负载压力 | 无异常降频或关机 | 高负载压力测试 15 分钟，记录 CPU/GPU 温度 | 过热关机或严重降频，降 C 级并备注 |
| 账户与 BIOS 锁 | 系统账户与 BIOS 密码已退出 | 重启进 BIOS 验证 + 系统登录验证 | 任一锁未退出，必拒 |
| 品牌专项点 | 按品牌分册逐项通过 | 按机型执行对应专项检测 | 按对应品牌规则降级或必拒 |

品牌专项按机型执行：MacBook Air 查 Apple ID 退出、T2/M 系列安全模式、键盘连击、电池循环；MacBook Pro 另加屏幕涂层脱落（staingate）、扬声器爆音、触控条。ThinkPad 查小红点、指纹模组、防滚架异响。联想小新查联想账号与性能模式切换。华为 MateBook 查华为账号、多屏协同、触屏。戴尔跑 SupportAssist 硬件自检并核对服务标签。惠普跑 HP 硬件诊断，转轴裂纹为通病必查。华硕查华硕账号与 OLED 烧屏。游戏本专项查独显直连、高负载烤机温度墙、风扇异响；轻薄本查核显性能与便携损耗；二合一查磁吸键盘触点与触屏漂移。

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封箱未开，封条完整 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 开箱试机后闲置，A 面有极轻微指纹 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 使用数月，C 面键帽轻微油光 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | A 面一条细划痕，D 面脚垫微磨损 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | C 面键帽磨损明显，D 面有磕碰痕迹 |
| D（7成新及以下） | 较重磨损/局部功能瑕疵，必须显著披露 | 屏幕有 ≤5 个坏点，外壳多处磕碰，循环 >500 次 |

电池健康阈值独立于外观成色：健康度 ≥90% 方可评 S 级，80–89% 最高评 A 级，低于 80% 必须在报告显著位置明示具体数值。循环次数超过 500 次同样显著标注，即使外观可评 S 级，也须注明"循环次数高"。

## 五、必拒情形

出现以下任一情形，直接拒收并终止流转：

1. 系统/BIOS 锁未退出（含 Apple ID、华为账号、联想账号等品牌账户锁）。
2. 电池鼓包。
3. 主板进水或维修史未申报。
4. 屏幕漏液或大面积坏点（>5 个）。
5. 配件缺失到影响开机（无电源适配器且电池报废）。

## 六、报告字段与拍照取证要求

报告字段固定为：机型与序列号、成色定级、外观瑕疵明细、电池健康与循环次数、功能检测结果、拆修史、必拒项核验结果。电池健康低于 80% 或循环超过 500 次，必须在报告显著位置加粗标注。

拍照取证至少 6 张：A 面、C 面、D 面各 ≥2 张，外加一张开机系统信息页与一张电池健康读数页。照片须含序列号标签特写，保证可追溯。争议项（划痕、磕碰、坏点、进水标）加拍局部微距，视频佐证不少于 15 秒，须完整展示瑕疵部位。

## 七、常见争议与判定口径

**争议一：卖家称"轻微使用痕迹"，买家收到后认为划痕过深。** 以验机仓侧光照片为准，A 面划痕长度超过所在面宽度一半即判 C 级，不以手感深浅论。

**争议二：电池健康偏低但外观如新。** 健康度低于 80% 必须明示，买家据此申请退货成立；外观成色不抵消电池披露义务。

**争议三：卖家否认拆修史，但底盖螺丝有拧动痕迹。** 螺丝痕迹、防拆贴破损或内部非原装件任一成立，即认定拆修，按隐瞒拆修必拒处理。
