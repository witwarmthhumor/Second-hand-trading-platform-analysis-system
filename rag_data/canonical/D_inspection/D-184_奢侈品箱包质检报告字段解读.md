# 奢侈品箱包质检报告字段解读

## 一、检测范围与流程

**第一条** 奢侈品箱包检测覆盖皮质、五金、内衬、附件四大类，品牌范围含 LV、Gucci、Chanel、Dior、Prada、Hermès、Celine、YSL、Burberry 及轻奢箱包。

**第二条** 检测流程按六步执行，顺序不可跳越：

1. 收件核验与登记：签收后 30 分钟内完成，全程录像。
2. 外观分级拍照：不少于 8 张，含五金特写。
3. 身份卡、序列号、镭射标核验。
4. 五金与皮质逐项检测。
5. 真伪综合判定，双人复核签字。
6. 出具报告：签收后 48 小时内完成。

**第三条** 报告出具后，买家可在 72 小时内申请复检。复检仅针对原报告结论，不新增检测项。

**第四条** 检测结论为仿品时，流程终止，直接进入必拒清单，不再进行成色判定。

## 二、检测工具与环境

**第五条** 检测在恒温恒湿的验货仓内进行，避免阳光直射造成皮质色差误判。

**第六条** 必备工具：60 倍放大镜（观察五金刻字与镭射标）、紫外灯（检测胶水与补色）、测厚仪（对比皮质厚度）、标准色卡（比对氧化程度）、软尺（测量包体尺寸与对花位）。

**第七条** 拍照设备像素不低于 1200 万，色温 5500K 标准光源。拍摄背景为中性灰，禁止使用滤镜与美颜。

**第八条** 检测人员佩戴白色棉质手套，避免手汗污染皮质。每件包独立放置于托盘，不与金属工具直接接触。

## 三、检测项明细表

**第九条** 奢侈品箱包检测项明细如下：

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 皮质划痕/磨白/龟裂 | 无贯穿性裂纹，浅表划痕允许 | 目视+触感，按区域记录 | 划痕长度超 3cm 降一档；龟裂贯穿即必拒 |
| 四角磨损 | 无露料，磨白面积小于 1cm² | 目视+放大镜 | 露料即降至 C 档及以下 |
| 内衬污渍与异味 | 无霉味/烟味，污渍面积小于 2cm² | 嗅觉+目视 | 不可去除异味即必拒 |
| 五金镀层脱落与氧化 | 镀层无剥落，氧化可接受 | 60 倍放大镜观察 | 镀层剥落面积超 30% 降一档 |
| 拉链顺滑度与拉头完整性 | 开合顺畅无卡顿，拉头无变形 | 手动开合 10 次 | 卡顿超 3 次即判定功能瑕疵 |
| 磁扣/转锁开合 | 闭合到位，无异响 | 手动测试 | 无法闭合即必拒 |
| 五金刻字清晰度与工艺对版 | 字体与品牌数据库一致 | 放大镜对比品牌分册 | 字体不符即判定仿品 |
| 身份卡编号与内标一致性 | 两者完全一致 | 核验系统 | 不一致即必拒 |
| 附件清点 | 防尘袋/肩带/小票齐全 | 逐项核对 | 缺失在报告中显著标注 |

**第十条** 品牌特殊检测点按分册执行。LV 查老花对花位与 Date code 格式；Chanel 查镭射标贴与身份卡对应关系；Hermès 查工匠刻印与手缝鞍线；Gucci 查双 G 五金对版。各品牌检测点详见对应分册。

## 四、成色判定表

**第十一条** 奢侈品箱包成色按六档判定，标准如下：

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 专柜原封，防尘袋未打开 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅试背一次，五金无划痕 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 使用 3-5 次，内衬干净 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 四角轻微磨白，五金细划痕 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 手柄汗渍变色，内衬局部污渍 |
| D（7成新及以下） | 较重磨损/局部功能瑕疵，必须显著披露 | 四角露料，拉链需用力拉合 |

**第十二条** 成色判定以最差单项为准。五金氧化不影响功能时，最高判至 B 档。

**第十三条** 任何拆修史必须写入报告。隐瞒拆修即必拒。护理修复后是否影响成色，按皮质老化与护理分册的可修复性分级执行。

## 五、必拒情形

**第十四条** 出现以下任一情形，直接拒收并出具说明：

1. 判定为仿品。
2. 主料破损，面料破洞或开裂贯穿。
3. 五金断裂且无法修复。
4. 强烈不可去除异味，霉味或烟味超常规。
5. 序列号与品牌数据库逻辑矛盾。

**第十五条** 必拒结论由双人复核确认，复核记录存档备查。拒收后原路退回，运费由寄卖方承担。

## 六、报告字段与拍照取证要求

**第十六条** 报告字段包含以下各项，缺一不可：

1. 报告编号、检测日期、检测人员签名与复核人员签名。
2. 品牌、系列、型号、包体尺寸与颜色。
3. 序列号/镭射标编号及核验结果。
4. 外观检测结论，按皮质、四角、内衬、五金、手柄/肩带分项记录。
5. 功能检测结论，含拉链、磁扣/转锁、刻字对版情况。
6. 成色判定等级及判定依据简述。
7. 附件清点结果，缺失项单独列明。
8. 必拒情形触发记录（如有）。
9. 报告出具时间与复检申请截止时间。

**第十七条** 拍照取证不少于 6 张，实际按外观分级拍照要求执行不少于 8 张。拍摄范围固定如下：

1. 包体正面全景一张。
2. 包体背面与底部各一张。
3. 五金件特写两张以上，含主扣与拉链头。
4. 身份卡或镭射标特写一张。
5. 内衬与内部标牌一张。
6. 瑕疵部位单独特写，瑕疵旁放置标准色卡作参照。

**第十八条** 所有照片须在签收后 30 分钟内拍摄完成，全程录像存档。录像时长不少于 15 秒，须连续拍摄，不得剪辑。

**第十九条** 进水标变色即判定进水，不论功能是否正常，写入报告显著位置。任何拆修史必须写入报告，隐瞒拆修即必拒。报告电子版与照片、录像一并归档，保存期限以平台页面公示为准。

## 七、常见争议与判定口径

**第二十条** 争议一：皮质划痕是否影响成色。判定口径：浅表划痕不降档，划痕长度超 3cm 降一档，贯穿性裂纹直接必拒。依据：外观检测项中皮质龟裂按区域分级执行。

**第二十一条** 争议二：五金氧化是否属于使用痕迹。判定口径：氧化不影响开合功能时，最高判至 B 档；镀层剥落面积超 30% 降一档；五金断裂无法修复即必拒。依据：成色判定以最差单项为准，功能正常优先于外观瑕疵。

**第二十二条** 争议三：护理修复后能否按原成色出售。判定口径：护理修复记录必须写入报告，修复后按皮质老化与护理分册的可修复性分级重新判定成色，不得隐瞒。依据：任何拆修史必须写入报告，隐瞒即必拒。

**第二十三条** 争议四：附件缺失是否影响成色。判定口径：防尘袋、肩带、小票缺失不改变成色等级，但必须在报告中显著标注。依据：附件清点结果独立列项，不纳入外观与功能评分。
