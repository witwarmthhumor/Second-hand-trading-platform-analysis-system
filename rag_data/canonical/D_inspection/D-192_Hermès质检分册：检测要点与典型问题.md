# Hermès质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于所有送检 Hermès 箱包，涵盖 Birkin、Kelly、Constance、Evelyne 及丝巾、小皮件等品类。检测目标是回答三个问题：是否为正品、当前成色、是否存在必拒情形。

验机仓签收后按以下步骤执行，全程录像：

1. **收件核验与登记**：签收后 30 分钟内完成。核对寄件人信息、包裹外观、运单号与系统订单一致，拆箱过程不得中断录像。
2. **外观分级拍照**：≥8 张，含正面、背面、底部、内里、五金特写、四角磨损位。光线不足时补光重拍，不修图。
3. **身份卡/序列号/镭射标核验**：Hermès 无传统镭射标，核验重点是工匠刻印、烫金序列号、身份卡编号与包内热压标的一致性。
4. **五金与皮质逐项检测**：按第三部分检测项明细表逐项执行，不得跳项。
5. **真伪综合判定**：双人复核。初检与复检由不同质检员完成，结论不一致时提交组长裁决。
6. **出报告**：签收后 48 小时内出具完整质检报告。买方对结果有异议的，可在 72 小时内申请复检。

## 二、检测工具与环境

检测台需配备：白炽灯与自然光双光源、10 倍放大镜（用于工匠刻印与鞍线针距观察）、UV 灯（辅助判断皮质老化与补色）、软尺（测量包身尺寸与肩带长度）、电子秤（核对克重区间）、微距镜头或手机微距模式。

环境要求：操作台面铺设软垫，质检员佩戴无尘手套，避免汗渍二次污染。检测区域与存放区域分离，贵重包款单包单柜存放。所有工具不与包身直接硬接触，金属工具需包裹绒布头。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 工匠刻印 | 刻印清晰、字体与年份对应，位置符合该包款工艺规范 | 10 倍放大镜观察刻印边缘与深浅 | 刻印模糊、字体不对版即存疑，进入双人复核 |
| 手缝鞍线 | 针距均匀、线迹倾斜角度一致，无跳针断线 | 目测+放大镜抽查三处针距 | 机缝线迹或针距明显不均，判定为仿品或重大工艺缺陷 |
| 皮质等级标识 | 烫金标识与皮质实际等级相符（Togo/Epsom/Box 等） | 比对皮质纹理与烫金内容 | 标识与皮质不符，记录并降级处理 |
| 五金刻字与镀层 | 刻字清晰无毛刺，镀层无脱落、无异常氧化 | 微距拍摄五金刻字，对比品牌工艺数据库 | 镀层脱落面积超过 2mm² 记入报告；刻字不对版进入真伪争议 |
| 四角磨损 | 无磨白或露料 | 目测+手指触感确认 | 磨白按面积分轻/中/重；露料直接进入必拒评估 |
| 拉链顺滑度 | 开合顺畅无卡顿，拉头完整 | 全程开合 5 次，听声感阻 | 卡顿或拉头变形，记录功能瑕疵 |
| 身份卡编号与内标一致性 | 身份卡编号与包内热压烫印编号完全一致 | 逐位比对，拍照留证 | 不一致即进入真伪争议流程 |
| 附件清点 | 防尘袋、肩带、雨衣、小票等齐全度记录 | 对照订单附件清单逐项勾选 | 缺失项在报告中显著披露，不影响成色主判 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全，身份卡塑封完好 | 专柜原装未拆，防尘袋折痕未展开 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅试背过一次，内里无使用痕，五金无氧化 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 手柄有极轻微汗渍变色，包底四角无磨损 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 四角轻微磨白（不露料），内衬有淡污渍 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 手柄汗渍变色明显，五金有可见氧化点 |
| D（7成新及以下） | 较重磨损或局部功能瑕疵，必须显著披露 | 四角露料、内衬破损、拉链需用力开合 |

皮质老化与护理痕迹单独评估：专业护理后的补色、压纹修复若不影响整体观感，可在原成色基础上维持；若护理痕迹明显（如色差、光泽不均），降半档处理。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 五、必拒情形

出现以下任一情形，直接拒收并出具拒收说明：

- 判定为仿品（工匠刻印、鞍线、五金工艺任一关键项不对版且无法合理解释）。
- 主料破损：皮质破洞或开裂贯穿，非表面划痕。
- 五金断裂无法修复：如锁扣断裂、D 环脱落且无法更换原厂件。
- 强烈不可去除异味：霉味或烟味超出常规护理可处理范围。
- 序列号与品牌数据库逻辑矛盾：烫金编号格式与生产年份、包款对应关系冲突。

## 六、报告字段与拍照取证要求

报告至少包含以下字段：送检单号、品牌与包款、尺寸与皮质、工匠刻印编号、身份卡编号、成色判定（N/S/A/B/C/D）、检测项异常明细、附件清点结果、必拒项结论、质检员与复核员签名。

拍照取证口径：

- 外观分级照 ≥8 张，覆盖正面、背面、底部、内里、五金特写、四角磨损位；每处瑕疵单独加拍一张微距。
- 工匠刻印、烫金序列号、身份卡编号逐位拍摄，确保放大后仍可辨认。
- 五金镀层脱落、氧化点位必须拍微距，照片能看清边界范围。
- 皮质瑕疵（划痕、磨白、龟裂）拍摄时放置比例尺参照物。
- 附件（防尘袋、肩带、雨衣、小票）单独拍一张合照。
- 所有照片不修图、不裁剪关键部位，拍摄时间与报告出具时间间隔不超过 48 小时。

## 七、常见争议与判定口径

**争议一：身份卡编号与内标烫印不一致，但包身工艺全部对版。**
判定口径：进入双人复核，仍不一致则判定为仿品。依据：Hermès 身份卡与内标编号出厂即一一对应，不一致无法用使用或老化解释。

**争议二：手柄汗渍变色明显，但皮质无其他损伤。**
判定口径：按变色面积与深度归入 B 或 C 档，不做必拒处理。依据：汗渍变色属正常使用痕迹，不影响真伪判定与功能。

**争议三：专业护理后补色，整体观感良好但局部有色差。**
判定口径：护理痕迹明显则降半档，色差仅在特定光线下可见则维持原档。依据：护理痕迹是否影响成色，以自然光与白炽灯双光源下目测为准。

**争议四：五金氧化严重，买方主张应降为 D 档。**
判定口径：五金氧化属外观瑕疵，不影响功能与真伪判定，按氧化范围与深度在 B 至 C 档间判定。依据：氧化可通过专业护理处理，不属于必拒清单中的"五金断裂无法修复"。
