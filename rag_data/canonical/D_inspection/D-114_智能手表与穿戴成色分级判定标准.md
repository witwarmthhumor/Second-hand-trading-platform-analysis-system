# 智能手表与穿戴成色分级判定标准

## 一、检测范围与流程

智能手表与穿戴设备的验货检测，按以下编号步骤执行，全程留痕。

1. **收件核验与登记**：签收后 30 分钟内完成包裹外观查验、序列号核对、配件清点，并录入系统生成工单。
2. **外观拍照**：对表体、表带、表扣分别取景，合计不少于 6 张照片，覆盖划痕、磕碰、镀层脱落等全部瑕疵面。
3. **配对锁解除验证**：逐一尝试与手机配对，确认无 Apple ID 激活锁、华为账号锁、小米账号锁等品牌锁定。
4. **功能逐项检测**：按第三节表格逐项执行，心率、血氧、ECG 读数需与标准设备对比并记录误差。
5. **电池健康读取**：支持机型通过系统接口读取电池健康度与循环次数，数据截图存档。
6. **出报告**：签收后 48 小时内出具完整验货报告；买卖任一方对结果有异议，可在 72 小时内申请复检。

检测全程在验机仓监控区域内完成，禁止将设备带离工位。

## 二、检测工具与环境

检测工位需配备标准手机（用于配对与锁验证）、充电线缆套装、放大镜或微距镜头、标准光源灯箱、以及各品牌电池健康读取工具。环境要求为常温干燥，桌面铺设防静电垫，避免表带与表壳在检测过程中产生额外磨损。防水检测采用外观检查与说明书口径核对方式，不做破坏性水测——任何情况下不得将设备浸入液体。各品牌账号解绑操作需在专用网络环境下进行，避免连接公共 Wi-Fi。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 配对锁/激活锁 | 全部解除，可正常配对 | 用标准手机尝试配对，核对品牌账号状态 | 未解除即进入必拒清单 |
| 表镜外观 | 无影响显示的划痕或碎裂 | 灯箱下目视 + 微距拍照 | 碎裂影响显示即必拒；轻微划痕按成色降档 |
| 表壳与镀层 | 无超过档位允许的磕碰 | 目视 + 拍照比对 | 磕碰/镀层脱落按位置与面积降档 |
| 表带状态 | 无拉伸老化、无异味、卡扣开合正常 | 拉伸测试 + 目视 + 嗅闻 | 严重老化或异味降档至 C 或以下 |
| 充电触点 | 无氧化或氧化不影响充电 | 目视 + 实际充电测试 | 氧化导致充不进电即必拒 |
| 心率/血氧/ECG | 与标准设备对比误差在可接受范围 | 同时佩戴标准设备对比读数 | 传感器模组失效即必拒 |
| GPS 定位 | 室外可正常定位 | 开启地图应用实测 | 无法定位按功能瑕疵披露 |
| 蓝牙连接与通话 | 连接稳定、通话清晰 | 连接标准手机实测通话 | 断连或无声按功能瑕疵降档 |
| 电池健康 | S 级 ≥90%，A 级 80-89% | 系统接口读取并截图 | 低于 80% 必须披露；低于 60% 即必拒 |
| 循环次数 | 超过 500 次须显著标注 | 系统接口读取 | 不标注即报告不合格 |
| 进水标 | 不变色 | 目视检查进水指示标 | 变色即判定进水，不论功能是否正常 |
| 拆修史 | 如实写入报告 | 螺丝刀痕、胶水残留、序列号核对 | 隐瞒拆修即必拒；有拆修按实际降档 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N 全新 | 未拆封未使用，配件包装齐全 | 原封盒装，表膜未撕 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 仅试戴过数次，无可见划痕；电池健康 ≥90% |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | 表带有极轻微折痕，表壳无磕碰；电池健康 80-89% |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | 表壳有 1-2 处细微划痕，充电触点轻微氧化 |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | 表壳有明显磕碰，表带老化但未断裂 |
| D 7成新及以下 | 较重磨损/局部功能瑕疵，必须显著披露 | 表镜有深划痕但不影响显示，GPS 偶发失灵 |

电池健康度低于 80% 的设备，无论外观多新，成色不得高于 C。循环次数超过 500 次必须在报告显著位置标注，标注后仍可正常分级。

## 五、必拒情形

出现以下任一情形，直接拒收并出具说明，不进入分级流程：

- 配对锁/激活锁未解除（含 Apple ID、华为账号、小米账号、荣耀账号、Samsung 账号、Garmin Connect 未解绑）
- 蜂窝版未解除运营商锁或 eSIM 未注销
- 电池鼓包（目视或按压可感知）
- 表镜碎裂影响显示
- 传感器模组失效（心率、血氧、ECG 任一无法读数）
- 进水标变色判定进水
- 隐瞒拆修史

必拒设备按平台规则退回寄方，相关检测记录留存备查。

## 六、报告字段与拍照取证要求

报告字段包括：设备品牌型号、序列号、外观描述（表体/表带/表扣）、功能检测结果逐项、电池健康度与循环次数、配对锁解除状态、拆修史声明、成色定级、瑕疵照片编号索引。

拍照取证要求：表体、表带、表扣合计不少于 6 张照片；每处瑕疵需单独微距特写；电池健康度与循环次数截图；配对锁解除成功界面截图；进水标状态照片。所有照片需在自然光或标准光源下拍摄，禁止美化和修图。视频记录不少于 15 秒，覆盖开机、配对、功能自检三个环节。

## 七、常见争议与判定口径

**表带异味但外观完好，按什么口径定级？**

表带异味属于使用痕迹而非功能缺陷，按成色表降档处理，通常不高于 C。判定时先确认异味来源——汗渍浸入硅胶或氟橡胶表带内部无法彻底清除，与表面污垢可擦除的情况分开处理。可擦除的污垢不作为降档依据，需在报告中注明"经清洁可去除"。

**进水标变色但功能一切正常，能否按外观瑕疵处理？**

不能。进水标变色即判定进水，不论功能是否正常，直接进入必拒清单。依据是进水对内部电路板的腐蚀不可逆，当前功能正常不代表后续不会失效。防水密封检测采用外观检查与说明书口径核对，不做破坏性水测，因此进水标是判断进水历史的唯一可靠依据。

**电池健康度读数与官方售后检测不一致，以谁为准？**

以验机仓系统接口读取的数值为准，同时截图存档。各品牌读取路径不同，读数口径存在差异属正常现象。若双方对读数争议较大，可申请在 72 小时内复检，由另一名检测员重新读取并比对两次截图。

**拆修史如何界定？官方售后维修算不算拆修？**

凡有开壳痕迹即视为拆修，官方售后维修同样属于拆修史，必须写入报告。判定依据为螺丝刀痕、胶水残留、密封胶圈更换痕迹及序列号在售后系统的记录。隐瞒拆修即必拒；如实披露的，按实际拆修范围与维修质量降档，不直接拒收。
