# 三星Tab质检分册：检测要点与典型问题

## 一、检测范围与流程

**第1条** 本分册适用于三星Tab系列平板电脑的回收质检与分级，含S Pen手写笔及原装配件。

**第2条** 检测流程按以下步骤执行，验机仓签收后48小时内出具检测报告：

1. 收件核验与防拆封登记，签收后30分钟内完成。
2. 外观分级拍照，不少于6张。
3. 进水标检查。
4. 功能逐项检测。
5. 电池健康读取（支持读取的型号）。
6. Samsung账号退出验证。
7. 出具报告。

**第3条** 卖家对检测结果有异议的，可在报告出具后72小时内申请复检。

**第4条** 检测全程录像，视频时长不少于15秒，覆盖开机、触控、S Pen压感三项关键操作。

## 二、检测工具与环境

**第5条** 检测工具包括：触控网格测试软件、电池健康读取设备、SIM卡托针、S Pen测试笔、直尺或塞尺、放大镜及强光手电。

**第6条** 检测环境照度不低于普通办公照明，避免强反光影响屏幕划痕判断。

**第7条** 电池健康读取需使用平台指定软件，读取失败时在报告中标注"无法读取"，不得估算。

**第8条** S Pen压感测试需在系统自带笔记应用中绘制渐变线条，观察线条粗细是否随压力连续变化。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 屏幕划痕/压伤 | 无可见划痕或压伤 | 强光下斜视检查，显示区分级同手机口径 | 划痕按长度与深度降级；压伤直接降级 |
| 背板弯曲 | 平测≤1.5mm | 平板屏幕朝下置于平台，用塞尺测量背板离缝 | 平测>1.5mm记录并降级 |
| 触控断触 | 16区域全部正常 | 网格法16区域逐区划线 | 任一区域断触即降级，超2区域必拒 |
| S Pen压感 | 压感正常 | 笔记应用画渐变线，检查线条连续性 | 压感失灵或跳变，按配件缺陷降级 |
| 电池健康 | ≥90%为S级，80-89%为A级 | 系统设置中读取电池健康度 | <80%须披露；<60%必拒 |
| 扬声器 | 四声道逐个发声正常 | 播放测试音频，逐个声道确认 | 单声道无声降级，多声道异常必拒 |
| Samsung账号 | 已退出且无激活锁 | 设置-账户中确认退出，重启后验证 | 未退出即必拒 |
| 进水标 | 白色未变色 | 检查SIM卡托内及背板内侧进水标 | 变色即判定进水，不论功能是否正常 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，包装及配件齐全 | 原封盒装，封条完好 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 拆封激活但使用时间极短，屏幕无划痕 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 边框有极轻微氧化点，屏幕无划痕 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 背板有细微划痕，屏幕贴膜下有细小划痕 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 边框有磕碰掉漆，屏幕有细划痕 |
| D（7成新及以下） | 较重磨损或局部功能瑕疵，必须显著披露 | 背板明显磕碰变形，或扬声器单侧无声 |

**第9条** 电池健康为S级时须≥90%，A级为80-89%，低于80%须在报告中披露，低于60%直接拒收。

**第10条** 循环次数超过500次必须在报告中显著标注。

## 五、必拒情形

**第11条** 出现以下任一情形，直接拒收且不进入分级流程：

1. Samsung账号或激活锁未退出。
2. 电池健康<60%（支持读取型号）。
3. 主板维修史未申报。
4. 屏幕漏液扩散中。
5. 序列号不一致（机身、系统、包装三者比对）。
6. 进水标变色判定进水。
7. 隐瞒拆修史。

**第12条** 拆修史判断依据：螺丝防拆标是否完好、主板有无非原厂焊点、屏幕有无非原厂胶痕。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 六、报告字段与拍照取证要求

**第13条** 检测报告须包含以下字段：设备序列号、Samsung账号状态、电池健康度、循环次数、进水标状态、外观分级、功能检测结果、S Pen状态、拆修记录、检测结论。

**第14条** 拍照取证不少于6张，覆盖以下角度：

1. 设备正面亮屏照（显示序列号界面）。
2. 设备背面整体照。
3. 屏幕划痕特写照。
4. 边框磕碰特写照。
5. 进水标特写照。
6. Samsung账号设置界面照。

**第15条** 照片须清晰可辨，不得使用美颜或修复功能。S Pen压感异常时加拍测试过程截图。

## 七、常见争议与判定口径

**争议一：S Pen笔尖磨损但机身完好，如何定级？**

判定口径：S Pen属于原装配件，笔尖磨损按配件损耗降半级处理，须在报告中注明"笔尖磨损"。依据：配件状态影响整机使用体验，须如实披露。

**争议二：屏幕有贴膜，贴膜下有细小划痕如何判定？**

判定口径：撕膜后按实际屏幕状态判定。卖家未声明贴膜下划痕的，按隐瞒瑕疵处理。依据：外观分级以屏幕本体为准，贴膜不作为遮挡瑕疵的依据。

**争议三：电池健康读取为80%，但使用时间不足一年，是否可升A级？**

判定口径：不可。电池健康度是硬性指标，80-89%对应A级，不因使用时间短而调整。依据：分级标准统一执行，不设例外。
