# iQOO质检分册：检测要点与典型问题

## 一、检测范围与流程

iQOO 机型按以下流程执行，全程留痕。

1. 收件核验与防拆封登记：签收后 30 分钟内完成，核对序列号与运单、封贴完好性。
2. 外观分级拍照：正面、背面、四边、接口共 ≥6 张，强光侧照补拍屏幕划痕细节。
3. 进水标检查：SIM 槽、充电口、耳机口（如有）逐一查看。
4. 功能逐项检测：按第三部分明细表执行，重点覆盖电竞肩键与屏幕触控。
5. 电池健康与循环次数读取：通过系统诊断页或厂商工具读取。
6. ID 锁/账户锁退出验证：确认 vivo 账号已退出、查找设备已关闭。
7. 出报告：签收后 48 小时内完成。买家对结果有异议，可在 72 小时内申请复检。

## 二、检测工具与环境

- 强光侧照灯：用于屏幕划痕与背板裂纹判定，光源与屏幕呈 15–30 度夹角。
- 网格触控测试页：全屏划分 12 区域，逐区画线检测断触。
- 电池诊断工具：读取健康度与循环次数，读数需截图存档。
- 防静电工作台与手套：避免拆检过程造成二次损伤。
- 检测环境照度均匀，避免反光干扰外观分级判断。
- 所有工具读数以检测当日实际值为准，不采用历史记录。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 屏幕划痕 | ≤2 条发丝纹且不在显示区 | 强光侧照，记录位置与长度 | 显示区划痕或超过 2 条计 A 级以下 |
| 边框磕碰 | 无露底金属 | 目视 + 手指触感确认 | 露底金属降 1 级；掉漆面积 >5mm² 计 C 级 |
| 背板裂纹 | 无任何裂纹 | 强光下旋转机身检查 | 任何裂纹计 D 级并显著披露 |
| 摄像头镜片划痕 | 中心区无划痕 | 强光透射检查镜片 | 中心区划痕降 1 级 |
| 屏幕坏点/色斑/断触 | 无坏点、色斑，12 区域全通 | 网格法全屏 12 区域画线 | 任一区域断触即计功能异常 |
| 电竞肩键 | 按压反馈清晰、无空键程 | 游戏模式下调出肩键映射逐键测试 | 单侧无响应或需大力按压计 B 级以下 |
| 面容 ID/指纹解锁 | 录入后 3 次解锁全部成功 | 实际录入并锁屏解锁 | 失败 1 次以上计功能异常 |
| 电池健康 | S 级 ≥90%，A 级 80–89% | 系统诊断页读取 | <80% 必须明示；<60% 必拒 |
| 充电口/扬声器/振动/听筒/麦克风 | 全部正常 | 实际充电、播放音频、录音回放 | 单项异常按功能缺陷降级 |
| 前后摄像头对焦与闪光灯 | 对焦迅速、闪光灯正常 | 远近各拍一张 + 闪光灯拍摄 | 对焦失败或闪光灯不亮计功能异常 |
| 传感器 | 陀螺仪/指南针/距离感应正常 | 系统自检页逐项触发 | 单项无响应计功能异常 |
| ID 锁/激活锁 | 必须为关闭状态 | 设置—账号与同步—vivo 账号 | 未退出即必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封盒装，封贴完好 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅充电口轻微插拔痕迹，电池健康 ≥90% |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | ≤2 条发丝纹且不在显示区，电池健康 80–89% |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 边框 1 处细微磕碰未露底，肩键正常 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 掉漆面积 >5mm²，或边框磕碰露底金属 |
| D（7成新及以下） | 较重磨损或局部功能瑕疵，必须显著披露 | 背板裂纹、屏幕显示区划痕、扬声器破音 |

电池健康 <80% 必须在报告中明示具体数值；循环次数超过 500 次必须在报告中显著标注。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 五、必拒情形

出现以下任一情形，直接拒收并退回，不进入分级流程：

- ID 锁/账户锁未退出（vivo 账号未注销或查找设备仍开启）。
- 电池健康 <60%。
- 主板维修史未申报。
- 进水标变色且功能异常。进水标变色即判定进水，不论功能是否正常。
- 机身弯曲变形（>1mm）。
- 序列号与机身或系统不一致。

## 六、报告字段与拍照取证要求

报告字段：序列号、机型与存储版本、成色等级、电池健康度、循环次数、进水标状态、维修史声明、功能检测结果逐项、异常描述、检测员编号。

拍照取证口径：

- 外观照 ≥6 张：正面、背面、左右边框、顶部/底部接口、充电口特写。
- 屏幕划痕与背板裂纹必须单独补拍，强光侧照下拍摄。
- 电池健康与循环次数读取页面截图存档。
- 进水标状态拍照，SIM 槽与充电口分别拍。
- 视频记录 ≥15 秒，覆盖开机、屏幕触控画线、肩键按压过程。
- 所有照片与视频在报告中标注对应检测项编号。

## 七、常见争议与判定口径

**争议 1：肩键松动但功能正常，是否降级？**
判定口径：功能正常不降级，但需在报告中备注"肩键轻微松动"。依据：外观瑕疵与功能缺陷分开判定，功能项通过即不触发功能降级。
