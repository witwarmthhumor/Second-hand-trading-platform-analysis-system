# Dior质检分册：检测要点与典型问题

## 一、检测范围与流程

Dior 箱包质检覆盖收件核验、外观分级、真伪判定、功能检测与出报告五个环节，适用于蒙田系列、Lady Dior、Saddle 马鞍包及 Dioriviera 等主流产品线。验机仓签收后须在 30 分钟内完成收件核验与登记，全程录像留存；签收后 48 小时内必须出具完整质检报告。买家对报告有异议的，可在 72 小时内申请复检，复检以双人复核结论为准。

流程分六步执行：第一步收件核验与登记，核对包裹外观、附件清单与寄件人信息；第二步外观分级拍照，不少于 8 张，含四角、手柄、内衬与五金特写；第三步核验身份卡、序列号与镭射标，重点比对内标编号与身份卡一致性；第四步按五金、皮质、功能逐项检测并记录异常；第五步真伪综合判定，必须双人复核，一人判定仿品即触发必拒流程；第六步出具报告，含成色分级、异常描述与照片附件。

## 二、检测工具与环境

检测区要求照度均匀的白色光源，避免暖黄光影响皮质与五金成色判断。配备微距镜头或手机微距模式拍摄五金刻字，另备紫外灯辅助核查部分年份的防伪特征。环境需通风干燥，异味判定须在无香氛干扰的空间内进行。检测台铺设软垫，防止硬质台面造成二次划伤。所有工具不涉及破坏性检测，禁止对包袋进行拆解、水洗或任何可能改变原始状态的护理操作。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 字母五金对版 | CD 字母刻字清晰、边缘锐利，字体比例与品牌工艺一致 | 微距拍摄刻字底部，对比同款正品图库 | 刻字模糊、字体变形或镀层下有气泡，判定存疑并送双人复核 |
| 蒙田包型工艺点 | 包身挺括度正常，前幅与侧围衔接走线均匀 | 目测 + 手感按压包身，观察回弹 | 包型塌陷或走线跳针，按 B 级以下外观瑕疵处理 |
| 皮质划痕/磨白/龟裂 | 按区域分级：提手位允许轻微磨白，前幅不允许可见划痕 | 侧光 45° 目测，手指轻抚确认深浅 | 前幅划痕超过 2cm 或龟裂露出底层纤维，降 C 级并显著披露 |
| 四角磨损 | 四角磨白不超过 1cm²，不允许露料 | 目测 + 卷尺测量磨损面积 | 露料即触发必拒；磨白超 1cm² 按 D 级披露 |
| 内衬污渍与异味 | 内衬无染色、无破损；无霉味或烟味 | 打开包口嗅闻 + 目测内衬全区域 | 强烈不可去除异味直接必拒；局部污渍按面积降级 |
| 五金镀层脱落与氧化 | 镀层无剥落，氧化点不超过 2 处且直径小于 1mm | 微距拍摄 + 棉签轻拭确认是否可去除 | 可去除氧化不降级；镀层剥落按 C 级以下处理 |
| 拉链顺滑度与拉头完整性 | 拉合顺畅无卡顿，拉头 CD 刻字清晰 | 全程拉合 3 次，观察拉头与链牙咬合 | 卡顿或拉头断裂无法修复，触发必拒 |
| 磁扣/转锁开合 | 开合干脆，吸力正常，无松旷 | 反复开合 10 次，听声 + 手感判断 | 松旷导致无法闭合，按功能瑕疵降 D 级 |
| 身份卡编号与内标一致性 | 身份卡编号与包内皮质烫印编号完全一致 | 紫外灯 + 目测比对两处编号 | 不一致即判定序列号矛盾，触发必拒 |
| 附件清点 | 防尘袋、肩带、小票齐全且无替换 | 对照附件清单逐项核验 | 缺附件不拒收，但报告中必须显著标注缺失项 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全，身份卡塑封完整 | 专柜原装未拆，吊牌未剪 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅试背一次，内衬无任何使用感 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 手柄有极轻微汗渍变色，但不明显 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 四角有轻微磨白，五金有 1 处可去除氧化点 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 前幅有 1-2cm 浅划痕，内衬局部污渍可清洁 |
| D（7成新及以下） | 较重磨损或局部功能瑕疵，必须显著披露 | 四角磨白超 1cm²，转锁松旷但可闭合 |

成色判定须结合皮质老化与护理历史。若送检前经过专业护理（如补色、镀层修复），护理痕迹不影响成色档位，但报告中必须写明护理史；护理后掩盖了原有破损的，按实际破损程度定级，不因护理而升档。

## 五、必拒情形

以下情形出现任意一项，直接拒收并出具说明，不做降级处理：

1. 判定为仿品。真伪存疑且双人复核无法达成一致时，按存疑拒收处理，不进入成色评级。
2. 主料破损。面料破洞、开裂贯穿皮质或帆布层，无法通过护理修复。
3. 五金断裂无法修复。如 CD 字母脱落、转锁断裂或拉头整体碎裂。
4. 强烈不可去除异味。霉味或烟味超常规，经通风 24 小时仍无法消散。
5. 序列号与品牌数据库逻辑矛盾。身份卡编号与内标不一致，或编号格式与生产年份逻辑冲突。

## 六、报告字段与拍照取证要求

报告至少包含以下字段：送检单号、品牌与系列、包袋尺寸与颜色、序列号/身份卡编号、成色分级、异常项逐条描述、护理史说明、附件清单、检测人与复核人签名。异常描述须写清位置与程度，如"前幅距底部 5cm 处有一条 3cm 浅划痕"，不得笼统写"轻微磨损"。

拍照取证不少于 6 张，实际按外观分级拍照口径执行：包身正面、背面、底部、内衬各 1 张，五金特写至少 2 张（含 CD 字母刻字与转锁），四角磨损与划痕等异常处单独加拍。所有照片须在自然光或标准白光下拍摄，禁止滤镜与美颜。身份卡与内标编号须同框拍摄一张，作为一致性核验凭证。录像全程留存，关键判定节点（如异味嗅闻、拉链拉合测试）须在录像中可回溯。

## 七、常见争议与判定口径

**送检时未说明的护理痕迹，算不算隐瞒？**

算。任何拆修史或护理史必须写入报告，隐瞒拆修即必拒。补色、镀层修复等护理虽不直接拒收，但未披露即视为隐瞒，买家可据此申请复检并重新定级。

**买家认为"四角磨白"应降为 D 级，但报告给了 B 级，以谁为准？**

以实测面积为准。磨白不超 1cm² 且未露料，按 B 级正常使用痕迹处理；超 1cm² 即降 D 级并显著披露。买家若对测量有异议，可在 72 小时内申请复检，复检以双人复核结论为准。

**异味判定有主观成分，如何让买家信服？**

异味须在无香氛干扰的通风环境中嗅闻，结论写入报告时附检测环境说明。霉味或烟味超常规且通风后仍无法消散的，直接必拒；轻微异味可经护理去除的，按 C 级以下处理并在报告中标注护理建议。
