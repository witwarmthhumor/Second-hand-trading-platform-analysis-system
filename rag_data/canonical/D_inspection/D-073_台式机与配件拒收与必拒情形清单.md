# 台式机与配件拒收与必拒情形清单

## 一、检测范围与流程

台式机与配件品类覆盖品牌整机、DIY 组装机及 CPU、显卡、主板、内存、硬盘、电源、散热器、显示器、机械键盘等单件配件。检测流程从验机仓签收开始计时，按五步执行：收件核验与登记（30 分钟内完成）、外观拍照（配件逐件清点）、通电点亮与功能测试、压力测试（仅整机类）、出报告。报告须在签收后 48 小时内出具；卖家对结果有异议的，可在报告出具后 72 小时内申请复检。复检以一次为限，结论以复检为准。

收件核验环节，先对照订单核对机型、配置与卖家申报的成色，再清点配件。配件缺件或与申报不符的，当场记录并拍照，不进入下一环节。整机类目须核对原装配置单（品牌整机）或配件清单（DIY 组装机），确认序列号与配置单一致。

## 二、检测工具与环境

检测环境须为防静电工作台，温湿度稳定，配备稳压电源。工具清单：CPU 压力测试软件（记录主频与温度）、3D 图形压力测试软件、Memtest 内存测试工具、硬盘 SMART 读取工具、纯色测试画面（用于显示器检测）、放大镜或微距镜头（用于针脚与金手指检查）。拆装工具须使用合规螺丝刀套装，避免损伤螺丝与卡扣。

所有检测在通电状态下进行，须确认接地良好。压力测试期间设备不得断电或休眠，测试数据实时记录。进水标检查使用目视与放大镜结合，进水标变色即判定进水，不论功能是否正常。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| CPU 针脚 | 无弯曲、无缺失 | 目视+放大镜逐排检查 | 针脚缺失 >2 根即必拒；弯曲可尝试矫正，矫正失败按 D 级披露 |
| CPU 压力测试 | 10 分钟压力测试无死机，主频不低于标称值 | 压力测试软件记录主频与温度曲线 | 温度异常升高或降频严重，按 C 级以下处理 |
| 显卡 3D 压力测试 | 15 分钟无花屏、无驱动崩溃 | 3D 压力测试软件全屏运行 | 花屏即必拒；驱动崩溃一次记录，两次以上必拒 |
| 内存识别与测试 | 全容量识别、双通道开启，Memtest 1 轮无报错 | BIOS 查看+Memtest 运行 | 容量识别不全或报错，按 D 级披露或拒收 |
| 硬盘 SMART | 无报警，重映射扇区未超阈值 | SMART 读取工具查看健康度 | SMART 报警即必拒；机械盘异响按必拒处理 |
| 电源电容与输出 | 电容无鼓包，输出电压稳定 | 目视电容+万用表测输出 | 电容鼓包即必拒；电压波动超 ±5% 按 D 级披露 |
| 显示器纯色测试 | 5 色纯色下无坏点/亮斑/背光不均 | 依次显示黑、白、红、绿、蓝纯色画面 | 坏点 ≤3 个按 B 级，>3 个按 C 级；背光不均按漏光分级披露 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封箱说全，封条完好 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅拆封通电验机，无划痕 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 有轻微指纹或插拔痕，无可见划伤 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 外壳有细微划痕，不影响观感 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 边角有磕碰，接口有氧化但功能正常 |
| D（7成新及以下） | 较重磨损或局部功能瑕疵，必须显著披露 | 外壳裂纹、接口部分失效、有拆修史 |

成色判定须结合功能测试结果。功能全部正常是 S 至 C 级的前提；存在局部功能瑕疵的，最高只能判 D。电池健康度适用于含电池的配件（如部分一体机），健康度 ≥90% 可评 S，80-89% 评 A，低于 80% 须披露，低于 60% 直接拒收。循环次数超过 500 次的，必须在报告中显著标注。

## 五、必拒情形

以下情形出现即拒收，不做降级处理，直接退回卖家并说明原因：

1. **硬盘 SMART 报警**——重映射扇区超阈值，存在数据安全风险。
2. **显卡花屏或虚焊史**——花屏经 3D 压力测试确认即拒；虚焊史通过拆检或维修痕迹确认。
3. **CPU 针脚缺失 >2 根**——缺失超过 2 根无法保证可靠接触。
4. **电源电容鼓包**——电容鼓包是电源失效的前兆，存在安全隐患。
5. **整机无法点亮且原因不明**——经排查无法确定故障点的，整机拒收。
6. **隐瞒拆修史**——任何拆修史必须写入报告，隐瞒拆修即必拒。
7. **进水标变色**——进水标变色即判定进水，不论功能是否正常。

必拒情形在报告中单独列出，附检测证据照片，不参与成色评级。

## 六、报告字段与拍照取证要求

报告字段按以下结构填写，缺项不予通过：

| 字段 | 填写要求 |
|---|---|
| 机型/配置 | 品牌整机填原装配置单型号，DIY 组装机逐项列配件清单 |
| 申报成色与实际成色 | 两者不一致时以实际检测为准，差异超一档须备注说明 |
| 功能测试结果 | 逐项列明 CPU/显卡/内存/硬盘/电源/显示器测试结论 |
| 必拒情形 | 命中的必拒项编号及对应证据照片索引 |
| 拆修史与进水情况 | 有拆修史须写明部位与程度；进水标变色直接判进水 |
| 电池健康度（如适用） | 健康度百分比与循环次数，循环超过 500 次显著标注 |
| 瑕疵描述 | 按外观→功能顺序列出，附位置说明 |

拍照取证每台设备至少 6 张：整机正面、整机背面/侧面、序列号特写、外观瑕疵特写、通电点亮状态、检测软件结果截图。配件类逐件单独拍摄，针脚、金手指、电容等关键部位用微距镜头补拍。照片须清晰可辨，能对应报告中的每一项异常描述，模糊或无法对应的一律补拍后重新提交。

## 七、常见争议与判定口径

**争议一：卖家称"仅拆封未使用"，但散热器硅脂有压痕。** 判定口径：硅脂压痕属于通电安装痕迹，按实际使用痕迹降级，不能按 S 级（99新）收货。依据：S 级要求"极少使用痕迹"，硅脂压痕说明已安装散热器并通电。

**争议二：显卡能正常点亮，但 3D 压力测试中途驱动崩溃一次。** 判定口径：驱动崩溃记录一次，复测仍崩溃即按必拒处理；复测通过则按 C 级披露。依据：单次崩溃可能由驱动版本引起，两次以上指向硬件不稳定。

**争议三：硬盘 SMART 显示"警告"但卖家称数据可正常读取。** 判定口径：SMART 报警即必拒，不因当前可读取而放行。依据：重映射扇区超阈值是渐进性故障，数据随时可能丢失。

**争议四：整机无法点亮，卖家主张是内存未插紧。** 判定口径：重新插拔内存后仍无法点亮，按"整机无法点亮且原因不明"必拒；插拔后正常则按正常流程继续检测。依据：必拒清单针对的是原因不明的不亮，可复现排除的接触问题不在此列。
