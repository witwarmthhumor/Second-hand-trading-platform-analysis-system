# 奢侈品箱包成色分级判定标准

## 一、检测范围与流程

奢侈品箱包检测覆盖皮质、五金、内衬、附件及真伪核验五个维度。流程按以下步骤执行，全程录像留档：

1. **收件核验与登记**——签收后 30 分钟内完成包裹外观核验、箱包基础信息登记，此环节全程录像。
2. **外观分级拍照**——拍摄不少于 8 张照片，含正面、背面、两侧、底部、内里及五金特写。
3. **身份卡/序列号/镭射标核验**——逐一比对身份卡编号、内标序列号、镭射标或 Date code 的一致性。
4. **五金与皮质逐项检测**——按第三、四节所列检测项逐项执行并记录。
5. **真伪综合判定**——由两名鉴定师独立复核，结论不一致时提交组长仲裁。
6. **出报告**——签收后 48 小时内出具完整检测报告。买方对结论有异议的，可在报告出具后 72 小时内申请复检。

## 二、检测工具与环境

检测区配备白光与自然光双光源工作台，色温恒定，避免因光线偏差影响皮质颜色与氧化程度的判断。必备工具包括：珠宝放大镜（用于刻字深度与电镀层观察）、紫外灯（辅助鉴别部分品牌防伪特征）、软尺与卡尺（测量包体尺寸及五金件规格）、白手套（避免检测过程中二次污染）、标准比色卡（用于皮质蜜色与氧化的色阶参照）。

检测环境要求通风良好、温湿度稳定。异味判断需在静置 5 分钟后的密闭空间内进行，避免与快递包装气味混淆。所有检测操作在录像范围内完成，检测台铺设软垫，五金检测时使用保护膜，防止划伤。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 皮质划痕/磨白/龟裂 | 表面无贯穿性损伤 | 分区目测 + 指腹触感 | 按区域面积分级：轻微（≤1cm 局部）记 B 级；明显（≥3 处或单处 >3cm）降 C/D 级 |
| 四角磨损 | 无露料或仅极轻微磨白 | 目测 + 放大镜观察纤维层 | 磨白未露料记 B 级；露料面积 >0.5cm² 记 C 级及以下 |
| 内衬污渍与异味 | 内衬无霉斑、无异味残留 | 目测 + 密闭嗅闻 | 可局部清洁的污渍降 C 级；霉味或烟味超常规直接列入必拒 |
| 五金镀层脱落与氧化 | 镀层完整，氧化不影响开合 | 目测 + 珠宝放大镜观察电镀层厚度与刻字深度对比 | 刻字变浅或镀层点状脱落降 B/C 级；断裂无法修复列入必拒 |
| 拉链顺滑度与拉头完整性 | 开合顺畅、无卡顿、拉头无变形 | 往复开合 5 次测试 | 卡顿可润滑修复记 C 级；拉头断裂列入必拒 |
| 磁扣/转锁开合 | 吸合到位、转锁旋转阻尼正常 | 反复开合 10 次 | 功能异常但可维修记 D 级；无法修复列入必拒 |
| 五金刻字清晰度与工艺对版 | 刻字深度、字体与品牌工艺一致 | 放大镜对比品牌分册标准图 | 刻字模糊或字体不对版，转入真伪复核流程 |
| 身份卡编号与内标一致性 | 编号完全一致，无涂改 | 逐位核对 + 紫外灯检查 | 不一致即触发真伪综合判定，逻辑矛盾列入必拒 |
| 附件清点 | 防尘袋/肩带/小票齐全 | 对照订单附件清单逐项勾选 | 缺失附件在报告中显著披露，不计入成色降级 |

## 四、成色判定表

成色判定在完成全部检测项后综合得出，以最低单项等级为最终成色。各品牌分册的特殊检测点（LV 老花对花位与 Date code、Chanel 镭射标与菱格走线、Hermès 工匠刻印与手缝鞍线、Gucci 双 G 五金对版等）按对应分册执行，不单独调整成色档位。

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 专柜原封，防尘袋未打开 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅试背过 1-2 次，五金无氧化 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 四角极轻微磨白，内衬干净 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 手柄轻微汗渍变色，五金细微氧化 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 四角磨白露料 ≤0.5cm²，内衬局部污渍 |
| D（7成新及以下） | 较重磨损/局部功能瑕疵，必须显著披露 | 皮质龟裂但未贯穿，拉链卡顿可修复 |

皮质老化与护理方面，可修复性分级独立于成色判定：经护理后外观改善的，按护理后状态定级，但护理史必须在报告中披露。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 五、必拒情形

出现以下任一情形，直接判定拒收，不进入成色分级流程：

- **判定为仿品**——经双人复核或品牌数据库比对确认。
- **主料破损**——面料破洞或开裂贯穿，超出可修复范围。
- **五金断裂无法修复**——如锁扣断裂、链条断开且无法更换原厂件。
- **强烈不可去除异味**——霉味或烟味超常规，经护理仍无法消除。
- **序列号与品牌数据库逻辑矛盾**——如 Date code 格式与产地对应关系不符、序列号在官方系统无记录。

## 六、报告字段与拍照取证要求

检测报告须包含以下字段：订单编号、品牌与型号、序列号/身份卡编号、成色等级、单项检测结果、附件清单、必拒项触发情况（如有）、鉴定师签名及复核人签名。报告出具后 48 小时内推送至平台，买方可在 72 小时内申请复检。

拍照取证不少于 6 张，实际执行按检测流程拍摄不少于 8 张，覆盖正面、背面、两侧、底部、内里及五金特写。每张照片需在画面内放置当日日期牌，确保可追溯。以下情形必须单独加拍特写：四角磨损、皮质划痕或龟裂、五金氧化或镀层脱落、内衬污渍、身份卡与内标编号对比、附件缺失。照片与报告一同归档，保存期限以平台页面公示为准。

| 取证类别 | 拍摄要求 | 对应报告字段 |
|---|---|---|
| 外观全景 | 正面/背面/两侧/底部各 1 张 | 外观特征描述 |
| 五金特写 | 刻字、锁扣、链条各 1 张 | 五金检测结果 |
| 瑕疵特写 | 每处瑕疵单独拍摄，含比例参照物 | 降级依据 |
| 编号证据 | 身份卡、内标、镭射标逐张拍摄 | 真伪判定依据 |
| 附件清点 | 防尘袋、肩带、小票同框拍摄 | 附件清单 |

## 七、常见争议与判定口径

**争议一：护理后能否提升成色等级。** 判定口径：以护理后状态定级，但护理史必须写入报告，且护理不得用于掩盖拆修痕迹或五金断裂。依据：可修复性分级独立于成色判定，隐瞒护理史视同隐瞒拆修。

**争议二：轻微氧化算不算五金缺陷。** 判定口径：氧化不影响开合且未导致刻字变浅的，按正常使用痕迹处理，不单独降级；镀层点状脱落或刻字明显变浅的，降 B/C 级。依据：五金氧化属常见使用痕迹，与断裂等结构性损伤分开判定。

**争议三：异味达到什么程度列入必拒。** 判定口径：密闭静置后霉味或烟味仍明显且经护理无法消除的，直接拒收；可经通风或专业护理去除的轻微异味，在报告中披露但不降级。依据：异味判断需排除快递包装气味干扰，以静置后结果为准。

**争议四：附件缺失是否影响成色。** 判定口径：附件缺失不影响成色等级，仅在报告中显著披露；身份卡缺失则触发真伪复核流程，序列号无法核验时列入必拒。依据：附件清点与真伪核验分属不同检测维度，身份卡是核验真伪的关键凭证。
