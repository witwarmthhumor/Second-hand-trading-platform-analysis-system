# 头戴式耳机质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于头戴式耳机（含无线与有线两类）的回收质检与成色判定。收件后按以下步骤执行，流程时限以平台公示为准。

1. 收件核验与登记：签收后 30 分钟内完成包裹外观、配件清单与机身序列号核对。
2. 外观拍照：耳机主体、头梁、耳罩、线材与插头分别取景，照片不少于 6 张。
3. 配对连接测试：无线型号做双耳与单耳连接，记录 10 分钟连接稳定性。
4. 功能逐项检测：按第三部分明细表逐项执行，异常项即时标记。
5. 出报告：签收后 48 小时内完成质检报告并上传系统。

买家对报告有异议的，可在 72 小时内申请复检。复检结论为最终结果，原报告作废。

## 二、检测工具与环境

检测环境需安静、无强干扰，环境噪声建议控制在可正常通话的水平。无线耳机测试前确认电量充足，连接设备为平台指定测试手机。

工具包括：序列号扫码枪或读码 App、电池健康读取工具（支持时）、耳罩清洁工具、头梁长度测量尺、标准 3.5mm 音频线（有线型号用）、备用耳罩与备用线材（用于交叉验证）。

电池健康读取仅适用于支持电量数据输出的型号。读取失败时，以实际续航表现作为参考，并在报告中注明"电池健康无法读取"。进水检测使用进水标观察法，变色即判定进水，不因功能正常而豁免。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 头梁伸缩与铰链 | 伸缩顺滑、无卡顿，铰链无松动异响 | 反复伸缩 5 次，转动耳罩检查阻尼 | 卡顿或异响降 C 级；铰链断裂入必拒 |
| 记忆海绵塌陷 | 按压回弹正常，无明显塌陷坑 | 指压 3 秒观察回弹速度 | 明显塌陷降 C 级；塌陷致佩戴变形降 D 级 |
| 耳罩皮质/蛋白皮 | 无开裂、无大面积脱皮 | 目测加指腹滑动检查 | 局部开裂降 C 级；大面积脱皮降 D 级 |
| 线材插拔与接触（有线） | 插头插入无杂音，旋转无断音 | 连接测试设备，旋转插头 90 度监听 | 单侧断音入必拒；接触不良降 C 级 |
| 左右声道与单元 | 双耳音量一致，无偏音 | 播放左右声道测试音频，记录主观对比 | 偏音明显降 D 级；单边无声入必拒 |
| 降噪与通透模式（无线） | 降噪开启后底噪无明显异常，模式切换正常 | 播放标准噪声源，对比开关降噪效果 | 降噪失效降 C 级；切换失灵降 D 级 |
| 触控/按键功能 | 全部按键响应正常，触控无失灵 | 逐键按压、逐手势测试 | 单键失灵降 C 级；触控板完全失灵降 D 级 |
| 电池续航与充电 | 电池健康不低于 60%，循环超 500 次显著标注 | 读取电池健康数据，测试充电是否正常 | 电池健康 60-80% 需披露；低于 60% 入必拒 |
| 序列号与包装对版 | 机身、包装、系统显示三码一致 | 扫码比对三处序列号 | 不一致按仿品流程处理，入必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N 全新 | 未拆封未使用，配件包装齐全 | 原封盒装，塑封完整 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 仅试戴过，耳罩无压痕，头梁无油光 |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | 耳罩有极轻微使用纹路，头梁无划伤 |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | 耳罩轻微压痕，头梁有细微划痕 |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | 耳罩皮质局部磨损，外壳有可见划痕 |
| D 7成新及以下 | 较重磨损/局部功能瑕疵，必须显著披露 | 耳罩开裂、头梁掉漆明显、单侧降噪失效 |

电池健康与成色的对应关系：电池健康 90% 及以上可评 S 或 A；80-89% 评 A 或 B；低于 80% 必须披露，且最高评 C；低于 60% 直接拒收。循环次数超过 500 次的，无论成色如何，报告中必须显著标注。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 五、必拒情形

以下情形出现即拒收，不进入成色判定流程：

- 单边无声音且原因不明（排除线材与设置因素后仍无声）
- 充电接口或电池无法充电（无线型号）
- 判定为仿品（序列号对版失败或做工明显不符）
- 电池鼓包（目测或手触外壳隆起）
- 进水标变色（判定进水，不论功能是否正常）
- 账号绑定设备未解除（支持查找功能且被锁定，无法退出）

## 六、报告字段与拍照取证要求

报告字段包括：设备型号与序列号、成色等级、电池健康（如可读取）、循环次数（如可读取）、维修史声明、进水标状态、功能检测结果逐项记录、异常项描述与分级、配件清单。

拍照取证要求：

- 外观照片不少于 6 张，覆盖：正面、背面、左侧耳罩、右侧耳罩、头梁内侧、线材插头。
- 异常项需单独加拍特写，保证瑕疵清晰可辨。
- 进水标状态需单独拍照留存。
- 序列号需拍清条码与数字，确保系统录入可核对。

照片上传后不可替换，复检时以原照片为参照。

## 七、常见争议与判定口径

**争议一：耳罩塌陷算不算功能问题**

判定口径：耳罩塌陷属于外观损耗，按记忆海绵回弹测试结果定级。按压后回弹明显变慢或留下指印坑的，降 C 级；塌陷导致佩戴时耳廓受压、漏音明显的，降 D 级。买家主张"塌陷影响降噪效果"的，以实际佩戴听感为准，不单凭肉眼判断。

依据：海绵塌陷直接影响佩戴密封性，密封不严则降噪与音质双双打折，故按影响程度分级而非一刀切。

**争议二：单侧偶发断音是拒收还是降级**

判定口径：反复插拔线材、旋转插头后仍出现断音的，按"单边无声音"处理，入必拒。仅在特定角度下断音、调整后恢复稳定的，降 D 级并显著披露，不直接拒收。买家坚持退货的，以复检时 10 分钟连接记录为准。

依据：偶发断音多为线材内部芯线断裂的早期表现，若已稳定复现则视为功能性故障，不能按外观瑕疵处理。

**争议三：降噪效果"不如新机"怎么判**

判定口径：降噪是主观体验项，不设量化指标。检测时以标准噪声源下开关降噪的差异为据：差异明显、底噪无异常的，判定合格；降噪开启后与关闭几乎无差别的，判定降噪失效，降 C 级。买家以"降噪变弱"申诉的，需在复检现场对比同型号参照机，无参照机时以检测记录为准。

依据：降噪性能随耳罩密封性与海绵状态自然衰减，属正常损耗，只有失效才构成功能缺陷。

**争议四：进水标变色但功能全好**

判定口径：进水标变色即判定进水，不论功能是否正常，直接拒收。买家辩称"只是受潮没进水"的，不受理。

依据：进水标为一次性化学指示件，变色即触发必拒条款，该口径适用于全品类，头戴式耳机不例外。
