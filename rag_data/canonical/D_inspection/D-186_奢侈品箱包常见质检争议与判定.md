# 奢侈品箱包常见质检争议与判定

## 一、检测范围与流程

收件核验与登记环节，验货仓必须在签收后 30 分钟内完成拆包、核对箱体外观与附件清单，全程录像。外观分级拍照不少于 8 张，五金特写必须单独成图，不能拿远景图凑数。身份卡、序列号、镭射标三项核验在拍照后立即执行，顺序不可颠倒——先拍后验，防止争议时说不清原始状态。

五金与皮质逐项检测按品类分册执行，LV 看老花对花位和 Date code，Chanel 看镭射标贴与身份卡，Hermès 看工匠刻印与手缝鞍线。真伪综合判定必须双人复核，一人签字不算数。报告在签收后 48 小时内出具，超时需报备原因。买家对结果有异议的，72 小时内可申请复检，复检以首次留档照片与录像为准，不接受二次寄回件直接改判。

## 二、检测工具与环境

检测台面铺设白色无纺布，光源采用色温 5000K 左右的双侧平行光，避免单侧强光造成皮纹误判。放大镜倍数以能看清五金刻字底部与镭射标数字边缘为准。序列号核验需连接品牌数据库查询端口，无法联网查询时暂停该项并上报。皮质老化检测配备湿度计，环境湿度异常时记录在案，不直接下结论。所有工具不接触箱体金属件，防止二次划伤。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 皮质划痕/磨白 | 浅表划痕不影响观感 | 侧光目测 + 指腹触摸 | 按区域分级：手柄位磨白属 B 级常见，包角磨白至露料降 C 级 |
| 四角磨损 | 无露料、无贯穿 | 目测 + 拍照对比 | 磨白未露料可评 B，露料评 C，贯穿开裂直接进入必拒流程 |
| 内衬污渍与异味 | 无霉味、烟味超常规 | 开盖嗅闻 + 内衬翻查 | 轻微污渍可清洗的评 C 并披露；不可去除异味直接必拒 |
| 五金镀层脱落与氧化 | 镀层完整或轻微氧化 | 放大镜观察 + 刻字深度对比 | YSL 五金氧化属通病，轻微氧化不降级；镀层剥落面积大降 C |
| 拉链顺滑度 | 开合顺畅无卡顿 | 全程拉合 3 次 | 卡顿可润滑处理；拉头断裂无法修复则必拒 |
| 身份卡编号与内标一致性 | 编号完全一致 | 与品牌数据库比对 | 编号逻辑矛盾（如产地代码与 Date code 不符）直接必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原盒塑封完好，身份卡未取出 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅试背一次，内衬无接触痕迹 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 手柄有极浅汗渍，五金无划痕 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 包角轻微磨白，内衬有淡印 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 五金镀层局部脱落，皮质有可护理划痕 |
| D（7成新及以下） | 较重磨损或局部功能瑕疵，必须显著披露 | 包角露料，拉链需用力拉合 |

皮质老化与护理项单独记录：可修复性分级按护理后是否影响成色判定。浅表划痕经护理可恢复至 A 级观感，深划痕护理后仍可见痕迹的按原级披露，不得因护理操作上调成色。

## 五、必拒情形

出现以下任一情形直接拒收，不进入成色评级流程：判定为仿品；主料破损（面料破洞或开裂贯穿）；五金断裂无法修复；强烈不可去除异味（霉味、烟味超常规）；序列号与品牌数据库逻辑矛盾。仿品判定需双人复核并留存全部证据照片，报告注明判定依据。序列号矛盾包括但不限于 Date code 格式与产地对应关系不符、镭射标数字字体与品牌历年工艺不符。

## 六、报告字段与拍照取证要求

报告字段包括：品牌与款号、序列号/镭射标编号、成色等级、检测项明细、瑕疵描述与位置图示、附件清点结果、检测人及复核人签名。拍照取证不少于 6 张，实际执行按外观分级拍照 8 张起，含整包正面、背面、底部四角、内衬、五金特写、身份卡与序列号。进水标变色即判定进水，不论功能是否正常，此项适用于带电子元件的智能箱包。任何拆修史必须写入报告，隐瞒拆修即必拒。皮质护理记录单独列项，护理前后照片对比存档。

## 七、常见争议与判定口径

**手柄汗渍变色算不算瑕疵？**
算。手柄与肩带使用痕迹及汗渍变色属于外观检测项，按区域分级。轻微变色可评 B，明显变色且皮质发硬评 C，报告必须附图披露。

**护理后划痕变浅，成色能上调吗？**
不能。护理后是否影响成色判定仅用于描述可修复性分级，成色以上架前实际状态为准。护理操作属于检测流程一部分，不构成上调成色的依据。

**五金氧化是通病还是瑕疵？**
看品牌与程度。YSL 五金氧化属通病，轻微氧化不降级；其他品牌五金镀层脱落按面积与位置分级。刻字深度对比法是关键手段，镀层厚度与刻字深度同时偏浅需警惕仿品风险。

**买家对成色有异议怎么办？**
72 小时内申请复检，以首次留档照片与录像为准。复检结论与原判一致的不再受理二次申诉，检测方出具书面说明。
