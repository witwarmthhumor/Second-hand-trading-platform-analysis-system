# 镶嵌牢固度质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于黄金珠宝品类中所有带镶嵌结构的商品，包括爪镶、包镶、轨道镶与密钉镶。镶嵌类商品的争议集中在掉石、松动与金重误差三个点上，流程因此单列镶嵌检查环节：收件登记（30 分钟内、全程录像）→ 克重实测 → 材质检测 → 镶嵌牢固度逐项检查 → 证书核验 → 出报告（签收后 48 小时内，异议 72 小时内可申请复检）。

## 二、检测工具与环境

| 工具 | 用途 | 要求 |
| 精密天平 | 克重实测 | 精度 0.01g，双人复核 |
| 光谱仪 | 材质纯度判定 | 足金口径以 990 为线 |
| 十倍放大镜 | 镶嵌爪位与宝石检查 | 逐颗检查 |
| 镊子与软布 | 拿取与擦拭 | 防止二次划伤 |

## 三、镶嵌牢固度检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
| 爪镶爪位 | 爪头紧贴宝石腰线，无翘起 | 十倍放大镜逐爪目视 | 单爪翘起降级并标注，多爪松动必拒 |
| 包镶边沿 | 包边完整包裹，无开裂 | 目视加手感轻推 | 边沿开裂必拒 |
| 轨道镶 | 石粒排列齐整、无浮起 | 放大镜横向扫查 | 浮起石粒超过一半必拒 |
| 底托焊点 | 无虚焊、无补焊痕迹 | 目视 | 有补焊痕迹必须标注维修嫌疑 |
| 镶嵌石数量 | 与证书及描述一致 | 逐颗清点 | 掉石、缺石未申报必拒 |
| 松动手感 | 轻摇无异响、石粒无位移 | 轻摇听音加放大镜复查 | 任何位移记录在报告 |

## 四、成色判定表

| 成色 | 定义 | 镶嵌类细化口径 |
| S 99新 | 极少使用痕迹 | 无划痕、石粒牢固、金面无凹陷 |
| A 95新 | 轻微使用痕迹 | 细微划痕不影响观感，镶嵌牢固 |
| B 9成新 | 正常使用痕迹 | 允许轻微磨砂面变亮，镶嵌牢固 |
| C 8成新 | 明显使用痕迹 | 划痕可见或金面小凹痕，镶嵌牢固且已披露 |
| D 7成新及以下 | 较重磨损 | 金面明显变形或镶石缺失，必须显著披露 |

## 五、必拒情形

- 掉石、缺石且卖家未申报；
- 爪位大面积变形导致宝石可位移；
- 实测克重与标称误差超过 0.5g 且无合理解释；
- 光谱判定与标称纯度不符；
- 证书编号不存在或参数与实物不符。

## 六、克重与证书的判定口径

金重实测与标称差在 0.05g 以内视为正常范围；超出 0.5g 且无法解释的直接必拒。天平读数双人复核并拍照留证。证书核验走官网加电话双通道，编号、参数、照片三点对齐才算通过；任何一项对不上，按证书存疑处理并中止交易。材质检测以光谱仪结果为准，火烧检测仅限客户明确授权后进行。

## 七、常见争议与判定口径

问：买家收到后自己碰掉石算谁的？答：以质检报告的镶嵌牢固度结论为准，报告判定牢固且照片清晰的，签收后脱落按售后窗口期规则处理。

问：改圈口后镶石松动了能复检吗？答：改动镶嵌结构后不复检原报告，按新件重新送检。

问：小钻掉了一颗能补吗？答：允许卖家返修补镶，返修后重新走全流程质检，成本承担按判责口径执行。
