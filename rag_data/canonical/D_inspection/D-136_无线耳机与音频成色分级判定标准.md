# 无线耳机与音频成色分级判定标准

## 一、检测范围与流程

本册适用于无线耳机（TWS、颈挂式、头戴式）、有线 HiFi 耳机、蓝牙音箱及麦克风的回收验货。流程自验机仓签收起计时，报告须在签收后 48 小时内出具；送检方有异议的，可在报告出具后 72 小时内申请复检，复检通过后寄回运费由送检方承担。

流程分五步顺序执行：

1. **收件核验与登记**（30 分钟内完成）：核对运单、包裹外观与配件清单，异常包裹（严重挤压、液体渗漏）当场拍照留证并上报。
2. **外观拍照**：耳机本体、充电盒、线材各角度拍照，总数不少于 6 张，覆盖耳壳、铰链、触点、耳塞套四部位。
3. **配对连接测试**：先双耳配对，再分别测试左/右单耳独立连接，记录 10 分钟内的连接稳定性。
4. **功能逐项检测**：按第三部分表格逐项执行，结果实时录入系统。
5. **出报告**：签收后 48 小时内完成分级并推送。

## 二、检测工具与环境

检测工位需配备：防静电垫、放大镜（或微距镜头）、触点清洁棒、备用耳塞套（S/M/L 各尺寸）、充电线（Lightning / Type-C / Micro-USB 各一条）、无线充电板（如支持）、经校准的音频测试手机两台（分属 iOS 与 Android 阵营）。

环境要求：检测区须安静，以现场可辨细微底噪为准；无线连接测试避开高干扰时段。电池健康读取需使用品牌官方工具或经平台认证的第三方读取设备，截图存档。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 左右声道与配对稳定性 | 双耳及单耳均正常发声，10 分钟连接记录无异常断连 | 播放左右声道测试音频，各耳单独佩戴确认 | 单边无声音且原因不明 → 必拒；间歇断连 → 降级至 D 并显著披露 |
| 触控/按键功能 | 所有触控指令与物理按键响应正常 | 逐项执行播放/暂停、切歌、接听、语音助手指令各 3 次 | 多次失灵 → 降级至 D |
| 降噪与通透模式 | 降噪开启后环境噪声明显衰减，通透模式人声清晰可辨 | 标准化噪声源前主观对比记录，同一检测员完成 | 降噪失效 → 降级至 C 以下；档位无法切换（索尼降噪豆）→ 降级至 D |
| 通话麦克风 | 通话对方可清晰听到人声，无持续杂音 | 拨打测试电话，双方各通话 30 秒 | 拾音底噪明显 → 降级至 C；完全无声 → 必拒 |
| 充电盒续航与无线充电 | 充电盒可为耳机完整充电至少一次，无线充电（如支持）正常识别 | 满电充电盒放电至低电量再完整回充；无线充电测试 5 分钟确认识别 | 充电盒无法充电 → 必拒；无线充电不识别 → 降级至 C |
| 真伪鉴别 | 序列号三码合一（机身/包装/系统读取），苹果系弹窗识别正常 | 核对序列号路径：设置-通用-关于本机；包装盒贴纸与机身蚀刻比对 | 判定仿品或序列号不一致 → 必拒 |
| 电池健康（支持读取的机型） | S 级 ≥90%，A 级 80-89%；低于 80% 必须披露；低于 60% 拒收 | 品牌工具读取电池健康百分比，截图存档 | 电池鼓包 → 必拒；健康度低于 60% → 拒收 |
| 外观：耳壳划痕与油光 | S 级无可见划痕，A 级允许细微划痕 | 放大镜观察，侧光检查油光面积 | 油光面积超 1/3 → 降级至 C；深划痕贯穿 → 降级至 D |
| 外观：充电盒铰链松紧与磕碰 | 铰链开合顺畅无旷量，盒体无磕碰凹陷 | 开合 10 次感受阻尼；目视检查边角 | 铰链松旷或磕碰露底漆 → 降级至 C |
| 外观：触点氧化与耳垢残留 | 触点光亮无绿锈，耳垢不影响充电接触 | 放大镜观察金属触点；清洁棒轻拭耳垢 | 氧化严重 → 降级至 C；耳垢堵塞 → 清洁后复测 |
| 外观：耳塞套老化 | 无开裂、无发粘、无变形 | 目视 + 指压回弹测试 | 老化开裂 → 更换原尺寸耳塞套后复测，成本计入报告 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，塑封完整，配件包装齐全 | 原封盒装，封条完好 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 拆封试听一次，耳塞套无佩戴痕，电池健康 ≥90% |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 使用两周内，耳壳有细微划痕，电池健康 80-89% |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 使用半年，充电盒轻微磕碰不露底漆，耳塞套有正常佩戴痕 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 耳壳油光明显，铰链略松，触控偶发不灵敏但复测通过 |
| D（7成新及以下） | 较重磨损或局部功能瑕疵，必须显著披露 | 降噪失效、单耳间歇断连、循环次数超过 500 次 |

电池健康低于 80% 必须在报告中披露，低于 60% 直接拒收。循环次数超过 500 次须在报告中显著标注。进水标变色即判定进水，不论功能是否正常。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 六、报告字段与拍照取证要求

报告须包含以下字段：设备品牌型号、序列号与包装对版结果、外观成色等级、电池健康（支持读取的机型）、循环次数、功能检测逐项结论、拆修史与进水标状态、必拒情形（如有）、检测员编号与报告时间。电池健康低于 80% 或循环次数超过 500 次的，须在报告显著位置标注，不可仅以小字附注。

拍照取证不少于 6 张，覆盖：整机正面、耳壳左右各一、充电盒开合状态、触点与耳垢残留特写、序列号或系统读取截图。进水标变色、拆修痕迹、鼓包等异常必须单独加拍特写，照片需能对应到具体机身码。每张照片带时间水印，检测完成后统一归档，随报告留存备查。

## 七、常见争议与判定口径

**争议一：降噪效果主观差异大，买家认为"降噪无效"要求降级。** 判定口径：以标准化降噪对比测试为准，同一检测员在相同噪声源下完成主观记录，检测结果写入报告；买家个人感受不作为降级依据，但若测试确认降噪失效，按 C 级以下处理并披露。

**争议二：进水标变色但功能全部正常，能否按正常成色回收？** 判定口径：进水标变色即判定进水，不论功能是否正常，须在报告中显著披露并降级；隐瞒进水状态按隐瞒拆修同等处理。

**争议三：序列号对版但弹窗识别异常，如何定性？** 判定口径：序列号三码合一且系统读取正常，仅弹窗偶发不识别，按功能异常降级至 C 并披露；若系统读取的序列号与机身不一致，按仿品必拒处理。

**争议四：买家主张"单耳无声但送检时是好的"。** 判定口径：以验机仓检测记录为准，复检申请须在报告出具后 72 小时内提出，复检通过后寄回运费由送检方承担；超出时限或复检结果与初检一致的，维持原判定。
