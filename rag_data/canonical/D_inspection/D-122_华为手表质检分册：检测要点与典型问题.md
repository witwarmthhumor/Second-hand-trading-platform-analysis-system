# 华为手表质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于华为品牌智能手表（含 Watch GT、Watch 数字系列及 Pro 系列）的回收质检。收件后按以下步骤执行，全程在验机仓内完成：

1. **收件核验与登记**：签收后 30 分钟内完成运单核对、机身序列号与包装标签比对，登记表号、买家备注的特殊瑕疵声明。
2. **外观拍照**：表体正面、背面、四角、表带内外侧、表扣共 ≥6 张，微距补拍表镜边缘与充电触点。
3. **配对锁解除验证**：进入设置确认华为账号已退出、无查找设备锁定；无法当场解除的转入必拒流程。
4. **功能逐项检测**：按第三节表格逐项执行，心率/血氧/ECG 需与标准设备对比并记录误差。
5. **电池健康读取**：支持机型通过「设置-电池」或工程菜单读取最大容量，记录循环次数（如可读）。
6. **出报告**：签收后 48 小时内出具完整质检报告；卖家对结果有异议的，可在报告出具后 72 小时内申请复检，复检以复核记录与照片为准。

检测过程中发现进水标变色、拆修痕迹或配对锁未解除的，立即终止流程，按第五节处理。

## 二、检测工具与环境

检测台需配备：防静电垫、微距镜头或放大镜（用于表镜划痕与镀层检查）、标准心率/血氧参考设备、蓝牙配对测试手机（安装华为运动健康 App）、充电底座及数据线、干燥无尘的操作台面。

环境要求：光线均匀，避免强反光影响表镜拍照；操作台需铺软垫，防止表体磕碰。防水密封仅做外观检查与说明书口径核对，不做破坏性水测，不将手表浸入任何液体。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 表镜划痕与碎裂 | 无影响显示的划痕或碎裂 | 目视 + 微距拍照，斜光照射观察 | 碎裂影响显示 → 必拒；轻微划痕按 B/C 档降级 |
| 表壳磕碰与镀层脱落 | 无可见磕碰或脱落 | 目视四角与侧面，触摸感知 | 明显磕碰 → C 档以下；镀层成片脱落 → D 档 |
| 表带拉伸老化与异味 | 无断裂、无严重拉伸、无异味 | 拉伸表带观察回弹，嗅闻 | 老化开裂 → 更换后复检或降级；异味无法去除 → 降级并披露 |
| 充电触点氧化 | 触点无绿锈、接触良好 | 目视 + 充电测试 | 氧化影响充电 → 清洁后复测，仍异常 → 降级 |
| 心率/血氧/ECG | 与标准设备误差在可接受范围 | 佩戴对比测试，各测 3 次取均值 | 误差超出说明书范围 → 传感器模组失效 → 必拒 |
| GPS 定位 | 开阔环境 2 分钟内定位成功 | 户外或窗边实测 | 无法定位 → 功能异常，按 D 档披露或拒收 |
| 蓝牙连接与通话 | 连接稳定、通话清晰 | 配对测试手机拨号测试 | 断连或无声 → 降级并披露 |
| 防水密封 | 密封圈无老化、无拆修痕迹 | 外观检查 + 说明书口径核对 | 进水标变色 → 必拒；密封圈老化 → 降级披露 |
| 电池健康 | S 档 ≥90%；A 档 80-89% | 系统读取最大容量百分比 | <80% 必须披露；<60% 拒收；循环次数 >500 次显著标注 |
| 华为账号与配对锁 | 账号已退出、无查找设备锁定 | 设置-账号与设置-安全核查 | 未解除 → 必拒 |
| 表盘商店授权 | 无异常绑定或盗刷记录 | 查看表盘商店登录状态 | 异常绑定 → 清除后复检，无法清除 → 拒收 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N 全新 | 未拆封未使用，原厂贴膜完好 | 包装塑封完整，配件齐全 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 仅表带轻微佩戴纹，电池健康 ≥90% |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | 表壳细划痕 ≤1cm，电池健康 80-89% |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | 表镜 1-2 处细微划痕，表带轻微磨损 |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | 表壳磕碰可见但未伤屏幕，电池健康 <80% 已披露 |
| D 7成新及以下 | 较重磨损或局部功能瑕疵，必须显著披露 | 表带开裂、GPS 偶发失灵，需逐项列明 |

电池健康 <60% 直接拒收，不进入成色判定。循环次数超过 500 次的，无论成色档位，必须在报告显著位置标注。

## 五、必拒情形

出现以下任一情形，直接拒收并在报告中注明原因，不进入后续检测：

- 华为账号未退出或配对锁/查找设备锁定未解除
- 电池鼓包（目视或触摸可感知）
- 表镜碎裂影响显示
- 蜂窝版未解除运营商锁（如有 eSIM 绑定）
- 传感器模组失效（心率/血氧/ECG 无法读取）
- 进水标变色（不论功能是否正常）
- 任何拆修史隐瞒不报（拆修本身不必然拒收，但隐瞒即必拒）

## 六、报告字段与拍照取证要求

报告需包含以下字段：平台订单号、机身序列号、品牌型号、成色档位、检测项逐项结果、电池健康百分比及循环次数（如可读）、异常项描述与对应照片编号、必拒原因（如有）、复检申请截止时间。

拍照取证不少于 6 张，覆盖表体正面、背面、表带内外侧、表扣及充电触点；表镜划痕、表壳磕碰等异常部位须微距补拍，每处异常至少 1 张特写。进水标变色、拆修痕迹等必拒情形须单独拍摄并放大标注。照片在报告出具后至少保留至复检期结束，作为争议复核依据。

## 七、常见争议与判定口径

**争议一：卖家称"只是贴膜划痕，表镜完好"**。判定口径：撕膜后复拍表镜，划痕在玻璃本体上按表镜划痕处理，仅在贴膜上则不影响成色。依据：外观检测以表镜实际状态为准。

**争议二：买家收货后称"检测时没发现进水，用几天才坏"**。判定口径：以进水标颜色为准，变色即判定进水，不论功能当时是否正常，也不接受"延迟损坏"的说法。依据：进水判定以指示剂状态为唯一依据。

**争议三：卖家隐瞒拆修史，辩称"只是换过电池，不算维修"**。判定口径：任何拆修史必须写入报告，隐瞒即必拒，不因维修内容或质量而豁免。依据：拆修史披露义务不区分维修类型。
