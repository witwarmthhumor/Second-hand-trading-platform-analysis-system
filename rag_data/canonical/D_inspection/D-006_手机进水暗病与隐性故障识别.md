# 手机进水暗病与隐性故障识别

## 一、检测范围与流程

本手册适用于回收、寄卖、置换场景下所有品牌手机的进水暗病与隐性故障识别。进水是手机最隐蔽的杀手，外观完好不等于内部安全。验机仓签收后须在 48 小时内出具完整检测报告；买卖双方对结果有异议的，可在 72 小时内申请复检。

检测按以下编号步骤执行，每步均须留痕：

1. **收件核验与防拆封登记**：签收后 30 分钟内完成。核对序列号与运单信息，对机身封条、防拆贴拍照存档。封条破损的，立即单独记录并通知送检方。
2. **外观分级拍照**：正面、背面、四边、接口共拍不少于 6 张照片。强光侧照下捕捉细微划痕与磕碰。
3. **进水标检查**：逐一检查 SIM 卡槽、充电口、耳机孔（如有）内的进水指示标。进水标变色即判定进水，不论功能是否正常。此条没有例外。
4. **功能逐项检测**：按第三节明细表执行，覆盖屏幕、面容/指纹、传感器、音频、摄像头、充电等全部项目。
5. **电池健康与循环次数读取**：通过系统设置及诊断工具读取。循环次数超过 500 次必须在报告中显著标注。
6. **ID 锁/账户锁退出验证**：确认 ID 锁、激活锁均为关闭状态。
7. **出具报告**：签收后 48 小时内完成。报告含成色分级、异常项、进水判定结论与取证照片。

## 二、检测工具与环境

- 强光手电筒（侧照用）与放大镜，用于划痕、磕碰、进水标变色识别。
- 屏幕网格测试图，用于坏点与断触检测。
- 品牌诊断工具或系统内置检测页，用于读取电池健康度、循环次数。
- SIM 卡托取出针，用于检查 SIM 槽内进水标。
- 防静电工作台与手套，避免检测过程造成二次损伤。
- 检测环境光线均匀，避免反光干扰外观判断。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 进水标（SIM 槽/充电口/耳机孔） | 不变色 | 目视 + 强光侧照 | 任一变色即判定进水，进入必拒评估流程 |
| 屏幕坏点/色斑/断触 | 无坏点、无断触 | 网格法全屏 12 区域逐区点划 | 单区断触或坏点 >3 个降 1 级；大面积失灵计 D 级 |
| 面容 ID / 指纹解锁 | 10 次内成功 ≥9 次 | 实际录入并反复解锁 | 成功率不足即计功能异常，按隐性故障披露 |
| 电池健康度 | S 级 ≥90%，A 级 80–89% | 系统设置读取 + 诊断工具复核 | <80% 必须明示；<60% 必拒 |
| 循环次数 | ≤500 次 | 诊断工具读取 | >500 次显著标注，不影响分级但须披露 |
| 充电口/扬声器/振动/听筒/麦克风 | 全部正常 | 实际充电、播放、通话测试 | 任一异常须排查是否进水腐蚀所致 |
| 前后摄像头对焦与闪光灯 | 对焦迅速、闪光正常 | 实拍远近物体各 3 张 | 对焦迟疑或闪光不均，拆机排查进水痕迹 |
| 传感器（陀螺仪/指南针/距离感应） | 响应准确 | 系统诊断页逐项触发 | 失灵且伴随充电口腐蚀痕迹的，按进水暗病处理 |
| ID 锁/激活锁 | 必须为关闭 | 设置中核对 + 官方渠道查询 | 未退出即必拒 |
| 机身弯曲变形 | ≤1mm | 平台放置 + 塞尺测量 | >1mm 即必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封原盒，无任何使用痕迹 |
| S（99 新） | 极少使用痕迹，功能全部正常，无维修史 | 拆封试用，无划痕无磕碰 |
| A（95 新） | 轻微使用痕迹，无功能缺陷，无拆修 | ≤2 条发丝纹且不在显示区，可计 A 级 |
| B（9 成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 边框轻微磨损，屏幕无划伤 |
| C（8 成新） | 明显使用痕迹或轻微磕碰，功能正常 | 磕碰露底金属降 1 级；掉漆面积 >5mm² 计 C 级 |
| D（7 成新及以下） | 较重磨损或局部功能瑕疵，必须显著披露 | 背板任何裂纹计 D 级；进水标变色且功能异常即必拒 |

电池健康度不直接决定成色档位，但 S 级要求 ≥90%，A 级要求 80–89%。健康度 <80% 的，无论外观多新，必须在报告中显著明示。

## 五、必拒情形

以下情形出现任意一项，直接拒收并出具说明，不做降级处理：

- ID 锁/账户锁未退出。
- 电池健康度 <60%。
- 主板维修史未申报——任何拆修史必须写入报告，隐瞒拆修即必拒。
- 进水标变色且功能异常。
- 机身弯曲变形 >1mm。
- 序列号与机身或系统不一致。

进水标变色但功能正常的，不直接拒收，但必须降级至 D 级并显著披露进水史。主板维修史无论是否申报，一律按隐性风险重点复检。

## 六、报告字段与拍照取证要求

报告须包含以下字段，缺一不可：

- 设备序列号、品牌型号、送检方信息
- 成色分级（N/S/A/B/C/D）及判定依据
- 进水判定结论（进水/未进水/疑似进水）
- 电池健康度与循环次数
- 功能异常项清单及对应检测方法
- 拆修史与维修痕迹记录
- 必拒项触发情况（如有）
- 检测员签名与报告编号

拍照取证遵循以下口径：

- 外观照不少于 6 张：正面、背面、四边、接口各角度覆盖，强光侧照下拍摄划痕与磕碰细节。
- 进水标特写：SIM 槽、充电口、耳机孔逐一拍摄，变色与否均须留证。进水标变色即判定进水，不论功能是否正常，照片是唯一判定依据。
- 屏幕检测录屏或连拍：坏点、色斑、断触区域须在画面中可辨认。
- 电池健康页截图：含健康度百分比与循环次数，循环次数超过 500 次的须显著标注。
- 每个异常项至少 1 张能说明问题的照片，宁多勿少。
- 视频取证不少于 15 秒，覆盖面容 ID 录入、指纹解锁、扬声器外放等动态功能验证。

## 七、常见争议与判定口径

**争议一：进水标变色但功能全好，算不算进水？**

判定口径：算。进水标变色即判定进水，不论功能是否正常。功能正常的，不拒收，但降级至 D 级并显著披露进水史；功能异常的，直接必拒。依据：进水标是官方设计的不可逆指示物，变色说明设备曾接触液体，内部腐蚀风险无法排除。

**争议二：卖家说"只是换过电池"，要不要按拆修处理？**

判定口径：要。任何拆修史必须写入报告，隐瞒拆修即必拒。换电池属于拆修，须在报告中注明维修范围与时间；若检测中发现主板维修痕迹而送检方未申报，直接拒收。依据：拆修史影响防水性能与后续故障概率，隐瞒即视为恶意隐瞒风险。

**争议三：电池健康度刚好在临界值附近，买家不认可怎么办？**

判定口径：以诊断工具读取值为准，报告中同时附系统设置页截图与诊断工具读数截图。健康度 <80% 的必须明示，<60% 的必拒。循环次数超过 500 次的须显著标注，不因外观成色好而豁免。依据：报告须可复核，双源截图保证读数无法篡改。

**争议四：买家收到货后说"屏幕有暗病"，但报告里没有？**

判定口径：以签收后 48 小时内出具的检测报告为准。买家可在 72 小时内申请复检，复检由独立检测员执行。若复检确认报告遗漏异常项，检测费由检测方承担；若复检无异常，买家承担运费。依据：检测报告是交易双方共同认可的判定基准，复检是唯一的异议通道。
