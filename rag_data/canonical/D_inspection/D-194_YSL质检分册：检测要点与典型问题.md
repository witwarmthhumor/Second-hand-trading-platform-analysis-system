# YSL质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于 YSL（Saint Laurent）品牌箱包的全流程质检，覆盖收件核验、外观分级、真伪判定、报告出具四个环节。

流程按六步执行：

1. 收件核验与登记。验机仓签收后 30 分钟内完成拆箱核对，全程录像。
2. 外观分级拍照。不少于 8 张，含五金特写与内标烫金特写。
3. 身份卡/序列号/镭射标核验。YSL 无独立镭射标，以身份卡编号与内标烫金一致性为准。
4. 五金与皮质逐项检测。按第三部分明细表执行。
5. 真伪综合判定。双人复核，一人主检一人复检，结论不一致时以更严口径为准。
6. 出报告。签收后 48 小时内完成，异议可在 72 小时内申请复检。

## 二、检测工具与环境

- 检测台：白色无影灯台面，色温 5000K 以上，避免暖光掩盖皮质泛黄与五金氧化。
- 放大镜：10 倍以上，用于观察五金刻字边缘与内标烫金颗粒。
- 紫外灯：辅助判断皮质涂层修补与胶水残留。
- 卡尺：测量五金件厚度与刻字深度，用于对版比对。
- 标准比对样：品牌分册中存档的 YSL 正品五金与内标烫金参照图。
- 环境要求：通风良好，无异味干扰源。检测员不得使用香水或带香护手霜。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 内标烫金 | 烫金字体清晰完整，边缘无毛刺，字母间距与品牌数据库一致 | 10 倍放大镜观察 + 与参照图比对 | 烫金脱落/模糊为 A 级以下；字体形态不符直接判仿品 |
| 五金氧化 | 允许均匀轻微氧化，镀层无大面积剥落 | 目视 + 特写拍照 | 点状氧化可评 B；镀层脱落露铜评 C 以下；断裂判必拒 |
| 皮质划痕 | 表面细浅划痕，未伤及涂层 | 侧光目视 | 浅划痕≤3 处可评 A；贯穿涂层评 B 以下；主料破洞判必拒 |
| 四角磨损 | 无露料或仅轻微磨白 | 目视 + 手指触感 | 磨白不露料评 B；露料评 C 以下 |
| 拉链顺滑度 | 开合顺畅无卡顿，拉头无变形 | 往复开合 5 次 | 卡顿可润滑处理评 C；拉头断裂判必拒 |
| 身份卡一致性 | 编号与内标烫金编号完全一致 | 逐位比对 + 数据库查询 | 不一致且无法合理解释判必拒 |
| 内衬状态 | 无污渍、无破损、无异味 | 目视 + 嗅觉 | 局部污渍可清洁评 B；霉味/烟味超常规判必拒 |
| 附件清点 | 防尘袋、肩带、身份卡齐全 | 对照附件清单逐项勾核 | 缺失附件在报告中显著披露，不影响成色档位 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N 全新 | 未拆封未使用，配件包装齐全 | 专柜原袋未拆，身份卡塑封完好 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 仅试背一次，内标烫金无磨损 |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | 五金有极轻微氧化点，皮质无划痕 |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | 四角轻微磨白，内衬无污渍 |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | 五金镀层局部脱落，皮质有可见划痕 |
| D 7成新及以下 | 较重磨损或局部功能瑕疵，必须显著披露 | 五金大面积氧化，四角露料，需护理修复 |

任何拆修史必须写入报告，隐瞒拆修即必拒。护理修复后是否影响成色判定，按皮质老化与护理分册的可修复性分级执行。

## 五、必拒情形

以下情形出现任意一项，直接拒收并出具说明：

- 判定为仿品。内标烫金字体与品牌数据库逻辑矛盾，或五金对版明显不符。
- 主料破损。皮质破洞或开裂贯穿，无法通过护理修复。
- 五金断裂无法修复。如 YSL 经典 Cassandre 锁扣断裂。
- 强烈不可去除异味。霉味或烟味超常规，经通风处理后仍残留。
- 序列号与品牌数据库逻辑矛盾。身份卡编号与内标不一致，或编号格式不符合品牌年代规律。

## 六、报告字段与拍照取证要求

报告字段包括：商品编号、品牌、型号、成色档位、检测项明细、异常描述、附件清点结果、维修史声明、检测员与复核员签名。

拍照取证口径：

- 外观分级照片不少于 8 张，含正面、背面、底部、内里、五金特写、内标烫金特写。
- 五金氧化与皮质划痕必须单独特写，照片需能清晰分辨异常范围。
- 身份卡与内标编号需同框拍摄，证明一致性。
- 所有照片在签收后 48 小时内上传系统，与报告关联存档。

## 七、常见争议与判定口径

**争议一：五金氧化算不算使用过度？**

判定口径：YSL 五金氧化属通病，不单列扣档。点状氧化且镀层完好，按正常使用痕迹评 B；镀层脱落露铜评 C 以下；只有氧化伴随刻字模糊、对版不符时才升级为真伪疑点。依据：五金氧化通病已在品牌分册特殊检测点单列，与仿品刻字工艺缺陷区分处理。

**争议二：内标烫金轻微脱落，买家质疑成色虚标。**

判定口径：烫金脱落按面积与位置分级。字母边缘轻微磨损不影响识读，评 A 至 B；整行烫金模糊或缺失，评 C 以下并在报告中显著披露。若烫金字体形态与品牌数据库不符，不按磨损处理，直接判仿品必拒。依据：内标烫金是 YSL 真伪判定核心项，磨损降级与字体不符是两条独立路径。

**争议三：卖家称"仅专柜试背"，但身份卡塑封已拆。**

判定口径：塑封拆开即视为已使用，N 档不成立，按 S 档起评。若同时存在五金轻微氧化或内衬压痕，按实际痕迹逐项降档。身份卡编号与内标一致但塑封缺失，不影响真伪结论，仅在报告中注明附件状态。依据：N 档定义要求"未拆封未使用，配件包装齐全"，塑封拆开已破坏未使用前提。

**争议四：异味经通风处理后减弱，是否仍判必拒？**

判定口径：以通风处理后的残留强度为准。霉味或烟味经通风后明显减弱、不刺鼻，可评 C 以下并显著披露；处理两次后仍气味强烈，判必拒。买家对异味程度有异议时，以复检员嗅觉判断为准，必要时两人独立嗅闻后取更严口径。依据：必拒清单针对"强烈不可去除异味"，可去除异味不在必拒范围。
