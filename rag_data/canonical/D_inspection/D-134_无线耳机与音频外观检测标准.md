# 无线耳机与音频外观检测标准

## 一、检测范围与流程

无线耳机与音频品类覆盖 TWS 真无线耳机、头戴式耳机、有线 HiFi 耳机、蓝牙音箱及麦克风。检测按以下步骤执行，收件后 30 分钟内完成登记，签收后 48 小时内出具报告，买家对结果有异议可在 72 小时内申请复检。

1. **收件核验与登记**：核对订单信息、机身序列号与包装标签是否一致，记录快递外观状态。
2. **外观拍照**：耳机本体、充电盒、线材各角度拍摄，照片不少于 6 张。
3. **配对连接测试**：分别进行双耳与单耳配对，记录连接稳定性。
4. **功能逐项检测**：按品类执行对应功能项，见第三部分明细表。
5. **出报告**：签收后 48 小时内完成分级与报告输出。

各品牌分册另有特殊检测点，检测时须对照执行。检测结果与实物不符的，以实物为准并拍照留证。

## 二、检测工具与环境

检测环境要求安静、无强干扰，环境噪声建议控制在可进行主观听音对比的程度。工具准备如下：

- 配对测试用手机（iOS 与 Android 各一台），用于弹窗识别、App 配对及鸿蒙生态测试。
- 充电测试线材与无线充电板（如支持）。
- 序列号核验终端，用于三码合一比对与真伪鉴别。
- 耳塞套规整工具、清洁工具、防静电手套。
- 主观听音参考设备（用于降噪与通透模式对比）。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 耳壳划痕与油光 | 无明显划痕或仅细微痕迹 | 目测 + 侧光检查 | 划痕明显按 B/C 级降档；油光明显且面积大按 C 级 |
| 充电盒铰链松紧与磕碰 | 铰链开合顺畅、无松动异响 | 手动开合 5 次，观察阻尼 | 铰链松垮或磕碰变形按 C/D 级；无法正常闭合进入必拒 |
| 触点氧化与耳垢残留 | 触点光亮无氧化，无耳垢 | 目测 + 棉签轻拭 | 氧化可清洁的按 B 级；耳垢残留严重按 C 级并清洁后复检 |
| 耳塞套老化 | 无开裂、无发粘、无变形 | 目测 + 指压回弹测试 | 老化开裂须更换后重新评级，更换成本计入报告 |
| 左右声道与配对稳定性 | 双耳与单耳均配对成功，10 分钟连接记录无断连 | 播放测试音频 10 分钟，记录断连次数 | 单耳无法配对或频繁断连进入必拒 |
| 触控/按键功能 | 触控响应灵敏，按键回弹正常 | 逐项触发并观察响应 | 触控失灵按 C 级；完全无响应进入必拒 |
| 降噪与通透模式 | 降噪开启后底噪明显降低，通透模式语音清晰 | 主观对比记录，参照标准降噪对比测试口径 | 降噪失效按 C 级；模式切换异常按 C 级 |
| 通话麦克风 | 通话拾音清晰、无明显杂音 | 实际拨打通话测试 | 麦克风无声或严重杂音按 D 级 |
| 充电盒续航与无线充电 | 充电盒可正常充电并给耳机供电 | 有线充电测试，支持无线充的加测无线充电 | 无法充电进入必拒；无线充电失效按 C 级 |
| 真伪鉴别 | 序列号与包装对版、弹窗识别正常 | 核对序列号三码合一，苹果系执行弹窗识别 | 判定仿品进入必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 塑封完整、封条未损 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅拆封试听，耳塞套无使用痕迹 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 充电盒底部有极轻微摩擦痕 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 耳壳有细微划痕，不细看不可见 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 充电盒边角有磕碰掉漆，功能正常 |
| D（7成新及以下） | 较重磨损或局部功能瑕疵，必须显著披露 | 耳壳大面积油光且单侧触控失灵 |

电池健康参考通用阈值：S 级要求 ≥90%，A 级 80-89%，低于 80% 须披露，低于 60% 直接拒收。循环次数超过 500 次必须在报告中显著标注。进水标变色即判定进水，不论功能是否正常。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 五、必拒情形

出现以下任一情形，直接拒收并出具说明：

- 单边无声音且原因不明。
- 充电盒无法充电。
- 判定为仿品。
- 电池鼓包。
- 账号绑定设备未解除（如支持查找功能且被锁定）。

进水标变色即判定进水，不论功能是否正常，同样进入必拒。隐瞒拆修史一经发现，按必拒处理并记录。

## 六、报告字段与拍照取证要求

报告须包含以下字段：订单号、设备型号、序列号、成色等级、检测项结果明细、功能异常描述、电池健康（如支持读取）、维修史声明、进水标状态、照片附件。所有分级结论须对应到检测项明细，禁止无依据跳级。

拍照取证要求：

- 外观照片不少于 6 张，覆盖耳机左右耳、充电盒内外、铰链、触点、线材插头。
- 每张照片须清晰可辨，能对应到具体检测项。
- 异常项须单独放大拍摄，并在照片文件名中标注对应检测项。
- 视频记录不少于 15 秒，用于功能异常或争议项留证。

照片与视频作为报告附件存档，买家申请复检时以存档为准重新核验。

## 七、常见争议与判定口径

**争议一：降噪效果"明显变差"算不算功能缺陷？**

判定口径：降噪属主观体验项，仅凭买家主观感受不构成降噪失效。检测时须按标准降噪对比测试口径执行，在相同环境噪声下与参考设备对比，降噪开启后底噪无明显差异的，按正常处理；确无降噪效果的，按 C 级降档并披露。依据：降噪检测以标准化对比测试为准，不以个人感受为据。

**争议二：充电盒有磕碰但充电正常，买家要求按必拒退货？**

判定口径：必拒清单中的"充电盒无法充电"指功能性失效，外观磕碰不触发必拒。磕碰按成色判定表对应 C 级或 D 级降档，报告中如实披露磕碰位置与程度即可。依据：外观瑕疵与功能故障分开判定，必拒情形以功能失效为前提。

**争议三：进水标变色但功能全部正常，是否可按 S 级出售？**

判定口径：不可以。进水标变色即判定进水，不论功能是否正常，报告须如实记录进水标状态并降档处理，S 级与 A 级均要求无进水记录。依据：进水判定以进水标变色为准，与功能表现无关。

**争议四：序列号与包装对版但弹窗不识别，是否判定仿品？**

判定口径：弹窗识别受系统版本与连接状态影响，单独一项不构成仿品判定。须结合序列号三码合一、外观做工、充电盒内部刻印等综合核验；核验无误的按功能异常处理，核验存疑的进入必拒。依据：真伪鉴别以序列号对版与多维度核验结果为准，不以单一识别功能定论。
