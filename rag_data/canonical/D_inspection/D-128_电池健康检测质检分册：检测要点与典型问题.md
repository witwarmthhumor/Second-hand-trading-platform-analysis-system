# 电池健康检测质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册覆盖智能手表与穿戴设备电池健康检测全流程，适用 Apple Watch、华为手表、小米手环与手表、荣耀手表、三星手表、Garmin 等主流品牌。收件后 30 分钟内完成核验登记，签收后 48 小时内必须出报告。买家对报告有异议的，可在 72 小时内申请复检。

流程按六步走：

1. 收件核验与登记（30 分钟内完成）
2. 外观拍照（表体/表带/表扣合计 ≥6 张）
3. 配对锁解除验证
4. 功能逐项检测
5. 电池健康读取（仅限支持机型）
6. 出报告（签收后 48 小时内）

电池健康读取放在功能检测之后，是因为部分机型需要先完成配对才能读到健康数据。配对锁未解除的机器，直接进入必拒流程，不继续往下测。

## 二、检测工具与环境

检测工位需配备：支持各品牌协议的充电底座或数据线、配对用手机（iOS/Android 各一台）、标准心率血氧参考设备、GPS 信号测试环境（靠窗或室外）、放大镜或微距镜头（用于检查表镜细微划痕与电极片状态）。

环境要求：室温 15-28℃，避免阳光直射屏幕影响外观判断。充电触点氧化检查需在明亮光线下进行，必要时使用无水酒精棉签轻拭后再判断。所有检测设备每日开机自检一次，参考设备每季度送校准一次。不做破坏性水测，防水判断以外观检查与说明书口径核对为准。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 电池健康度 | ≥90% 为 S 级；80-89% 为 A 级 | 系统设置-电池-健康度读取 | 80% 以下必须披露；60% 以下直接拒收 |
| 循环次数 | ≤500 次 | 系统诊断页读取 | 超过 500 次必须在报告中显著标注 |
| 进水标 | 白色未变色 | 拆开表带槽查看进水指示器 | 变色即判定进水，不论功能是否正常，拒收 |
| 配对锁/激活锁 | 必须解除 | 与手机配对验证 | 未解除即拒收 |
| 心率/血氧/ECG | 与标准设备对比误差在允许范围 | 同时佩戴对比测量 | 误差超限或无法读数，按传感器模组失效拒收 |
| GPS 定位 | 室外 60 秒内锁定 | 户外实测 | 无法定位或漂移严重，降级至 D 并披露 |
| 蓝牙连接与通话 | 连接稳定、麦克风收音正常 | 与配对手机通话测试 | 断连或通话无声，按功能瑕疵降级 |
| 表镜划痕与碎裂 | 无影响显示的划痕或裂纹 | 强光下目视 + 微距检查 | 碎裂影响显示即拒收 |
| 表壳磕碰与镀层脱落 | 轻微使用痕迹可接受 | 目视 + 拍照记录 | 明显磕碰按 B/C 级判定，镀层大面积脱落降级 |
| 表带拉伸老化与异味 | 无断裂、无异味 | 拉伸表带目视 + 嗅觉 | 老化开裂或异味明显，需更换后重新判定 |
| 充电触点氧化 | 触点光亮无绿锈 | 目视 + 放大镜 | 轻度氧化可清洁复测；严重氧化影响充电则降级 |
| 表冠转动（Apple Watch） | 转动顺滑、无卡顿 | 手动转动表冠 | 卡顿或无法转动，按功能瑕疵降级 |
| 光学心率窗划痕（Garmin） | 无影响读数的划痕 | 强光下目视 | 划痕影响传感器读数，按传感器模组失效拒收 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N 全新 | 未拆封未使用，配件包装齐全 | 原封盒装，表带未上过手 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 仅拆封试戴，电池健康 ≥90%，循环 ≤500 次 |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | 表壳有极细发丝纹，电池健康 80-89% |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | 表带有轻微佩戴痕迹，表壳有 1-2 处微小磕点 |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | 表镜有可见划痕但不影响显示，表壳镀层局部磨损 |
| D 7成新及以下 | 较重磨损/局部功能瑕疵，必须显著披露 | 表壳多处磕碰，GPS 偶发失灵，电池健康低于 80% 已披露 |

电池健康度 80% 以下必须披露，60% 以下直接拒收，不进入成色判定环节。循环次数超过 500 次的，无论成色如何都要在报告中显著标注。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 五、必拒情形

出现以下任一情形，直接拒收并出具说明：

- 配对锁/激活锁未解除（含 Apple ID 激活锁、华为账号、小米账号、荣耀账号、Samsung 账号、Garmin Connect 账号未解绑）
- 电池鼓包
- 表镜碎裂影响显示
- 蜂窝版未解除运营商锁（如有）
- 传感器模组失效（含 ECG 电极片失效、光学心率窗损坏）
- 进水标变色（不论功能是否正常）
- 隐瞒拆修史

蜂窝版还需核对 eSIM 注销状态，未注销的需在报告中注明并联系卖家处理。Garmin 设备需确认 Connect 账号已解绑，否则新用户无法正常配对。

## 六、报告字段与拍照取证要求

报告必须包含以下字段：设备品牌与型号、序列号/IMEI（蜂窝版）、电池健康度、循环次数、成色等级、功能检测结果逐项、拆修史、进水标状态、配对锁解除状态、eSIM 注销状态（蜂窝版）、检测结论。

拍照取证要求：

- 表体/表带/表扣合计至少 6 张照片
- 电池健康度页面截图（支持机型）

## 七、常见争议与判定口径

**争议一：电池健康度处于 80% 临界值上下，买家对披露义务有异议**

判定口径：以读取数值为准，健康度低于 80% 即必须披露，不因"只差一点"或"功能正常"而豁免。依据：披露线是硬性阈值，与外观成色无关。

**争议二：进水标变色但功能一切正常，买家要求按正常机回收**

判定口径：进水标变色即判定进水，不论功能是否正常，直接拒收。依据：进水损伤具有滞后性，当前功能正常不代表后续不出现腐蚀短路。

**争议三：卖家声称"只是换过电池，不算拆修"**

判定口径：任何拆修史必须写入报告，换电池属于拆修，隐瞒即必拒。依据：拆修记录影响买家对设备内部状态的判断，不得以维修内容为由省略。

**争议四：循环次数超限但健康度仍高，成色如何定**

判定口径：循环次数超过 500 次必须在报告中显著标注，成色按实际外观与功能判定，但标注不可省略。依据：循环次数反映电池实际损耗历程，健康度只反映当前状态，两者需同时披露。
