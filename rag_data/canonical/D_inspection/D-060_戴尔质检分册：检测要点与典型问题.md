# 戴尔质检分册：检测要点与典型问题

## 一、检测范围与流程

戴尔分册适用于 RAGreflow 平台流通的戴尔品牌笔记本，含 XPS、Latitude、Inspiron、Alienware 等产品线。检测在验机仓完成，流程如下：

1. 收件核验与防拆封登记：签收后 30 分钟内完成，核对机身序列号与寄件单、平台订单三方一致，拍照留底后贴防拆贴。
2. 外观分级拍照：A 面（顶盖）、C 面（键盘面）、D 面（底盖）各拍不少于 2 张，含机身四角与转轴区特写。
3. 拆底盖核验：征得卖家同意后拆机，查硬盘/内存原装性、进水痕迹、螺丝动过痕迹。戴尔机型底盖螺丝多为 T5 内六角，滑丝是常见减分项。
4. 功能与压力检测：按第三部分明细逐项执行，高负载测试 15 分钟。
5. 电池循环与健康读取：用 SupportAssist 或 BIOS 内电池自检读取设计容量与当前容量，记录循环次数。
6. 账户/BIOS 锁退出验证：确认无戴尔账户锁、Windows 登录密码、BIOS 密码残留。
7. 出报告：签收后 48 小时内出具完整质检报告。卖家对结果有异议，可在报告出具后 72 小时内申请复检。

## 二、检测工具与环境

- 恒温干燥环境，避免静电环境拆机。
- 纯色显示测试软件（黑、白、红、绿、蓝 5 色），用于亮/坏点与均匀性判断。
- 外接 U 盘（含 Windows PE 或诊断镜像）、Type-C 扩展坞、HDMI 测试显示器、3.5mm 音频测试线。
- 扭矩螺丝刀套装（含 T5/T6 内六角与十字头），拆机时使用防静电手环。
- 高负载压力测试工具（如 AIDA64 / FurMark），记录 CPU/GPU 温度曲线与降频日志。
- 备用电源适配器，用于验证"无适配器且电池报废"类必拒情形。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| SupportAssist 硬件自检 | 全部项通过无报错 | 开机进 SupportAssist，运行"硬件扫描"完整项 | 报错项按严重度降级或必拒；电池报错需二次确认 |
| 服务标签核对 | 机身标签、BIOS、系统三处一致 | 查看 D 面标签，BIOS 内 System Information，系统内查询序列号 | 不一致即记录，疑似拼装/换壳，最高评 C |
| 屏幕亮/坏点与均匀性 | 纯色下无 >5 个坏点，无漏液 | 5 色纯色全屏目视 + 放大镜辅助 | 坏点 ≤5 个按位置降级；>5 个或漏液直接必拒 |
| 键盘全键与触控板 | 全键触发正常，无连击/失灵 | 按键测试软件逐键按压，触控板多点滑动 | 单键失灵评 C 以下；键盘整体更换史需披露 |
| 全接口插拔 | USB/HDMI/音频/读卡器全部识别 | 逐一插拔实测，Type-C 口测充电与 DP 输出 | 单口失灵评 C；影响开机使用的接口缺失按必拒处理 |
| 电池健康与循环 | S≥90%，A 80–89%；<80% 必须明示 | SupportAssist 读取设计容量与当前满充容量 | 循环 >500 次必须在报告显著标注；健康 <60% 必拒 |
| 高负载压力测试 | 15 分钟无异常关机，降频在正常范围 | AIDA64 单烤 FPU + GPU 双烤 15 分钟 | 过热关机/严重降频评 C 以下；风扇异响记录并降级 |
| 转轴阻尼与异响 | 开合 20 次无卡顿、无异响、无裂纹 | 手动开合 20 次，目视转轴区 | XPS 翻转本重点查转轴区裂纹，有裂纹即评 C 以下 |
| 系统/BIOS 锁退出 | 无账户锁、无 BIOS 密码 | 重启进 BIOS 查密码项，系统内查登录账户 | 任一锁未退出即必拒，不进入后续流程 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N 全新 | 未拆封未使用，原厂封条完好 | 整箱未开封，适配器与说明书齐全 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 拆封试机后回盒，A 面无划痕，电池循环 ≤5 次 |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | A 面 1–2 处细微划痕（<1cm），键盘无油光 |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | D 面脚垫轻微磨损，C 面键帽轻度油光 |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | 边角磕碰 ≤2 处，转轴区细微裂纹但开合正常 |
| D 7成新及以下 | 较重磨损/局部功能瑕疵，必须显著披露 | 屏幕 ≤5 个坏点，单 USB 口失灵，外壳多处明显划痕 |

电池健康阈值独立于外观成色：健康度 ≥90% 对应 S 级电池表现，80–89% 对应 A 级，<80% 必须在报告中明示具体数值。外观成色与电池健康分开评级，最终综合等级取两者中较低者。

## 五、必拒情形

出现以下任一情形，直接拒收，不进入后续检测流程，报告注明必拒原因：

- 系统/BIOS 锁未退出：含 Windows 登录密码、BIOS 密码、戴尔账户锁任一残留。
- 电池鼓包：目视底盖隆起或按压有异感即判定，不论功能是否正常。
- 主板进水或维修史未申报：进水标变色即判定进水；隐瞒拆修史即必拒。
- 屏幕漏液或大面积坏点：坏点 >5 个，或任何位置漏液。
- 配件缺失到影响开机：无电源适配器且电池报废，无法完成通电检测。

## 六、报告字段与拍照取证要求

报告必填字段：服务标签、产品线型号、外观成色（N/S/A/B/C/D）、电池健康百分比与循环次数、拆修史（有/无，有则写明部位）、功能异常清单、必拒原因（如适用）、综合判定等级。

拍照取证不少于 6 张，覆盖：A/C/D 三面各 1 张以上、服务标签特写、屏幕纯色测试实拍、拆机内部全景（进水标与螺丝位）、电池信息页。进水标变色、螺丝动过痕迹、循环次数超 500 次三项必须单独特写。视频取证不少于 15 秒，拍开机进系统与转轴开合过程。

## 七、常见争议与判定口径

**争议一：卖家称"只是清灰拆过机"，不算维修史。**
判定口径：任何拆底盖行为均属拆修史，必须写入报告。清灰属拆修，隐瞒即按必拒处理。依据：拆修史申报是平台强制项，不因维修内容豁免。

**争议二：电池健康低于 80% 但功能正常，买家要求按功能完好收货。**
判定口径：健康度 <80% 必须在报告中明示具体数值，外观成色不受影响，但综合等级需如实反映电池状况。依据：电池健康是独立于外观的评级维度，明示义务不可免除。

**争议三：SupportAssist 报错但机器实际使用无异常。**
判定口径：以 SupportAssist 硬件自检结果为准，报错项按严重度降级或必拒；电池类报错需二次确认后再定级。依据：自检结果是戴尔机型硬件状态的标准化依据，避免主观判断分歧。
