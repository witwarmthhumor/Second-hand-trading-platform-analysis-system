# 散热质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于风冷散热器、一体式水冷、分体水冷配件及风扇单品。检测按以下步骤执行，收件核验与登记须在签收后 30 分钟内完成，整机老化测试另见对应分册。

1. 收件核验与登记：核对寄件单与订单信息，记录散热器型号、扣具平台（Intel/AMD）、附件清单。
2. 外观拍照：散热器本体、风扇、扣具、背板、螺丝包逐件清点并拍照。
3. 通电点亮与功能测试：风扇转速、灯效、水泵运转状态。
4. 压力测试：风冷/水冷上机实测，记录满载温度与噪音。
5. 出报告：签收后 48 小时内出具完整质检报告。买家对结果有异议，可在报告出具后 72 小时内申请复检。

## 二、检测工具与环境

- 恒温环境：室温控制在 22-26°C，避免阳光直射与气流干扰。
- 测温设备：红外测温枪、热电偶温度计，用于热管与冷排表面温度抽测。
- 噪音计：距离散热器 30cm 处测量风扇全速运转噪音。
- 上机测试平台：标准 ATX 测试台，搭配已知良好 CPU 与主板，排除平台因素干扰。
- 目检工具：高亮度 LED 灯、放大镜，用于检查热管微裂纹与鳍片变形。
- 电子秤：用于称重核对散热器本体重量，辅助判断热管数量与冷排规格是否与标称一致。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 热管直触平整度 | 底座与热管接触面平整，无肉眼可见缝隙 | 目检 + 直尺贴合检查 | 不平整导致接触不良，降级或必拒 |
| 热管外观 | 无凹陷、无微裂纹、无氧化发黑 | 放大镜目检 | 单根热管凹陷 >1mm 判 C 级以下 |
| 鳍片状态 | 鳍片排列整齐，无大面积倒伏 | 目检 + 逐排拨动 | 倒伏超过 5 片且无法修复，降 B 级以下 |
| 扣具齐全度 | 对应平台扣具、背板、螺丝齐全且无滑丝 | 对照说明书逐件清点 | 缺件按平台标注披露，缺主扣具必拒 |
| 风扇运转 | 通电后转速平稳，无异响、无停转 | 上电实测 + 听诊 | 异响或停转，更换风扇后复测 |
| 风扇扇叶 | 扇叶无裂纹、无断叶 | 目检 + 轻拨转动 | 存在裂纹即判 C 级以下，断叶必拒 |
| 水泵运转（水冷） | 通电后水泵有稳定运转声，无高频啸叫 | 上电实测 + 噪音计 | 水泵不转或异响，判必拒 |
| 冷排密封性（水冷） | 接口无渗漏痕迹，管路无鼓包 | 目检 + 纸巾擦拭接口 | 任何渗漏痕迹即必拒 |
| 灯效功能 | RGB/ARGB 灯珠全亮，无暗珠 | 通电目检 | 单颗灯珠不亮可降级披露 |
| 硅脂残留 | 底座无旧硅脂残留，无刮擦伤 | 目检 | 残留需清理后复检，刮擦伤按面积降级 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N 全新 | 未拆封未使用，包装盒、附件、贴纸齐全 | 原封未拆散热器 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 上机点亮一次即拆下，底座无硅脂痕迹 |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | 底座有少量硅脂残留，鳍片无变形 |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | 风扇有轻微积灰，鳍片个别倒伏已修复 |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | 鳍片局部倒伏，扣具包装缺失但功能完好 |
| D 7成新及以下 | 较重磨损或局部功能瑕疵，必须显著披露 | 热管氧化明显，风扇轴承噪音偏大 |

水冷散热器因存在密封老化风险，成色判定整体从严一档。任何水冷若有过拆修史，必须写入报告，隐瞒拆修即必拒。

## 五、必拒情形

出现以下任一情形，直接拒收并说明原因：

- 冷排或管路存在渗漏、鼓包、接口变形。
- 水泵无法启动或运转时发出明显异响。
- 热管存在贯穿性裂纹或断裂。
- 风扇断叶或轴心歪斜导致运转卡滞。
- 扣具断裂、变形或关键螺丝滑丝，导致无法正常安装。
- 散热器底座严重变形，无法与 CPU 表面贴合。
- 隐瞒拆修史或进水史，进水标变色即判定进水，不论功能是否正常。

## 六、报告字段与拍照取证要求

质检报告须包含以下字段：散热器品牌型号、所属平台、散热类型（风冷/水冷）、热管数量/冷排规格、风扇数量与尺寸、扣具附件清单、外观瑕疵描述、功能测试结果（风扇转速、水泵状态、温度表现）、成色判定、必拒判定及原因。

拍照取证至少 6 张，覆盖以下角度：

1. 散热器整体正面照。
2. 底座接触面特写（展示热管直触状态与硅脂残留）。
3. 鳍片区域整体照（展示倒伏与变形）。
4. 风扇扇叶特写（展示裂纹与断叶）。
5. 扣具与附件全家福（展示齐全度）。
6. 水冷额外增加冷排接口与管路特写（展示渗漏痕迹）。

照片须清晰可辨，光线充足，能支撑报告中的每一项瑕疵描述。

## 七、常见争议与判定口径

**争议一：水冷散热器"轻微渗漏"是否可修复后放行？**

判定口径：不可修复，直接必拒。冷排或管路一旦出现渗漏痕迹，说明密封结构已失效，上机后存在损坏主板、显卡等其他硬件的风险。依据：本分册必拒清单明确"任何渗漏痕迹即必拒"，不以渗漏程度轻重作为区分。

**争议二：风扇异响但转速正常，能否按 B 级放行？**

判定口径：不可按 B 级放行。风扇异响通常指向轴承磨损或润滑油干涸，属功能性缺陷而非纯外观问题。若更换同规格风扇后复测无异响，可按更换后状态定级，但报告中须注明"风扇已更换"；若无法更换，按 C 级以下披露。依据：检测项明细表中"异响或停转，更换风扇后复测"的处置口径。

**争议三：散热器底座有旧硅脂残留，是否影响成色判定？**

判定口径：硅脂残留本身不构成功能缺陷，清理干净后复检，按清理后的底座状态定级。但若清理过程中发现底座存在刮擦伤，则须按刮擦面积降级披露，不得隐瞒。依据：检测项明细表中"残留需清理后复检，刮擦伤按面积降级"的判定标准。

**争议四：买家质疑"风扇灯珠有一颗不亮，为何只降一级不放行？"**

判定口径：单颗灯珠不亮属外观瑕疵而非功能失效，不影响散热性能，按降级披露处理即可。若灯珠不亮数量较多或灯效模式无法切换，则按功能缺陷处理，降级幅度加大。依据：检测项明细表中"单颗灯珠不亮可降级披露"的判定口径，灯效非散热核心功能，不触发必拒。
