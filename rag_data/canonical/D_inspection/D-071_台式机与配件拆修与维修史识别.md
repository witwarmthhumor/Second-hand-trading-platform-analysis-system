# 台式机与配件拆修与维修史识别

## 一、检测范围与流程

本分册覆盖整机（品牌机与 DIY 组装机）及 CPU、显卡、内存、硬盘、主板、电源、散热器、显示器、机械键盘等配件。拆修与维修史识别贯穿全流程，任何拆修痕迹必须写入报告，隐瞒拆修即必拒。

检测流程按五步执行：

1. **收件核验与登记**：签收后 30 分钟内完成，核对运单、序列号与寄件人申报。
2. **外观拍照**：配件逐件清点，拆修痕迹先于功能测试记录。
3. **通电点亮与功能测试**：按配件类型执行对应检测项。
4. **压力测试**：整机类执行连续运行 4 小时老化测试。
5. **出报告**：签收后 48 小时内出具，超时需报备原因。

买家对报告有异议的，可在报告出具后 72 小时内申请复检。复检通过时，二次寄送运费由买家承担。

## 二、检测工具与环境

- 防静电手环与防静电垫，拆装全程佩戴。
- 无尘操作台，温湿度维持适宜范围。
- 螺丝刀套装、塑料撬棒、硅脂与清洁工具。
- 万用表（电源输出电压测试用）。
- 纯色测试画面生成器（显示器检测用，5 色）。
- 压力测试软件：CPU 与显卡分别使用对应负载工具，内存使用 Memtest。
- 高倍放大镜或微距镜头，用于针脚、金手指与电容外观检查。
- 拍照设备：能清晰呈现螺丝划痕与贴纸破损。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| CPU 针脚 | 针脚无弯曲、无缺失 | 目视+放大镜逐排检查 | 缺失 >2 根即必拒；弯曲 ≤2 根可矫正后复测 |
| CPU 压力测试 | 主频稳定、温度正常 | 压力测试 10 分钟，记录主频与温度曲线 | 降频明显或温度异常即判功能缺陷 |
| CPU 拆修史 | 无开盖、无打磨痕迹 | 核对步进与盒装散装标签，检查顶盖边缘 | 有开盖或超频史痕迹即写入报告，降级处理 |
| 内存识别 | 全容量与双通道正确识别 | 开机进 BIOS 读取，再跑 Memtest 1 轮 | 识别容量不符或 Memtest 报错即判异常 |
| 内存颗粒 | 颗粒品牌与条数一致 | 目视颗粒编号，与 SPD 信息核对 | 混用颗粒或条数不符即写入报告 |
| 显卡 3D 测试 | 无花屏、无驱动崩溃 | 3D 压力测试 15 分钟，观察画面 | 花屏或驱动崩溃即必拒；虚焊史必拒 |
| 显卡拆修史 | 核心硅脂无更换痕迹 | 检查核心周围螺丝与硅脂颜色 | 有更换史即写入报告，按 D 档披露 |
| 硬盘 SMART | 健康状态正常 | 读取 SMART 信息与通电小时数 | 重映射扇区超阈值即必拒 |
| 硬盘异响 | 机械盘运行无异常噪音 | 通电听音，连续读写时监听 | 有异响即判功能缺陷，写入报告 |
| 主板电容 | 无鼓包、无漏液 | 目视电容顶部与底部 | 电容鼓包即必拒 |
| 主板接口 | 金手指无氧化 | 目视+放大镜检查 PCIe 与内存插槽 | 氧化明显即写入报告 |
| 电源输出 | 各路电压稳定 | 万用表测 +12V/+5V/+3.3V | 偏离规范即判异常 |
| 电源电容 | 无鼓包 | 开盖目视（需用户授权） | 鼓包即必拒 |
| 显示器纯色测试 | 无坏点、无亮斑 | 纯色 5 色逐一显示，近距离观察 | 坏点明显或亮斑可见即降级披露 |
| 显示器漏光 | 漏光不显著 | 全黑画面下目视四角 | 按轻微/明显/严重三级记录，严重即降级 |
| 整机老化 | 连续运行稳定 | 连续运行 4 小时，记录重启与蓝屏 | 期间出现任何崩溃即判不稳定 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封箱、静电袋未破 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 拆封点亮测试后即收纳 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 使用数月，外壳无可见划痕 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 有细微划痕但不影响观感 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 边角磕碰、贴纸残留 |
| D（7成新及以下） | 较重磨损或局部功能瑕疵，必须显著披露 | 有拆修史、硅脂更换史、超频史 |

电池健康度适用于含电池的整机或配件：≥90% 可评 S，80-89% 评 A，低于 80% 必须披露，低于 60% 拒收。循环次数超过 500 次必须在报告中显著标注。进水标变色即判定进水，不论功能是否正常，直接按必拒处理。

## 五、必拒情形

出现以下任一情形，直接拒收并说明原因：

1. 硬盘 SMART 报警（重映射扇区超阈值）。
2. 显卡花屏或存在虚焊史。
3. CPU 针脚缺失 >2 根。
4. 电源电容鼓包。
5. 整机无法点亮且原因不明。
6. 进水标变色（判定进水）。
7. 隐瞒拆修史，报告出具后发现未披露的拆修痕迹。

## 六、报告字段与拍照取证要求

报告必填字段：

- 设备类型、品牌、型号、序列号
- 检测结果与成色判定
- 拆修与维修史记录（含隐瞒必拒说明）
- 电池健康度（如有）与循环次数

## 七、常见争议与判定口径

**争议一：卖家称"只清灰，不算拆修"，报告怎么写？**

判定口径：凡打开机箱或配件外壳、动过螺丝或卡扣，一律记为拆修史，写入报告并降级披露。依据：任何拆修史必须写入报告，隐瞒拆修即必拒；清灰属于拆修，不因动机善意而豁免。

**争议二：进水标变色但功能测试全部通过，能否按正常成色收货？**

判定口径：不能。进水标变色即判定进水，不论功能是否正常，直接按必拒处理。依据：进水腐蚀具有滞后性，当前功能正常不代表后续稳定，按必拒清单执行。

**争议三：显卡核心硅脂有更换痕迹，但 3D 压力测试 15 分钟无花屏，如何定级？**

判定口径：功能合格但拆修史成立，按 D 档（7成新及以下）显著披露，不可按 A 或 B 档收货。依据：硅脂更换史属于拆修史，任何拆修史必须写入报告，降级处理不以功能测试通过为前提。

**争议四：买家对成色判定有异议，申请复检后结果不变，运费谁承担？**

判定口径：复检通过（即原判定无误）时，二次寄送运费由买家承担；复检推翻原判定则费用由平台或检测方承担。依据：复检申请时限为报告出具后 72 小时内，复检通过时买家承担二次寄送运费。
