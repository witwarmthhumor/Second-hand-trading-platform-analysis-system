# 奢侈品箱包拆修与维修史识别

## 一、检测范围与流程

奢侈品箱包检测覆盖皮质主料、五金件、内衬、肩带手柄、拉链磁扣及附件清点。拆修与维修史识别贯穿全程，凡涉及针脚重缝、五金更换、边油重封、内衬更换、皮质补色等痕迹，一律按维修史处理。

流程按以下步骤执行：

1. 收件核验与登记：签收后 30 分钟内完成，全程录像。
2. 外观分级拍照：不少于 8 张，含五金特写与四角磨损位。
3. 身份卡、序列号、镭射标核验。
4. 五金与皮质逐项检测，重点排查拆修痕迹。
5. 真伪综合判定：双人复核，意见不一致时升级复检。
6. 出报告：签收后 48 小时内完成。

买家对报告有异议的，可在报告出具后 72 小时内申请复检。复检结果维持原判的，往返运费由买家承担。

## 二、检测工具与环境

检测台配备白光灯与自然光双光源，照度需保证皮质纹理与五金刻字无反光死角。工具包括：高倍放大镜（用于观察针脚密度与走线均匀度）、紫外线灯（用于排查补色、胶水残留与镭射标贴异常）、游标卡尺（用于测量五金件厚度与刻字深度）、内窥镜（用于检查内袋夹层与包底边油状态）。

环境要求：温湿度相对稳定，避免阳光直射导致皮质颜色误判。检测全程录像，录像文件与报告编号绑定存档，保存周期以平台公示为准。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 针脚与走线 | 针距均匀，线迹与出厂一致，无线头外露 | 放大镜对比同品牌同款出厂线迹 | 针距不一致或线色偏差即判定拆修史 |
| 边油封边 | 边油连续无断点，颜色与出厂一致 | 观察边角与提手根部 | 边油重封痕迹明显即记维修史 |
| 五金件状态 | 镀层完整，刻字清晰，无更换痕迹 | 卡尺测厚度，对比刻字深度与字体 | 五金更换过即记维修史，断裂无法修复进必拒 |
| 皮质补色与护理 | 无补色痕迹，护理后不影响成色判定 | 紫外线灯照射，观察荧光反应 | 补色区域超 2 处即按维修史披露 |
| 内衬与隔层 | 内衬无更换、无破损 | 内窥镜查内袋夹层缝线 | 内衬更换即记维修史 |
| 拉链与拉头 | 拉链顺滑，拉头为原装 | 反复开合 5 次，观察拉头背面刻字 | 拉头非原装即记维修史 |
| 身份卡与序列号 | 编号与内标一致，无涂改 | 与品牌数据库比对 | 序列号逻辑矛盾进必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N 全新 | 未拆封未使用，配件包装齐全 | 专柜原封，防尘袋未展开 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 试背后存放柜中，五金无氧化 |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | 四角轻微磨白，手柄无汗渍 |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | 五金轻微氧化，内衬无污渍 |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | 四角露料，边油局部开裂 |
| D 7成新及以下 | 较重磨损或局部功能瑕疵，必须显著披露 | 皮质龟裂，五金镀层大面积脱落 |

有拆修史的箱包，成色上限为 C 级。即使外观接近 S 级，只要确认拆修，一律按 C 级及以下处理，并在报告中显著标注维修史详情。

## 五、必拒情形

出现以下任一情形，直接拒收并出具说明：

- 判定为仿品，或序列号与品牌数据库逻辑矛盾。
- 主料破损：面料破洞、开裂贯穿。
- 五金断裂且无法修复。
- 强烈不可去除异味：霉味、烟味超常规。
- 隐瞒拆修史：报告出具后发现未披露的维修痕迹，即必拒。

拆修史本身不构成必拒，但隐瞒拆修史构成必拒。检测中发现任何拆修痕迹，无论程度轻重，必须写入报告。

## 六、报告字段与拍照取证要求

报告字段包括：品牌与型号、序列号/镭射标编号、成色等级、拆修史详情（有/无及具体部位）、维修史描述、五金状态、皮质状态、内衬状态、附件清单、检测结论。

拍照取证不少于 6 张，覆盖：包身正面、包身背面、四角磨损位、五金刻字特写、内标与序列号、拆修痕迹部位。有拆修史的，需对维修部位单独加拍不少于 3 张特写，含针脚与边油细节。所有照片需在自然光下拍摄，不得使用滤镜。

## 七、常见争议与判定口径

**争议一：边油开裂后重新封边，算维修史还是护理？**
判定口径：边油重封属于维修史，须写入报告。依据：边油工艺涉及加热与刮刀处理，超出日常护理范畴，可能影响包身结构。

**争议二：五金自然氧化抛光后，是否需要披露？**
判定口径：仅抛光不更换五金，按护理记录备注，不记维修史。依据：五金氧化是自然老化，抛光不改变原装件属性。

**争议三：肩带更换算拆修还是配件缺失？**
判定口径：更换非原装肩带按拆修史处理；原装肩带缺失按附件不齐处理。依据：非原装肩带改变包身受力结构，且影响转售对版。

**争议四：补色面积很小，是否影响成色？**
判定口径：补色即记维修史，成色上限 C 级。依据：补色掩盖皮质真实状态，买家有权知悉原始磨损程度。
