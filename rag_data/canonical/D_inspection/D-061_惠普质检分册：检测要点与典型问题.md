# 惠普质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于惠普品牌全系笔记本电脑（Pavilion、Envy、Spectre、暗影精灵、星系列等）的回收质检。流程共七步，验机仓签收后 48 小时内必须出报告；有异议可在报告出具后 72 小时内申请复检。

1. **收件核验与防拆封登记**（30 分钟内）：核对序列号与订单一致，检查封条完好性并拍照留档。封条破损或 SN 不符的，暂停检测并上报。
2. **外观分级拍照**：A/C/D 面各拍 ≥2 张，转轴区单独加拍。环境光均匀，避免反光遮盖瑕疵。
3. **拆底盖核验**：征得同意后拆盖，检查硬盘/内存原装性、进水标颜色、螺丝拧动痕迹、主板维修残留。任何拆修史必须写入报告，隐瞒拆修即必拒。
4. **功能与压力检测**：按第三部分明细表逐项执行。
5. **电池循环与健康读取**：用 HP Support Assistant 或 BIOS 电池健康菜单读取。
6. **账户/BIOS 锁退出验证**：确认 Windows 账户、HP 账户及 BIOS 密码均已退出。
7. **出报告**：签收后 48 小时内完成全部检测并出具电子报告。

## 二、检测工具与环境

- 防静电桌垫与接地手环，拆机全程佩戴。
- 纯色测试图（黑/白/红/绿/蓝五色）、外接显示器、USB 测试盘、Type-C 扩展坞、测试耳机、双频 WiFi 环境。
- 拆机工具：塑料撬棒、精密螺丝刀套装；禁止磁性螺丝刀接触主板。
- 压力测试：HP 硬件诊断工具（UEFI 版）或同类烤机软件。
- 电池读取：HP Support Assistant 电池检查模块，或进 BIOS 查看电池健康菜单。
- 环境要求：温度、湿度控制在适宜电子设备运行的常规范围，照明均匀无强反光。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 屏幕显示 | 无亮/坏点，亮度均匀，无漏液 | 纯色 5 色全屏测试，逐色目视 | 漏液或坏点 >5 个即必拒；1–5 个按数量降级 |
| 转轴与开合 | 阻尼正常，无异响，无裂纹 | 开合 20 次测试，目视转轴区 + 手感 | 转轴区裂纹（惠普通病）即必拒；异响降级 |
| 键盘与触控板 | 全键触发正常，无连击 | 逐键按压测试，触控板全区域滑动 | 单键失效降级；连击超 3 键降级至 D |
| 接口功能 | USB/HDMI/音频/读卡器全部识别 | 逐一插拔，外接设备读写验证 | 任一接口失效降级；影响开机即必拒 |
| 无线与摄像头 | WiFi/蓝牙稳定，摄像头/麦克风正常 | 连接测试路由，视频通话实测 | 功能缺失降级至 C/D |
| 电池健康 | S 级 ≥90%，A 级 80–89%，<80% 必须明示 | HP Support Assistant 读取健康度与循环次数 | 循环 >500 次显著标注；健康 <60% 或鼓包必拒 |
| 压力测试 | CPU/GPU 温度正常，无明显降频 | 高负载烤机 15 分钟，记录温度曲线 | 过热关机或严重降频降级 |
| 系统与账户 | Windows/HP 账户、BIOS 密码均已退出 | 进系统验证，重启进 BIOS 验证 | 任一锁未退出即必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，包装配件齐全 | 原封箱未开，封条完整 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 拆封试用，A/C/D 面无可见划痕 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | A 面 1–2 处细微划痕，转轴无异常 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | C 面键帽轻微油光，D 面正常磨损 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | A 面明显划痕或一角磕碰，个别接口失效 |
| D（7成新及以下） | 较重磨损或局部功能瑕疵，必须显著披露 | 坏点 3–5 个，多处磕碰，电池健康 <80% |

电池健康单独执行：S 级 ≥90%，A 级 80–89%，低于 80% 必须显著披露并影响成色，低于 60% 直接拒收。

## 五、必拒情形

出现以下任一情形，直接拒收并在报告中注明：

- 系统/BIOS 锁未退出（含 HP 账户锁、Windows 密码、BIOS 密码）。
- 电池鼓包（目视底盖隆起或按压有弹性手感）。
- 主板进水或维修史未申报——进水标变色即判定进水，不论功能是否正常。
- 屏幕漏液或大面积坏点（>5 个）。
- 转轴区裂纹（惠普通病，Spectre 与 Envy 翻转本重点检查）。
- 配件缺失到影响开机（无电源适配器且电池健康已报废）。

## 六、报告字段与拍照取证要求

报告必填字段：设备 SN、外观成色（N/S/A/B/C/D）、屏幕状态、转轴状态、电池健康度与循环次数、拆修史（有/无）、账户锁状态、检测结论、拒收原因（如有）。

拍照取证：A/C/D 面各 ≥2 张，合计至少 6 张；转轴裂纹、进水标、电池鼓包、屏幕坏点等异常项必须单独特写加拍。照片需清晰可辨，能对应报告中的每一项判定结论。

## 七、常见争议与判定口径

**争议一：进水标轻微变色但功能全好，能不能按正常机收？**
不能。进水标变色即判定进水，不论功能是否正常，直接拒收。依据：进水腐蚀是渐进过程，当下功能正常不代表后续不返修，隐瞒进水风险由平台承担。

**争议二：卖家说"只是清灰拆过"，算不算拆修史？**
算。任何拆修史必须写入报告，隐瞒拆修即必拒。清灰、加装内存、换硅脂都属于拆修，卖家口头解释不作数，以底盖螺丝痕迹与内部残留为准。

**争议三：屏幕坏点 3 个，买家要求按 D 成色收货，怎么定？**
按数量与位置定级。坏点 >5 个才触发必拒；1–5 个按数量降级，3 个坏点落在屏幕边缘可按 C 成色处理，落在中央可视区则降一级。判定口径以拍照留档为准，避免口头争议。

**争议四：电池健康度与循环次数矛盾时听谁的？**
两个指标都要写，不互相替代。健康度低于 60% 直接拒收；循环次数超过 500 次必须在报告中显著标注。若健康度尚可但循环已超限，按循环标注并如实披露，不做主观折中。
