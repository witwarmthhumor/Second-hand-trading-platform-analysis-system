# 手机瑕疵描述术语与分级话术

## 一、检测范围与流程

问：一台手机从签收到出报告，要走完哪些步骤？

答：验机仓签收后按六步走，全程须在 **48 小时内** 出具报告。第一步，收件核验与防拆封登记，**30 分钟内** 完成，拆封前先拍快递面单与封条状态；第二步，外观分级拍照，正面、背面、四边、接口共 **≥6 张**，强光侧照找划痕；第三步，进水标检查，SIM 槽、充电口、耳机口如有进水标必须逐一查看；第四步，功能逐项检测，屏幕坏点、面容 ID、扬声器、摄像头对焦等按清单过；第五步，电池健康与循环次数读取；第六步，ID 锁/账户锁退出验证，确认关闭后出具报告。买家对报告有异议的，可在 **72 小时内** 申请复检，超时不再受理。

## 二、检测工具与环境

问：验机要备哪些工具，环境有什么要求？

答：工具上，至少备有强光手电或侧照灯（照划痕用）、显微镜或高倍放大镜（看镜片划痕与掉漆边界）、电池检测仪或读取电池循环次数的软件、SIM 卡槽探针、防静电手套。环境要求光线均匀，建议色温 5000K 左右的白色光源，避免黄光影响成色判断。桌面铺防滑垫，拆机工具与手机分开放置，防止磕碰。拍照背景统一为中性灰或纯白，不得使用滤镜或美颜。进水标变色与否，用裸眼加放大镜双重确认，拿不准就拍照留证。

## 三、检测项明细表

问：手机检测项那么多，每项合格线到底怎么定？

答：下表是手机品类通用检测项，标准列的数字均来自平台现行规则，未写明的以平台页面公示为准。

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 屏幕划痕 | ≤2 条发丝纹且不在显示区可计 A 级 | 强光侧照，沿屏幕 45° 角扫光 | 显示区划痕或超过 2 条降 1 级；深划痕计 B 级以下 |
| 边框磕碰 | 无露底金属 | 目测 + 手指触摸确认 | 磕碰露底金属即降 1 级；掉漆面积 >5mm² 计 C 级 |
| 背板裂纹 | 无任何裂纹 | 侧照 + 透光检查 | 任何裂纹计 D 级并显著披露 |
| 摄像头镜片划痕 | 中心区无划痕 | 放大镜观察镜片中心 | 中心区划痕降 1 级；边缘轻微划痕可计 A 级 |
| 屏幕坏点/色斑/断触 | 无坏点、无断触 | 网格法全屏 12 区域逐区触摸 | 任一区域断触计 D 级；坏点 ≥3 个降 1 级 |
| 面容 ID/指纹解锁 | 正常识别 | 录入后连续解锁 5 次 | 失败 2 次以上计 D 级，苹果面容 ID 模组异常必拒 |
| 电池健康 | S≥90%，A 80–89%，<80% 必须明示 | 系统读取或检测仪读取 | <80% 明示并降级；<60% 必拒 |
| 充电口/扬声器/振动/听筒/麦克风 | 功能正常 | 逐一插拔、播放、通话测试 | 单项失灵降 1 级；充电口接触不良计 C 级 |
| 前后摄像头对焦与闪光灯 | 对焦清晰、闪光正常 | 实拍远近各 3 张 + 闪光灯测试 | 对焦失败或闪光灯不亮降 1 级 |
| 传感器（陀螺仪/指南针/距离感应） | 数据正常 | 系统自带诊断或第三方工具 | 陀螺仪失灵计 D 级 |
| ID 锁/激活锁状态 | 必须为关闭 | 设置中查看并联网验证 | 未退出必拒 |

## 四、成色判定表

问：N、S、A、B、C、D 六档成色，落到手机上怎么对号入座？

答：先看功能再看外观，功能缺陷直接压档，外观瑕疵按表对照。电池健康是硬指标：S 档要求 **≥90%**，A 档 **80–89%**，低于 80% 必须明示，低于 60% 直接拒收。循环次数超过 **500 次** 的，无论成色多新，报告必须显著标注。

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封盒装，封条完好 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 拆封激活但贴膜使用，边框无痕 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | ≤2 条发丝纹且不在显示区，电池健康 80–89% |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 边框 1–2 处微小磕碰但不露底，屏幕细划痕在非显示区 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 掉漆面积 >5mm²，或边框露底金属但功能全好 |
| D（7成新及以下） | 较重磨损或局部功能瑕疵，必须显著披露 | 背板裂纹、摄像头对焦失败、电池健康 <80% 但 ≥60% |

## 五、必拒情形

问：哪些情况不用纠结，直接拒收？

答：出现以下任一情形即拒收，报告注明原因并附证据，不做降级处理：

- ID 锁/账户锁未退出，无法验证为关闭状态；
- 电池健康低于 60%；
- 主板维修史未申报，隐瞒拆修即必拒；
- 进水标变色且功能异常，进水标变色即判定进水，不论功能是否正常；
- 机身弯曲变形超过 1mm；
- 序列号与机身或系统不一致。

## 六、报告字段与拍照取证要求

问：报告要写哪些字段，照片拍够数就行吗？

答：报告字段必须完整，缺一项即退回补录。必填字段包括：机型与序列号、成色等级、电池健康百分比、循环次数（超过 500 次显著标注）、进水标状态、维修史声明、ID 锁状态、检测项逐项结果、异常描述与对应照片编号。任何拆修史必须写入报告，隐瞒拆修即必拒。

照片取证至少 **6 张**：正面、背面、四边、接口各一张，外加进水标特写与瑕疵部位特写。进水标变色、背板裂纹、边框露底等异常，必须单独加拍。每张照片需能看清序列号或机身特征，确保照片与机器一一对应。视频取证不少于 **15 秒**，围绕机身完整转一圈，瑕疵处停顿 2 秒以上。

## 七、常见争议与判定口径

问：屏幕划痕在显示区边缘，算不算 A 级？

答：不算。发丝纹只要落在显示区范围内，无论边缘还是中央，都按显示区划痕处理，降 1 级。依据是检测项表中"≤2 条发丝纹且不在显示区可计 A 级"的表述，显示区是硬边界。

问：电池健康刚好卡在临界值，怎么定级？

答：按区间下限执行。健康度低于 80% 必须明示并降级，低于 60% 必拒，不存在"差一点"的通融。读取数值以检测仪或系统读数为准，复检时以第二次读取结果为准。

问：进水标变色但功能全好，收不收？

答：收，但必须显著披露。进水标变色即判定进水，不论功能是否正常——功能正常可继续交易，只是成色按 D 级处理；若变色同时伴随功能异常，则进入必拒清单。

问：买家说边框磕碰是发货前就有的，怎么判？

答：以签收后 30 分钟内拍摄的拆封前照片为准。快递面单、封条状态、四边照片三样对得上，责任归买家；对不上或没拍全，按卖家描述不符处理。依据是流程第一步的收件核验与防拆封登记要求。
