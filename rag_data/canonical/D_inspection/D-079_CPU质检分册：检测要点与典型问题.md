# CPU质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于台式机与配件品类中的独立中央处理器，涵盖英特尔与锐龙各代桌面级型号，以及随整机一同送检的板载 CPU。CPU 是整机里最依赖交叉验证的部件，单看点亮不足以判定好坏，必须结合压力测试、温度表现与外观痕迹综合下结论。盒装、散装与拆机片在报告中分别标注，不混为一谈。

收件后 30 分钟内完成核验登记，核对型号、步进、序列号与卖家申报是否一致，随后依次执行：外观与针脚检查、平台点亮、识别信息核对、压力测试、温度与降频记录、超频痕迹排查、出报告。验机仓签收后 48 小时内出具报告，对结论有异议可在 72 小时内申请复检。

## 二、检测工具与环境

| 工具 | 用途 | 说明 |
| 兼容测试主板平台 | 点亮与稳定性测试 | 英特尔、锐龙各备一套插槽平台 |
| CPU-Z | 型号、步进、规格核对 | 与顶盖丝印逐项对照 |
| 压力测试软件 | 满载压测 | 单轮连续运行 10 分钟 |
| 温度监测软件 | 核心温度与频率记录 | 压测全程后台记录曲线 |
| 放大镜台灯 | 针脚、电容、触点检查 | 重点看针脚弯曲与缺失 |
| 防静电手环与绝缘垫 | 拿取防护 | 禁止徒手直接触碰针脚区 |

检测工位保持室温 18-26 摄氏度、通风干燥，散热器使用已知状态良好的参照件并均匀涂覆硅脂，排除散热安装不当对温度判断的干扰。压测前记录待机温度作为基线，避免把环境差异误判成 CPU 体质问题。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
| 型号与步进 | CPU-Z 识别与顶盖丝印、订单一致 | 软件识别加顶盖拍照对照 | 型号不符必拒，步进差异需如实标注 |
| 针脚与触点 | 无弯曲、无缺失、无氧化烧蚀 | 放大镜逐区检查 | 针脚缺失超过 2 根必拒，单根可修复降级 |
| 点亮识别 | 测试平台一次点亮、正常进系统 | 兼容主板上机实测 | 无法点亮交叉验证后仍失败必拒 |
| 压力测试 10 分钟 | 满载不降频异常、不报错、不关机 | 连续满载 10 分钟并记录曲线 | 中途报错或过热保护降级，反复关机必拒 |
| 核心温度 | 满载温度在参照散热合理区间 | 记录峰值与各核温差 | 温度异常偏高需排查开盖史并降级 |
| 主频与睿频 | 全核频率符合官方规格 | 压测中读取实际频率 | 长期锁低频需排查硬件故障并披露 |
| 超频痕迹 | 无人工加电压、开盖、剪脚痕迹 | 查 BIOS 记录、顶盖封漆与基板 | 有超频史必须披露，开盖更换硅脂按维修史标注 |
| 集成核显（如有） | 视频输出与硬件解码正常 | 不插独显接显示输出测试 | 核显失效降级并明示，影响整机定价 |

## 四、成色判定表

| 成色 | 外观特征 | CPU 细化口径 |
| N 全新 | 未拆封，盒装封条完整 | 原盒原码未上机，触点无压痕 |
| S 99新 | 极少使用痕迹 | 触点极轻压痕，顶盖无划痕，无超频史 |
| A 95新 | 轻微使用痕迹 | 顶盖轻痕，针脚触点完好，压测稳定 |
| B 9成新 | 正常使用痕迹 | 顶盖有正常压盖印，功能全部正常 |
| C 8成新 | 明显使用痕迹 | 单根针脚修复或轻微氧化已处理，压测稳定并披露 |
| D 7成新及以下 | 较重磨损或局部功能瑕疵 | 温度异常、超频史、多核温差大等必须显著披露 |

## 五、必拒情形

- 针脚缺失超过 2 根，或针脚区存在烧蚀、崩角；
- 兼容平台交叉验证后仍无法点亮；
- 压力测试 10 分钟内反复报错、过热关机或自动降频至异常水平；
- 型号与订单不符、顶盖丝印被打磨或篡改；
- 存在剪脚、飞线、硬改针脚等非原厂改动；
- 开盖更换核心或伪造顶盖，按假冒处理直接拒收。

## 六、报告字段与拍照取证要求

报告必含字段：品牌与型号、步进与批次、盒装或散装标识、成色结论、针脚状态、压测时长与峰值温度、全核频率、核显状态、超频与开盖史声明、瑕疵照片编号。拍照不少于 6 张，顶盖丝印、针脚或触点正反两面、基板边缘必须有特写。压测过程保留温度曲线截图，整机订单还需记录连续运行 4 小时老化测试的稳定性结果，CPU 在老化中的表现以整机报告为准。

## 七、常见争议与判定口径

问：单根针脚弯了掰回去还能算合格吗？答：修复后能稳定点亮、压测通过的，按 C 级降级并在报告写明修复史；针脚缺失超过 2 根或修复后仍接触不良的，直接拒收。

问：怎么区分原装硅脂痕迹和开盖更换？答：看顶盖封漆是否完整、基板与顶盖接缝有无撬动痕，原装压痕规则均匀，开盖件边缘常有撬印与残胶，一旦确认开盖按维修史处理。

问：压测温度偏高一定是 CPU 问题吗？答：不一定。先换参照散热、重涂硅脂复测，温度恢复正常即归为散热安装问题；更换参照件后仍显著偏高的，才计入 CPU 本体瑕疵并降级。
