# 箱包五金鉴定质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册覆盖奢侈品箱包及轻奢箱包的收件、检测、分级、出报告全流程。检测对象包括主料（皮质/帆布/老花）、五金件（拉链、磁扣、转锁、刻字牌）、内衬、肩带/手柄及附件。箱包品类与手机、腕表等共用验收节点：验机仓签收后 48 小时内出报告，异议可在报告出具后 72 小时内申请复检，复检通过后买家承担寄回运费。

检测流程固定六步，全程录像存档：

1. 收件核验与登记：签收后 30 分钟内完成，核对订单与封箱状态。
2. 外观分级拍照：不少于 8 张，含四角、内衬、手柄、五金特写。
3. 身份卡/序列号/镭射标核验：核对内标、身份卡、序列号三者一致性。
4. 五金与皮质逐项检测：按第三部分明细表执行。
5. 真伪综合判定：双人复核，结论不一致时提交组长裁决。
6. 出报告：签收后 48 小时内推送电子报告。

## 二、检测工具与环境

检测台配备白光光源与放大镜，色温恒定，避免自然光干扰成色判断。五金镀层对比需使用放大镜观察刻字边缘与电镀层断面。皮质老化判定需配备湿度计，环境湿度需稳定，湿度过高影响皮质手感判断。拍照设备需支持微距模式，五金特写必须开启。所有操作佩戴洁净手套，避免汗渍二次污染。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 皮质划痕/磨白/龟裂 | 无明显划痕或仅局部轻微磨白 | 目视 + 手指触感，按区域记录 | 手柄/边角磨白露料判 C 级起；龟裂贯穿主料判必拒 |
| 四角磨损 | 四角无露料，允许极轻微磨白 | 目视对比左右对称性 | 磨白可护理修复按 B/C 分级；露料判 C 级以下 |
| 内衬污渍与异味 | 内衬洁净无异味 | 目视 + 嗅觉，重点查底部边角 | 霉味/烟味超常规且不可去除判必拒 |
| 五金镀层脱落与氧化 | 镀层完整，允许自然氧化 | 放大镜观察 + 棉签轻拭 | 局部脱落按面积分级；断裂无法修复判必拒 |
| 拉链顺滑度与拉头完整性 | 开合顺畅，拉头无变形 | 全程开合 3 次，察阻力听声音 | 卡顿需润滑判 C 级；拉头断裂判必拒 |
| 磁扣/转锁开合 | 开合到位，无松旷 | 反复开合 5 次 | 磁力明显衰减需维修判 D 级披露 |
| 五金刻字清晰度与工艺对版 | 刻字清晰、字体符合品牌工艺 | 放大镜对比品牌标准字库 | 刻字模糊或不对版，结合其他项判仿品 |
| 身份卡编号与内标一致性 | 内标、身份卡、序列号编号一致 | 逐一核对三项 | 不一致且无法解释判仿品或必拒 |
| 附件清点 | 防尘袋/肩带/小票齐全 | 对照订单附件清单逐项勾选 | 缺失附件在报告中显著标注，不影响成色但影响定价 |

品牌分册另有特殊检测点：LV 查老花对花位与 Date code 格式；Gucci 查双 G 五金对版；Chanel 查镭射标贴、身份卡与菱格走线；Hermès 查工匠刻印与手缝鞍线；Celine 按凯旋门五金年代断代。轻奢箱包按通用对版点速查执行。

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N 全新 | 未拆封未使用，配件包装齐全 | 专柜原封，防尘袋未打开 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 仅试背一次，五金无氧化 |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | 边角极轻微磨白，五金自然氧化 |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | 手柄轻微汗渍变色，内衬局部微污 |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | 四角磨白露料，五金镀层局部脱落 |
| D 7成新及以下 | 较重磨损/局部功能瑕疵，必须显著披露 | 拉链卡顿需维修，皮质龟裂未贯穿 |

皮质老化与护理按可修复性分级：可护理恢复的划痕与氧化不影响原级判定；护理后仍留痕迹的按程度降级。护理本身不视为拆修，但需在报告备注"经护理处理"。

## 五、必拒情形

出现以下任一情形，直接拒收并出具说明，不进入成色判定：

- 判定为仿品，含五金刻字工艺与品牌数据库逻辑矛盾。
- 主料破损：面料破洞或开裂贯穿。
- 五金断裂无法修复：拉头断裂、转锁结构损坏、刻字牌脱落无法复原。
- 强烈不可去除异味：霉味、烟味超常规，经护理无法消除。
- 序列号与品牌数据库逻辑矛盾：Date code、镭射标编号与产地规则冲突。

隐瞒拆修史即必拒。检测发现任何拆修痕迹，无论功能是否正常，必须写入报告；送检方未申报而检测发现的，直接按必拒处理。

## 六、报告字段与拍照取证要求

报告按固定字段输出，缺项不出仓：订单号、品牌与型号、序列号/身份卡编号、成色判定、检测结论、异常项明细、附件清点结果、检测人与复核人签名。拆修史、护理史、附件缺失三项必须显著标注，不得以脚注或小字带过。

拍照取证不少于 6 张，实际按品类加拍：包体正面、背面、底部四角、内衬全貌、手柄/肩带、五金件特写各成一张。五金特写必须开启微距，刻字、镀层脱落、氧化点位逐一单独成图，不拼图不裁切。皮质划痕与龟裂需放一把直尺作参照，确认真实尺寸。进水标变色即判定进水，不论功能是否正常，变色点必须留图。所有照片在检测完成后当日归档，与报告编号绑定，保存期限以平台公示为准。

## 七、常见争议与判定口径

**争议一：五金氧化算瑕疵还是自然老化。** 判定口径：镀层完整、仅表面氧化变暗的按自然老化处理，不影响成色；镀层起皮、脱落露底材的按外观瑕疵分级。依据：氧化可护理恢复，脱落不可逆。

**争议二：护理后能否恢复原成色。** 判定口径：护理只去除表面污渍与浅划痕的，维持原级；护理磨薄了皮质或改变了五金原色的，按处理痕迹降级。依据：护理后是否影响成色判定按可修复性分级执行。

**争议三：身份卡与内标编号不一致。** 判定口径：先查品牌数据库核对序列号规则，编号本身矛盾且无法解释的判必拒；仅身份卡遗失、内标清晰可核的，不判仿品，在报告中显著标注附件缺失。依据：序列号与品牌数据库逻辑矛盾即必拒，附件缺失不影响成色但影响定价。

**争议四：轻微使用痕迹的成色边界。** 判定口径：手柄汗渍变色、内衬局部微污归 B 级；四角磨白露料、五金镀层局部脱落归 C 级。依据：按成色判定表逐项对照，不跨级合并。
