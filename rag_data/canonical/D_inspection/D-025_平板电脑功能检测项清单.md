# 平板电脑功能检测项清单

## 一、检测范围与流程

本清单适用于进入回流二手验机仓的全部平板电脑，覆盖 iPad、安卓各品牌平板与学习平板，是平板电脑品类功能检测的逐项执行表。外观分级与成色判定另见外观与成色分册，本篇只对功能负责，每一项都要留下可复核的检测记录。

收件后 30 分钟内完成核验登记，随后按七步执行：外观分级拍照、进水标检查、屏幕与触控检测、通信与音频检测、电池健康读取、配件连接与账户锁验证、出具报告。验机仓签收后 48 小时内出具质检报告；买卖双方对结论有异议的，可在报告出具后 72 小时内申请复检，复检以首次签收时的检测基准为准，不因为复检而重新起算时限。

## 二、检测工具与环境

| 工具 | 用途 | 环境要求 |
| 网格测试图 | 全屏触控分区检测 | 标准分辨率铺满屏幕 |
| 纯色测试页 | 坏点、色斑、背光与压伤排查 | 黑白红绿蓝逐色切换 |
| 蓝牙键盘与手写笔 | 配件配对与连接压感测试 | 每工位各备一套通用件 |
| 千兆有线网络与备用热点 | 蜂窝版、WiFi 版联网验证 | 网络稳定，便于账户状态在线核验 |
| 充电线与功率表 | 充电电流与接口实测 | 匹配各品牌充电协议 |

检测工位保持室温 18-26 摄氏度、通风干燥，屏幕检测避开强光直射与灯光反光。涉及电池健康读取的机型，检测前先把电量充到便于读数的区间，避免低电量下读数漂移。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
| 屏幕显示 | 无坏点色斑、无漏液、亮度均匀、原彩正常 | 纯色五色全屏切换，侧视看压伤与光斑 | 显示区坏点按数量降级，漏液扩散中直接计 D 级并必拒 |
| 全屏触控 | 全屏响应无断触，边缘手势正常 | 网格法划过全部 16 个区域，逐区补测 | 局部断触降级并明示，整屏断触必拒 |
| 手写笔与压感 | 配对顺畅、压感连续、无断连 | 手写笔配对后画线与倾斜书写 | 压感断档降级，完全无法配对按配件缺失处理 |
| 外接键盘 | 配对稳定、按键全触发、转轴正常 | 连接键盘逐键测试并反复开合 | 单键失灵降级，连接不稳需在报告写明 |
| WiFi 与蓝牙 | WiFi 联网稳定，蓝牙配对正常 | 连接路由与耳机各实测一次 | 单功能失效降级，通信模块整体故障必拒 |
| 蜂窝网络（如支持） | 识别 SIM、可注册网络 | 插测试卡核验 eSIM 或实体卡槽 | 蜂窝故障且无法修复必拒，并标注版本类型 |
| 扬声器与麦克风 | 各声道出声清晰、录音回放正常 | 多声道逐个播放，录音后回放 | 单声道失声降级，全部无声必拒 |
| 前后摄像头 | 对焦正常、无霉斑、闪光灯可用 | 远近景各拍一组并录像 | 镜片霉斑降级，无法成像必拒 |
| 电池健康 | S 级不低于 90%，A 级落在 80-89% | 系统设置或诊断工具读取 | 低于 80% 必须明示，低于 60% 必拒 |
| 充电与接口 | 插拔稳定、充电不中断 | 功率表实测充电曲线 | 接触不良降级，完全无法充电必拒 |
| 账户与激活锁 | 全部账号退出、可恢复出厂 | 现场退出并恢复出厂实测 | 任一账号锁未退出必拒 |
| 传感器 | 重力感应、距离与光线感应正常 | 横竖屏切换与通话遮挡测试 | 单项失灵降级并逐项标注 |

## 四、成色判定表

| 成色 | 外观特征 | 平板细化口径 |
| N 全新 | 未拆封未使用，配件齐全 | 封膜完整，未激活或激活未使用 |
| S 99新 | 极少使用痕迹，功能全部正常 | 屏幕无划痕，电池健康不低于 90%，无拆修 |
| A 95新 | 轻微使用痕迹，无功能缺陷 | 非显示区极轻发丝纹，电池健康 80-89%，无拆修 |
| B 9成新 | 正常使用痕迹 | 边框轻微磕碰不露底金属，功能全部正常 |
| C 8成新 | 明显使用痕迹或轻微磕碰 | 背板平测弯曲在允许范围内并记录，功能正常 |
| D 7成新及以下 | 较重磨损或局部功能瑕疵 | 屏幕压伤、局部断触等，必须显著披露 |

电池健康与成色联动：健康度不低于 90% 才可以评 S 或 A；落在 80-89% 的，成色最高评到 B；低于 80% 的无论外观多新都要在报告显著位置写明，并把读数截图留档。支持读取循环次数的机型，循环超过 500 次必须显著标注。

## 五、必拒情形

出现下列任一情形，直接拒收并在报告注明依据，不进入议价与上架环节：

- 账户锁、激活锁或家长控制未解除、无法恢复出厂；
- 电池健康低于 60%，或电池鼓包顶屏；
- 屏幕漏液处于扩散中，或显示区出现大面积坏点；
- 主板维修史未申报，进水标变色且伴随功能异常；
- 整屏触控失灵、蜂窝版无法注册网络且无法说明原因；
- 机身序列号与系统信息、卖家申报不一致。

## 六、报告字段与拍照取证要求

质检报告必含字段：成色结论、逐项功能检测结果、电池健康读数与循环次数、账户锁退出状态、配件配对结果、维修史声明、瑕疵照片编号。拍照不少于 6 张，正面亮屏、背面、四边、接口与卡槽必须入镜，屏幕瑕疵要在纯色背景下单独拍摄。开机演示视频不少于 15 秒，画面中要完整呈现触控划屏与一次解锁过程。任何瑕疵结论都要有对应编号的照片支撑，不允许出现无照片依据的口头判定。

## 七、常见争议与判定口径

问：电池健康刚好压在 A 档下限附近怎么判？答：以系统读数为准，落在 80-89% 区间即按 A 档电池口径处理，一旦读数低于区间下限就按披露口径降级，不做四舍五入。

问：手写笔是卖家后配的，影响检测吗？答：主机与原装配件分开判定，后配手写笔只验证能否配对使用，并在报告注明非原装，不把配件成色算进主机。

问：学习平板解除家长控制后还算功能正常吗？答：解除家长控制、恢复出厂后能正常进入系统即按正常处理；无法解除、预装课程授权无法剥离的，按账户锁未退出处理。
