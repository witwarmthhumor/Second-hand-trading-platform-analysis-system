# PS4质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于回流二手验机仓承接的 PlayStation 4 全系列，包含初代厚机、PS4 Slim 与 PS4 Pro 的光驱版，以及随附的 DualShock 4 手柄、电源线、HDMI 线与原装手柄线。PS4 采用光驱与硬盘双仓结构，相比其他主机更要重点查验光驱读盘、风扇噪音与硬盘更换史，Ban 机状态一律在线核验，不接受离线截图作为依据。

收件后 30 分钟内完成核验登记，核对机身序列号、型号与容量是否与订单一致，缺少电源线导致无法开机的直接进必拒清单。检测按七步走：外观逐件拍照、Ban 机在线核验、开机自检与系统版本、光驱读写测试、硬盘与扩容查验、手柄专项检测、出报告。验机仓签收后 48 小时内出具报告，对结论有异议可在 72 小时内申请复检。

## 二、检测工具与环境

| 工具 | 用途 | 说明 |
| 正版蓝光测试碟 | 光驱读盘与噪音测试 | 准备无划痕测试盘一张 |
| 千兆有线网络 | Ban 机在线核验 | 必须有线联网，避免无线波动误判 |
| HDMI 测试线与显示器 | 画面输出验证 | 确认主机接口而非线材问题 |
| 移动硬盘 | 扩容与外接识别测试 | 验证 USB 存储功能 |
| 软毛刷与气吹 | 散热口积灰检查 | 只清理表面，不拆内部 |
| 手柄摇杆测试工具 | 摇杆漂移量化 | 静置读数与画圈测试结合 |

工位保持室温 18-26 摄氏度、通风干燥。主机检测前先静置适应环境温度，风扇噪音判断要在冷机与热机两种状态下分别记录，避免把刚开机的风扇转速当成异常。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
| 开机自检与系统版本 | 正常进主界面、可登录官方账号 | 通电开机并记录系统版本 | 无法开机必拒，版本异常需排查破解 |
| Ban 机核验 | 在线功能正常、账号可登录商店 | 有线联网测试多人与商店功能 | 在线功能永久封禁且未申报必拒 |
| 光驱读盘 | 正版碟秒读、安装与读取稳定 | 放入测试碟观察读盘与噪音 | 光驱无法读盘必拒，挑盘降级并披露 |
| 硬盘与容量 | 容量与型号标注一致、无坏道告警 | 系统存储信息加健康检测 | 换过硬盘必须披露，存在坏道必拒 |
| 风扇噪音 | 冷机安静、热机无异响啸叫 | 双状态听辨并录音留档 | 啸叫、打叶声按风扇老化降级 |
| HDMI 与音频 | 画面输出稳定、声音无杂音 | 换线交叉验证接口 | 接口脱焊导致无画面按 D 级处理 |
| USB 与手柄连接 | 接口识别正常、手柄可有线连接 | 逐个 USB 口插测 | 单口失效降级并明示 |
| 手柄摇杆 | 静置 5 秒位移不超过 2% | 平放静置读数加画圈测试 | 静置位移持续超过 2% 未披露必拒 |
| 手柄按键与震动 | 全键触发、触控板可用、震动正常 | 逐键测试并触发震动 | 单键失灵或无震动降级 |
| 手柄电池 | 续航与充电正常，健康度达标 | 充电后记录掉电速度 | 健康度低于 80% 明示，低于 60% 必拒 |

## 四、成色判定表

| 成色 | 外观特征 | PS4 细化口径 |
| N 全新 | 未拆封未使用，封条与配件齐全 | 整箱未开，原装塑封完整 |
| S 99新 | 极少使用痕迹，功能全部正常 | 外壳无可见划痕，散热口基本无灰，无拆修 |
| A 95新 | 轻微使用痕迹，无功能缺陷 | 表面极轻擦痕，光驱与硬盘均为原装，无拆修 |
| B 9成新 | 正常使用痕迹 | 外壳细划、手柄按键轻度磨损，功能正常 |
| C 8成新 | 明显使用痕迹或轻微磕碰 | 外壳泛黄、散热口积灰明显，换过硬盘已披露 |
| D 7成新及以下 | 较重磨损或局部功能瑕疵 | 风扇异响、手柄轻微漂移未超阈值等必须显著披露 |

DualShock 4 手柄内置电池参照通用阈值：健康度不低于 90% 可评 S 级，落在 80-89% 评 A 级，低于 80% 必须披露，低于 60% 直接拒收；循环次数超过 500 次显著标注。

## 五、必拒情形

- Ban 机未申报，在线功能被永久封禁，无论离线功能是否正常；
- 破解、硬降或改装机冒充原装机出售；
- 光驱无法读取正版光盘，或光驱仓结构损坏；
- 手柄摇杆静置位移持续超过 2% 且卖家未披露；
- 硬盘存在坏道告警，或扩容后无法稳定运行；
- 缺电源线等关键配件到无法开机，进水标变色且功能异常。

## 六、报告字段与拍照取证要求

报告必含字段：型号（厚机或 Slim 或 Pro）、机身序列号、标称与实际容量、系统版本、Ban 机核验结果、光驱测试结果、风扇噪音记录、硬盘更换史、手柄检测数据（含摇杆静置位移）、成色结论、必拒或通过结论。拍照不少于 6 张，主机正面、背面序列号、双仓开盖、散热口、手柄正面与摇杆特写必须入镜。手柄摇杆检测录制不少于 15 秒视频，清晰呈现静置状态与系统读数。

## 七、常见争议与判定口径

问：风扇声音大是不是一定老化？答：分情况。冷机安静、热机风量增大属正常散热调度；任何状态下都有啸叫、打叶声或节奏异响，才按风扇老化降级，结论以录音留档为据。

问：卖家自己换过固态硬盘算维修吗？答：算可披露的更换史而非故障，但必须写明硬盘品牌容量与更换原因，健康检测通过可以正常评级，隐瞒更换按描述不符处理。

问：离线状态下卖家出示的未封禁截图能采信吗？答：不采信。Ban 机状态必须在验机仓有线联网现场核验，离线截图无法反映账号与主机的实时状态。
