# 智能手表与穿戴外观检测标准

## 一、检测范围与流程

智能手表与穿戴设备（含 Apple Watch、华为手表、小米手环与手表、荣耀手表、三星手表、Garmin 等品牌）的回收检测，从验机仓签收起算，须在 48 小时内出具检测报告。买家或卖家对报告有异议的，可在签收报告后 72 小时内申请复检。流程按以下编号步骤执行：

1. **收件核验与登记（30 分钟内）**：核对机身序列号、型号、配件清单与寄件单是否一致，拍摄快递面单存档。
2. **外观拍照**：表体、表带、表扣各角度拍摄，不少于 6 张，覆盖表镜、表壳、表带内外侧、充电触点。
3. **配对锁解除验证**：逐一尝试与手机配对，确认无 Apple ID 激活锁、华为账号、小米账号、荣耀账号、Samsung 账号、Garmin Connect 账号等绑定。
4. **功能逐项检测**：按第三部分检测项明细表逐项执行，记录每项结果。
5. **电池健康读取（支持机型）**：读取电池健康度与循环次数，数据写入报告。
6. **出报告**：签收后 48 小时内完成，报告含照片、检测项结果、成色判定与必拒结论。

## 二、检测工具与环境

检测工位须配备：手机配对测试机（覆盖 iOS 与 Android 主流系统）、各品牌手表充电器/充电底座、光学放大镜（用于表镜微痕与镀层检查）、标准计时设备、GPS 信号测试环境（窗边或室外）、蓝牙信号源。环境要求：工位光线均匀，避免强反光影响表镜拍照；配对测试机系统版本保持更新，确保可读取各品牌最新系统信息。电池健康读取须使用品牌官方或授权路径，非支持机型不做电池健康百分比判定，仅在报告中标注"不支持读取"。不做破坏性水测，防水密封检测以外观检查与说明书口径核对为准。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 表镜划痕与碎裂 | 无影响显示的划痕或碎裂 | 光学放大镜目视 + 强光侧照 | 碎裂影响显示即必拒；细微划痕按成色降档 |
| 表壳磕碰与镀层脱落 | 无超过 3mm 的磕碰痕迹 | 目视 + 触摸感知 | 明显磕碰按 B 级及以下判定；镀层脱落面积过大降档 |
| 表带拉伸老化与异味 | 无断裂、无严重拉伸变形 | 拉伸测试 + 嗅闻 | 异味或严重老化建议更换表带后复检；无法更换则降档 |
| 充电触点氧化 | 触点无阻碍充电的氧化层 | 目视 + 充电测试 | 氧化导致接触不良按功能异常处理 |
| 心率/血氧/ECG | 与标准设备对比误差在可接受范围 | 佩戴标准设备同步测量对比 | ECG 区域授权差异需核对型号支持范围；电极片脏污先清洁复测 |
| GPS 定位 | 开阔环境下 60 秒内完成定位 | 室外实测 | 无法定位按功能异常降档 |
| 蓝牙连接与通话 | 10 米内稳定连接并通话清晰 | 配对测试机实测 | 断连或通话异常按功能缺陷处理 |
| 防水密封 | 密封圈无老化开裂，说明书口径一致 | 外观检查 + 说明书核对，不做水测 | 密封圈老化按降档处理；进水标变色即判定进水，不论功能是否正常 |
| 电池健康 | S 级 ≥90%，A 级 80-89% | 品牌官方路径读取 | 低于 80% 须在报告中披露；低于 60% 拒收；循环次数超过 500 次须显著标注 |
| 配对锁/激活锁 | 必须完全解除 | 各品牌解除流程逐项验证 | 未解除即必拒 |
| 蜂窝版运营商锁 | eSIM 已注销，运营商锁解除 | 核对 eSIM 状态与型号 | 未解除即必拒 |
| 表冠转动（Apple Watch） | 转动顺滑、无卡顿异响 | 手动转动测试 | 卡顿按功能异常降档 |
| 光学心率窗划痕（Garmin） | 无影响读数的划痕 | 目视 + 读数对比 | 划痕影响读数按传感器异常处理 |
| 生耳松动与表扣开合力 | 生耳无松动，表扣开合干脆 | 手动按压与开合测试 | 松动或开合不畅建议更换配件后复检 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封盒装，表带未上过手 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅试戴过，无划痕，电池健康 ≥90% |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 表壳有细微发丝痕，电池健康 80-89% |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 表带有正常佩戴痕，表镜无划伤 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 表壳有可见磕点，表带轻微老化 |
| D（7成新及以下） | 较重磨损或局部功能瑕疵，必须显著披露 | 表镜有划痕但不影响显示，电池健康低于 80% 须披露 |

电池健康阈值与成色联动：S 级要求 ≥90%，A 级 80-89%，低于 80% 即披露后按 C 级及以下评估，低于 60% 直接拒收。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 五、必拒情形

出现以下任一情形，直接拒收并出具拒收说明，不做成色判定：

1. **配对锁/激活锁未解除**：Apple ID 激活锁、华为账号、小米账号、荣耀账号、Samsung 账号、Garmin Connect 账号任一未解绑即拒收。
2. **电池鼓包**：表体或表带下方可见隆起变形，存在安全隐患，立即拒收。
3. **表镜碎裂影响显示**：碎裂区域遮挡屏幕内容或影响触控，拒收；不影响显示的可视碎裂程度按 C 级及以下评估。
4. **蜂窝版未解除运营商锁**：eSIM 未注销或运营商锁未解除，拒收。
5. **传感器模组失效**：心率、血氧、ECG、GPS 任一模组完全无响应，拒收。
6. **隐瞒拆修史**：报告未披露拆修记录，经查实存在拆修即必拒。

## 六、报告字段与拍照取证要求

报告须包含以下字段：设备型号与序列号、成色等级、电池健康度（支持机型）与循环次数、配对锁解除状态、eSIM 注销状态（蜂窝版）、防水密封检查结论、检测项逐项结果、异常项描述、必拒结论（如有）。

拍照取证不少于 6 张，覆盖：表盘正面（亮屏状态）、表盘侧面与表壳四角、表镜反光面（侧光拍摄划痕）、表带内外侧与表扣、充电触点特写、序列号或关于本机页面。异常项须加拍局部特写，进水标变色、电池鼓包、表镜碎裂等必拒情形须单独建档留证。照片须在自然光或均匀光源下拍摄，不得使用美颜或滤镜。

## 七、常见争议与判定口径

**问：表镜有划痕但功能正常，该定什么成色？**
判定口径：划痕不影响显示与触控，按划痕数量与深度在 C 级及以下评估；影响显示即必拒。依据：表镜碎裂影响显示是必拒红线，但非碎裂性划痕属于外观瑕疵，按成色表降档处理。

**问：进水标变色了，但设备一切功能正常，能收吗？**
判定口径：进水标变色即判定进水，不论功能是否正常，按必拒处理。依据：进水可能造成内部腐蚀，当下功能正常不代表后续稳定，检测标准对此不作功能豁免。

**问：卖家说没拆修过，但检测发现内部螺丝有拧动痕迹，怎么办？**
判定口径：任何拆修史必须写入报告，隐瞒拆修即必拒。依据：拆修记录是成色判定的基础信息，隐瞒行为本身违反检测规则，不因拆修质量好坏而改变结论。

**问：电池健康低于 80% 但外观很新，能定 A 级吗？**
判定口径：不能。电池健康低于 80% 必须在报告中显著披露，并按 C 级及以下评估。依据：成色判定联动电池健康阈值，S 级要求 ≥90%，A 级 80-89%，低于 80% 已跌破 A 级下限。
