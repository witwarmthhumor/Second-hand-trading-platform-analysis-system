# 手机拆修与维修史识别

## 一、检测范围与流程

拆修与维修史识别是手机验货的第一道闸门。凡进仓手机，一律按以下步骤执行，顺序不可跳、不可倒。

1. **收件核验与防拆封登记**——签收后 30 分钟内完成。核对序列号与包裹面单，对机身封条、螺丝位、屏幕胶合缝做首轮影像留底。防拆封登记不完整，后续拆修判定失去参照，退回重验。
2. **外观分级拍照**——正面、背面、四边、接口共 ≥6 张，强光侧照拍摄。
3. **进水标检查**——SIM 槽、充电口、耳机口（如有）逐一查看。进水标变色即判定进水，不论功能是否正常。
4. **功能逐项检测**——按第三部分明细表执行。
5. **电池健康与循环次数读取**——记录健康度百分比与循环次数。
6. **ID 锁/账户锁退出验证**——必须为关闭状态。
7. **出报告**——签收后 48 小时内出具完整验机报告。有异议可在 72 小时内申请复检。

## 二、检测工具与环境

- 强光手电或可调角度台灯（侧照用），照度以能看清发丝纹为准。
- 拆机工具一套（仅限有拆机授权的质检员使用，普通验机流程不拆机）。
- 电池健康读取设备：系统诊断模式或厂商维修诊断软件。
- 防静电工作台与手套，避免二次损伤。
- 环境要求：光线均匀、无强反射面，桌面平整，拍照背景统一纯色。

拆修识别不依赖单一工具。螺丝刀拧痕、屏幕胶合溢胶、防水标状态、主板序列号磨损，这些痕迹的组合比任何单一指标都可靠。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 屏幕划痕 | ≤2 条发丝纹且不在显示区可计 A 级 | 强光侧照，目视加微距拍照 | 显示区划痕或超过 2 条降 1 级；深划痕计 C 级 |
| 边框磕碰 | 无露底金属 | 目视加触感确认 | 磕碰露底金属即降 1 级；掉漆面积 >5mm² 计 C 级 |
| 背板裂纹 | 无任何裂纹 | 侧光目视全背板 | 任何裂纹计 D 级并显著披露 |
| 摄像头镜片划痕 | 中心区无划痕 | 强光下斜视镜片 | 中心区划痕降 1 级 |
| 屏幕坏点/断触 | 无坏点、无断触 | 网格法全屏 12 区域逐区划动 | 任一区域断触计 C 级以下 |
| 面容 ID/指纹解锁 | 实际录入并成功解锁 | 录入后连续解锁验证 | 任一失败即降级 |
| 电池健康 | S 级 ≥90%，A 级 80–89% | 系统诊断读取 | <80% 必须明示；<60% 必拒 |
| 电池循环次数 | 循环次数 ≤500 次 | 系统诊断读取 | 超过 500 次必须在报告中显著标注 |
| 进水标 | 不变色 | SIM 槽、充电口、耳机口目视 | 变色即判定进水，不论功能是否正常 |
| ID 锁/激活锁 | 必须为关闭 | 系统设置中验证 | 未退出直接必拒 |
| 机身弯曲 | 变形 ≤1mm | 平放桌面，塞尺或目视缝隙 | 弯曲变形 >1mm 必拒 |
| 序列号一致性 | 机身、系统、包装三者一致 | 核对 IMEI/SN | 任一不一致必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封未动，无任何使用痕迹 |
| S（99 新） | 极少使用痕迹，功能全部正常，无维修史 | 开箱试机后闲置，电池循环 ≤10 次 |
| A（95 新） | 轻微使用痕迹，无功能缺陷，无拆修 | ≤2 条发丝纹且不在显示区，电池健康 80–89% |
| B（9 成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 边框细微磨损，电池健康 80–89% |
| C（8 成新） | 明显使用痕迹或轻微磕碰，功能正常 | 掉漆 ≤5mm²，或边框露底金属 1 处 |
| D（7 成新及以下） | 较重磨损/局部功能瑕疵，必须显著披露 | 背板裂纹、电池健康 <80%、维修史已申报 |

电池健康阈值是成色判定的硬约束。S 级必须 ≥90%，A 级必须 80–89%。外观达到 S 但电池健康只有 80–89% 的，按 A 级定，不按外观定。循环次数超过 500 次的，无论外观多新，必须在报告中显著标注，且不得评为 S 级。

## 五、必拒情形

出现以下任一情形，直接拒收，不进入后续定级流程：

- ID 锁/账户锁未退出。
- 电池健康 <60%。
- 主板维修史未申报——隐瞒拆修即必拒，不因功能正常而豁免。
- 进水标变色且功能异常。
- 机身弯曲变形 >1mm。
- 序列号与机身/系统不一致。

主板维修史未申报是性质最严重的一条。申报过的主板维修可进入 D 级评估，隐瞒不报则直接拒收，并记录卖家信用档案。

## 六、报告字段与拍照取证要求

验机报告至少包含以下字段，缺一项即视为报告不完整，需退回补录：

- 序列号/IMEI，与机身、系统核对结果。
- 外观成色定级（N/S/A/B/C/D）。
- 屏幕、边框、背板、摄像头镜片四项外观异常明细。
- 电池健康百分比与循环次数。
- 进水标状态（SIM 槽、充电口、耳机口如有）。
- ID 锁/激活锁状态。
- 拆修史结论：无拆修 / 有拆修已申报 / 有拆修未申报。
- 品牌分册特殊检测点结果（如面容 ID 模组、Knox 熔断状态、铰链阻尼等）。
- 必拒情形命中情况。

拍照取证不少于 6 张，缺角度即补拍：

- 正面、背面各 1 张，光线均匀，整机入画。
- 四边各 1 张，侧光拍摄，重点覆盖边框磕碰与屏幕边缘。
- 接口特写 1 张，包含充电口与 SIM 槽，进水标须清晰可见。
- 异常部位单独加拍：划痕、磕碰、裂纹、变色进水标，均需微距特写。
- 每张照片须带时间水印或与报告编号关联，防止调换。

拆修痕迹的取证比外观更严格。螺丝位、屏幕胶合缝、防水标这三处必须单独留底，照片模糊或反光过强的一律重拍。视频留证不少于 15 秒，围绕机身四边缓慢旋转一周，确保封条与螺丝位连贯可见。隐瞒拆修即必拒，而拒收决定的底气全在照片里。

## 七、常见争议与判定口径

**争议一：进水标变色，但功能全部正常。**

判定口径：进水标变色即判定进水，不论功能是否正常。功能正常只影响定级，不影响进水定性。依据：进水是过程性损伤，腐蚀可能在数周后才显现，功能正常不能推翻进水结论。

**争议二：卖家申报"换过电池"，但屏幕胶合缝有溢胶。**

判定口径：换电池属拆修史，必须写入报告。若申报内容与实际拆修范围一致（仅电池仓区域有痕迹），按 D 级处理；若发现主板螺丝拧痕或屏幕排线动过而卖家未申报，按隐瞒拆修必拒。依据：任何拆修史必须写入报告，隐瞒拆修即必拒。

**争议三：循环次数已超 500 次，外观接近全新。**

判定口径：循环次数超过 500 次的，不得评为 S 级，必须在报告中显著标注。外观再新，电池寿命已进入衰减区间，按实际健康度对应的成色定级。依据：循环次数超过 500 次必须在报告中显著标注。

**争议四：电池健康处于 80–89% 区间，外观却接近 S 级。**

判定口径：成色定级以电池健康为硬约束，外观为参考。健康度落在 80–89% 即按 A 级定，不因外观崭新而升 S 级。报告须同时明示健康度数值与定级依据，避免买家误读。依据：S 级电池健康须 ≥90%，A 级为 80–89%。
