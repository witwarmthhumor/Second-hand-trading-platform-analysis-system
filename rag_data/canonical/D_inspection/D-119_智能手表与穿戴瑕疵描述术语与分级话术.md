# 智能手表与穿戴瑕疵描述术语与分级话术

## 一、检测范围与流程

智能手表与穿戴设备品类覆盖 Apple Watch、华为手表、小米手环与手表、荣耀手表、三星手表、Garmin 等主流品牌。收件后按以下固定步骤执行，每一步都需在工单系统留痕：

1. **收件核验与登记（30 分钟内）**：核对机型、序列号、IMEI（蜂窝版）、配件清单与寄卖单一致。发现型号不符或机身码缺失，立即拍照并上报。
2. **外观拍照（表体/表带/表扣 ≥6 张）**：正面、背面、两侧表冠、表带内外侧、表扣开合处。瑕疵位置必须加拍特写。
3. **配对锁解除验证**：逐品牌验证 Apple ID 激活锁、华为账号、小米账号、荣耀账号、Samsung 账号、Garmin Connect 账号解绑状态。锁未解除即列入必拒。
4. **功能逐项检测**：心率/血氧/ECG、GPS 定位、蓝牙连接与通话、防水密封（外观检查与说明书口径核对，不做破坏性水测）、电池健康读取（支持机型）。
5. **电池健康读取**：按品牌分册读取路径执行，数值记录精确到个位。
6. **出报告（签收后 48 小时内）**：报告生成后推送寄卖方；对结论有异议，可在 72 小时内申请复检，复检以初次留档照片与数据为准。

## 二、检测工具与环境

检测工位需配备：高倍率放大镜（表镜与光学心率窗检查用）、专用螺丝刀套装（仅用于表带拆卸，不拆机）、蓝牙测试手机（Android 与 iOS 各一台）、GPS 信号测试环境（窗边或室外）、标准对比设备（心率/血氧/ECG 参考值来源）。

环境要求：工位光照不低于常规办公照明，避免强反光影响表镜划痕判断；配对与功能测试需在屏蔽干扰的稳定网络下进行。所有检测工具定期校准，对比设备误差记录随报告归档。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 表镜划痕与碎裂 | 无影响显示的划痕或裂纹 | 放大镜斜光观察，碎裂需透光检查 | 碎裂影响显示 → 必拒；细微划痕按成色降档 |
| 表壳磕碰与镀层脱落 | 无深度磕碰，镀层无成片脱落 | 目视 + 触感检查，记录位置与面积 | 明显磕碰 → C 级以下；镀层脱落按面积降档 |
| 表带拉伸老化与异味 | 无断裂、无严重拉伸变形、无异味 | 拉伸回弹测试，表带内侧嗅检 | 老化开裂 → 更换后定级；异味无法去除 → 如实披露 |
| 充电触点氧化 | 触点无绿锈，充电正常 | 目视 + 充电测试 | 轻微氧化可清洁；严重氧化影响充电 → 降档 |
| 心率/血氧/ECG | 与标准设备对比误差在可接受范围 | 佩戴对比设备同时测量，记录误差值 | 传感器模组失效 → 必拒；误差超限 → 降档披露 |
| GPS 定位 | 开阔环境 1 分钟内定位成功 | 户外或窗边实测，记录定位时长 | 无法定位 → 功能瑕疵，按 D 级披露 |
| 蓝牙连接与通话 | 连接稳定，通话无断续 | 与测试手机配对，通话 1 分钟 | 频繁断连 → 功能瑕疵降档 |
| 防水密封 | 密封圈无老化开裂，说明书口径一致 | 外观检查密封圈，不进行破坏性水测 | 密封圈老化 → 披露并建议更换 |
| 电池健康 | S 级 ≥90%，A 级 80-89%，低于 80% 必须披露，低于 60% 拒收 | 品牌读取路径读取电池健康度 | 按阈值对应成色；循环次数超 500 次显著标注 |
| 配对锁/激活锁 | 必须解除，无任何账号绑定 | 逐品牌验证解除流程 | 未解除 → 必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N 全新 | 未拆封未使用，配件包装齐全 | 原封盒装，表带未上机 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 仅试戴一次，无划痕，电池健康 ≥90% |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | 表带有极轻微佩戴纹，表镜无划痕，电池健康 80-89% |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | 表壳有 1-2 处细微划痕，充电触点轻微氧化 |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | 表壳磕碰可见，表带老化但未断裂 |
| D 7成新及以下 | 较重磨损/局部功能瑕疵，必须显著披露 | 表镜有划痕但不影响显示，GPS 偶发失灵 |

电池健康低于 80% 必须在报告中显著披露；低于 60% 直接拒收。循环次数超过 500 次必须在报告中显著标注，即使电池健康仍在 A 级区间。

## 五、必拒情形

以下情形出现即拒收，不进入定级流程：

- **配对锁/激活锁未解除**：Apple ID、华为账号、小米账号、荣耀账号、Samsung 账号、Garmin Connect 任一未解绑。
- **电池鼓包**：表壳变形或屏幕被顶起。
- **表镜碎裂影响显示**：碎裂区域遮挡或干扰屏幕内容。
- **蜂窝版未解除运营商锁**：eSIM 未注销或运营商锁未解除。
- **传感器模组失效**：心率、血氧、ECG 任一传感器无响应。
- **进水标变色**：进水标变色即判定进水，不论功能是否正常。
- **隐瞒拆修史**：任何拆修史必须写入报告，隐瞒拆修即必拒。

## 六、报告字段与拍照取证要求

报告至少包含以下字段：机型与序列号、成色定级、电池健康度（支持机型）、循环次数（如超 500 次）、配对锁解除状态、拆修史、进水标状态、各检测项结论、瑕疵描述及对应照片编号。瑕疵描述须引用标准术语，例如"表镜细微划痕（长度约 2mm，位于左上角）"，不得使用"有点花""还行"等模糊表述。

拍照取证至少 6 张，覆盖表体正面、背面、两侧表冠、表带内外侧、表扣开合处。每处瑕疵单独加拍特写，照片需清晰可辨，作为复检与争议判定的唯一依据。进水标变色、电池鼓包等必拒情形必须单独留证。照片与报告字段一一对应，缺图即视为该项未检。

## 七、常见争议与判定口径

**问：买家说表镜划痕报告里没写清楚，怎么办？**  
判定以报告照片为准。凡照片中可见的瑕疵，报告未描述即判定为检测遗漏，按买家举证重新定级；照片中不可见的，不予采纳。

**问：电池健康度读数与买家自行读取不一致，信谁的？**  
以我方留档的读取截图和检测设备记录为准。买家需提供同品牌同路径的读取证据，否则维持原判定。

**问：进水标变色但功能正常，算不算进水？**  
算。进水标变色即判定进水，不论功能是否正常，按必拒处理，不进入定级流程。

**问：卖家说只是换过表带，不算拆修吧？**  
换表带属于拆修史，必须写入报告。隐瞒拆修即必拒，无论功能是否正常。
