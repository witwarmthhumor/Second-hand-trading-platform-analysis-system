# 手机拒收与必拒情形清单

## 一、检测范围与流程

手机品类检测覆盖全部品牌与折叠屏机型，流程按以下步骤执行，验机仓签收后 48 小时内必须出报告；买卖双方对结果有异议的，可在报告出具后 72 小时内申请复检。

1. **收件核验与防拆封登记**：签收后 30 分钟内完成包裹外观、运单号、序列号三核对，拆封前拍照留档。此环节发现序列号与运单不符的，立即转入争议流程。
2. **外观分级拍照**：按正面、背面、四边、接口共 ≥6 张取景，强光侧照捕捉划痕与磕碰细节。
3. **进水标检查**：逐一查看 SIM 槽、充电口、耳机口（如有）的进水标。进水标变色即判定进水，不论功能是否正常。
4. **功能逐项检测**：按第三节明细表执行，含屏幕、面容/指纹、传感器、摄像头、充电口、扬声器等。
5. **电池健康与循环次数读取**：读取电池健康百分比与循环次数；循环次数超过 500 次必须在报告中显著标注。
6. **ID 锁/账户锁退出验证**：确认 ID 锁/激活锁为关闭状态，并核对序列号与机身、系统三者一致。
7. **出报告**：签收后 48 小时内完成分级与报告上传。

## 二、检测工具与环境

检测工位须配备强光侧照灯、SIM 卡槽取卡针、充电测试线材（含对应品牌快充协议）、面容 ID 遮挡测试工具、网格法触控测试图、机身弯曲度测量平台。环境要求为桌面平整、光照均匀，避免反光影响外观判定。电池健康与循环次数读取使用对应品牌官方或授权诊断工具，第三方工具读数仅作参考，最终以官方工具为准。折叠屏机型须额外准备开合测试支架。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 屏幕划痕 | 显示区无发丝纹；≤2 条发丝纹且不在显示区可计 A 级 | 强光侧照，目视+微距拍照 | 显示区划痕降 1 级；多条划痕计 C/D 级 |
| 边框磕碰 | 无露底金属磕碰 | 目视+触感检查 | 磕碰露底金属即降 1 级；掉漆面积 >5mm² 计 C 级 |
| 背板裂纹 | 无任何裂纹 | 强光侧照目视 | 任何裂纹计 D 级并显著披露 |
| 摄像头镜片划痕 | 镜片中心区无划痕 | 强光下斜向目视 | 中心区划痕降 1 级；边缘轻微划痕可计 A 级 |
| 屏幕坏点/色斑/触摸断触 | 全屏 12 区域网格法无坏点、无色斑、无断触 | 网格法全屏 12 区域逐区测试 | 任一区域断触计 D 级；坏点 >3 个降 1 级 |
| 面容 ID/指纹解锁 | 面容 ID 与指纹均正常录入并解锁 | 实际录入+锁屏解锁测试 | 面容 ID 模组异常（苹果）或指纹失败率 >30% 计 D 级 |
| 电池健康 | S 级 ≥90%，A 级 80–89% | 官方诊断工具读取 | <80% 必须明示；<60% 必拒 |
| 充电口/扬声器/振动/听筒/麦克风 | 全部功能正常 | 实际充电、播放、通话测试 | 任一功能失效降 1 级；充电口接触不良计 C 级 |
| 前后摄像头对焦与闪光灯 | 对焦清晰、闪光灯正常 | 实拍远近景各 2 张+闪光灯测试 | 对焦失败或闪光灯不亮降 1 级 |
| 传感器（陀螺仪/指南针/距离感应） | 全部正常响应 | 系统自带诊断+实际调用 | 陀螺仪失效计 D 级；指南针偏差 >15° 降 1 级 |
| ID 锁/激活锁状态 | 必须为关闭 | 系统设置+官方查询 | 未退出即必拒 |
| 折叠屏专项：铰链/折痕/内屏触控 | 铰链阻尼正常无异响，折痕深度 ≤0.5mm，内屏触控全分区正常 | 开合 20 次听异响+目视折痕+分区触控测试 | 铰链异响降 1 级；折痕深度 >0.8mm 计 C 级；内屏分区失灵即必拒；屏幕胶合开胶即必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封盒装，封条完好 |
| S（99 新） | 极少使用痕迹，功能全部正常，无维修史 | 仅充电口轻微插拔痕迹，电池健康 ≥90% |
| A（95 新） | 轻微使用痕迹，无功能缺陷，无拆修 | ≤2 条发丝纹且不在显示区，电池健康 80–89% |
| B（9 成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 边框 1 处轻微磕碰未露底，屏幕无划痕 |
| C（8 成新） | 明显使用痕迹或轻微磕碰，功能正常 | 掉漆面积 >5mm²，或充电口接触不良但可充电 |
| D（7 成新及以下） | 较重磨损/局部功能瑕疵，必须显著披露 | 背板裂纹、陀螺仪失效、屏幕断触局部 |

电池健康阈值引用通用标准：S 级 ≥90%，A 级 80–89%，<80% 必须在报告中明示，<60% 直接拒收。循环次数超过 500 次的，无论成色档位，报告中显著标注。

## 五、必拒情形

出现以下任一情形，直接拒收并出具拒收说明，不进入成色分级：

| 序号 | 必拒情形 | 判定要点 |
|---|---|---|
| 1 | ID 锁/账户锁未退出 | 系统设置或官方查询显示激活锁/账户锁为开启状态 |
| 2 | 电池健康 <60% | 官方诊断工具读取，读数以官方工具为准 |
| 3 | 主板维修史未申报 | 拆修痕迹明显或检测发现主板动过，卖家未在寄售时申报 |
| 4 | 进水标变色且功能异常 | 进水标变色即判定进水；若进水但功能正常，降级处理并显著披露 |
| 5 | 机身弯曲变形（>1mm） | 弯曲度测量平台实测，超过阈值即拒收 |
| 6 | 序列号与机身/系统不一致 | 三者任一不一致即拒收，转入争议流程 |
| 7 | 隐瞒拆修史 | 任何拆修史必须写入报告，隐瞒即必拒 |

进水标变色但功能正常的，不直接拒收，按进水机降级并显著披露；隐瞒拆修史一经查实，无论报告是否已出，一律追回并拒收。

## 六、报告字段与拍照取证要求

报告字段如下：

- 基础信息：序列号、品牌型号、存储容量、颜色、IMEI/MEID
- 成色分级：N/S/A/B/C/D 六档之一
- 电池健康百分比与循环次数（循环次数超过 500 次显著标注）
- 进水标状态：正常/变色（变色须附特写照片）
- 维修史声明：无拆修/有拆修（有拆修须注明维修部位）
- ID 锁/激活锁状态：关闭/未退出
- 检测结论：通过/拒收（拒收须注明对应必拒情形）
- 异常项明细：每项异常对应检测项、判定等级、证据照片编号

拍照取证至少 6 张，取景口径固定：正面、背面、四边各 1 张、接口特写 1 张，外加进水标特写或异常部位特写。每张照片须包含序列号标签或检测工单编号水印，保证照片与报告一一对应。进水标变色、背板裂纹、屏幕断触等必拒或降级情形，须在对应特写照片旁附文字标注。视频取证不少于 15 秒，覆盖开机、屏幕触控滑动、面容/指纹录入三个动作，视频文件名须含序列号后四位。

## 七、常见争议与判定口径

**争议一：进水标变色但功能全部正常，卖家主张按正常机回收。**

判定口径：进水标变色即判定进水，不论功能是否正常。功能正常的按进水机降级处理并显著披露，不直接拒收；卖家不接受降级的，可申请复检。

**争议二：卖家声称"从未拆修"，检测发现主板有维修痕迹。**

判定口径：任何拆修史必须写入报告，隐瞒拆修即必拒。检测以螺丝封胶状态、主板焊点、防水胶条完整性为据，不以卖家口述为准。

**争议三：买家认为屏幕划痕应计 A 级，检测判定为 B 级。**

判定口径：≤2 条发丝纹且不在显示区可计 A 级，超过该标准或划痕位于显示区即降 1 级。判定以强光侧照照片为证，双方对照片无异议后按档位执行。

**争议四：折叠屏内屏触控偶发失灵，卖家称是贴膜影响。**

判定口径：撕除贴膜后在网格法全屏 12 区域下复测，仍存在分区失灵即必拒；复测正常的，以复测结果为准并注明检测过程。
