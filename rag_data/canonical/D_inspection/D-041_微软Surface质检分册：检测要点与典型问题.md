# 微软Surface质检分册：检测要点与典型问题

## 一、检测范围与流程

Surface 机型按整机序列号建档，覆盖 Pro、Laptop、Go、Book 各产品线。收件后按以下步骤流转：

1. 收件核验与防拆封登记：签收后 30 分钟内完成，核对序列号、机身码与订单信息是否一致。
2. 外观分级拍照：不少于 6 张，含正面、背面、四角、铰链与支架展开状态。
3. 进水标检查：Surface 机身及充电口附近进水标变色即判定进水，不论功能是否正常。
4. 功能逐项检测：按第三部分明细表执行，重点覆盖触屏、支架铰链、键盘盖接口。
5. 电池健康读取：支持读取的型号记录设计容量与当前实际容量。
6. Windows 账户退出验证：确认微软账户、组织账户及 BitLocker 恢复密钥状态。
7. 出报告：签收后 48 小时内完成并上传系统。

验机仓出具报告后，买家如有异议，可在 72 小时内申请复检。复检仅针对原报告所列检测项，不扩大范围。

## 二、检测工具与环境

- 检测台：防静电工作台，光照度满足外观瑕疵识别需求，避免强反光影响屏幕判定。
- 屏幕检测：使用纯色背景图（白、灰、黑、红、绿、蓝）逐屏切换，观察亮斑、坏点与压伤。
- 触控检测：系统自带触控诊断页或第三方网格测试工具，按 16 区域网格法逐格划动。
- 电池读取：使用 Windows 命令行生成电池报告（`powercfg /batteryreport`），记录设计容量、满充容量与循环次数。
- 铰链检测：手动开合支架 10 次以上，感受阻尼是否均匀，观察转轴是否有异响或晃动。
- 配件验证：原装充电器核对序列号标签、接口针脚与输出功率标识；键盘盖与触控笔单独建档。
- 网络检测：连接 2.4GHz 与 5GHz 双频段 Wi-Fi，蓝牙配对官方键盘或鼠标验证稳定性。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 屏幕显示 | 无漏液、无扩散中斑点、无 3 处以上亮点 | 纯色背景逐色切换，暗室环境下目视 | 漏液扩散中直接必拒；亮点按面积与数量降级 |
| 屏幕划痕/压伤 | 显示区无可见划痕为 S/A 级前提 | 斜射光下目视，笔尖压痕重点看触屏中央区 | 划痕明显按长度与深度降级；压伤发白按显示区口径分级 |
| 触控断触 | 16 区域网格法全部区域响应正常 | 触控笔与手指分别划过每个网格 | 任一区域无响应即降级；大面积断触按功能缺陷处理 |
| 支架铰链 | 开合阻尼均匀，无晃动、无异响 | 手动开合 10 次，观察转轴与机身连接处 | 铰链松动或异响降级；支架无法固定任一角度按功能缺陷处理 |
| 电池健康 | S 级 ≥90%，A 级 80-89% | `powercfg /batteryreport` 读取 | 低于 80% 必须披露；低于 60% 直接必拒 |
| 电池循环次数 | 循环次数 ≤500 次可不显著标注 | 电池报告中 Cycle Count 字段 | 超过 500 次必须在报告中显著标注 |
| Windows 账户锁 | 微软账户已退出，无 BitLocker 恢复密钥锁定 | 设置-账户-电子邮件和账户逐一核对 | 账户未退出直接必拒 |
| 扬声器 | 左右声道输出正常，无破音 | 播放测试音频，逐个声道静音对比 | 单侧无声或明显破音按功能缺陷降级 |
| 充电接口与充电器 | 原装充电器可正常握手充电 | 连接充电器观察充电指示灯与系统电量变化 | 非原装充电器需备注；接口接触不良降级 |
| 键盘盖/触控笔配件 | 键盘按键全触发，笔尖无过度磨损 | 键盘逐键测试；触控笔在屏幕上画线 | 配件问题单独标注，不影响主机成色但需在报告中披露 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N 全新 | 未拆封未使用，包装与封条完整 | 原封箱未开，配件齐全未上机 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 开箱激活但使用不足一周，机身无可见痕迹 |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | 细小微划痕在特定角度可见，电池健康 ≥80% |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | 边框有轻微氧化点或细划痕，支架铰链正常 |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | 边角有磕碰掉漆，屏幕有可见划痕但显示正常 |
| D 7成新及以下 | 较重磨损或局部功能瑕疵，必须显著披露 | 背板平测弯曲 >1.5mm，或扬声器单侧故障 |

电池健康与成色联动：S 级要求 ≥90%，A 级要求 80-89%。电池健康低于 80% 的，无论外观多新，成色不得高于 B 级。循环次数超过 500 次的，在报告中显著标注。

## 五、必拒情形

出现以下任一情形，直接拒收并在系统中登记原因：

- Windows 账户/组织账户未退出，或 BitLocker 恢复密钥未解除。
- 电池健康低于 60%（支持读取的型号）。
- 主板维修史未申报，或检测中发现主板级维修痕迹。
- 屏幕漏液扩散中，或屏幕有可见液体渗入。
- 序列号不一致，机身码与系统登记信息不符。
- 进水标变色，判定为进水机。

隐瞒拆修史即必拒。检测中发现拆修痕迹但卖家未申报的，按隐瞒处理，不进入后续议价流程。

## 六、报告字段与拍照取证要求

报告必填字段：整机序列号、机身码、成色等级、电池健康与循环次数、Windows 账户状态、进水标状态、拆修史、配件清单、检测结论。

拍照取证不少于 6 张：正面、背面、四角、铰链展开、进水标特写、屏幕纯色显示状态。进水标变色、铰链松动、屏幕压伤等异常项须单独加拍特写。照片需带时间水印，与检测报告一一对应。

## 七、常见争议与判定口径

**争议一：卖家称"只是没退出账户，功能都正常"。** 判定：账户未退出即必拒，不进入议价。依据：账户锁未退出属必拒清单，与功能是否正常无关。

**争议二：买家收到后称"屏幕有压伤，报告没写"。** 判定：以验机仓照片为准，照片中可见的压伤若报告未披露，按漏检处理；照片中不可见的，不予认定。依据：拍照取证不少于 6 张，外观问题以影像留证为判定基础。

**争议三：电池健康读数与卖家自测不一致。** 判定：以验机仓 `powercfg /batteryreport` 生成报告为准，卖家自测截图仅作参考。依据：电池报告含设计容量与循环次数，数据可追溯。

**争议四：充电器非原装但能正常充电。** 判定：非原装充电器不构成必拒，但必须在报告中备注；买家因此退货的，买家承担退货运费。依据：配件问题单独标注，不影响主机成色判定。
