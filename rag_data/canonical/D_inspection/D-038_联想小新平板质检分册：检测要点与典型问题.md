# 联想小新平板质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于联想小新系列平板（含小新 Pad、小新 Pad Pro 等）的回收质检。检测流程共七步，验机仓签收后 48 小时内必须出报告；买卖任一方对结论有异议，可在报告出具后 72 小时内申请复检。

1. **收件核验与防拆封登记**：签收后 30 分钟内完成。核对序列号与订单信息，拍照记录原包装封条状态，拆封前确认无第三方拆修痕迹。
2. **外观分级拍照**：≥6 张，覆盖正面、背面、四角、边框、屏幕点亮与息屏状态。
3. **进水标检查**：小新部分型号机身留有进水指示标，变色即判定进水，不论功能是否正常。
4. **功能逐项检测**：按第三节明细表逐项执行，触控断触采用网格法 16 区域全屏检测。
5. **电池健康读取**：支持读取的型号记录健康度百分比；不支持读取的型号以循环次数与充电实测作为参考。
6. **账户锁退出验证**：确认联想账号已退出、无设备锁或家长控制残留。
7. **出报告**：签收后 48 小时内完成，超时需在报告中说明原因。

## 二、检测工具与环境

检测台需配置防静电垫、补光灯、放大镜、序列号扫码枪。电池健康读取使用厂商授权诊断工具或第三方电池检测仪，读数精确到个位。触控检测使用标准网格测试图，屏幕划分为 16 区域逐一划动验证。WiFi 检测需连接 5GHz 与 2.4GHz 双频段网络各一次；蓝牙检测需配对至少一台外部设备。环境要求为室内常温、光线均匀，避免强反光影响外观判定。所有检测工具每日开机自检一次，读数异常时停止使用并送校。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 屏幕划痕/压伤 | 显示区无肉眼可见划痕 | 息屏强光斜照 + 点亮纯色背景 | 划痕长度 >3mm 降 B；压伤白斑直接降 C 并披露 |
| 背板弯曲 | 平测翘曲 ≤1.5mm | 平板平放于大理石台面，塞尺测最大间隙 | 平测 >1.5mm 记录并降级，超过 3mm 走必拒复核 |
| 触控断触 | 16 区域全部连续响应 | 网格法逐区划线 + 多点触控测试 | 任一区域断触即功能缺陷，降 D 或必拒 |
| 电池健康 | S 级 ≥90%；A 级 80-89% | 诊断工具读取健康度 | <80% 必须披露；<60% 必拒 |
| 循环次数 | 报告中如实记录 | 诊断工具读取 | 循环次数超过 500 次必须在报告中显著标注 |
| 扬声器 | 四声道逐个发声正常 | 播放测试音频逐侧贴近听 | 单侧无声降 C，双侧异常降 D |
| 联想账号 | 已退出且无设备锁 | 设置-账户-退出并重启验证 | 未退出即必拒 |
| 扩展坞接口 | Type-C 视频输出与数据传输正常 | 连接扩展坞 + HDMI 显示器实测 | 接口失效降 C，需在报告中注明 |
| 进水标 | 白色/原色未变色 | 目视检查指示标 | 变色即判定进水，不论功能是否正常 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N 全新 | 未拆封未使用，原厂封条完整 | 包装塑封完好，配件齐全未上机 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 仅拆封试机，无划痕无磕碰，电池健康 ≥90% |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | 边框有 1-2 处细微擦痕，屏幕完美，电池健康 80-89% |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | 背板细微划痕，边框轻微氧化，平测 ≤1.5mm |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | 边框磕碰掉漆，屏幕有 ≤3mm 划痕，电池健康 <80% 已披露 |
| D 7成新及以下 | 较重磨损/局部功能瑕疵，必须显著披露 | 背板弯曲 >1.5mm、单侧扬声器无声、扩展坞接口失效 |

电池健康判定与成色联动：S 级必须 ≥90%，A 级 80-89%，低于 80% 无论外观多新，成色最高只能到 C 且必须在报告显著位置披露。循环次数超过 500 次同样强制披露，不因外观良好而豁免。

## 五、必拒情形

出现以下任一情形，直接拒收并出具说明，不进入成色判定环节：

- **联想账号/设备锁未退出**：任何形式的账户锁残留，包括家长控制未解除。
- **电池健康 <60%**：支持读取的型号以工具读数为准，低于阈值即拒。
- **主板维修史未申报**：拆修史必须写入报告，隐瞒拆修即必拒；检测中发现主板级维修痕迹同样拒收。
- **屏幕漏液扩散中**：漏液区域呈扩散趋势，或按压有流动感。
- **序列号不一致**：机身、包装、系统内序列号三者不一致。
- **进水标变色**：变色即判定进水，不论功能是否正常。

## 六、报告字段与拍照取证要求

报告字段包括：序列号、成色等级、电池健康度（支持读取型号）、循环次数、进水标状态、维修史声明、功能检测结果逐项勾选、异常描述、配件清单、检测员编号、报告时间。

拍照取证不少于 6 张，固定角度如下：

1. 机身正面息屏（反光下拍划痕）
2. 机身正面点亮纯色背景（拍压伤/亮点）
3. 机身背面整体（拍磕碰与氧化）
4. 四角特写拼图（拍磕碰掉漆）

## 七、常见争议与判定口径

**争议一：屏幕划痕在息屏与点亮状态下可见度不同，买家不认可降级结论。**
判定口径：以息屏强光斜照下的检测结果为准，拍照时必须在斜照角度下补拍一张特写作为证据。点亮纯色背景下的可见度仅作参考，不改变分级。依据：外观分级以最严苛观测条件下的损伤为准，避免主观差异。

**争议二：电池健康度读数在第三方工具与官方诊断间存在偏差。**
判定口径：以官方授权诊断工具读数为准，第三方工具读数仅作参考。若官方工具无法读取，则在报告中注明"读数来源为第三方工具"，并附循环次数作为佐证。依据：官方工具口径统一，可复现，减少买卖双方扯皮。

**争议三：买家称"只是换过电池，不算维修史"，要求按无拆修成色交易。**
判定口径：凡拆机即属拆修史，无论更换部件是否为原厂。报告必须写明"有拆修史——更换电池"，成色按拆修机口径封顶至 B 级。依据：拆修史必须写入报告，隐瞒拆修即必拒；换电池属于拆修，不因部件常规而豁免。

**争议四：扩展坞接口时好时坏，买家认为是线材问题而非机器故障。**
判定口径：使用检测台标配的同一根扩展坞线材与同一台显示器复测三次，两次及以上失败即判定接口失效，降 C 并披露。买家自行更换线材的测试结果不作为判定依据。依据：检测环境须统一，排除外部变量干扰。
