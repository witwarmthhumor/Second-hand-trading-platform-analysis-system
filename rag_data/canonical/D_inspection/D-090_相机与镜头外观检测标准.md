# 相机与镜头外观检测标准

## 一、检测范围与流程

本品类覆盖可换镜头相机（单反/微单）、固定镜头相机、摄像机、运动相机及 CCD 相机。验机仓签收后 48 小时内必须出报告，异议可在报告出具后 72 小时内申请复检。

流程按以下步骤执行：

1. **收件核验与登记**（30 分钟内完成）：核对机身号、镜头号与卖家申报一致，检查包装完整性并拍照留档。
2. **外观分级拍照**：机身、镜头、屏幕各角度取景，照片不少于 6 张。
3. **快门数读取**：支持机型按品牌分册方法读取。
4. **功能逐项检测**：按第三部分明细表逐项执行。
5. **镜头透光检查**：强光手电从前后组分别照射。
6. **出报告**：签收后 48 小时内完成。

## 二、检测工具与环境

检测区域需洁净、光线均匀。必备工具：强光手电（透光检查与霉斑分级）、气吹与镜头清洁工具、白墙或均匀白板（传感器坏点检测）、防静电工作台、对应型号电池与存储卡。

环境保持常温干燥、避免阳光直射造成误判。微单与单反取景方式不同——单反靠反光板光学取景，微单用电子取景器；两者传感器清洁流程有差异，微单清洁 SENSOR 时需在菜单开启"无镜头释放快门"模式。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 机身蒙皮脱胶与磨损 | 无脱胶，磨损不露底材 | 目视加指腹按压蒙皮边缘 | 脱胶面积大或露底材降级至 C 及以下 |
| 快门按键与转盘行程 | 行程清晰、回弹干脆 | 逐档拨转盘并半按快门 | 卡滞或空转判定功能异常 |
| 热靴氧化 | 触点无绿锈黑斑 | 目视加手电斜照 | 氧化明显写入报告并降级 |
| 镜头镜片划痕/霉斑/进灰 | 强光下无镀膜层划伤，霉斑未侵入镀膜层 | 强光手电透光，前后组分别观察 | 霉斑分点状/丝状/侵入三级；侵入镀膜层即必拒 |
| 镜筒变焦/对焦环阻尼 | 阻尼均匀、无滑头 | 全程转动变焦环与对焦环 | 变焦滑头或阻尼突变判定异常 |
| 快门数读取 | S 级 ≤5 万张优先，>10 万张显著标注 | 按品牌分册读取（佳能/尼康/索尼菜单或工具读取） | 循环次数超过 500 次必须在报告中显著标注 |
| 传感器坏点/灰尘 | 坏点 ≤10 个 | 小光圈拍白墙，放大检查 | 大面积坏点（>10 个）即必拒 |
| 对焦精度 | 中央与边缘均准确合焦 | 拍摄对焦测试卡，视频模式测跟焦 | 跑焦标注偏移方向与幅度 |
| 防抖功能 | 开启后取景画面稳定 | 长焦端半按快门观察稳定性 | 防抖无效判定功能异常 |
| 取景器与 LCD 显示 | 无坏点、亮度均匀 | 纯色画面逐色检查 | 坏点集中区域拍照取证 |
| 全接口与卡槽读写 | 读写正常 | 逐一插拔并写入读出测试文件 | 接触不良或无法读写判定异常 |
| 镜头对焦马达异响/光圈叶片 | 对焦无异响，光圈收缩到位 | 静音环境听音，连拍观察光圈 | 异响明显或叶片黏滞需降级披露 |
| 电池健康度 | S 级 ≥90%，A 级 80-89% | 读取电池循环与健康数据 | 低于 80% 必须披露，低于 60% 拒收 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封盒装，封条完整 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 快门数 ≤5 万张，机身无可见磨损，电池健康度 ≥90% |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 极轻微摩擦痕，镜片洁净，电池健康度 80-89% |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 蒙皮轻微磨损不露底，热靴有触点痕迹 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 角落磕碰掉漆，遮光罩有划痕 |
| D（7成新及以下） | 较重磨损/局部功能瑕疵，必须显著披露 | 蒙皮大面积脱胶、按键字符磨损不清、电池健康度低于 80% |

## 五、必拒情形

出现即拒收，报告标注"必拒"并说明原因：

1. **传感器大面积坏点**（>10 个），影响成像。
2. **镜头内部霉斑侵入镀膜层**，除霉无法恢复光学性能。
3. **机身进水/摔机史未申报**——进水标变色即判定进水，不论功能是否正常；隐瞒拆修史即必拒。
4. **快门报错或连拍卡死**，无法正常拍摄。
5. **翻新机当原装机出售**，以翻新充全新属欺诈。

## 六、报告字段与拍照取证要求

报告必含字段：机身号/镜头号、品牌型号、快门数（支持机型）、电池健康度、外观成色等级、功能检测逐项结果、镜头透光检查结论、必拒/异常标注、检测员与复检员签字。

拍照取证：外观照片不少于 6 张，覆盖机身正面、背面、顶部按键区、镜头前后镜片、屏幕开机与纯色画面、机身底部序列号。进水标变色、霉斑、坏点等异常点必须单独微距拍摄。快门数读取界面与电池健康度界面需截屏存档。

## 七、常见争议与判定口径

**问：卖家说"轻微进灰不算问题"，镜头进灰到底怎么判？**

判定口径：进灰与霉斑是两回事。镜片表面浮灰用气吹可清理，属正常使用痕迹，不影响成色定级；但灰尘进入镜组内部且无法通过常规清洁去除的，需在报告中披露并视数量降级。霉斑则按点状、丝状、侵入三级判定——点状霉斑可尝试除霉，丝状霉斑写入报告并降级，侵入镀膜层的直接必拒。依据：霉斑侵入镀膜层即不可逆，属必拒清单。

**问：快门数超了但外观很新，能定 S 级吗？**

判定口径：不能。S 级要求快门数 ≤5 万张且无维修史，外观只是定级条件之一。快门数超过 10 万张的，无论外观多新，都必须在报告中显著标注，成色上限为 B 级。循环次数超过 500 次的电池同样须显著标注。依据：快门数是判断相机实际使用强度的核心指标，外观可翻新、快门数难造假。

**问：进水标变色但机器功能一切正常，算不算进水？**

判定口径：算。进水标变色即判定进水，不论功能是否正常，这条没有例外。功能正常只能说明进水程度轻或已干燥，但内部电路板可能存在隐性腐蚀，后续故障风险无法评估。报告标注"进水史"，成色直接定 D 级以下；若卖家申报时隐瞒进水史，则按必拒处理。依据：进水标是客观化学指示，变色即触发必拒清单中"机身进水未申报"条款。

**问：买家收到货说"对焦不准"，但检测时是好的，怎么处理？**

判定口径：先核对报告中的对焦检测记录。检测时中央与边缘均准确合焦、且报告已注明跑焦测试方法及结果的，原则上以检测报告为准。若买家坚持异议，可在 72 小时内申请复检，复检时重点复核对焦精度与镜头马达状态。需注意区分机身跑焦与镜头跑焦——前者是反光板或对焦模块偏差，后者是镜组位移，两者修复方式和责任归属不同。依据：复检申请时限为报告出具后 72 小时内，对焦检测方法在检测项明细表中有明确记录。
