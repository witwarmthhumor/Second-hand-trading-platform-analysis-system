# 一加质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于一加品牌全系手机（含国行 HydrogenOS 与海外 OxygenOS 版本）的回收质检。验机仓签收后 48 小时内必须出具完整报告，买卖双方对结果有异议的，可在报告出具后 72 小时内申请复检。流程按以下编号步骤执行：

1. 收件核验与防拆封登记：签收后 30 分钟内完成，核对序列号与运单信息，发现机身码与系统码不一致立即标记异常。
2. 外观分级拍照：正面、背面、四边、接口共 ≥6 张，强光侧照辅助划痕识别。
3. 进水标检查：SIM 槽、充电口、耳机口如有进水标，逐一查看。
4. 功能逐项检测：按第三节表格逐项执行。
5. 电池健康与循环次数读取：通过系统设置与工程模式双路径核对。
6. ID 锁/账户锁退出验证：必须确认 OxygenOS/HydrogenOS 账号已退出。
7. 出报告：签收后 48 小时内完成，逾期需上报组长。

## 二、检测工具与环境

检测台配备 1000 lux 以上可调角度光源、强光手电筒、屏幕网格测试图、Type-C 充电测试线、SIM 卡托取出针。环境要求为无强反射背景的工位，桌面铺设防静电垫。高刷屏档位验证需在设置中切换刷新率选项并观察实际帧率变化，测试环境光线需稳定，避免频闪干扰判断。所有检测操作在防拆封登记完成后进行，拆机仅限授权工程师，普通质检员不得开启后盖。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 屏幕显示与触控 | 无坏点、无断触、无色斑 | 网格法全屏 12 区域逐区滑动测试 | 单区断触即降 1 级；坏点 >3 个计 C 级 |
| 高刷屏档位 | 系统设置中对应档位可正常切换 | 设置-显示-刷新率逐档验证 | 无法切换或实际帧率不达标降 1 级 |
| 电池健康 | S 级 ≥90%，A 级 80–89% | 系统电池健康读数 + 工程模式循环次数 | <80% 必须明示；<60% 必拒 |
| 电池循环次数 | 循环 ≤500 次可正常评级 | 工程模式读取 | 超过 500 次必须在报告中显著标注 |
| 面容/指纹解锁 | 录入后 3 次内成功解锁 | 实际录入并测试 | 失败 3 次以上降 1 级 |
| 充电口与闪充 | 充电正常、无松动 | Type-C 线插入并观察握手协议 | 松动或无法握手降 1 级 |
| 摄像头对焦与闪光灯 | 前后摄对焦清晰、闪光灯正常 | 实拍近远景各 2 张，开启闪光灯 | 对焦失败或闪光灯不亮降 1 级 |
| 传感器 | 陀螺仪/指南针/距离感应正常 | 系统自带测试页逐项验证 | 单项失效降 1 级 |
| 扬声器/听筒/麦克风 | 播放与录音清晰无杂音 | 播放测试音频并录音回放 | 有杂音或无声降 1 级 |
| 振动马达 | 振动强度正常 | 设置中触发振动 | 无振动或异常振动降 1 级 |
| ID 锁/账户锁 | 必须为关闭状态 | 设置-账户中查验退出状态 | 未退出即必拒 |
| 进水标 | 不变色 | 目视检查 SIM 槽、充电口 | 变色即判定进水，不论功能是否正常 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，包装配件齐全 | 原封盒装，封条完好 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅拆封激活，机身无可见划痕 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | ≤2 条发丝纹且不在显示区，边框无磕碰 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 屏幕有 1–2 条细微划痕，边框轻微磨损但未露底 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 掉漆面积 >5mm²，或磕碰露底金属 |
| D（7成新及以下） | 较重磨损/局部功能瑕疵，必须显著披露 | 背板裂纹、屏幕色斑明显、摄像头镜片中心区划痕 |

电池健康阈值独立于外观成色：S 级要求 ≥90%，A 级 80–89%，低于 80% 必须在报告中明示具体数值。外观与电池分别定级后取较低档为最终成色。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 五、必拒情形

出现以下任一情形即拒收，不进入后续评级流程：

- OxygenOS/HydrogenOS 账号锁未退出
- 电池健康 <60%
- 主板维修史未申报
- 进水标变色且功能异常
- 机身弯曲变形（>1mm）
- 序列号与机身/系统不一致
- 屏幕胶合开胶或内屏触控分区失灵（该两项同时适用折叠屏专项标准）

进水标变色即判定进水，不论功能是否正常——即使功能全部正常，只要进水标变色且存在功能异常即必拒；进水标变色但功能正常的情形需上报复核，不得自行放行。

## 六、报告字段与拍照取证要求

报告至少包含以下字段：订单号、序列号、品牌型号（区分国行/海外版）、外观成色、电池健康百分比与循环次数、功能检测结果逐项勾选、进水标状态、拆修史声明、ID 锁状态、最终判定与报价依据。电池健康低于 80% 的，报告必须明示具体数值；循环次数超过 500 次的，须在显著位置标注。任何拆修史必须写入报告，隐瞒拆修即必拒。

拍照取证共 ≥6 张，缺一不可：正面、背面、左侧、右侧、顶部/底部接口、SIM 卡托（进水标特写）。屏幕划痕须强光侧照拍摄，要求划痕走向清晰可辨；边框磕碰须微距拍摄露底部位；背板裂纹须整机入镜加局部特写各一张。所有照片须带时间水印并与报告序列号对应，作为争议复核依据。

## 七、常见争议与判定口径

**争议一：卖家称"只是贴膜划痕"，实际是屏幕划痕。** 判定口径：撕膜后强光侧照复验，划痕在玻璃层即按屏幕划痕定级；贴膜划痕不计入屏幕成色，但须在报告中注明贴膜状态。依据：外观分级以裸机状态为准。

**争议二：进水标变色但功能全部正常，能否按正常机回收。** 判定口径：变色即判定进水，不论功能是否正常；功能正常的情形上报复核，不得自行放行。依据：进水是隐性风险，后期腐蚀无法预判。

**争议三：卖家声称"没拆过"，但螺丝有拧动痕迹。** 判定口径：以螺丝漆封、防拆标完整性和内部胶痕为准，外观无痕不代表未拆修；发现拆修史必须写入报告，隐瞒拆修即必拒。依据：拆修史直接影响整机可靠性与定级。

**争议四：电池健康低于 60% 但外观接近全新，能否按外观定级。** 判定口径：外观与电池分别定级后取较低档为最终成色，电池健康 <60% 直接进入必拒清单，不因外观良好而豁免。依据：电池是功能项，功能必拒优先于外观评级。
