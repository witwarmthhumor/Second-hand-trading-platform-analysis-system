# 奢侈品箱包拒收与必拒情形清单

## 一、检测范围与流程

收件核验与登记在签收后 30 分钟内完成，全程录像。录像从拆外包装开始，不停机、不剪辑。登记内容包括寄件人信息、箱包品牌型号、申报成色、附件清单，以及外包装状态。

外观分级拍照要求不少于 8 张，其中必须包含五金特写。拍完照进入身份卡、序列号、镭射标核验环节，这一环节直接决定后续检测路径。核验通过后做五金与皮质逐项检测，最后进行真伪综合判定，由两名质检员独立复核，结论不一致时以更严格一方为准。

出报告时限为签收后 48 小时内。买家对报告有异议的，可在 72 小时内申请复检。复检只做一次，以复检结论为最终结果。检测流程中任一环节触发必拒清单条件的，立即终止后续流程，转入拒收处理通道。

## 二、检测工具与环境

检测台面铺设白色无纺布，避免硬物划伤皮面。光源使用显色指数不低于 90 的 LED 灯，色温 4000K 至 5000K，保证五金氧化与皮质色差能真实呈现。放大镜倍率 10 倍起，用于观察刻字工艺与镭射标细节。

紫外灯用于辅助判断部分品牌防伪特征，不单独作为鉴定依据。卡尺用于测量五金件尺寸与刻字深度。软尺用于测量包体尺寸与肩带长度。环境要求通风良好，异味判断需在无香氛干扰的环境下进行。

拍照设备像素不低于 1200 万，关闭美颜与滤镜。所有检测工具定期校准，校准记录留存备查。检测人员佩戴一次性手套，避免手汗污染皮面。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 皮质划痕/磨白/龟裂 | 无明显划痕或仅轻微痕迹 | 目测 + 手指触感确认深度 | 按区域分级：轻微划痕可接受；龟裂贯穿皮质层触发必拒 |
| 四角磨损 | 无磨白或露料 | 目测 + 放大镜观察纤维层 | 磨白属正常使用痕迹；露料视面积判定 C 级或 D 级 |
| 五金镀层脱落与氧化 | 镀层完整，无大面积脱落 | 目测 + 特写拍照对比 | 局部氧化属通病可接受；断裂无法修复触发必拒 |
| 拉链顺滑度与拉头完整性 | 拉动顺滑，拉头无变形 | 反复开合 5 次测试 | 卡顿可润滑处理；拉头断裂且无法更换配件触发必拒 |
| 身份卡编号与内标一致性 | 编号完全一致 | 逐位核对 + 品牌数据库比对 | 不一致且无法合理解释，判定序列号逻辑矛盾触发必拒 |
| 附件清点 | 防尘袋/肩带/小票齐全 | 对照清单逐项勾选 | 缺失附件在报告中显著标注，影响成色判定 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N 全新 | 未拆封未使用，配件包装齐全 | 原盒塑封完好，身份卡未取出 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 仅试背一次，内衬无任何污渍 |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | 四角轻微磨白，五金无氧化 |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | 手柄有正常汗渍变色，内衬无污渍 |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | 四角露料面积较小，五金氧化明显 |
| D 7成新及以下 | 较重磨损/局部功能瑕疵，必须显著披露 | 内衬污渍明显，拉链局部卡顿但可修复 |

任何拆修史必须写入报告，隐瞒拆修即必拒。护理后是否影响成色判定，以护理是否改变原始皮质纹理为准，翻新喷涂掩盖瑕疵的按必拒处理。循环次数等电子类阈值不适用于本品类，本品类以皮质与五金状态为核心判定依据。

## 五、必拒情形

以下情形出现即拒收，不做降级处理：

- 判定为仿品。真伪综合判定由双人复核确认，任一鉴定点存在仿品特征即触发。
- 主料破损。面料破洞或开裂贯穿皮质层，无法通过护理修复。
- 五金断裂无法修复。拉头断裂、锁扣断裂且品牌方无配件供应。
- 强烈不可去除异味。霉味或烟味超常规，经通风处理后仍无法消除。
- 序列号与品牌数据库逻辑矛盾。序列号格式与产地、生产年份对应关系不符。

品牌分册特殊检测点中，LV 需核对 Date code 格式与产地对应关系，老花对花位偏差过大触发必拒。Chanel 镭射标贴与身份卡编号不一致触发必拒。Hermès 工匠刻印模糊无法辨认的，需二次复核皮质等级标识，仍无法确认的按必拒处理。

## 六、报告字段与拍照取证要求

报告字段包括：品牌、系列、型号、成色等级、外观检测结果、功能检测结果、附件清单、必拒触发情况、检测人与复核人签名、报告编号。报告在签收后 48 小时内出具，超时需说明原因。

拍照取证要求不少于 8 张，含五金特写。必拒情形需额外拍摄 3 张以上细节图，包括破损部位、异味来源区域、序列号特写。照片需包含拍摄时间水印，与检测录像时间线对应。视频取证不少于 15 秒，覆盖开箱至检测完成全过程。

身份卡、序列号、镭射标需单独拍摄清晰特写，保证数字可辨识。五金刻字深度需用微距模式拍摄，便于复核工艺对版。

## 七、常见争议与判定口径

**买家认为轻微划痕应降为 C 级，卖家坚持按 B 级成交，以谁为准？**

以检测报告为准。划痕是否"轻微"按区域与深度判定：仅表面、未触及皮质纤维层的划痕属正常使用痕迹，对应 B 级；划痕明显凹陷或磨白露料才降 C 级。判定依据是四角磨损与皮质划痕两项检测记录，不因买卖双方主观描述改变。

**护理过的包，成色按护理前还是护理后判？**

按护理后的实际状态判，但护理方式决定结果。清洁、补色等不改变皮质原始纹理的护理，按护理后成色定级；翻新喷涂掩盖裂纹或磨损的，视为隐瞒瑕疵，直接触发必拒。报告必须写明护理痕迹，未写即违规。

**五金氧化算不算瑕疵？买家以此要求降价怎么办？**

不算功能瑕疵，属正常老化通病。LV、Gucci 等品牌五金氧化普遍存在，轻微氧化不影响成色定级，仅在氧化面积大或镀层起皮时在报告中标注并酌情降档。买家以"五金不亮"为由要求降价，不成立。

**序列号查不到对应记录，一定是仿品吗？**

不直接判定仿品。先核对序列号格式与品牌产地、生产年份的对应逻辑，再查品牌数据库。格式逻辑矛盾且无合理解释的，触发必拒；仅数据库暂无记录但格式与工艺对版、双人复核无仿品特征的，按真品处理并在报告中注明"数据库未收录"。
