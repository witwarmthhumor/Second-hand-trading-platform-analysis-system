# 折叠屏专项质检分册：检测要点与典型问题

## 一、检测范围与流程

折叠屏机型按本分册执行，通用流程与直板机一致，另增铰链、内屏、折痕三项专项检测。

1. 收件核验与防拆封登记，签收后 30 分钟内完成。
2. 外观分级拍照，正面/背面/四边/接口，共 ≥6 张，展开态与折叠态各半。
3. 进水标检查，覆盖 SIM 槽、充电口，折叠屏额外检查铰链缝隙处。
4. 功能逐项检测，折叠屏须先过直板机全部功能项，再走专项。
5. 电池健康与循环次数读取。
6. ID 锁/账户锁退出验证。
7. 出报告，签收后 48 小时内完成。

异议复检申请窗口为 72 小时，超时不予受理。折叠屏专项检测不通过则整机不进入成色评级流程。

## 二、检测工具与环境

- 强光手电或可调角度台灯，用于折痕与铰链缝隙观察。
- 放大镜（建议 10 倍），检查铰链表面磨损与内屏胶合边界。
- 屏幕网格测试图，全屏划分 12 区域做触控检测。
- 折叠寿命测试用手动开合，不借助机器，单次完整开合计 1 次。
- 检测台面须平整、无硬质颗粒，防止二次损伤内屏。
- 环境光线均匀，避免直射导致折痕误判。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
| --- | --- | --- | --- |
| 铰链阻尼与异响 | 开合顺畅、无卡顿、无异响 | 手动开合 30 次，听诊异响 | 有明显异响或段落感计 B 级以下；卡死即拒 |
| 折痕深度 | 息屏强光侧照下折痕不明显 | 强光侧照 + 手指横划感知 | 折痕可见但触感轻微计 A 级；触感明显计 B 级；凹陷深、影响观看计 C 级 |
| 内屏触控分区失灵 | 12 区域全部响应正常 | 网格法全屏 12 区域逐点触控 | 任一区域断触即计 D 级并显著披露 |
| 屏幕胶合开胶 | 屏幕与边框胶合紧密、无翘起 | 目视 + 指甲轻划边界 | 开胶长度 >1cm 计 C 级；开胶导致内屏进灰计 D 级 |
| 内屏坏点/色斑 | 无坏点、无异常色斑 | 纯色画面逐色检查 | 中心区坏点降 1 级；色斑面积 >3mm² 计 C 级 |
| 铰链外观磨损 | 铰链无明显露底金属 | 目视 + 放大镜检查 | 露底金属即降 1 级；掉漆面积 >5mm² 计 C 级 |
| 外屏划痕 | 强光侧照 ≤2 条发丝纹且不在显示区 | 强光侧照分级 | 超出标准降 1 级；显示区划痕计 B 级以下 |
| 电池健康 | S≥90%，A 80–89% | 系统读取 + 循环次数记录 | <80% 必须明示，<60% 必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
| --- | --- | --- |
| N 全新 | 未拆封未使用，配件包装齐全 | 原封未动，铰链无开合痕迹 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 开合 <50 次，折痕几乎不可见 |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | 折痕轻微可见，铰链无磨损，电池健康 ≥90% |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | 折痕触感轻微，铰链有细纹但无露底 |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | 折痕明显、铰链露底金属，或掉漆面积 >5mm² |
| D 7成新及以下 | 较重磨损/局部功能瑕疵，必须显著披露 | 内屏分区断触、开胶进灰、折痕凹陷影响观看 |

折叠屏折痕与铰链状态是定级前置条件，先定专项等级再套六档。电池健康 <80% 必须在报告中明示，循环次数超过 500 次须显著标注。

## 五、必拒情形

出现以下任一情形即拒收，不进入评级流程：

- ID 锁/账户锁未退出。
- 电池健康 <60%。
- 主板维修史未申报。
- 进水标变色且功能异常。
- 机身弯曲变形（>1mm），折叠屏含铰链座变形。
- 序列号与机身/系统不一致。
- 铰链卡死无法正常开合。
- 内屏大面积断触（超过 3 个网格区域失灵）。
- 隐瞒拆修史，一经发现必拒。

进水标变色即判定进水，不论功能是否正常。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 六、报告字段与拍照取证要求

报告字段：机型与序列号、铰链状态、折痕深度分级、内屏触控结果、电池健康、循环次数、ID 锁状态、专项异常项。

拍照取证口径：

- 至少 6 张照片，展开态正面、展开态背面、折叠态侧边、铰链特写、折痕侧照、接口进水标。
- 折痕照片须强光侧照拍摄，角度与光线条件写入报告备注。
- 铰链特写须覆盖左右两端与中部。
- 进水标照片须对焦清晰，能辨认颜色状态。
- 视频记录至少 15 秒，包含完整开合动作与触控滑动演示。

照片不足 6 张或关键异常项无影像证据的，报告不予通过。

## 七、常见争议与判定口径

**争议一：折痕明显但功能全好，买家要求按 D 级退货**

判定口径：折痕深浅只影响成色定级，不构成功能缺陷。触感轻微计 B 级，触感明显计 C 级，凹陷深、影响观看才计 C 级下限；只有折痕伴随内屏断触、开胶进灰等实质功能问题才计 D 级。买家仅以"折痕不好看"主张退货的，不予支持，按报告定级结算。依据：折痕属折叠屏正常使用损耗，定级表已按触感与观感分档，功能正常即不触发必拒条款。

**争议二：铰链有异响但开合顺畅，算不算质量问题**

判定口径：开合顺畅、无卡顿，仅偶发轻微摩擦声，不计异常；有明显异响或段落感，计 B 级以下并在报告中显著披露；卡死即拒。买家收货后自行频繁开合导致异响加剧的，以签收时报告记录为准，不追溯。依据：铰链阻尼与异响检测项以"开合顺畅、无卡顿、无异响"为合格线，异响分级须结合阻尼状态综合判断，单一声音现象不直接升级为必拒。

**争议三：内屏贴膜下有气泡，买家误认为屏幕开胶**

判定口径：撕膜后确认气泡位于贴膜层而非屏幕胶合层，不计异常；若气泡位于胶合边界且指甲轻划有翘起感，按屏幕胶合开胶处理，开胶长度 >1cm 计 C 级，开胶导致内屏进灰计 D 级。判定时须留取撕膜前后对比照片各一张。依据：开胶判定以胶合层分离为准，贴膜气泡属外观层问题，两者检测方法不同，不得混同定级。

**争议四：循环次数高但电池健康仍达标，定级是否受影响**

判定口径：电池健康与循环次数分开披露，互不折算。健康度 ≥90% 且循环次数超过 500 次的，成色可维持 A 级，但循环次数须在报告中显著标注；健康度 <80% 必须明示，<60% 必拒。买家以"循环多所以该降价"为由压价的，按报告明示信息协商，不强制改级。依据：电池健康以系统读数为准，循环次数是磨损参考项，两者各自独立写入报告，不互为加减分项。
