# 手机成色分级判定标准

## 一、检测范围与流程

本标准适用于 RAGreflow 平台全品牌手机（含折叠屏）的验货质检与成色分级。检测在验机仓内完成，流程固定为七个步骤，全程留痕。

1. 收件核验与防拆封登记：签收后 30 分钟内完成，核对序列号、机身外观与寄件信息一致性，拍照记录封条状态。
2. 外观分级拍照：正面、背面、四边、接口共 ≥6 张，强光侧照补拍屏幕划痕细节。
3. 进水标检查：逐一查看 SIM 槽、充电口、耳机口（如有）的进水标。进水标变色即判定进水，不论功能是否正常。
4. 功能逐项检测：按第三节表格逐项执行，含屏幕网格法、面容/指纹、传感器、摄像头等。
5. 电池健康与循环次数读取：用平台指定工具读取，记录健康度百分比与循环次数。
6. ID 锁/账户锁退出验证：确认激活锁、账户锁均为关闭状态。
7. 出报告：签收后 48 小时内出具完整验机报告。买卖任一方对结果有异议，可在 72 小时内申请复检。

## 二、检测工具与环境

检测区需保持恒温干燥，配备强光手电（用于侧照划痕）、工业放大镜、屏幕网格测试图、平台专用电池检测工具、SIM 卡槽顶针。折叠屏机型另备开合角度测量工具。所有工具定期校准，检测台面铺设防静电软垫，防止二次损伤。拍照背景统一为中性灰，光源角度固定，确保照片可复现、可追溯。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 屏幕划痕 | ≤2 条发丝纹且不在显示区 | 强光侧照，目视+放大镜 | 显示区划痕降 1 级；>2 条发丝纹降 1 级 |
| 边框磕碰 | 无露底金属磕碰 | 目视+触感 | 露底金属即降 1 级；掉漆面积 >5mm² 计 C 级 |
| 背板裂纹 | 无任何裂纹 | 目视+强光透照 | 任何裂纹计 D 级并显著披露 |
| 摄像头镜片划痕 | 镜片无中心区划痕 | 强光下斜视 | 中心区划痕降 1 级 |
| 屏幕坏点/断触 | 无坏点、无断触 | 网格法全屏 12 区域滑动测试 | 任一区域断触即功能异常，按 D 级披露 |
| 面容 ID/指纹解锁 | 录入后 3 次内成功解锁 | 实际录入与解锁 | 失败即功能异常，按 D 级披露 |
| 电池健康 | S 级 ≥90%，A 级 80–89% | 平台专用工具读取 | <80% 必须明示；<60% 必拒 |
| 循环次数 | 无硬性阈值 | 工具读取 | 循环次数超过 500 次必须在报告中显著标注 |
| 进水标 | 不变色 | SIM 槽、充电口、耳机口目视 | 变色即判定进水，不论功能是否正常 |
| ID 锁/激活锁 | 必须为关闭 | 系统设置内查验 | 未退出即必拒 |
| 充电口/扬声器/振动/听筒/麦克风 | 全部正常 | 实际插拔、播放、通话测试 | 任一异常按功能缺陷披露 |
| 前后摄像头对焦与闪光灯 | 对焦清晰、闪光正常 | 实拍远近景各 1 张 | 异常按功能缺陷披露 |
| 传感器（陀螺仪/指南针/距离感应） | 响应正常 | 系统自带诊断+实际调用 | 异常按功能缺陷披露 |
| 序列号一致性 | 机身、系统、包装三者一致 | 核对 IMEI/SN | 不一致即必拒 |

品牌分册另有特殊检测点，按平台分册执行。苹果 iPhone 加测面容 ID 模组、原彩显示、零部件维修提示弹窗，核对官换机/资源机标识；三星加测 Knox 熔断状态并鉴别国行/港版/海外版；折叠屏专项加测铰链阻尼与异响、折痕深度、内屏触控分区失灵、屏幕胶合开胶。

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封机，塑封膜完好 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 拆封激活但使用极短，屏幕无划痕，边框无磕碰，电池健康 ≥90% |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 屏幕 ≤2 条发丝纹且不在显示区，边框无露底磕碰，电池健康 80–89% |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 边框 1 处轻微磕碰但未露底金属，屏幕有细微划痕但不在显示区 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 掉漆面积 >5mm²，或边框磕碰露底金属（降级至此档） |
| D（7成新及以下） | 较重磨损/局部功能瑕疵，必须显著披露 | 背板裂纹、摄像头中心区划痕、电池健康 <80% 且功能异常 |

电池健康 <60% 直接进入必拒，不参与成色判定。循环次数超过 500 次时，不论成色档位，报告中均须显著标注。

## 五、必拒情形

以下情形出现任意一项，即拒收并出具说明，不进入成色分级流程：

- ID 锁/账户锁未退出
- 电池健康 <60%
- 主板维修史未申报
- 进水标变色且功能异常
- 机身弯曲变形（>1mm）
- 序列号与机身/系统不一致

任何拆修史必须写入报告，隐瞒拆修即必拒。进水标变色但功能正常者，不直接拒收，但须降级至 D 级并显著披露。

## 六、报告字段与拍照取证要求

验机报告须包含以下字段：设备序列号与 IMEI、品牌型号、成色档位、电池健康度与循环次数、进水标状态、ID 锁/账户锁状态、维修史声明、功能检测结果逐项勾选、外观瑕疵位置标注图、检测员编号与出报告时间。任一字段缺失，报告视为无效。

拍照取证至少 6 张，覆盖正面、背面、四边与接口，强光侧照补拍屏幕细节。划痕、磕碰、掉漆等瑕疵须局部特写，瑕疵位置在标注图上圈出。进水标变色、背板裂纹、机身弯曲等必拒情形，须单独加拍，照片能清晰辨认判定依据。所有照片拍摄后不得裁剪、调色，原图归档备查。

报告出具后 48 小时内可申请复检，复检以首次检测照片与留样为准。

## 七、常见争议与判定口径

**争议一：进水标变色但功能全好，算不算进水？**
判定口径：算。进水标变色即判定进水，不论功能是否正常。功能正常者不直接拒收，降级至 D 级并显著披露；功能异常者直接必拒。依据：进水标变色说明机身曾接触液体，内部腐蚀风险无法排除，功能正常只是当前状态。

**争议二：卖家说"只是换过电池"，要不要降级？**
判定口径：任何拆修史必须写入报告，隐瞒拆修即必拒。换电池属于拆修，如实申报后按拆修机处理，成色最高不超过 B 级；未申报被查出，直接拒收。依据：拆修史影响防水性与内部工艺完整性，买家有权在知情前提下决定是否购买。

**争议三：屏幕划痕在显示区边缘，算不算"不在显示区"？**
判定口径：以点亮屏幕后的可视区域为界，划痕落在点亮区域内即算显示区划痕，降 1 级；仅在边框或黑边区域则不算。拍照时须点亮屏幕，让划痕位置可判定。依据：显示区划痕直接影响日常使用观感，与边框划痕对成色的影响不同。
