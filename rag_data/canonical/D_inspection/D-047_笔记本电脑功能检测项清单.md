# 笔记本电脑功能检测项清单

## 一、检测范围与流程

笔记本电脑品类执行七步标准流程，全程留痕。验机仓签收后 48 小时内必须出报告；买卖任一方对结果有异议，可在报告出具后 72 小时内申请复检，复检以平台公示规则为准。

1. **收件核验与防拆封登记（30 分钟内）**：核对机身 SN、配件清单与卖家申报是否一致，对包裹外观、封条状态拍照存档。发现封条破损或机身 SN 与申报不符，立即上报并暂停检测。
2. **外观分级拍照**：A 面（顶盖）、C 面（键盘面）、D 面（底盖）各取 ≥2 张，转轴两侧、四角、接口区域必须入镜。照片需在自然光或标准光源下拍摄，不得使用滤镜。
3. **拆底盖核验（征得同意后）**：确认硬盘、内存是否原装，检查进水标、螺丝动过痕迹、主板维修飞线。买家未授权拆盖的，在报告中注明"未拆盖核验"，相关项按"无法确认"处理。
4. **功能与压力检测**：按第三部分明细表逐项执行，高负载压力测试 15 分钟，记录 CPU/GPU 温度曲线与降频情况。
5. **电池循环与健康读取**：使用系统报告或第三方工具读取设计容量、实际满充容量与循环次数。
6. **账户/BIOS 锁退出验证**：确认 Windows 账户、Apple ID、品牌账号及 BIOS 密码均已退出或清除。
7. **出报告**：签收后 48 小时内完成。报告含成色判定、检测项明细、异常披露与照片附件。

## 二、检测工具与环境

检测工位需配备稳定电源、千兆有线网络（用于系统激活与在线诊断）、标准光源灯箱。软件工具包括：CPU-Z、HWiNFO64、CrystalDiskInfo、品牌官方诊断工具（如戴尔 SupportAssist、惠普 HP 硬件诊断）。系统层面使用 Windows 自带"电池报告"命令读取循环数据，macOS 使用系统信息中的电源选项卡。压力测试统一使用 AIDA64 或 FurMark，测试时长 15 分钟。屏幕检测使用纯色测试页，覆盖黑、白、红、绿、蓝 5 色。环境要求：室温 20–26℃，工位无强光直射屏幕，外接键盘鼠标各一套备用。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 屏幕亮/坏点/亮度均匀性 | 无亮点，坏点 ≤5 个，无漏液 | 纯色 5 色测试，全屏目视 + 纯色照片留档 | 坏点 >5 个或漏液即必拒；1–5 个坏点按 D 级披露 |
| 键盘全键与触控板 | 全键触发正常，无连击，触控板无漂移 | 逐键测试（含 Fn 组合键），触控板画圈测试 | 单键失灵可修复则 B 级以下；连击需更换键盘，按 C 级并披露 |
| 全接口插拔 | USB/HDMI/音频/读卡器均识别正常 | 每接口插拔 ≥3 次，USB 接移动硬盘实测读写 | 接口松动或失灵，按 C 级以下并披露具体接口 |
| WiFi/蓝牙/摄像头/麦克风 | 连接稳定，音画正常 | WiFi 连 5G 频段、蓝牙配对耳机、摄像头拍测试照、麦克风录音回放 | 任一功能失效按 D 级披露；WiFi 模块故障建议必拒 |
| 电池健康与循环次数 | 健康度 S≥90%，A 80–89%；循环 >500 次显著标注 | 读取设计容量与实际满充容量比值；循环次数读取系统数据 | 健康度 <80% 必须明示；<60% 直接拒收；鼓包即必拒 |
| 高负载压力测试 15 分钟 | 无异常关机、无降频至基频以下 | AIDA64 单烤 FPU + FurMark 双烤 15 分钟，记录温度曲线 | 温度墙内降频属正常；异常关机或过热重启按 D 级披露 |
| 系统/BIOS 账户锁退出 | Windows/Apple ID/品牌账号全部退出，BIOS 无密码 | 重启进 BIOS 验证无密码；系统内检查账户列表 | 任一锁未退出即必拒，不进入后续流程 |
| 转轴阻尼与异响 | 开合 20 次无卡顿、无异响、无松动 | 手动开合 20 次，角度从 0° 到最大开合角 | 异响或阻尼异常按 C 级披露；转轴区裂纹（翻转本重点）按必拒处理 |
| 扬声器与音频 | 左右声道正常，无爆音 | 播放低频/高频测试音频，逐步调至最大音量 | 爆音或单侧无声按 C 级披露；MacBook Pro 扬声器爆音按品牌专项处理 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封箱未开，封条完整，电池循环 0–1 次 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 开箱试机后退回，A/C/D 面无划痕，循环 ≤5 次 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 使用数月，A 面有极轻微细划（自然光下不明显），循环 ≤50 次 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | C 面键帽轻微油光，D 面脚垫有磨损，循环 ≤200 次 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 边角磕碰 ≤1cm，键帽油光明显，电池健康 80–89% |
| D（7成新及以下） | 较重磨损/局部功能瑕疵，必须显著披露 | 屏幕坏点 1–5 个，接口部分失灵，电池健康 <80% 且 ≥60% |

## 五、必拒情形

以下情形出现即拒收，不进入后续流程，直接通知卖家并说明原因：

- 系统/BIOS 锁未退出（含 Windows 账户、Apple ID、品牌账号、BIOS 密码任一未清除）
- 电池鼓包（目视或手感确认即拒，不论功能是否正常）
- 主板进水或维修史未申报——进水标变色即判定进水；隐瞒拆修史即必拒
- 屏幕漏液或坏点 >5 个
- 配件缺失到影响开机（无电源适配器且电池报废）

任何拆修史必须写入报告，隐瞒拆修即必拒。

## 六、报告字段与拍照取证要求

报告必含字段：机身 SN、申报成色与判定成色、电池健康度与循环次数、拆盖核验结论、检测项逐项结果、异常披露、必拒/通过结论。循环次数超过 500 次必须在报告中显著标注；电池健康度 <80% 必须明示。

拍照取证至少 6 张：A/C/D 面各 ≥2 张，加拍转轴两侧、四角、接口区域、进水标、螺丝特写。每段视频不少于 15 秒，覆盖开合测试与压力测试过程。照片命名规则：SN_部位_序号，与报告条目一一对应。

## 七、常见争议与判定口径

**争议一：卖家称"仅拆盖清灰"不算拆修。** 判定口径：凡拆过底盖即属拆修史，必须写入报告；未申报即按隐瞒拆修处理，必拒。依据：拆修史申报是必拒清单红线，不区分维修内容。

**争议二：电池健康度读数与卖家自测不一致。** 判定口径：以验机仓读取的实际满充容量与设计容量比值为准，第三方工具读数仅作参考。依据：电池健康度 <60% 直接拒收，读数差异影响成色判定，必须统一口径。

**争议三：屏幕坏点数量在临界值附近。** 判定口径：坏点以纯色测试下肉眼可辨为准，计数时取两次独立测试的较大值；坏点 >5 个即必拒。依据：屏幕漏液或大面积坏点（>5 个）属必拒清单，临界情形从严判定。
