# 联想小新质检分册：检测要点与典型问题

## 一、检测范围与流程

联想小新定位轻薄本，常见于学生与办公场景，整机便携损耗与电池衰减是质检主线。本分册覆盖小新 Air、Pro 及数字系列，流程沿用笔记本电脑通用七步法，验机仓签收后 48 小时内必须出报告。

1. **收件核验与防拆封登记**：签收后 30 分钟内完成序列号核对、外观预检与防拆贴登记。封条破损或机身码与订单不符，立即拍照上报。
2. **外观分级拍照**：A/C/D 面各 ≥2 张，转轴区与四角补拍特写。
3. **拆底盖核验**：征得卖家同意后执行。重点查硬盘/内存原装性、进水痕迹与螺丝动过痕迹。小新底盖卡扣脆弱，须用塑料撬片，金属工具留下撬痕会直接影响成色定级。
4. **功能与压力检测**：按第三部分明细表逐项执行，高负载测试 15 分钟并记录 CPU/GPU 温度与降频情况。
5. **电池循环与健康读取**：使用联想自带诊断工具或 AIDA64 读取设计容量、满充容量与循环次数。
6. **账户/BIOS 锁退出验证**：确认联想账号已退出、Windows 账户已移除、BIOS 密码已清除。
7. **出报告**：签收后 48 小时内完成。买家有异议的，可在 72 小时内申请复检。

## 二、检测工具与环境

| 工具/环境 | 要求 |
|---|---|
| 标准光源 | 色温 5000K 左右，照度均匀，避免侧光造成误判 |
| 放大镜/微距镜头 | 用于转轴裂纹与进水标变色确认 |
| 纯色测试图 | 黑/白/红/绿/蓝 5 色，用于屏幕检测 |
| 压力测试软件 | AIDA64 或 FurMark，持续 15 分钟 |
| 电池读取工具 | 联想 Vantage 或 AIDA64 |
| 拆机工具 | 塑料撬片、精密螺丝刀，扭矩不可过大 |
| 防静电手环 | 拆底盖全程佩戴 |
| 环境要求 | 温度与湿度参照实验室通用标准，桌面铺设防静电垫 |

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 联想账号退出 | 设备已退出卖家联想账号，无 Find My Device 锁定 | 设置-账户-检查登录状态；重启后确认无锁屏提示 | 未退出即必拒，需卖家配合远程退出 |
| 性能模式切换 | 智能/均衡/野兽模式可正常切换，风扇响应正常 | 联想电脑管家-性能模式，逐一切换并观察 | 切换失效或报错，按功能瑕疵降级；野兽模式下风扇异响按 B 级以下处理 |
| 屏幕亮/坏点/均匀性 | 无亮线，坏点 ≤5 个，纯色下无肉眼可见亮度不均 | 纯色 5 色测试，全屏观察 | 坏点 >5 个或漏液即必拒；轻微亮度不均按 C 级披露 |
| 键盘与触控板 | 全键无连击、无失灵，触控板点击与多指手势正常 | 逐键测试 + 触控板手势测试 | 单键失灵按 B 级；连击超过 3 键按 C 级 |
| 转轴阻尼与异响 | 开合 20 次无卡顿、无异响，任意角度可停留 | 手动开合 20 次，单手持屏测试 | 异响或阻尼异常按 B 级；转轴区裂纹即必拒 |
| 全接口插拔 | USB/HDMI/音频/读卡器均识别正常 | 逐一插拔测试，USB 读写文件验证 | 单接口失灵按 C 级；影响开机的接口故障按 D 级 |
| 电池健康与循环 | S 级 ≥90%，A 级 80-89%；<80% 必须明示 | 读取设计容量与满充容量比值 | 循环 >500 次必须在报告显著标注；健康 <60% 即必拒 |
| 高负载压力测试 | 15 分钟内无异常关机，温度未触发强制降频 | AIDA64 单烤 FPU 15 分钟，记录温度曲线 | 过热关机或降频严重按 C 级并注明散热状况 |
| 电池鼓包 | 底盖平整，无鼓包 | 目视 + 手按压底盖中央与边缘 | 鼓包即必拒，无论功能是否正常 |
| 进水标状态 | 进水标为白色/原色 | 拆底盖后目视检查主板多处进水标 | 进水标变色即判定进水，不论功能是否正常 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封箱未开，封条完整 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅开箱通电验机，A 面无划痕，键盘无油光 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | A 面 1-2 处细微划痕，D 面脚垫轻微磨损 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | C 面键帽轻微油光，转轴阻尼略松但无异响 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 边角磕碰 ≤2 处，电池健康 80% 以下，单接口失灵 |
| D（7成新及以下） | 较重磨损/局部功能瑕疵，必须显著披露 | 屏幕有 3-5 个坏点，键盘多键连击，电池健康 <60% |

电池健康单独定级：S 级要求 ≥90%，A 级 80-89%。健康度 <80% 必须明示并直接影响成色上限。循环次数超过 500 次必须在报告显著标注。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 六、报告字段与拍照取证要求

报告字段按通用模板填写，联想小新分册额外要求以下字段必填：

| 字段 | 填写要求 |
|---|---|
| 序列号 | 与机身 D 面、系统内三码一致 |
| 联想账号状态 | 已退出/未退出，未退出须注明处理进度 |
| 性能模式验证结果 | 三种模式是否可切换 |
| 电池健康度与循环次数 | 健康度按百分比填写；循环 >500 次显著标注 |
| 拆修史 | 有/无；有则注明维修部位与时间 |
| 进水标状态 | 全部检测点位逐一记录颜色 |
| 成色定级 | 按第四部分判定表执行，附定级依据 |

拍照取证不少于 6 张，覆盖：整机 A 面、C 面键盘区、D 面脚垫与螺丝、转轴区特写、屏幕纯色测试画面、电池健康读数截图。进水标变色、螺丝滑丝、撬痕等异常点须单独补拍微距特写。所有照片须在标准光源下拍摄，文件名以"序列号+部位+时间"命名，禁止修图或调色。

## 七、常见争议与判定口径

**争议一：卖家称"只拆过加内存，没动其他"，买家认为算拆修。** 判定口径：只要底盖螺丝有动过痕迹，即按拆修记录写入报告，不区分拆修目的。依据：隐瞒拆修即必拒，拆修史必须如实披露。

**争议二：电池健康读数偏低，卖家质疑检测工具不准。** 判定口径：以联想 Vantage 与 AIDA64 双工具交叉读取，两次读数一致即采信；读数不一致时取较低值并注明。依据：健康度 <80% 必须明示，低于必拒线即拒收。

**争议三：性能模式切换正常但野兽模式下风扇声音偏大，卖家认为属正常散热。** 判定口径：高负载测试 15 分钟内风扇无异响、无高频啸叫即判正常；持续异响按 B 级以下处理并在报告注明。依据：风扇异响属于功能异常，须如实披露。
