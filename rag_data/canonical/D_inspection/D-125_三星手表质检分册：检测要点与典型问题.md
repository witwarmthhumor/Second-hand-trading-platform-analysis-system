# 三星手表质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于三星 Galaxy Watch 系列（含 Classic、Pro、FE 等子型号）及旧款 Tizen 系统机型的回收质检。验机仓签收后 48 小时内必须出报告；买卖任一方对结果有异议，可在报告出具后 72 小时内申请复检。

流程按以下步骤执行，每步留痕：

1. **收件核验与登记**：签收后 30 分钟内完成包裹拆封、序列号核对与系统登记。核对表身 IMEI/SN 与订单信息是否一致。
2. **外观拍照**：表体、表带、表扣三个部位合计至少 6 张照片，含微距特写。
3. **配对锁解除验证**：确认 Samsung 账号已退出、激活锁已解除。此项不通过直接进入必拒流程，不继续后续检测。
4. **功能逐项检测**：按第三节明细表顺序执行。
5. **电池健康读取**：支持机型通过手表设置路径读取电池健康度；Tizen 旧款无法直接读取的，以循环次数与充电实测作为参考依据。
6. **出报告**：签收后 48 小时内完成全部检测并出具电子报告。

## 二、检测工具与环境

检测工位需配备：防静电垫、微距镜头（手机外接或台架均可）、标准光源色温灯、蓝牙配对测试机（Android/iOS 各一台）、充电底座（无线充电板）、GPS 信号测试环境（窗边或室外即可，无需专业设备）。

环境要求：桌面平整、光线均匀，避免强反光影响表镜划痕判断。配对测试机需提前关闭系统自动更新，防止检测过程中系统升级导致变量。所有检测操作须在防静电手环或防静电垫上进行，避免静电损伤电子元器件。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| Samsung 账号与激活锁 | 账号已退出、激活锁已解除 | 设置—账户—退出登录；恢复模式验证 | 未解除即必拒 |
| 表镜外观 | 无碎裂、划痕不影响显示 | 微距拍照 + 侧光观察 | 碎裂影响显示即必拒；细微划痕按成色降档 |
| 表壳与镀层 | 无磕碰变形、镀层无大面积脱落 | 目视 + 触感检查 | 明显磕碰按 C/D 档；镀层脱落写入报告 |
| 表冠转动 | 转动顺滑、无卡滞、按压回弹正常 | 手动旋转与按压各 10 次 | 卡滞或失灵按功能缺陷处理 |
| 心率/血氧/ECG | 与标准设备对比误差在可接受范围 | 同时佩戴标准设备静坐 60 秒对比 | 传感器模组失效即必拒；误差偏大按 D 档披露 |
| GPS 定位 | 室外空旷处 2 分钟内定位成功 | 开启户外跑步模式实测 | 无法定位按功能缺陷处理 |
| 蓝牙连接与通话 | 与测试机连接稳定、通话清晰 | 配对测试机拨打测试电话 | 连接频繁断开按功能缺陷处理 |
| 防水密封 | 密封圈无老化开裂、说明书口径一致 | 外观检查密封圈，不做破坏性水测 | 密封圈老化开裂按必拒处理 |
| 电池健康 | S 档 ≥90%，A 档 80-89%，低于 80% 必须披露，低于 60% 拒收 | 设置—电池—健康度读取 | 循环超 500 次须在报告显著标注 |
| 充电触点 | 无氧化、接触良好 | 目视 + 充电测试 | 触点氧化导致充不进电按功能缺陷处理 |
| 表带与表扣 | 无拉伸老化、无异味、生耳不松动 | 拉伸表带观察回弹，按压生耳 | 生耳松动更换后复检；异味严重按 C/D 档 |
| 蜂窝版 eSIM | eSIM 已注销、运营商锁已解除 | 设置—连接—移动网络核对 | 未解除运营商锁即必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N 全新 | 未拆封未使用，配件包装齐全 | 原封盒装，封条完好 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 仅试戴过，表带无折痕，电池健康 ≥90% |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | 表壳有极细发丝纹，电池健康 80-89% |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | 表带有轻微佩戴纹，表镜无划痕 |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | 表壳有可见磕点，表带轻微老化 |
| D 7成新及以下 | 较重磨损或局部功能瑕疵，必须显著披露 | 表镜有划痕但不影响显示，电池健康低于 80% |

电池健康低于 80% 必须披露，低于 60% 直接拒收。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 五、必拒情形

出现以下任一情形，直接拒收并终止检测：

- Samsung 账号未退出或激活锁未解除
- 蜂窝版未解除运营商锁（如有）
- 电池鼓包
- 表镜碎裂影响显示
- 传感器模组失效（心率/血氧/ECG 任一无法工作）
- 进水标变色（不论功能是否正常）
- 隐瞒拆修史

## 六、报告字段与拍照取证要求

报告须包含以下字段，缺一项即视为无效报告：

| 字段 | 要求 |
|---|---|
| 订单号与序列号 | 与收件登记一致 |
| 成色判定 | 按第四节六档标准，注明判定依据 |
| 电池健康度 | 支持机型填写百分比；Tizen 旧款填写循环次数或"无法读取" |
| 拆修史 | 有则如实填写，隐瞒即必拒 |
| 功能异常清单 | 逐项列出异常项及检测方法 |
| 进水标状态 | 变色即判定进水，不论功能是否正常 |
| 照片附件 | 至少 6 张，含微距特写 |

拍照取证口径：表体正面、背面、四角、表带内外侧、表扣开合处各角度覆盖；划痕、磕碰、氧化点必须单独微距拍摄，照片需能对应到具体部位。进水标变色、电池鼓包等必拒情形须额外拍摄特写留存。循环次数超过 500 次的手表，报告须在显著位置标注，并附截图或照片佐证。所有照片在报告出具后保留备查，复检期内不得删除。

## 七、常见争议与判定口径

**争议一：表镜有细微划痕但买家认为应判 B 档。** 判定口径：以侧光下肉眼是否可见为准，不可见的按 B 档，可见的降为 C 档。依据是成色判定表以"明显使用痕迹"为 C 档起点，细微划痕不属于明显痕迹。

**争议二：手表功能正常但进水标变色，卖家主张不影响使用。** 判定口径：进水标变色即判定进水，不论功能是否正常，直接拒收。依据是进水导致的内部腐蚀往往滞后显现，当前功能正常不能排除后续故障风险。

**争议三：电池健康度读取值与买家自测不一致。** 判定口径：以验机仓读取值为准，买家可在 72 小时内申请复检，复检仍不一致的以两次读取中较低者为准。依据是电池健康度受温度、充电习惯影响，单次读数存在正常波动。

**争议四：卖家称手表从未拆修，但检测发现防水胶圈有更换痕迹。** 判定口径：任何拆修史必须写入报告，隐瞒拆修即必拒，不因功能正常而豁免。依据是拆修过的防水密封无法恢复原厂状态，直接关系防水性能判定。
