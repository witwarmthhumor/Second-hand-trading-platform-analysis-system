# 智能手表与穿戴拒收与必拒情形清单

## 一、检测范围与流程

智能手表与穿戴类目涵盖 Apple Watch、华为手表、小米手环与手表、荣耀手表、三星手表、Garmin 等主流品牌，以及配套表带、表壳等配件。检测目标是确认设备功能完整、账号锁已解除、外观瑕疵如实披露，并为每一台设备出具可追溯的验机报告。

验机仓签收后按以下流程推进，全程时限受系统管控：

1. **收件核验与登记**：签收后 30 分钟内完成包裹外观核验、序列号登记、与寄卖单信息比对。
2. **外观拍照**：表体、表带、表扣各角度拍照，不少于 6 张，覆盖全部外观检测项。
3. **配对锁解除验证**：逐品牌核对账号锁状态，确认已解除后方可进入功能检测。
4. **功能逐项检测**：按第三部分检测项明细表逐项执行，记录每项结果。
5. **电池健康读取**：支持机型读取电池健康百分比与循环次数，写入报告。
6. **出报告**：签收后 48 小时内出具完整验机报告；卖家对结果有异议的，可在报告出具后 72 小时内申请复检。

## 二、检测工具与环境

检测在标准验机工位完成，工位配备防静电垫、软毛刷、气吹、放大镜、充电线材及各品牌专用读取工具。环境要求光线均匀，避免反光影响表镜划痕判断；工位保持干燥清洁，禁止在有水渍或高湿度环境下操作设备。

电池健康读取使用各品牌官方或授权诊断工具，读取路径以品牌分册为准。防水密封检测只做外观检查与说明书口径核对，不做破坏性水测，任何情况下不得将设备浸入液体。拍照设备像素须满足划痕与磕碰的清晰呈现要求，照片不得美颜、不得修图。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 表镜划痕与碎裂 | 无影响显示与触控的划痕或裂纹 | 放大镜目视 + 强光侧照 | 轻微划痕按 B/C 级披露；表镜碎裂影响显示即必拒 |
| 表壳磕碰与镀层脱落 | 无明显磕碰或镀层剥落 | 目视 + 触感确认 | 轻微磕碰按 C 级披露；露出底材的深磕碰降 D 级 |
| 表带拉伸老化与异味 | 表带无断裂、无严重拉伸变形 | 拉伸测试 + 嗅觉确认 | 明显老化按 C 级披露；断裂或不可修复异味降 D 级 |
| 充电触点氧化 | 触点无影响充电的氧化 | 目视 + 充电测试 | 轻微氧化可清洁后复测；严重氧化导致充不进电即必拒 |
| 心率/血氧/ECG | 读数与标准设备误差在合理范围 | 与标准设备对比记录 | 误差超范围或无法读数即必拒（传感器模组失效） |
| GPS 定位 | 室外定位正常 | 室外实测定位 | 无法定位或漂移严重按功能异常处理 |
| 蓝牙连接与通话 | 蓝牙配对正常、通话清晰 | 与标准手机配对实测 | 无法连接或通话异常按功能缺陷降级 |
| 防水密封 | 密封圈无老化、无进水痕迹 | 外观检查 + 说明书口径核对 | 进水标变色即判定进水，不论功能是否正常，即必拒 |
| 电池健康 | S 级 ≥90%，A 级 80-89% | 官方工具读取 | 低于 80% 须披露；低于 60% 即必拒 |
| 配对锁/激活锁 | 各品牌账号锁已解除 | 按品牌分册流程查验 | 未解除即必拒 |
| 表冠转动（Apple Watch） | 转动顺滑、无卡顿 | 手动转动测试 | 卡顿或异响按功能缺陷处理 |
| 腕带卡扣（小米） | 卡扣开合正常 | 手动开合测试 | 卡扣失效影响佩戴即降 D 级 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封盒装，表带未上过手 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅试戴过，无划痕，电池健康 ≥90% |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 表壳有极轻微细纹，电池健康 80-89% |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 表带有正常折痕，表壳有 1-2 处轻微划痕 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 表壳有可见磕碰，表镜有细划痕但不影响显示 |
| D（7成新及以下） | 较重磨损/局部功能瑕疵，必须显著披露 | 表带开裂、表镜多处划痕、电池健康低于 80% |

电池健康低于 80% 必须在报告中显著披露；循环次数超过 500 次同样须在报告中显著标注。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 五、必拒情形

出现以下任一情形，设备直接拒收，不进入成色判定流程：

1. **配对锁/激活锁未解除**：Apple ID 激活锁、华为账号、小米账号、荣耀账号、Samsung 账号、Garmin Connect 账号等任一未解除。
2. **电池鼓包**：表体变形或屏幕被顶起，存在安全隐患。
3. **表镜碎裂影响显示**：裂纹贯穿显示区域或影响触控。
4. **蜂窝版未解除运营商锁（如有）**：eSIM 未注销或运营商锁未解除。
5. **传感器模组失效**：心率、血氧、ECG、光学心率窗等传感器无法正常工作。
6. **进水**：进水标变色即判定进水，不论功能是否正常。
7. **隐瞒拆修史**：报告未如实写入拆修记录。

## 六、报告字段与拍照取证要求

每份验机报告须包含以下字段：设备品牌与型号、序列号、成色等级、电池健康百分比（支持机型）、循环次数、账号锁状态、eSIM 注销状态（蜂窝版）、外观瑕疵逐项记录、功能检测结果、必拒项触发情况、检测员与检测时间。

拍照取证不少于 6 张，覆盖表体正面、背面、表带内外侧、表扣及充电触点。每处外观瑕疵须单独微距拍摄，照片命名与报告瑕疵描述一一对应。电池健康读数、循环次数、账号锁解除界面须截图存档。进水标状态单独拍照，变色即取证留存。

## 七、常见争议与判定口径

**争议一：卖家称表镜划痕为出厂贴膜划伤。** 判定口径：撕膜后复检表镜本体，划痕在膜上则按无瑕疵处理，划痕在玻璃上按实际成色披露。依据：外观判定以表镜本体状态为准。

**争议二：电池健康低于 60% 但功能正常，卖家要求按 A 级回收。** 判定口径：电池健康低于 60% 即必拒，不进入成色判定。依据：必拒清单对电池健康设有硬性下限。

**争议三：设备进水但功能一切正常。** 判定口径：进水标变色即判定进水，直接拒收，不做功能验证。依据：进水判定以指示剂状态为准，不以功能表现为准。

**争议四：卖家否认拆修，但螺丝有拧动痕迹。** 判定口径：拆修史以螺丝痕迹与密封胶状态综合判断，确认拆修即必拒。依据：隐瞒拆修即必拒，报告须如实记录。
