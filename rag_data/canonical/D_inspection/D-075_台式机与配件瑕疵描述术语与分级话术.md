# 台式机与配件瑕疵描述术语与分级话术

## 一、检测范围与流程

台式机与配件检测覆盖：品牌整机、DIY 组装机、CPU、显卡、主板、内存、硬盘、电源、散热器、显示器、机械键盘。验机仓签收后 30 分钟内完成收件核验与登记，配件逐件清点并拍照留档。签收后 48 小时内必须出报告，买家可在报告出具后 72 小时内申请复检。

流程分五步，按序执行：

1. 收件核验与登记（30 分钟内完成，核对快递单号、SN 码、配件数量）。
2. 外观拍照（配件逐件清点，针脚、金手指、电容、风扇逐一特写）。
3. 通电点亮与功能测试（整机类先点亮，配件类上测试平台）。
4. 压力测试（整机与显卡、CPU 必须跑压力测试）。
5. 出报告（签收后 48 小时内，报告含分级结论与瑕疵描述）。

## 二、检测工具与环境

检测环境要求：防静电工作台、接地手环、温度 20-28℃ 的恒温房间。工具清单如下：

- CPU 压力测试用 AIDA64 或 Prime95，显卡用 FurMark 或 3DMark，内存用 Memtest。
- 硬盘读取用 CrystalDiskInfo 或 HD Tune，读取 SMART 信息与通电小时数。
- 显示器检测用纯色测试图，覆盖黑、白、红、绿、蓝五色。
- 拆机工具：防静电镊子、塑料撬棒、螺丝刀套装，禁止使用金属镊子直接触碰针脚。
- 拍照设备：像素不低于 1000 万的手机或相机，开启日期水印。

测试平台电源必须稳定，避免因测试平台自身问题误判配件故障。所有测试数据实时记录，不得事后补录。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|--------|----------|----------|---------------|
| CPU 针脚 | 无弯曲、无缺失 | 目视 + 微距拍照，逐排检查 | 缺失 >2 根必拒；弯曲 ≤2 根可矫正后复测 |
| CPU 压力测试 | 10 分钟稳定运行，温度不异常飙升 | AIDA64 单烤 FPU，记录主频与温度曲线 | 主频明显掉档或温度异常，降级至 C 并备注 |
| 显卡 3D 压力测试 | 15 分钟无花屏、无驱动崩溃 | FurMark 或 3DMark 循环跑 | 花屏/驱动崩溃即必拒；虚焊史直接必拒 |
| 内存识别与测试 | 全容量识别、双通道开启 | BIOS 查看 + Memtest 跑 1 轮 | 容量不对或双通道未开启，降级至 C；报错即必拒 |
| 硬盘 SMART | 健康状态良好，无报警 | CrystalDiskInfo 读取 | SMART 报警（重映射扇区超阈值）即必拒 |
| 机械盘异响 | 运行无异常咔嗒声 | 通电后贴近听诊 | 异响明显即降级至 D，需显著披露 |
| 电源电容 | 无鼓包、无漏液 | 开盖目视检查 | 电容鼓包即必拒 |
| 显示器坏点/亮斑 | 纯色 5 色下无可见坏点 | 逐色切换目视 + 拍照 | 坏点 ≤3 个降级至 B；亮斑面积大降级至 C |
| 机械键盘轴体 | 逐键触发正常、无连击 | 按键测试软件逐键按压 | 连击键位超过 3 个降级至 C，需披露具体键位 |
| 整机老化测试 | 连续运行 4 小时无重启死机 | 整机满载或混合负载跑 4 小时 | 中途死机重启，排查后仍复现即必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|------|----------|----------|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封箱说全，静电袋未拆 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 装机点亮一次即拆，无划痕 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 轻微插拔痕迹，金手指有极轻微氧化 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 外壳有细微划痕，风扇有少量积灰 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 机箱边角磕碰，内存金手指有明显划痕 |
| D（7成新及以下） | 较重磨损/局部功能瑕疵，必须显著披露 | 显卡散热鳍片变形、机械盘有异响 |

电池健康度适用于含电池的配件或一体机：S 级要求 ≥90%，A 级为 80-89%，低于 80% 必须披露具体数值，低于 60% 直接拒收。循环次数超过 500 次必须在报告中显著标注，不得隐藏。

## 五、必拒情形

以下情形出现即拒收，不做降级处理：

- 硬盘 SMART 报警（重映射扇区超阈值）。
- 显卡花屏/虚焊史，或检测中发现花屏。
- CPU 针脚缺失 >2 根。
- 电源电容鼓包。
- 整机无法点亮且原因不明。
- 进水标变色即判定进水，不论功能是否正常。
- 任何拆修史必须写入报告，隐瞒拆修即必拒。

拒收需在报告中写明拒收原因与对应证据照片编号，并通知寄卖方。

## 六、报告字段与拍照取证要求

报告字段按下述顺序填写，缺项即退回补录：

- 订单号、SN/序列号、配件逐项清单及数量。
- 外观瑕疵描述：位置 + 类型 + 尺寸/数量，用第三、四章术语表述。
- 功能测试结果：压力测试时长、温度/主频记录、SMART 数据、Memtest 结果。
- 成色定级（N/S/A/B/C/D）及降级理由。
- 必拒情形（如有）：引用具体条款编号。
- 拆修史与进水判定：进水标变色即判进水，不论功能是否正常；任何拆修史必须写入报告，隐瞒拆修即必拒。
- 电池健康度（适用时）：数值 + 循环次数，循环次数超过 500 次显著标注。
- 检测员编号与报告生成时间。

拍照取证至少 6 张，覆盖以下角度：

1. 整机/配件正面全景（含日期水印）。
2. SN 码或序列号特写。
3. 外观瑕疵特写（划痕、磕碰、氧化位置）。
4. 针脚/金手指/电容等关键部位微距。
5. 通电点亮或测试过程截图。
6. 必拒情形证据（报警界面、花屏画面、进水标变色）。

照片与报告字段一一对应，每张照片在报告中标注编号。视频取证不少于 15 秒，用于异响、风扇噪音、花屏等动态异常。证据不足的结论一律不下。

## 七、常见争议与判定口径

**争议一：买家认为"轻微氧化"应降级，卖家坚持按 A 级成交。**
判定口径：金手指氧化以是否影响识别与稳定性为准。氧化导致内存/显卡无法一次点亮，降级至 C；仅插拔痕级别的极轻微氧化，维持 A 级。依据：功能缺陷优先于外观痕迹定级。

**争议二：卖家称"只是清灰不算拆修"，买家认为隐瞒拆修。**
判定口径：凡打开机箱、拆卸散热器或更换硅脂均属拆修史，必须写入报告。清灰若未拆卸任何部件且留照证明，可不计拆修；拆卸过散热器即须披露。依据：隐瞒拆修即必拒，不因拆修内容善意与否改变。

**争议三：整机老化测试中途死机一次，复测通过，是否按合格出报告？**
判定口径：复测通过且查明死机原因为测试环境（如供电不稳）所致，可正常出报告，但须在备注中记录首次死机情况。复测仍死机或原因不明，按必拒处理。依据：整机无法点亮且原因不明即必拒，死机同理。

**争议四：显卡疑似挖矿痕迹但功能测试全部通过，如何定级？**
判定口径：核心硅脂更换史、显存测试异常或散热模组锈蚀等挖矿痕迹明显者，无论功能是否正常，最高定级不超过 C，并在报告中显著披露。功能测试全部通过且无上述痕迹，按正常成色定级。依据：挖矿痕迹属使用史披露范畴，不因功能正常而豁免。
