# 苹果iPhone质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于 RAGreflow 平台流通的所有 iPhone 机型（含官换机、资源机）。检测从验机仓签收开始计时，按以下步骤执行，全程需在签收后 48 小时内完成并出具报告。若卖家对判定结果有异议，可在报告出具后 72 小时内申请复检。

1. **收件核验与防拆封登记**（30 分钟内完成）：核对序列号与快递面单、平台订单是否一致，对包裹外观拍照留档，确认封条完整后拆封。
2. **外观分级拍照**：正面、背面、四边、接口部位，合计不少于 6 张。强光侧照下拍摄屏幕，确保划痕可辨。
3. **进水标检查**：检查 SIM 卡槽、充电口内的进水指示标。进水标变色即判定进水，不论功能是否正常。
4. **功能逐项检测**：按本文第三部分明细表逐项执行。
5. **电池健康与循环次数读取**：通过系统设置及辅助工具读取电池健康百分比与循环次数。
6. **ID 锁/账户锁退出验证**：确认「查找我的 iPhone」已关闭，iCloud 账户已退出。
7. **出报告**：签收后 48 小时内完成，报告需附全部取证照片及检测结论。

## 二、检测工具与环境

检测工位需配备：强光手电或可调角度台灯（用于侧照划痕）、显微镜或高倍放大镜（用于镜片划痕与掉漆边界判定）、iPhone 专用数据线及电脑端诊断工具（用于读取电池循环次数与维修记录）。环境要求为干燥、防静电，桌面铺设软垫以防磕碰。面容 ID 检测需在正常室内光线下进行，避免强逆光干扰。原彩显示检测需在色温稳定的光源下进行，避免因环境光变化造成误判。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
| --- | --- | --- | --- |
| 屏幕划痕 | 显示区无肉眼可见划痕；≤2 条发丝纹且不在显示区可计 A 级 | 强光侧照屏幕，倾斜 30° 观察 | 显示区划痕降 1 级；深划痕计 C 级 |
| 边框磕碰 | 无磕碰或极轻微 | 目测 + 手指触感确认 | 磕碰露底金属即降 1 级；掉漆面积 >5mm² 计 C 级 |
| 背板裂纹 | 无任何裂纹 | 强光下目测全背板 | 任何裂纹计 D 级并显著披露 |
| 摄像头镜片划痕 | 镜片中心区无划痕 | 放大镜观察前后摄镜片 | 中心区划痕降 1 级 |
| 屏幕坏点/触摸 | 无坏点、色斑，全屏触摸无断触 | 网格法全屏 12 区域逐区划动测试 | 任一区域断触计 D 级 |
| 面容 ID | 录入后解锁成功 | 设置中重新录入面容并锁屏测试 | 无法录入或识别失败，计 D 级并显著披露 |
| 电池健康 | S 级 ≥90%，A 级 80–89% | 设置 > 电池 > 电池健康读取 | <80% 必须明示；<60% 必拒 |
| 电池循环次数 | 无硬性阈值 | 电脑诊断工具读取 | 循环次数超过 500 次必须在报告中显著标注 |
| 原彩显示 | 开启后色温随环境光变化 | 控制中心开关原彩，观察屏幕色温 | 无变化则判定原彩模组异常，降 1 级 |
| 维修提示弹窗 | 无「未知部件」弹窗 | 设置 > 通用 > 关于本机查看 | 出现弹窗即记录拆修史，隐瞒拆修即必拒 |
| ID 锁/激活锁 | 必须为关闭状态 | 设置 > iCloud 检查「查找」状态 | 未退出即必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
| --- | --- | --- |
| N（全新） | 未拆封未使用，配件包装齐全 | 原封盒装，塑封膜完好 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅充电口有轻微插拔痕迹，电池健康 ≥90% |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | ≤2 条发丝纹且不在显示区，边框无露底磕碰 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 屏幕有 1 条可见划痕但不在显示区，电池健康 80–89% |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 边框掉漆但面积 ≤5mm²，或摄像头镜片边缘划痕 |
| D（7成新及以下） | 较重磨损/局部功能瑕疵，必须显著披露 | 背板裂纹、面容 ID 失效、电池健康 <80% |

电池健康阈值跨档位适用：S 级要求 ≥90%，A 级要求 80–89%，低于 80% 的机器无论外观多新，成色上限为 C 级，且报告中必须明示具体数值。

## 五、必拒情形

出现以下任一情形，直接拒收并退回卖家，不进入分级流程：

- **ID 锁/账户锁未退出**：「查找我的 iPhone」仍开启或 iCloud 账户未退出。
- **电池健康 <60%**：低于必拒红线，无协商空间。
- **主板维修史未申报**：检测发现主板级维修痕迹而卖家未申报。
- **进水标变色且功能异常**：进水标变色即判定进水；若伴随功能异常，直接必拒。
- **机身弯曲变形（>1mm）**：平放桌面翘起明显，或目测中框弯曲。
- **序列号与机身/系统不一致**：机身刻印、系统「关于本机」、包装三处序列号无法对应。

官换机或资源机需在报告中显著标注其标识，不得混同于全新零售机出售。

## 六、报告字段与拍照取证要求

报告需包含以下字段：平台订单号、序列号、机型与存储容量、外观成色（N/S/A/B/C/D）、各检测项结果、电池健康百分比、循环次数、拆修史记录、进水标状态、ID 锁状态，以及最终判定结论。任何拆修史必须写入报告，隐瞒拆修即必拒；循环次数超过 500 次必须在报告中显著标注；电池健康低于 80% 必须明示具体数值。

取证照片合计不少于 6 张，覆盖正面、背面、四边、接口部位。拍照要求：强光侧照屏幕以呈现划痕；边框磕碰处微距拍摄露底细节；背板裂纹需整机入镜加局部特写；进水标变色需在放大状态下拍摄。每张照片需在画面内放置含订单号的标签纸，确保可追溯。关键异常项（如维修弹窗、ID 锁未退）需额外录制不少于 15 秒的视频佐证。

## 七、常见争议与判定口径

**问：卖家说屏幕划痕是贴膜上的，怎么判？**  
撕膜后重新侧照。若划痕随膜去除而消失，按屏幕完好处理；若仍可见，按屏幕划痕分级。以撕膜后的实际状态为准，不采信口头描述。

**问：电池健康低于 80% 但外观接近全新，能定 A 级吗？**  
不能。电池健康低于 80% 时成色上限为 C 级，且报告中必须明示具体数值。外观成色与电池健康分别判定，取较低档位为最终成色。

**问：进水标变色但功能全部正常，收不收？**  
进水标变色即判定进水，不论功能是否正常。功能正常时按 D 级处理并显著披露；若伴随功能异常，直接必拒。

**问：官换机当零售机卖，怎么识别？**  
核对「关于本机」中的型号号码：官换机以字母 N 开头，零售机以 M 开头。识别为官换机后必须在报告中显著标注，不得混同于全新零售机。
