# LV质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于所有进入 RAGreflow 平台的 Louis Vuitton 箱包类商品，涵盖手提包、斜挎包、双肩包、旅行袋及小型皮具。收件后先做核验登记，30 分钟内完成，全程录像。录像文件与商品绑定，存档保留至订单完结后 90 天。

检测流程按六步执行：收件核验与登记 → 外观分级拍照（≥8 张，含五金特写）→ 身份卡/序列号/镭射标核验 → 五金与皮质逐项检测 → 真伪综合判定（双人复核）→ 出报告。报告须在签收后 48 小时内出具；卖家有异议的，可在 72 小时内申请复检，复检由另一组质检员独立完成。

LV 分册在通用流程之外，强制加入三个品牌特殊检测点：老花对花位、Date code 格式与产地对应、皮贴氧化蜜色。三项直接写入检测工单，缺一项即视为流程不完整。

## 二、检测工具与环境

检测台配备白光光源与侧光补光灯，照度均匀，避免强反光影响对花位判断。放大镜用于观察 Date code 刻印边缘与五金刻字底部。游标卡尺用于测量五金件厚度与刻字深度。UV 灯辅助检查部分年份款式的防伪特征。

皮质检测需在干燥环境下进行，高湿环境暂停皮质龟裂判定，避免误判。拍照背景统一为中性灰，不得使用滤镜或修图软件调整颜色。所有检测工具定期校准，校准记录留存备查。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|--------|----------|----------|----------------|
| 老花对花位 | 图案对称、拼接处花位连续无错位 | 目测 + 侧光观察拼接缝 | 错位＞2mm 降一级；明显错位且无法修复列入必拒 |
| Date code 格式与产地 | 格式与产地代码对应品牌数据库逻辑 | 放大镜读取 + 数据库比对 | 逻辑矛盾直接必拒；磨损模糊按 C 级以下披露 |
| 皮贴氧化蜜色 | 变色均匀，无深色斑块 | 目测 + 对比色卡 | 局部深斑降一级；整面不均匀且影响美观降两级 |
| 五金镀层与刻字 | 镀层无脱落，刻字清晰、底部平整 | 放大镜观察 + 指腹触感 | 镀层脱落面积＞3mm² 降一级；刻字模糊按工艺缺陷披露 |
| 四角磨损 | 无磨白或露料 | 目测 + 指腹触感 | 磨白不露料降一级；露料降两级；贯穿开裂必拒 |
| 拉链顺滑度 | 开合顺畅无卡顿，拉头完整 | 往复开合 5 次 | 卡顿需润滑为 B 级；拉头断裂无法修复必拒 |
| 内衬状态 | 无污渍、无异味 | 目测 + 嗅觉 | 局部污渍可清洁为 B 级；霉味超常规必拒 |
| 附件清点 | 防尘袋/肩带/小票齐全 | 对照清单逐项勾选 | 缺失附件须在报告中显著披露 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|------|----------|----------|
| N（全新） | 未拆封未使用，配件包装齐全 | 专柜原包装完整，防尘袋未打开 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅试背过，五金无划痕，皮贴无变色 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 边角极轻微磨白，五金正常氧化 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 手柄有汗渍变色，内衬轻微使用感 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 四角磨白不露料，皮贴氧化不均匀 |
| D（7成新及以下） | 较重磨损或局部功能瑕疵，必须显著披露 | 边角露料、拉链需用力开合 |

任何拆修史必须写入报告，隐瞒拆修即必拒。此条不因成色档位而豁免。

## 五、必拒情形

以下情形出现任意一项，直接拒收并出具说明：

- 判定为仿品。Date code 与品牌数据库逻辑矛盾，或老花对花位严重错位且工艺特征不符。
- 主料破损。面料破洞或开裂贯穿，超出可修复范围。
- 五金断裂无法修复。如拉头断裂、D 形环脱落且无法原厂更换。
- 强烈不可去除异味。霉味或烟味超常规，经护理后仍无法消除。
- 序列号与品牌数据库逻辑矛盾。如产地代码对应错误、日期编码超出该款式生产周期。

必拒商品退回卖家，平台不承担二次鉴定费用。卖家对必拒结论有异议的，同样适用 72 小时复检申请通道。

## 六、报告字段与拍照取证要求

报告字段包括：商品编号、品牌/系列/款式、Date code、成色档位、检测项明细、异常描述、附件清单、质检员编号、复核员编号、结论。报告中必须包含 Date code 与内标一致性核验结果，以及皮贴氧化蜜色的具体描述。

拍照取证至少 6 张，实际执行按 ≥8 张。必拍角度：正面整体、背面整体、底部四角、内衬全景、五金特写（含刻字）、Date code 特写、皮贴氧化区域特写、附件合影。每张照片须清晰可辨，模糊或反光过重的照片视为无效，需补拍。

进水标变色即判定进水的规则适用于具备防水涂层的 LV 旅行袋。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 七、常见争议与判定口径

**卖家认为"正常使用痕迹"被降级，怎么申诉？**

降级依据是检测项明细表中的异常分级，不是主观感受。四角磨白不露料、五金正常氧化这类，按 B 级或 C 级披露；若卖家认为降级过重，可在 72 小时内申请复检，由另一组质检员独立复核。复检结论为最终结果，不再接受二次申诉。

**皮贴氧化到什么程度算瑕疵，什么程度算老化？**

均匀蜜色氧化属于自然老化，不影响成色判定，报告中如实描述即可。局部深色斑块或整面不均匀且影响美观的，按检测项明细表降级处理。判定边界以侧光下是否出现明显色差为准，拿不准时拍照上传由复核员会商，不单凭个人判断。

**老花对花位轻微错位，买家收货后不认可怎么办？**

错位超过 2mm 才触发降级，2mm 以内的轻微偏差属于工艺公差，报告中标注"轻微错位"但不降级。买家若对此有异议，平台以检测照片和复核记录为判定依据，不因买家主观感受更改结论。卖家发货前可自行测量，避免争议。

**拆修史没写进报告，事后被发现怎么办？**

隐瞒拆修即必拒，这条不因成色档位豁免。检测时发现任何拆修痕迹，无论是否影响使用，都必须写入报告；漏写属于质检责任，卖家可据此申请复检并追溯原质检员。买家发现报告未披露拆修而商品实际有拆修的，平台支持退货并由责任方承担运费。
