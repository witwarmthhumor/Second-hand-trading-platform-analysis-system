# ThinkPad质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于 ThinkPad 全系笔记本（X/T/P/L/E 系列）回收质检。验机仓签收后 48 小时内出报告；异议可在报告出具后 72 小时内申请复检。

1. **收件核验与防拆封登记**（30 分钟内）：核对机身 SN、机型与订单一致，对包裹外观、封条拍照存证。
2. **外观分级拍照**：A 面（顶盖）、C 面（键盘面）、D 面（底盖）各拍 ≥2 张。
3. **拆底盖核验**（征得卖家同意后）：查硬盘/内存原装性、进水痕迹、螺丝动过痕迹。ThinkPad 底盖螺丝滑丝常见于私自拆修机型。
4. **功能与压力检测**：按第三部分表格逐项执行。
5. **电池循环与健康读取**：用 Lenovo Vantage 或 `powercfg /batteryreport`。
6. **账户/BIOS 锁退出验证**：确认 Windows 账户、BIOS 密码、Computrace 均无锁。
7. **出报告**：签收后 48 小时内完成上传。

## 二、检测工具与环境

- 防静电垫与接地手环；塑料撬棒与合适螺丝刀头，避免损伤防滚架螺丝孔。
- 纯色测试图（黑/白/红/绿/蓝 5 色）预存 U 盘，外接显示器备用。
- 压力测试用 AIDA64 或 FurMark。
- 电池健康以 Lenovo Vantage 为准，循环次数以电池固件报告为准，冲突时取更差值。
- 环境为常规室内温湿度，WiFi 信号不低于两格。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 小红点（TrackPoint） | 光标移动灵敏，中键滚动无跳变 | 指针设置中画圆 3 圈 + 中键滚动测试 | 漂移/无响应：B 级起扣，更换小红点帽后复测 |
| 指纹模组 | 录入 2 枚指纹，解锁正常 | Windows Hello 录入并锁屏验证 5 次 | 识别失败 ≥2 次：C 级，需显著披露 |
| 防滚架异响 | 对角扭转无咯吱声 | 双手对角扭转机身 + 开合屏幕 20 次听音 | 异响明显：C 级，拆机紧固螺丝后复测 |
| 键盘全键 | 无脱落、连击、失灵 | 键盘测试软件逐键按压 + 目视键帽油光 | 单键失灵：C 级；键帽油光按外观项分级 |
| 屏幕亮/坏点 | 纯色 5 色下无 >5 个坏点 | 5 色纯色图全屏目视确认 | 坏点 >5 个：必拒；≤5 个按位置与数量分级 |
| 电池健康 | S 级 ≥90%，A 级 80–89%，<80% 必须明示 | Lenovo Vantage 读取健康度与循环次数 | 健康 <60%：必拒；循环 >500 次：报告显著标注 |
| 转轴阻尼与异响 | 开合 20 次无卡顿、无异响 | 单手开合至 90° 停留 5 秒观察是否下垂 | 阻尼异常/异响：C 级；转轴区裂纹：必拒 |
| 高负载压力测试 | 15 分钟满载无蓝屏、无过热关机 | AIDA64 单烤 FPU + GPU 双烤 15 分钟 | 温度墙降频严重/关机：C 级并记录温度曲线 |
| 接口全插拔 | USB/HDMI/音频/读卡器全部识别 | 逐一插拔，读卡器写入文件验证 | 单口失灵：C 级，列明具体接口 |
| 系统/BIOS 锁 | 无 Windows 密码、BIOS 密码、Computrace | 重启进 BIOS 查看 + 系统登录验证 | 任一锁未退出：必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N 全新 | 未拆封未使用，原厂封条完整，配件包装齐全 | 整箱未开封，电池循环 0 次 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 拆封试机后闲置，循环 ≤5 次 |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | A 面有细微划痕，键盘无油光 |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | C 面键帽轻微油光，D 面脚垫正常磨损 |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | A 面划痕明显，小红点帽需更换 |
| D 7成新及以下 | 较重磨损/局部功能瑕疵，必须显著披露 | 外观多处磕碰，电池健康 <80% |

电池健康阈值独立于外观成色：健康度 <80% 的，无论外观多新，报告中必须明示具体数值；循环 >500 次的，显著位置加粗标注。外观成色与电池健康冲突时，取较低档位。

## 五、必拒情形

出现任意一条即拒收，不进入分级流程：

- **系统/BIOS 锁未退出**：含 Windows 账户密码、BIOS 密码、Computrace。
- **电池鼓包**：目视底盖凸起或按压有弹性形变，立即断电停止检测。
- **主板进水或维修史未申报**：进水标变色即判定进水，不论功能是否正常；任何拆修史必须写入报告，隐瞒拆修即必拒。
- **屏幕漏液/大面积坏点**：坏点 >5 个。
- **配件缺失到影响开机**：无电源适配器且电池报废。

## 六、报告字段与拍照取证要求

报告至少包含以下字段：

- **基础信息**：订单号、SN、机型与配置（CPU/内存/硬盘/屏幕）。
- **外观成色**：按第四部分判定表给出 N/S/A/B/C/D 档位，注明关键瑕疵位置。
- **电池数据**：健康度百分比与循环次数。健康度 <80% 必须明示具体数值；循环 >500 次显著标注。
- **功能检测结论**：逐项列明通过/异常，异常项附说明。
- **维修史声明**：有无拆修、进水痕迹，进水标变色即判定进水。
- **锁状态**：Windows 账户、BIOS 密码、Computrace 均无锁。

拍照取证至少 6 张，全部嵌入报告留档：

1. 机身 SN 特写（可辨读）。
2. A 面整体与瑕疵局部。
3. C 面键盘、小红点、指纹模组。
4. D 面脚垫、螺丝孔。
5. 屏幕纯色检测画面（亮/坏点）。
6. 电池健康度与循环次数截图。

进水标、螺丝滑丝、防滚架裂痕等关键异常单独加拍局部特写。照片须清晰可辨，模糊或反光导致无法判定时视为未取证，需补拍后再出报告。

## 七、常见争议与判定口径

**争议一：卖家称"未拆修"，但底盖螺丝有拧动痕迹。**
判定口径：以螺丝痕迹与进水标状态为准，不以卖家陈述为准。螺丝动过即记录拆修史并写入报告，隐瞒拆修即必拒。

**争议二：电池健康度低于 80%，但外观几乎全新，买家质疑成色定级。**
判定口径：外观成色与电池健康独立判定，冲突时取较低档位。健康度 <80% 的，报告显著位置明示数值，不因外观新而升档。

**争议三：小红点漂移，更换小红点帽后恢复正常。**
判定口径：更换帽后复测通过的不作为功能缺陷，按外观损耗轻微处理；复测仍漂移的按功能异常分级并披露。
