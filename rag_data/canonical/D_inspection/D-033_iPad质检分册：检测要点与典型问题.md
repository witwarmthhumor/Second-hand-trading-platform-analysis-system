# iPad质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于回流二手验机仓承接的各代 iPad，包括数字款、iPad Air、iPad mini、iPad Pro 的无线局域网版与蜂窝版，以及随附的 Apple Pencil、妙控键盘等原装配件。iPad 与安卓平板的账号体系不同，本分册围绕 Apple ID 退出、原彩显示、手写笔配对三条主线展开，通用功能项仍按平板电脑品类总表执行。

收件后 30 分钟内完成核验登记，核对机身序列号、型号容量与订单是否一致，随后依次执行：外观逐区拍照、进水标与密封检查、屏幕与触控检测、Apple ID 与激活锁验证、原彩与显示检测、Pencil 与键盘配对、电池健康读取、出报告。验机仓签收后 48 小时内出具报告，对结论有异议可在 72 小时内申请复检。

## 二、检测工具与环境

| 工具 | 用途 | 说明 |
| 原装充电线与功率表 | 充电实测 | 确认是否支持对应快充档位 |
| Apple Pencil（两代各备一支） | 配对与压感测试 | 按机型接口代际选用 |
| 妙控键盘或智能键盘 | 键盘连接与转轴测试 | 验证磁吸与触点通信 |
| 纯色测试页与网格图 | 屏幕与全屏触控 | 重点排查局部断触与压伤 |
| 测试 SIM 卡 | 蜂窝版联网与卡槽 | 区分实体卡槽与 eSIM 机型 |

工位保持室温 18-26 摄氏度、干燥通风。iPad 屏幕面积大，检测时需放平并避免灯光在屏幕上形成反光斑，原彩与原色温判断要在关闭原彩、开启原彩两种状态下对照进行。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
| Apple ID 与激活锁 | 账号完全退出、查找已关闭、可正常激活 | 现场退出账号并恢复出厂后重新激活 | 激活锁未退出必拒，不进入后续流程 |
| 原彩显示 | 开关存在且切换时色温自然变化 | 控制中心与设置内双重确认 | 原彩缺失提示换屏嫌疑，降级并标注 |
| 屏幕显示 | 无坏点色斑、无漏液、背光均匀 | 纯色五色全屏，斜看背光与压伤 | 漏液扩散中计 D 级并必拒 |
| 全屏触控 | 全屏 16 区域无断触，边缘手势正常 | 网格图全屏划动，四角重点补测 | 局部断触降级，整屏失灵必拒 |
| Apple Pencil | 配对顺畅、压感与倾斜连续、悬停正常 | 配对后画线、轻重落笔与侧锋涂写 | 压感断档降级，无法配对按配件异常标注 |
| 键盘配件 | 磁吸稳固、全键触发、触控板手势正常 | 连接后逐键测试并开合转轴 | 单键失灵降级，触点不通需明示 |
| 蜂窝网络（蜂窝版） | 识别 SIM、可注册移动网络 | 插卡测试，eSIM 机型核验菜单状态 | 蜂窝故障必拒，并标注为无线局域网版还是蜂窝版 |
| 扬声器与麦克风 | 四扬声器逐一声道清晰、录音正常 | 分声道播放与录音回放 | 单声道失声降级，全无声必拒 |
| 前后摄像头 | 对焦正常、无进灰霉斑 | 远近景拍摄与录像 | 镜头进灰降级，无法成像必拒 |
| 电池健康 | S 级不低于 90%，A 级落在 80-89% | 系统电池设置与诊断读数交叉确认 | 低于 80% 明示，低于 60% 必拒 |
| 充电与接口 | Type-C 或 Lightning 插拔稳定、充电连续 | 功率表实测充电曲线 | 接触不良降级，无法充电必拒 |
| Face ID 与按键 | 面容录入解锁正常，按键回弹清脆 | 录入面容并反复解锁，逐键按压 | 面容失效降级并标注维修嫌疑 |

## 四、成色判定表

| 成色 | 外观特征 | iPad 细化口径 |
| N 全新 | 未拆封未使用，封膜与配件齐全 | 未激活或激活未使用，充电口无插拔痕 |
| S 99新 | 极少使用痕迹，功能全部正常 | 屏幕无划痕，电池健康不低于 90%，无拆修 |
| A 95新 | 轻微使用痕迹，无功能缺陷 | 非显示区极轻发丝纹，电池健康 80-89%，无拆修 |
| B 9成新 | 正常使用痕迹 | 边角极轻磕碰不露底铝，功能全部正常 |
| C 8成新 | 明显使用痕迹或轻微磕碰 | 背板平测弯曲在允许范围内并记录，功能正常 |
| D 7成新及以下 | 较重磨损或局部功能瑕疵 | 屏幕压伤、局部断触、换屏嫌疑等必须显著披露 |

电池健康与成色联动：不低于 90% 才可以评 S 或 A，落在 80-89% 的最高评 B，低于 80% 的无论外观成色都要显著标注读数。循环次数超过 500 次的机型，读数与循环一并写入报告。

## 五、必拒情形

- Apple ID 未退出、激活锁无法关闭或激活过程提示监管锁；
- 电池健康低于 60%，或电池鼓包顶起屏幕；
- 屏幕漏液扩散、显示区大面积坏点；
- 换屏后原彩无法恢复且卖家未申报维修史；
- 蜂窝版无法注册网络、卡槽损坏且无法说明原因；
- 机身序列号与系统、卖家申报不一致，或被标注为丢失模式。

## 六、报告字段与拍照取证要求

报告必含字段：型号与容量、蜂窝版或无线局域网版标识、成色结论、逐项检测结果、Apple ID 退出状态、原彩检测结果、电池健康与循环次数、Pencil 与键盘配对结果、维修史声明、瑕疵照片编号。拍照不少于 6 张，亮屏正面、背面、四角、接口、摄像头区域必须入镜，屏幕瑕疵在纯色背景下加拍特写。开机演示视频不少于 15 秒，要完整呈现一次解锁、全屏划动与手写笔画线。

## 七、常见争议与判定口径

问：设置里没有原彩开关，是不是一定换过屏？答：是重点嫌疑项。先核对系统版本与机型是否本就支持原彩，确认支持却缺失开关的，按换屏嫌疑降级并要求卖家申报维修史，拒绝口头保证。

问：Apple Pencil 是卖家另购的，怎么写报告？答：主机与配件分开判定，另购 Pencil 只验证配对与压感，并注明非随机原装，不把配件成色并入主机评级。

问：电池读数刚好落在 A 档区间下限附近怎么办？答：以系统读数为准，落在 80-89% 即按 A 档电池口径，一旦低于区间下限就按披露口径降级，不做人为抬档。
