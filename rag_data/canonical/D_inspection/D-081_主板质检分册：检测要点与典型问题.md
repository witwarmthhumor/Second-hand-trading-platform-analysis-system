# 主板质检分册：检测要点与典型问题

## 一、检测范围与流程

本分册适用于台式机与配件品类中的独立主板与整机内主板。收件后 30 分钟内完成核验登记，检测流程依次为：外观逐区检查、通电点亮、内存与存储通道测试、压力测试、出报告。验机仓签收后 48 小时内出具报告，买家如有异议可在 72 小时内申请复检。

## 二、检测工具与环境

| 工具 | 用途 | 说明 |
| 放大镜台灯 | 针脚、焊点、电容目视 | 十倍放大优先 |
| Memtest 介质 | 内存通道稳定性 | 每轮完整跑完 |
| 温度监测软件 | 供电与芯片温度记录 | 压力测试期间全程开启 |
| 防静电手环 | 拆装防护 | 工位标配 |

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
| PCB 外观 | 无裂纹、无腐蚀、无飞线 | 目视加放大镜 | 明显腐蚀或飞线直接计 D 级并显著披露 |
| 电容状态 | 无鼓包、无漏液 | 顶部平整度逐颗目视 | 鼓包即记为维修嫌疑，多发鼓包必拒 |
| 针脚与插槽 | 无弯曲、无氧化、无物理损伤 | 目视加插拔实测 | CPU 插槽针脚缺失超过 2 根必拒 |
| 内存通道 | 双通道全识别、Memtest 通过 | 插满测试一轮 | 单通道可用降级，报错必拒 |
| PCIe 插槽 | 显卡与扩展卡识别稳定 | 实插实测 | 接触不良降级，无法识别必拒 |
| 供电接口 | 无烧蚀、无松动 | 目视加插拔 | 烧蚀痕迹必拒 |
| BIOS | 版本可查、无密码锁 | 进系统前界面确认 | 带密码锁且无法解除必拒 |
| 接口 | USB、网口、音频全部可用 | 逐个插拔 | 单个失效降级并明示 |

## 四、成色判定表

| 成色 | 定义 | 主板细化口径 |
| S 99新 | 极少使用痕迹 | 无拆装痕迹，插槽无氧化，全部功能正常 |
| A 95新 | 轻微使用痕迹 | 有轻插拔痕迹但无氧化，功能正常 |
| B 9成新 | 正常使用痕迹 | 允许插槽轻微氧化，功能全部正常 |
| C 8成新 | 明显使用痕迹 | 存在非关键接口失效或清灰补焊痕迹，必须披露 |
| D 7成新及以下 | 较重磨损或局部功能瑕疵 | 多插槽失效或明显维修史，必须显著披露 |

## 五、必拒情形

- 通电无法点亮且原因不明；
- 电容鼓包多发或供电区域烧蚀；
- CPU 插槽针脚缺失超过 2 根；
- 内存或 PCIe 插槽物理破损；
- 进液腐蚀痕迹且功能异常；
- BIOS 密码锁无法解除。

## 六、报告字段与拍照取证要求

报告字段：成色结论、逐项检测结果、Memtest 结论、BIOS 版本、维修嫌疑标注、瑕疵照片编号。拍照不少于 6 张，插槽、电容区域与接口必须有特写；演示视频不少于 15 秒，包含点亮过程。装机订单还需记录 4 小时整机老化测试结果，主板上机运行的稳定性以老化测试为准。

## 七、常见争议与判定口径

问：主板有清灰补焊痕迹算不算维修史？答：算。任何拆焊痕迹都必须在报告标注，未标注按隐瞒维修史处理。

问：老主板只有单根内存插槽可用怎么办？答：如实降级披露，买家下单页面必须可见，不允许口头承诺。

问：主板与 CPU 故障怎么区分？答：交叉替换测试，替换后故障跟板走即主板责任，跟件走即配件责任，结论写入报告。
