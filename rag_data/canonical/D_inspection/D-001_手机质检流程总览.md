# 手机质检流程总览

## 一、检测范围与流程

本手册适用于进入回流二手验机仓的全部手机订单，是 14 个品类分册的总纲。流程固定为七步，任何一步不达标即中止并记录：

1. 收件核验与防拆封登记，30 分钟内完成，全程录像；
2. 外观分级拍照，正面、背面、四边与接口特写合计不少于 6 张；
3. 进水标检查，SIM 卡槽、充电口等位置逐处目视核对；
4. 功能逐项检测，按第三节明细表执行；
5. 电池健康与循环次数读取；
6. 账户锁与激活锁退出验证；
7. 出具质检报告，验机仓签收后 48 小时内完成；买家对报告有异议的，可在报告出具后 72 小时内申请复检。

## 二、检测工具与环境

| 工具 | 用途 | 环境要求 |
| 强光手电 | 屏幕划痕与进水标检查 | 遮光工位 |
| 网格测试图 | 触控分区检测 | 标准分辨率 |
| 原装规格充电线 | 充电与接口实测 | 每工位备用两条 |
| 防静电垫与指套 | 拆装与取证 | 无尘台面 |

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
| 屏幕显示 | 无坏点、无色斑、亮度均匀 | 纯色图逐色检查 | 显示区坏点降 1 级，漏液扩散中直接计 D 级并显著披露 |
| 触控 | 全屏响应无断触 | 网格法划过 12 个区域 | 局部断触降级，整屏断触必拒 |
| 电池健康 | S 级不低于 90%，A 级 80–89% | 系统设置读取 | 低于 80% 必须在报告明示，低于 60% 必拒 |
| 充电与接口 | 插拔稳定、充电不中断 | 实测半小时充电曲线 | 接触不良降级，无法充电必拒 |
| 摄像头 | 对焦正常、镜片无划痕霉斑 | 远近景拍摄各一组 | 镜片中心区划痕降 1 级 |
| 生物识别 | 面容或指纹可录入可解锁 | 现场实测 | 失效降级并标注维修嫌疑 |
| 进水标 | 全部未变色 | 卡槽与充电口目视 | 变色即判进水，不论功能是否正常 |
| 账户锁 | 全部退出并可恢复出厂 | 恢复出厂实测 | 未退出必拒 |

## 四、成色判定表

| 成色 | 定义 | 手机品类细化口径 |
| N 全新 | 未拆封未使用 | 封膜完整，配件包装未拆动 |
| S 99新 | 极少使用痕迹，功能全部正常 | 无划痕无磕碰，电池健康不低于 90%，无维修史 |
| A 95新 | 轻微使用痕迹，无功能缺陷 | 发丝纹不超过 2 条且不在显示区，电池健康 80–89%，无拆修 |
| B 9成新 | 正常使用痕迹 | 允许极轻微外观瑕疵，边框细小磕碰不露底金属 |
| C 8成新 | 明显使用痕迹或轻微磕碰 | 掉漆面积 5mm² 以内，功能全部正常 |
| D 7成新及以下 | 较重磨损或局部功能瑕疵 | 背板裂纹、进水痕迹等，必须在报告显著披露 |

## 五、必拒情形

出现以下任一情形，直接拒收并在报告注明依据：

- 账户锁、激活锁未退出；
- 电池健康低于 60%；
- 主板维修史未申报；
- 进水标变色且伴随功能异常；
- 机身弯曲变形超过 1mm；
- 序列号与机身、系统信息不一致。

## 六、报告字段与拍照取证要求

质检报告必含字段：成色结论、逐项检测结果、电池健康读数、循环次数、维修史声明、瑕疵照片编号。拍照不少于 6 张，另附开机演示视频不少于 15 秒。照片编号与瑕疵描述一一对应，报告中不允许出现无照片支持的瑕疵结论。循环次数超过 500 次的机型，读数必须在报告显著标注。

## 七、常见争议与判定口径

问：边缘发丝纹到底算 A 还是 B？答：以是否进入显示区划线，进入显示区即降级，边缘两处以内且长度不超过 5mm 计 A 级。

问：报告没写的问题后来出现了算谁的？答：以报告与照片为准，报告未记录且照片无法指认的瑕疵，按平台仲裁口径处理，买家可在 72 小时内申请复检。

问：验货通过后寄回的运费谁出？答：按平台现行口径，验货通过后寄回买家的运费由买家承担，下单页面有明确提示。
