# 腕表质检流程总览

## 一、检测范围与流程

腕表品类覆盖机械表、石英表、智能腕表及高端奢华腕表。签收后 30 分钟内完成收件核验与登记，全程录像。验机仓签收后 48 小时内出报告，买家可在报告出具后 72 小时内申请复检。流程共六步：

1. 收件核验与登记——核对运单、表款、序列号，30 分钟内完成，全程录像。
2. 外观分级拍照——≥8 张，含表扣内侧特写、表镜反光面、后盖、表带节距。
3. 机芯走时测试——满弦静置 24 小时记录误差，再测半弦与方位差。
4. 附件与保卡核验——保卡、盒、吊牌三件套与序列号一致性比对。
5. 真伪综合判定——双人复核，独立结论，签字确认。
6. 出报告——签收后 48 小时内推送。

复检申请仅限一次，以平台页面公示为准。检测全程录像留存，关键片段不短于 15 秒。

## 二、检测工具与环境

检测台需配备防静电垫、目镜（10 倍起）、校表仪、消磁器、软毛刷、气吹、扭矩螺丝刀（适配不同品牌后盖）、紫外灯（验保卡与夜光涂层）。环境要求：温度与湿度控制在适宜范围，远离强磁场源。蓝宝石镜面用折射测试笔辅助判断，矿物玻璃直接目检。开盖操作仅限授权质检员执行，非破坏性检查优先，不承诺实测防水深度。拍照背景统一为中性灰卡，光源角度固定。所有工具定期校准，校表仪每日开机自检一次。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 表镜划痕 | 蓝宝石镜面无可见划痕；矿物玻璃允许细微发丝痕 | 目镜观察 + 蓝宝石折射测试 | 深划痕降 C 级以下；裂纹必拒 |
| 表壳磨损 | 拉丝面与抛光面磨损程度分级 | 目镜对比标准样照 | 打磨过度/改尺寸必拒 |
| 表带节距 | 节距无异常松动、拉伸均匀 | 手动弯折 + 卡尺量节距 | 明显拉伸降 C/D；五珠链节距异常重点查 |
| 后盖开盖痕 | 无撬痕、无划伤 | 目镜观察后盖边缘 | 有开盖痕必须写入报告，隐瞒拆修即必拒 |
| 机芯走时误差 | ≤±15 秒/天为 S/A 参考线 | 校表仪满弦静置 24 小时 | >±30 秒/天显著标注并建议保养 |
| 日历/月相/计时 | 逐项切换顺畅、跳历准确 | 手动操作各功能 | 卡历/跳历异常降级并披露 |
| 自动陀上弦效率 | 满弦到停走时间符合机芯型号 | 上弦后静置观察 | 效率低显著标注 |
| 防水密封圈 | 外观无老化、开裂、变形 | 目检密封圈状态 | 仅外观检查，不承诺实测深度 |
| 磁化检测 | 受磁后走时明显加快 | 校表仪 + 消磁器处理 | 退磁后复测，记录前后数据 |
| 附件与保卡 | 三件套序列号与表身一致 | 紫外灯验保卡防伪 | 假保卡冒充原装必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N 全新 | 未拆封未使用，配件包装齐全 | 原封膜完好，吊牌未剪 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 仅试戴痕迹，表扣内侧无划痕 |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | 表扣有极轻微细纹，机芯走时正常 |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | 表带有佩戴折痕，表壳有细微点状痕 |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | 表壳有可见磕点，表镜有短划痕 |
| D 7成新及以下 | 较重磨损/局部功能瑕疵，必须显著披露 | 表带拉伸明显，日历跳历偶发异常 |

成色判定需结合走时误差。机械表日误差 ≤±15 秒方可评 S/A，>±30 秒/天必须显著标注并建议保养。翻新表盘（红字重涂、夜光重涂）一律不得评 N/S/A，按实际状态降级并披露。任何拆修史必须写入报告，隐瞒拆修即必拒。

## 五、必拒情形

以下情形直接拒收，不出具成色报告：

- 判定为仿品（含 Rehaut 激光刻字不符、序列号年代对不上）。
- 机芯非原装（拼装机芯，ETA 机芯对版不符）。
- 表壳重大改尺寸或打磨过度。
- 机芯锈蚀或进水凝固。
- 假保卡冒充原装附件。

进水标变色即判定进水，不论功能是否正常。品牌分册另有特殊必拒点：劳力士查五珠链节距与序列号年代，欧米茄查同轴机芯摆频与螺旋表冠，卡西欧实测电波/光动能功能，精工查 Spring Drive 扫秒与水鬼圈口。高端腕表（百达翡丽/爱彼）刻印与对版不符即拒。

## 六、报告字段与拍照取证要求

报告字段：订单号、品牌型号、序列号、机芯类型、走时误差（满弦/半弦/方位差）、外观瑕疵描述、附件清单（保卡/盒/吊牌）、成色等级、必拒/通过结论、质检员与复核员签名。

拍照取证：外观照片 ≥8 张，含表扣内侧特写、表镜反光面、后盖、表带节距、表盘细节、序列号特写。关键检测环节录像 ≥15 秒。进水标变色、开盖痕、翻新痕迹等异常点必须单独放大拍摄并附于报告中。

## 七、常见争议与判定口径

**争议一：卖家称"仅试戴"，但表扣内侧已有明显划痕，能否评 S？**

判定口径：不能。表扣内侧是佩戴时摩擦最集中的区域，出现可见划痕即属使用痕迹，按实际状态评 A 或以下。依据：S 级定义为"极少使用痕迹"，表扣内侧特写照片是分级拍照的固定机位，痕迹无法回避。

**争议二：买家质疑"走时偏快，是不是受磁了"，但报告中未做磁化记录。**

判定口径：以校表仪数据为准。若检测时走时误差在合格线内且无受磁迹象，报告中可不单列磁化项；若受磁明显加快，必须记录退磁前后数据并显著标注。依据：磁化检测是流程固定步骤，退磁后复测数据留痕，买家可凭报告申请复检，复检仅限一次。

**争议三：后盖有极轻微开盖痕，但卖家坚称"专柜保养过"，能否按无拆修处理？**

判定口径：不能。只要有开盖痕，无论是否专柜保养，一律写入报告并降级披露，不得隐瞒。依据：任何拆修史必须写入报告，隐瞒拆修即必拒；专柜保养记录需附保卡或维修单据佐证，否则按拆修处理。

**争议四：防水检测只查密封圈外观，买家收货后进水，责任如何划分？**

判定口径：报告已注明"仅外观密封圈状态检查，非破坏性，不承诺实测深度"，则检测环节无责；若密封圈外观存在老化、开裂却未披露，则判定为检测遗漏，支持买家申诉。依据：防水项明确为非破坏性外观检查，不承诺实测深度，报告字段中已向买家明示边界。
