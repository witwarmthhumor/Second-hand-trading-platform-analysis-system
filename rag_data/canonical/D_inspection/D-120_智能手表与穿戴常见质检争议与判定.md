# 智能手表与穿戴常见质检争议与判定

## 一、检测范围与流程

第1条 本品类检测范围涵盖智能手表、智能手环及穿戴配件，含表体、表带、充电配件及包装附件。

第2条 验机仓自签收起30分钟内完成收件核验与登记，登记内容包括运单号、机型、串号及外观初判。

第3条 外观拍照须覆盖表体正面、背面、四角、表带内外侧及表扣，合计不少于6张。

第4条 配对锁解除验证在功能检测前执行，未解除配对锁的设备不得进入后续检测流程。

第5条 功能检测按心率、血氧、ECG、GPS、蓝牙通话、防水密封、电池健康顺序逐项执行。

第6条 电池健康读取仅限支持机型，读取结果按本手册第七节判定标准执行。

第7条 检测报告须在签收后48小时内出具。买方或卖方对报告有异议的，可在72小时内申请复检。

第8条 复检申请通过后，由未参与初检的质检员执行，复检结论为终判。

## 二、检测工具与环境

第9条 检测环境须为恒温干燥室内，温度控制在常温范围，避免阳光直射及高湿环境。

第10条 功能检测须配备标准比对设备，包括心率血氧参考机、GPS信号测试环境及蓝牙通话测试终端。

第11条 电池健康读取使用厂商授权诊断工具或官方配套应用，读取路径以各品牌官方文档为准。

第12条 防水密封检测仅执行外观检查与说明书口径核对，不做破坏性水测。任何进水标变色即判定进水，不论功能是否正常。

第13条 表镜检测使用高亮手电及放大镜辅助观察，记录划痕长度、深度及碎裂范围。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
| --- | --- | --- | --- |
| 配对锁/激活锁 | 必须解除 | 按品牌流程验证配对状态 | 未解除即必拒 |
| 表镜 | 无影响显示的划痕或碎裂 | 目视+手电透光检查 | 碎裂影响显示即必拒 |
| 表壳与镀层 | 允许正常使用痕迹 | 目视检查磕碰与脱落 | 明显磕碰降级至C/D |
| 表带 | 无断裂、无严重老化 | 拉伸测试+异味检查 | 生耳松动降级，断裂即拒 |
| 心率/血氧/ECG | 与标准设备比对在合理误差内 | 佩戴比对测试 | 传感器失效即必拒 |
| GPS定位 | 室外空旷处定位成功 | 实际定位测试 | 定位失败降级至D |
| 蓝牙连接与通话 | 连接稳定、通话清晰 | 配对测试终端通话 | 功能异常降级至D |
| 电池健康 | 按第七节标准 | 官方工具读取 | 低于60%即必拒 |
| 蜂窝版运营商锁 | 必须解除 | eSIM状态查询 | 未解除即必拒 |
| 充电触点 | 无氧化影响充电 | 目视+充电测试 | 氧化严重降级至C |
| 表冠转动（Apple Watch） | 转动顺畅、反馈清晰 | 手动转动测试 | 卡滞降级至C/D |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
| --- | --- | --- |
| N 全新 | 未拆封未使用，配件包装齐全 | 原封盒装，封条完好 |
| S 99新 | 极少使用痕迹，功能全部正常，无维修史 | 仅试戴，无可见划痕 |
| A 95新 | 轻微使用痕迹，无功能缺陷，无拆修 | 表带有极轻微穿戴纹 |
| B 9成新 | 正常使用痕迹，允许极轻微外观瑕疵 | 表壳有细微擦痕，不显眼 |
| C 8成新 | 明显使用痕迹或轻微磕碰，功能正常 | 表壳有可见磕点，表带有磨损 |
| D 7成新及以下 | 较重磨损或局部功能瑕疵，必须显著披露 | 表镜有划痕但不影响显示，GPS偶发失灵 |

第15条 电池健康≥90%可评S级，80-89%评A级，低于80%须在报告中显著披露，低于60%直接拒收。

第16条 循环次数超过500次必须在报告中显著标注，不影响成色但须明示。

第17条 任何拆修史必须写入报告，隐瞒拆修即必拒，不论外观成色如何。

## 五、必拒情形

第18条 出现以下任一情形，设备直接拒收，不做降级处理：

（一）配对锁/激活锁未解除；

（二）电池鼓包；

（三）表镜碎裂影响显示；

（四）蜂窝版未解除运营商锁（如有）；

（五）传感器模组失效；

（六）进水标变色，不论功能是否正常；

（七）隐瞒拆修史。

第19条 必拒情形须在报告中注明拒收代码及对应证据照片，照片纳入取证档案。

## 六、报告字段与拍照取证要求

第20条 检测报告须包含以下字段：订单编号、设备型号、序列号、成色等级、电池健康度、循环次数、功能检测结果逐项、必拒项状态、检测员编号、复检记录。

第21条 拆修史字段为必填项，无拆修填"无"，有拆修须描述维修范围并附拆机痕迹照片。

第22条 拍照取证不少于6张，覆盖表体正面、背面、表带、表扣、充电触点及瑕疵特写。瑕疵特写须在自然光下拍摄，保证瑕疵清晰可辨。

第23条 视频取证不少于15秒，内容须包含开机演示、屏幕滑动及功能操作画面，视频中设备串号须清晰可见。

第24条 电池健康度低于80%的设备，报告须在显著位置标注"电池健康度偏低"提示，并附电池读取界面截图。

第25条 进水标变色设备须单独拍摄进水标特写照片，该照片作为必拒判定的核心证据。

## 七、常见争议与判定口径

第26条 争议一：卖方主张"仅试戴几天，应评S级"。判定口径：S级须同时满足功能全部正常、无维修史、极少使用痕迹三项条件。电池健康度低于90%或循环次数超过500次的，即使外观无痕，亦不得评S级。依据：成色判定以客观检测数据为准，不以卖方自述使用时长为依据。

第27条 争议二：买方认为表带老化属功能缺陷，要求按必拒处理。判定口径：表带拉伸老化、异味或生耳松动属外观与配件损耗，按降级处理，不列入必拒清单；仅当表带断裂或生耳脱落导致无法正常佩戴时，方可拒收。依据：必拒清单以影响核心功能或存在安全隐患为限，表带属可更换配件。

第28条 争议三：卖方隐瞒拆修史，买方收货后发现主板有维修痕迹，要求退货并赔偿。判定口径：隐瞒拆修即必拒，不论设备当前功能是否正常、外观成色如何。检测报告拆修史字段填"无"但实际存在拆修的，判定为质检漏检或卖方欺诈，按平台争议规则由责任方承担往返运费。依据：任何拆修史必须写入报告，隐瞒拆修即必拒。

第29条 争议四：防水性能争议。卖方称设备官方标注支持防水，买方投诉雨天佩戴后进水。判定口径：本品类不做破坏性水测，防水判定以进水标状态为准。进水标变色即判定进水，不论功能是否正常，亦不论卖方是否主张使用环境合规。依据：防水密封检测仅执行外观检查与说明书口径核对，进水标为唯一判定依据。
