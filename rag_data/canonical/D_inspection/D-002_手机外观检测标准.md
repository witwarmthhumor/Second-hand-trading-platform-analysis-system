# 手机外观检测标准

## 一、检测范围与流程

本标准适用于所有进入 RAGreflow 验货仓的手机品类，覆盖外观成色判定、功能检测、电池健康读取、ID 锁验证及报告出具全流程。检测对象包括直板机与折叠屏机型，品牌分册特殊检测点按第四节列明执行。

验货仓签收后按以下步骤推进，全程留痕：

1. **收件核验与防拆封登记**：签收后 30 分钟内完成外包装拍照、序列号核对、防拆封贴登记。序列号与机身或系统不一致的，直接进入必拒流程。
2. **外观分级拍照**：按"正面/背面/四边/接口"五个方位取景，合计不少于 6 张，强光侧照下拍摄屏幕划痕细节。
3. **进水标检查**：逐一检查 SIM 槽、充电口、耳机口（如有）的进水标。进水标变色即判定进水，不论功能是否正常。
4. **功能逐项检测**：按第三部分功能检测项清单逐项执行，折叠屏机型加测铰链与内屏专项。
5. **电池健康与循环次数读取**：读取电池健康度及循环次数，数据写入报告。
6. **ID 锁/账户锁退出验证**：确认 ID 锁、激活锁、账户锁均为关闭状态。
7. **出报告**：签收后 48 小时内出具完整检测报告。买家对结果有异议的，可在 72 小时内申请复检。

## 二、检测工具与环境

检测工位配备：强光侧照灯（用于屏幕划痕分级）、高倍放大镜（用于摄像头镜片与边框磕碰观察）、网格法触控测试图、各品牌充电线材、SIM 卡托取出工具、电池健康读取设备。

环境要求：工位照度均匀，避免反光干扰屏幕判定；检测台面铺设防滑软垫，防止二次损伤。折叠屏机型额外配备开合测试支架，用于铰链阻尼与异响检测。所有拍照取证使用验货仓统一水印相机，确保时间与工号可追溯。

## 三、检测项明细表

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 屏幕划痕 | 显示区无划痕；非显示区 ≤2 条发丝纹可计 A 级 | 强光侧照观察 | 显示区划痕降 1 级；非显示区超过 2 条或非发丝纹降 1 级 |
| 边框磕碰 | 无露底金属磕碰 | 目视 + 触感检查四边及四角 | 磕碰露底金属即降 1 级；掉漆面积 >5mm² 计 C 级 |
| 背板裂纹 | 无任何裂纹 | 强光透照背板 | 任何裂纹计 D 级并显著披露 |
| 摄像头镜片划痕 | 镜片无划痕 | 高倍放大镜观察前后摄镜片 | 中心区划痕降 1 级；边缘划痕不影响成像可备注 |
| 屏幕坏点/色斑/触摸断触 | 无坏点、无色斑、全区域触控正常 | 网格法全屏 12 区域逐区测试 | 任一区域断触即计 D 级；坏点/色斑按面积与位置降级 |
| 面容 ID/指纹解锁 | 面容 ID 模组、指纹模组功能正常 | 各品牌生物识别录入与解锁测试 | 面容 ID 模组故障、指纹失败即降级或必拒（见必拒清单） |
| 电池健康 | S 级 ≥90%；A 级 80–89% | 系统电池健康读取 + 循环次数读取 | <80% 必须明示；<60% 必拒；循环次数超 500 次须显著标注 |
| 充电口/扬声器/振动/听筒/麦克风 | 全部功能正常 | 逐一插拔充电、播放音频、通话测试 | 单项故障按功能缺陷降级，维修史如实写入报告 |
| 前后摄像头对焦与闪光灯 | 对焦迅速、闪光灯正常 | 远近景各拍 3 张，开启闪光灯测试 | 对焦失败或闪光灯不亮计功能缺陷 |
| 传感器（陀螺仪/指南针/距离感应） | 数据稳定无漂移 | 系统自带诊断工具或第三方校准 App | 传感器失效计功能缺陷，需显著披露 |
| ID 锁/激活锁状态 | 必须为关闭 | 设置-账户体系逐项核对 | 未退出即必拒 |

## 四、成色判定表

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原封盒装，封条完好，激活状态为未激活 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅充电口有轻微插拔痕迹，屏幕无划痕，电池健康 ≥90% |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 背板有细微划痕，非显示区 ≤2 条发丝纹，电池健康 80–89% |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 边框有细微掉漆但未露底金属，屏幕无坏点，功能全部正常 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 边框磕碰露底金属、掉漆面积 >5mm²，但功能无缺陷 |
| D（7成新及以下） | 较重磨损/局部功能瑕疵，必须显著披露 | 背板裂纹、显示区划痕、触摸断触、电池健康 <80% 等 |

折叠屏机型额外参考：铰链阻尼异常、折痕深度明显、内屏分区触控失灵、屏幕胶合开胶，任一情形在对应成色基础上再降 1 级，D 级为下限。

品牌分册特殊检测点按以下口径执行：苹果核对面容 ID 模组、原彩显示、电池循环次数、零部件维修提示弹窗及官换机/资源机标识；华为核对鸿蒙系统激活状态与荣耀拆分前型号区分；小米核对 MIUI/HyperOS 账号解锁及骁龙版/天玑版；三星核对 Knox 熔断状态与国行/港版/海外版鉴别；折叠屏机型统一执行铰链与内屏专项。

## 五、必拒情形

出现以下任一情形的，直接拒收并出具说明，不进入成色判定流程：

| 必拒情形 | 判定依据 |
|---|---|
| ID 锁/账户锁未退出 | 设置-账户体系核对为开启状态，无法当场退出 |
| 电池健康 <60% | 系统读取数值低于 60% |
| 主板维修史未申报 | 拆修痕迹明显或系统提示维修记录，送检方未申报 |
| 进水标变色且功能异常 | 进水标变色即判定进水，叠加功能异常即拒 |
| 机身弯曲变形 | 变形幅度超过 1mm，平放翘起明显 |
| 序列号与机身/系统不一致 | 三码核对任一不符 |

隐瞒拆修史、进水史或更换序列号等造假行为的，除拒收外同步记录送检方信用档案。

## 六、报告字段与拍照取证要求

检测报告须包含以下字段：送检单号、品牌型号、序列号/IMEI、成色等级、电池健康度、循环次数（超 500 次显著标注）、进水标状态、维修史声明、必拒项核查结果、检测工号与时间戳。

拍照取证口径：正面、背面、四边、接口合计不少于 6 张；屏幕划痕须强光侧照特写；边框磕碰与背板裂纹加拍局部放大图；进水标变色须单独拍摄并标注位置。所有照片使用统一水印相机拍摄，时间、工号、送检单号三要素齐全。折叠屏机型加拍展开与折叠两种状态，铰链区域单独取景。

## 七、常见争议与判定口径

**争议一：屏幕划痕在显示区与非显示区边界，如何定级？** 以点亮屏幕后的可视区域为准，划痕延伸入显示区即按显示区划痕处理，降 1 级。

**争议二：进水标变色但功能全部正常，收不收？** 收，但必须显著披露进水史。进水标变色即判定进水，功能正常不构成隐瞒理由。

**争议三：买家对成色等级有异议怎么办？** 签收后 72 小时内可申请复检，复检以原机原图复核为准，复检通过后买家承担往返运费。

**争议四：维修史申报了，但申报内容与实际拆修范围不符？** 以拆修范围与申报内容是否一致为判定口径，不一致的按隐瞒拆修处理，进入必拒流程。
