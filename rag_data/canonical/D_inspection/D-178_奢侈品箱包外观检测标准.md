# 奢侈品箱包外观检测标准

## 一、检测范围与流程

第一条 本标准适用于 RAGreflow 平台奢侈品箱包品类全部送检商品，覆盖 LV、Gucci、Chanel、Dior、Prada、Hermès、Celine、YSL、Burberry 及轻奢箱包。

第二条 检测流程按以下步骤执行，全程录像留存：

（一）收件核验与登记。包裹签收后 30 分钟内完成拆包核验，登记包袋外观状态与附件清单，此阶段全程录像。

（二）外观分级拍照。拍摄不少于 8 张照片，必须包含五金特写、四角、手柄、内衬、身份卡/序列号位置。

（三）身份卡、序列号、镭射标核验。逐项核对身份卡编号与内标一致性，LV 核对 Date code 格式与产地对应，Chanel 核对镭射标贴与身份卡。

（四）五金与皮质逐项检测。按第三部分检测项明细表逐项执行。

（五）真伪综合判定。由两名鉴定师独立判定，结论一致方可出具报告；结论不一致时提交组长复核。

（六）出报告。自签收后 48 小时内出具完整检测报告。

第三条 送检人对报告结论有异议的，可在报告出具后 72 小时内申请复检。复检结论为最终结论。

## 二、检测工具与环境

第四条 检测环境须满足以下通用要求：

（一）操作台配备白光光源与可调角度辅助灯，确保皮质纹理、五金刻字、镀层状态可清晰观察。

（二）配备微距镜头或高倍放大镜，用于检查五金刻字深度、镭射标细节、走线工艺。

（三）配备紫外灯，用于辅助核查部分品牌防伪特征。

（四）配备标准色卡，用于比对皮质颜色与氧化变色程度。

（五）检测区域保持干燥通风。异味判定须在通风环境静置后复核，避免与运输包装气味混淆。

第五条 检测工具使用前须校验。拍照设备像素须满足放大查看五金刻字细节的要求。

## 三、检测项明细表

第六条 外观与功能检测项按下表执行：

| 检测项 | 合格标准 | 检测方法 | 异常判定/分级 |
|---|---|---|---|
| 皮质划痕/磨白/龟裂 | 全新状态无任何痕迹；S 级允许极少使用痕迹 | 白光下目测加触感检查，按区域记录 | 划痕集中或龟裂贯穿至面料层，降级至 C 或以下 |
| 四角磨损（磨白/露料） | 四角无磨白；A 级允许轻微磨白 | 目测加指腹触感确认是否露料 | 磨白面积扩大或露料，按程度降至 C/D 级 |
| 内衬污渍与异味 | 内衬洁净无污渍，无霉味/烟味 | 目测内衬全区域，异味须静置复核 | 污渍无法去除降级；强烈不可去除异味直接拒收 |
| 五金镀层脱落与氧化 | 镀层完整无脱落；轻微氧化属正常使用痕迹 | 微距观察镀层边缘与刻字内部 | 镀层脱落面积明显或氧化发黑，降至 C 级以下 |
| 手柄/肩带使用痕迹与汗渍变色 | S 级手柄无变色；A 级允许轻微汗渍 | 目测手柄全段，比对皮质原色 | 汗渍导致明显变色或皮质硬化，降级处理 |
| 拉链顺滑度与拉头完整性 | 拉合顺畅无卡顿，拉头无变形 | 全程拉合 3 次，检查拉头齿位 | 卡顿或拉头断裂无法修复，拒收 |
| 磁扣/转锁开合 | 开合正常，吸力或锁扣力度符合品牌工艺 | 反复开合 5 次 | 无法闭合或锁扣失效，按功能瑕疵降级 |
| 五金刻字清晰度与工艺对版 | 刻字清晰、字体与品牌工艺对版 | 微距拍照，对照品牌分册对版点 | 刻字模糊或字体不对版，判定真伪风险 |
| 身份卡编号与内标一致性 | 编号完全一致，无涂改 | 逐位核对，紫外灯辅助 | 不一致即真伪风险，进入双人复核 |
| 附件清点（防尘袋/肩带/小票） | 附件齐全程度如实记录 | 逐项清点并拍照 | 缺失附件须在报告中显著标注 |

## 四、成色判定表

第七条 成色判定按以下六档执行：

| 成色 | 外观特征 | 典型情形 |
|---|---|---|
| N（全新） | 未拆封未使用，配件包装齐全 | 原装塑封完好，吊牌未剪 |
| S（99新） | 极少使用痕迹，功能全部正常，无维修史 | 仅试背一次，五金无氧化，内衬全新 |
| A（95新） | 轻微使用痕迹，无功能缺陷，无拆修 | 四角轻微磨白，五金轻微氧化，皮质无划痕 |
| B（9成新） | 正常使用痕迹，允许极轻微外观瑕疵 | 手柄轻微汗渍变色，内衬少量污渍可清理 |
| C（8成新） | 明显使用痕迹或轻微磕碰，功能正常 | 四角露料，五金镀层局部脱落，皮质明显划痕 |
| D（7成新及以下） | 较重磨损或局部功能瑕疵，必须显著披露 | 皮质龟裂，五金氧化严重，需护理修复 |

第八条 任何拆修史必须写入报告。隐瞒拆修即必拒。维修史不作为单独降级依据，但须在报告中显著披露，由买家知情确认。

第九条 护理修复后是否影响成色判定，按可修复性分级执行：可逆护理（清洁、补色）不影响原成色档位；不可逆处理（换皮、补料）须降一档披露。

## 五、必拒情形

第十条 出现下列任一情形，直接判定拒收，不出具成色报告：

（一）判定为仿品。真伪综合判定结论为仿品的，终止检测流程。

（二）主料破损。面料破洞或开裂贯穿，无法通过护理修复。

（三）五金断裂无法修复。拉头、锁扣、连接环断裂且无法更换原厂配件。

（四）强烈不可去除异味。霉味、烟味经通风静置复核仍超常规，判定不可去除。

（五）序列号与品牌数据库逻辑矛盾。序列号格式、产地编码与品牌官方记录冲突。

第十一条 拒收结论须经双人复核确认，并在报告中载明拒收依据及对应照片编号。

## 六、报告字段与拍照取证要求

第十二条 检测报告须包含以下字段：商品编号、品牌与型号、送检人信息、成色结论、检测项明细、异常描述、附件清点结果、拒收依据（如适用）、检测人与复核人签名、报告出具时间。

第十三条 拍照取证不少于 6 张，实际按检测流程执行不少于 8 张，须覆盖：包袋正面全身、背面、底部四角、内衬全貌、五金特写、身份卡/序列号/镭射标、手柄/肩带。每张照片须能清晰辨认对应瑕疵位置。

第十四条 瑕疵部位须单独加拍特写，照片文件名标注瑕疵类型。视频取证不少于 15 秒，须连贯展示拉链拉合、锁扣开合等动态功能。

## 七、常见争议与判定口径

第十五条 争议一：轻微氧化是否降级。判定口径：五金轻微氧化属正常使用痕迹，不单独降级；氧化发黑或镀层脱落面积明显，降至 C 级以下。依据：五金氧化通病按品牌分册区分正常老化与异常损耗。

第十六条 争议二：护理后是否影响成色。判定口径：清洁、补色等可逆护理不影响原成色；换皮、补料等不可逆处理降一档披露。依据：可修复性分级标准。

第十七条 争议三：附件缺失是否降级。判定口径：附件缺失不改变成色档位，但须在报告中显著标注，由买家确认。依据：附件清点结果如实记录原则。

第十八条 争议四：异味判定标准。判定口径：通风静置复核后仍存在霉味或烟味超常规，按强烈不可去除异味拒收；轻微异味在报告中披露并降级。依据：异味须与运输包装气味区分，静置复核后判定。
