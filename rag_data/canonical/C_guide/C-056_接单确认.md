# 接单确认

## 什么时候看这篇

买家拍下并付款后，你的第一动作不是欢呼，而是去「卖家中心-订单管理-待发货」里点开这笔订单，逐项核对再确认接单。接单确认做错了，后面发货、质检、收款全链条都会跟着出问题。

## 操作步骤

1. 收到「您有订单待处理」推送后，进入「卖家中心-订单管理-待发货」，找到对应订单，点击「订单详情」。
2. 核对五项：买家收货地址是否完整、商品与你在售SKU是否一致、成交价与你的心理底价是否吻合、买家留言里有没有特殊要求、该商品是否命中强制质检类目。手机、平板电脑、笔记本电脑、相机与镜头、智能手表与穿戴、游戏主机与游戏、奢侈品箱包、腕表、黄金珠宝这九类必须送检。
3. 核对无误后，点击「确认接单」。系统开始倒计时，发货时效为48小时，以买家付款成功那一刻起算，不是从你点击确认起算。
4. 若商品属于强制质检类目，确认接单后立即在「卖家中心-订单管理-送检入口」提交质检申请，按页面提示选择就近质检点或预约上门取件。
5. 若发现任何一项对不上——比如买家拍的是iPhone 15却留言要iPhone 14——不要点确认，先通过「订单沟通」联系买家澄清，必要时请买家取消重拍。

## 关键规则

- 发货时效为48小时（自买家付款成功起算），超时未发货将触发平台违约处理，相关扣分计入卖家信用分体系（RL-102）。
- 普通商品买家签收后10天系统自动确认收货；经过平台质检的商品，自动确认收货周期延长至15天（RL-103）。
- 强制质检类目以平台公示清单为准，送检报告需在48小时内出具，若对报告结论有异议，可在72小时内提交复检申请（RL-201）。
- 买家在付款后24小时内可无理由取消未发货订单，卖家无需操作，系统自动处理（RL-104）。
- 质检通过后，若买家因个人原因拒收，买家需承担退货运费（RL-202）。
- 平台技术服务费按商品实际所属品类收取，费率区间为1%至3%，单笔最低0.1元，结算周期为T+1（RL-301）。具体费率以「卖家中心-类目费率公示」页面为准。

## 常见问题

**问：买家刚付款我就发现标错价了，能直接取消订单吗？**
答：不能单方面取消。立即联系买家说明情况，请对方取消或协商改价。擅自不发货等买家申请取消，会被记为发货违约。

**问：我卖的是二手手机，买家说不用质检，直接寄给他行不行？**
答：不行。手机属于强制质检类目，必须走平台质检流程。跳过质检直接发货，后续出现成色纠纷时你缺少平台质检报告作为证据，判责会非常被动。

**问：48小时是从我点确认接单开始算吗？**
答：不是。从买家付款成功那一刻就开始计时了。你拖到临届点才点确认接单，只剩很少时间打包叫快递，风险极高。

**问：买家拍下后一直不付款，我要管吗？**
答：未付款订单系统会自动保留一段时间，超时自动关闭，无需你操作。你只需关注「待发货」里已付款的订单。

**问：质检报告显示商品成色比我的描述低一级，怎么办？**
答：在72小时内提交复检申请，同时准备好你拍摄的商品细节图。若复检维持原结论，你可以选择接受降价成交或取消订单，具体路径以平台页面公示为准。

## 风险与避坑

- **别急着点确认**。核对地址和SKU只需一两分钟，但漏掉一条买家留言里的改色、改容量要求，后面扯皮的成本远高于这点时间。
- **强制质检类目别心存侥幸**。手机、相机这类商品跳过送检直接发货，一旦成色有争议，你没有平台质检报告撑腰，判责大概率吃亏。
- **发货时限从付款起算，不是从你确认起算**。付款后拖了快一天才点确认，留给打包叫快递的时间所剩无几，超时违约得不偿失。
- **保留沟通记录**。买家要求改价、改地址、加赠品，一律在「订单沟通」里说，别用站外聊天工具，纠纷时平台只认站内证据。
