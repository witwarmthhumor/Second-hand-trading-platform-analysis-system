# 实名认证失败处理

## 什么时候看这篇

你在 RAGreflow（回流二手）提交卖家入驻资料后，系统提示实名认证未通过、需要重新提交或申诉时，按这篇的步骤排查和解决。

## 操作步骤

1. 打开 App，进入「我的-卖家中心-入驻进度」，查看失败原因。系统会明确标注是哪一项没通过，常见三类：身份证照片模糊、人脸识别不匹配、银行卡信息与身份证不一致。

2. 根据失败原因修正资料后重新提交。身份证照片请确保证件四角完整入镜、无反光、无遮挡；人脸识别时摘掉口罩和墨镜，在光线均匀的环境下操作，按提示完成点头、眨眼动作。

3. 如果多次重试仍失败，进入「我的-客服中心-实名认证申诉」，按页面要求上传补充材料。可上传的材料包括：身份证原件照片（需手持）、护照或驾照等辅助证件、近期本人正面照。提交后等待平台人工复核。

4. 复核期间保持手机畅通。平台可能通过站内信或短信联系你补充信息，一般会在 3 个工作日内给出复核结论，具体时效以平台页面公示为准。

5. 复核通过后回到「卖家中心-入驻进度」继续完成后续开店步骤。若复核仍未通过，页面会显示当前卡点，你可以对照下方"常见问题"排查原因后再次申诉。

## 关键规则

- 实名认证是开店前置条件，未通过认证前无法发布商品，也无法使用「我的-卖家中心-商品管理」下的任何功能。
- 认证主体必须与后续绑定的收款账户主体一致。个人卖家认证使用本人身份证和本人银行卡；企业卖家认证使用营业执照对应主体信息（参考《企业卖家入驻》）。
- 认证失败不会影响你的平台信用分。信用分初始值为 800 分，只有在交易环节出现违规才会触发扣分（制度编号 RL-204）。
- 同一身份证件在平台仅可注册一个卖家账号。若提示"证件已被注册"，请先确认是否为本人历史账号，再走申诉流程。
- 实名认证通过后，个人卖家无需缴纳保证金（0 元）；升级为专业卖家需缴纳 500 元保证金（制度编号 RL-107）。
- 认证过程中提交的证件信息仅用于平台身份核验，平台按隐私政策加密存储，不会向其他用户展示完整证件号。

## 常见问题

**"我身份证拍了好几次都说模糊，到底要怎么拍？"**
把身份证平放在深色桌面上，手机垂直于证件正上方拍摄，避免倾斜和阴影。不要用截图或翻拍旧照片，必须拍原件。

**"人脸识别一直失败，是不是系统有问题？"**
先检查光线和网络。逆光、过暗、戴眼镜反光都会导致失败。连续失败 5 次后系统会锁定当日识别次数，建议第二天再试，不要反复硬刷。

**"我银行卡是我老公的，用我的身份证能过吗？"**
不能。认证主体、银行卡持卡人、身份证三者必须为同一人。换绑本人银行卡后再提交。

**"申诉提交后多久有结果？"**
平台人工复核一般 3 个工作日内完成，具体以页面公示为准。期间留意站内信通知。

**"认证失败会影响我买东西吗？"**
不影响。买家身份与卖家认证相互独立，你仍可正常下单购买。

## 风险与避坑

- **别拿旧证件凑合**。身份证过期、地址与现居地不符都会触发人工复核，拖慢整个入驻节奏。提交前先看证件有效期。
- **照片翻拍是大忌**。用手机翻拍电脑屏幕上的证件图，系统会直接判为"疑似复印件"驳回，且该次失败记录会留在审核日志里。
- **银行卡别临时借**。认证绑定的卡若后续被银行冻结或注销，你的货款结算会卡在提现环节，到账时间（T+1）会顺延。绑卡前确认该卡长期可用。
- **申诉材料一次给全**。手持身份证照要能看清证件号码和五官，别用美颜滤镜。材料不全被打回，一来一回又多等几天。
- **留意失败次数**。反复提交错误资料不会封号，但会拉长整体入驻周期。连续失败两次以上，建议先找客服确认原因再提交，别闷头重试。
