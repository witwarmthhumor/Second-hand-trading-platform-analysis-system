# 赔偿协商

## 什么时候看这篇
买家发起售后、你不同意全额退款、或者东西在途中/质检环节出了岔子，需要谈赔偿金额时，先翻这篇。

## 操作步骤
1. 收到售后申请后，先看买家诉求属于哪一类：退货退款、仅退款、还是补差价。路径：「我的-客服中心-售后申请」。
2. 核对订单快照与发货记录，确认商品成色标注（N/S/A/B/C/D 六级）与买家描述是否对得上。成色描述不符是赔偿协商里最容易被判责的点。
3. 在售后详情页点「协商方案」，填写你愿意承担的赔偿金额或补偿方式（部分退款、补寄配件、承担返修运费等）。提交后买家有 72 小时回应，超时未回应平台将按流程介入。
4. 协商不成，申请平台介入。平台在收到申请后 72 小时内给出判定，复杂案件最长 5 个工作日。期间可补充证据：订单快照、商品图片视频、聊天记录、物流凭证、质检报告、付款凭证，六类都认。
5. 协商达成或平台判定后，按结果执行退款或补偿。赔偿款从货款或保证金中扣，T+1 结算。

## 关键规则
- 售后窗口期：买家签收后 15 天内可发起售后申请（含赔偿诉求）。超期后平台不再受理强制赔偿，但双方自愿协商不在此限。
- 质检类商品（手机、平板、笔记本、相机与镜头、智能手表与穿戴、游戏主机与游戏、奢侈品箱包、腕表、黄金珠宝）：以平台质检报告为准。买家对报告有异议可申请复检，须在 72 小时内提出。
- 卖家发货时限 48 小时。超时发货导致买家拒收或退货，运费及差价损失通常由卖家承担。
- 信用分初始 800，纠纷率是店铺评分四维之一。被判责的赔偿协商会计入纠纷率，直接影响流量与活动报名资格。
- 赔偿金额无统一费率，以双方举证和平台判定为准；平台介入后按订单快照、聊天记录、物流凭证等综合裁量。

## 常见问题
- 「买家说屏幕有划痕，我发货前明明检查过，怎么办？」
  先看成色标注。你标了 A（95新）但划痕肉眼可见，大概率判你责；若能提供发货前视频证明划痕是运输中产生，可转向物流索赔。
- 「买家想留货但要我退 200，合理吗？」
  协商自由。只要双方同意，平台不干涉金额。建议参考商品实际折价与维修报价，别随口答应。
- 「质检报告说功能正常，但买家坚持有问题，复检要谁出运费？」
  复检结论维持原判时，买家承担来回运费；复检推翻原判，平台承担或由质检方担责。以平台页面公示为准。
- 「协商没谈拢，平台会怎么判？」
  平台看证据链完整性。你聊天记录里承认过瑕疵，基本就输了；全程否认但有发货视频，胜算大。
- 「赔偿了会影响我的店铺分吗？」
  协商成功且双方无异议，通常不计纠纷率；走到平台判定且判你责，会计入。

## 风险与避坑
- 发货前拍 360° 视频，重点拍屏幕、边角、镜头、按键。这是你对抗「到手刀」的唯一硬证据。
- 成色描述宁低勿高。标了 B（9成新）却出现 C 级才该有的磕碰，买家申请赔偿你几乎没有辩护空间。
- 聊天记录里别出现「应该没问题」「大概没修过」这类模糊表述，截图出去都是对你不利的。
- 赔偿协商期间不要主动关闭售后入口，也别诱导买家线下转账。平台发现会按违规处理，扣信用分。
- 涉及质检类目，别绕过平台私下交易。当面交易仅限非强制质检品类，且必须在平台留痕。
