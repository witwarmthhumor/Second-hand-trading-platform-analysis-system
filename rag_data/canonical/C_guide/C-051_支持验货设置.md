# 支持验货设置

## 正确用法与错误用法，先看对比

正确做法：发布支持验货的商品前，把瑕疵在描述里写透，配合平台质检报告，成交更快、纠纷更少。错误做法：开着验货选项，描述里却藏着瑕疵，指望质检报告"碰运气"——质检报告会把问题写得清清楚楚，最后吃亏的是你的店铺分。

## 哪些品类必须走验货

平台有九个品类强制走验货：手机、平板电脑、笔记本电脑、相机与镜头、智能手表与穿戴、游戏主机与游戏、奢侈品箱包、腕表、黄金珠宝（来源：inspection.categories_required，RL-A-034）。这些品类发布时验货选项默认开启且不可关闭。其余品类由卖家自主选择是否支持验货。

## 操作步骤

1. 发布页找到「验货服务」开关；
2. 强制品类确认开启，自主品类按商品价值决定；
3. 填写运费承担方式，看清规则：验货通过后寄回买家的运费由买家承担（来源：inspection.buyer_bear_shipping_when_pass，RL-A-035）；
4. 发布后商品页会出现质检标识，买家下单时能看到。

## 验货对你这个卖家意味着什么

- 商品寄到验机仓后，签收 48 小时内出质检报告（来源：inspection.report_deadline_hours）；
- 报告不通过的订单会原路退款，商品退回给你；
- 买家对报告有异议的，可在报告出具后 72 小时内申请复检（来源：inspection.recheck_apply_hours，RL-A-037）。

## 常见问题

问：验货费谁出？按商品页展示的验货服务说明执行，发布前先读一遍收费口径。

问：验货不通过亏运费怎么办？如实描述是最省钱的方案，描述到位的不合格率自然低。

问：报告把成色判低了不服气怎么办？申请复检是正规通道，复检结论为最终结论。

## 风险与避坑

- 强制验货品类绕开验货私下成交，属于违规引导，双方都有风险；
- 描述里的瑕疵写清楚，等于给质检报告"对答案"，报告写不出你已披露的瑕疵时，纠纷率显著下降；
- 验货商品打包按《奢品贵重打包规范》执行，寄出前留存影像，防调包也从你这一端做起。
