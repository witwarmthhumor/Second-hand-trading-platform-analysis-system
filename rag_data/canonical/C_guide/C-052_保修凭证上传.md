# 保修凭证上传

## 什么时候看这篇

你刚在「回流二手」上架一台 2023 款 MacBook Pro，买家拍下前私信问"有没有购买发票和保修记录"。你翻遍相册只找到一张模糊的电子发票截图，犹豫要不要传。这篇就是给你这种情况准备的——搞清哪些凭证该传、传到哪里、传错会怎样。

## 操作步骤

1. 进入商品发布页，在「商品描述」区域下方找到「保修与凭证」区块。该区块在电脑端和 App 端均位于商品主图与价格信息之后，若未看到可先保存草稿再重新编辑进入。
2. 点击「添加凭证」按钮，从相册或文件中选择图片。支持格式为 JPG、PNG，单张大小不超过 10MB。可一次上传多张，系统会自动压缩生成预览图。
3. 按凭证类型分别上传：购买发票、电子保修卡截图、官方维修记录、延保服务协议。每类凭证最多上传 3 张，超出部分建议合并为长图后上传。
4. 上传完成后，在「凭证说明」文本框内补充关键信息：购买日期、购买渠道、设备序列号或 IMEI 号、剩余保修时长。例如"2024-03-15 购于京东自营，序列号 FVFLC0Y8Q1MP，AppleCare+ 至 2027-03-14"。
5. 点击「保存并预览」，确认凭证缩略图清晰可读。若系统提示"图片模糊，可能影响审核"，建议重新拍摄后再上传。
6. 发布成功后，凭证信息会展示在商品详情页的「卖家提供凭证」区域。买家下单后，订单详情中也会同步展示，供验货环节比对。

## 关键规则

保修凭证上传遵循平台《商品发布与信息管理规则》RL-102 及《交易履约与售后时效规则》RL-204 的相关条款。

- 手机、平板电脑、笔记本电脑、相机与镜头、智能手表与穿戴、游戏主机与游戏、奢侈品箱包、腕表、黄金珠宝这九类商品强制要求送平台验货，验货报告出具时限为 48 小时。上传的保修凭证会随商品一同送检，作为验货员核验序列号真伪的辅助材料。
- 凭证信息属于商品描述的一部分。若你上传的凭证显示商品仍在官方保修期内，但实际商品已过保或存在私自拆修记录，买家在签收后 15 天售后窗口期内发起"描述不符"申诉，平台将依据 RL-204 判定责任。
- 凭证图片需与商品实际状况一致。上传他人商品的发票、PS 修改日期的截图、或遮挡关键信息的图片，一经发现按 RL-301 信用分规则处理：每次违规扣除相应信用分，信用分初始值为 800 分，低于 350 分将限制发布权限。
- 非强制验货类目（如台式机与配件、无线耳机与音频、运动鞋服、图书、小家电）不强制上传保修凭证，但上传完整凭证可提升商品质量分，进而影响店铺在搜索结果中的排序。
- 涉及保修状态的表述，若凭证无法清晰证明，建议在商品描述中标注"保修情况以官方查询为准"。平台查验时若发现描述与凭证不符，将按虚假描述处理，具体处罚节点以平台页面公示为准。

## 常见问题

"发票是朋友送的，上面不是我的名字，能传吗？"——能。凭证用于佐证商品来源与保修状态，不要求购买人姓名与卖家一致，但商品型号、序列号必须对得上。

"保修卡丢了，只有官网查询截图行不行？"——行。截图需包含完整的查询网址和商品序列号，建议连拍两屏，把查询结果页和商品信息页都放进去。

"上传之后买家说看不清，能换吗？"——能。商品未售出前可随时编辑替换；已售出则需在发货前联系买家说明，或走平台客服通道补充凭证。

"我传了发票，平台会不会把我的个人信息泄露给买家？"——不会。凭证展示时平台会自动打码姓名、地址等敏感字段，买家仅能看到商品型号、购买日期与保修截止日。

## 风险与避坑

- 传凭证前先核对序列号。二手圈最常见的纠纷就是发票是真的、机器是换过的——凭证上的序列号和你实际发货的机器对不上，验货环节一查就穿。
- 别用"保修还剩一年"这种模糊说法。买家截图留证后，到期日差一天都可能成为"描述不符"的依据，写清楚"至 2027-03-14"这类具体日期。
- 截图类凭证记得露出查询时间和网址。平台审核时无法溯源的截图，效力等同没传。
- 若商品有拆修史但凭证显示在保，建议主动在描述里披露。隐瞒拆修被买家在售后窗口期内申诉，责任判定对你很不利。
- 凭证上传后留意系统审核结果。被退回的凭证不修改直接重发，反复多次可能触发信用分预警。
