# 开店必备资料

## 什么时候看这篇
准备在回流二手（RAGreflow）上卖东西、但还没完成入驻的你。把下面这份清单备齐，从注册到上架第一件商品，全程不用因为缺材料而卡住。

## 操作步骤
1. 注册账号并完成实名认证。入口在 App 首页「我的-卖家中心-立即入驻」，按提示上传身份证正反面，系统自动核验身份信息，通常几分钟内出结果。
2. 选择卖家类型。个人卖家零保证金即可开店，适合偶尔出闲置；专业卖家需缴纳 500 元保证金，适合稳定出货的商家，两类卖家的权限差异见《个人与专业卖家区别》。
3. 按所选类型提交补充资料。个人卖家准备本人银行卡与手机号；专业卖家还需提供营业执照、法人身份证、对公账户信息。企业卖家额外提交企业授权书，路径为「卖家中心-资质管理-企业认证」。
4. 等待平台审核。资料提交后进入人工复核环节，审核结果通过站内信通知。审核通过后，在「卖家中心-店铺设置」里完善店铺名称、头像、简介，即可开始发布商品。
5. 发布第一件商品前，先确认商品类目是否属于强制质检范围。手机、平板电脑、笔记本电脑、相机与镜头、智能手表与穿戴、游戏主机与游戏、奢侈品箱包、腕表、黄金珠宝这九类必须送平台质检，发布时系统会引导你创建质检单。

## 关键规则
- 个人卖家入驻保证金为 0 元，专业卖家为 500 元（来源：RL-FEE-003）。保证金在关店且无未完结订单后可申请退还。
- 平台按成交价向卖家收取佣金，费率因类目而异：手机数码 1%、电脑办公 1.5%、相机影音 2%、奢侈品 3%、服饰鞋包 2%、图书音像 1%、家居家电 1.5%、其他 2%，单笔最低 0.1 元（来源：RL-FEE-001）。跨品类商品按实际所属品类取费率。
- 强制质检类目若未送检，商品无法上架；送检后平台需在 48 小时内出具质检报告（来源：RL-INS-001）。质检通过后买家承担寄回运费，若买家拒收或超时未处理，以平台页面公示为准。
- 卖家须在订单成立后 48 小时内发货（来源：RL-TRD-002），超时可能触发买家取消权并影响店铺信用分。
- 店铺信用分初始 800 分，区间 350–950 分，由商品质量分、服务态度分、物流履约分、纠纷率四个维度构成（来源：RL-CRD-001）。扣分节点与处罚措施见《卖家入驻流程》中的信用规则表。

## 常见问题
- **我没有营业执照，能开店吗？**
  能。个人卖家凭身份证即可入驻，零保证金，适合出个人闲置。但个人卖家无法开通部分专业功能，具体差异看《个人与专业卖家区别》。
- **资料提交后多久能审核完？**
  实名认证通常即时通过，人工复核一般 1–2 个工作日。高峰期可能延长，以站内信通知为准。
- **卖手机一定要先送质检吗？**
  对。手机属于强制质检类目，不送检无法上架。质检报告 48 小时内出具，通过后买家承担寄回运费。
- **保证金什么时候能退？**
  关店清算完成后可申请退还，前提是没有未完结订单和未处理的纠纷。具体到账时间以平台页面公示为准。
- **我是企业，想用对公账户收款，需要额外提交什么？**
  企业卖家需提交营业执照、法人身份证和对公账户信息，并在「卖家中心-资质管理-企业认证」里完成企业授权书签署。

## 风险与避坑
- 身份证照片要四角完整、无反光，模糊件会被驳回，白白浪费一个审核周期。
- 银行卡户名必须与实名认证姓名一致，不一致会导致 T+1 结算失败，货款滞留在平台账户里。
