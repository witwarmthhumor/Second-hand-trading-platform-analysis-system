# 审核驳回高频原因

## 什么时候看这篇
你刚上架的商品被平台驳回，或者连续几次提交都没过审，想搞清楚到底哪里出了问题、怎么改才能一次通过。

## 操作步骤

1. 查看驳回通知——打开「我的-商品管理-审核记录」，点开被驳回的商品，逐条阅读驳回原因。平台会列出具体违规点，不会只给一句"信息不符"。
2. 对照原因逐项修改——驳回原因通常分三类：图片问题、描述问题、类目问题。图片模糊或与实物不符的，重新拍摄；描述夸大成色的，按实际成色修改；类目放错的，在「发布商品-选择类目」里重新选。
3. 修改后重新提交——在「审核记录」页面找到该商品，点「重新提交审核」。提交后进入排队，审核结果会通过站内信和短信通知你。
4. 若仍被驳回——不要反复提交同一版内容。先对照本文档逐项自查，或联系「我的-客服中心-在线客服」询问具体卡点。

## 关键规则

审核驳回的高频原因，集中在以下几个维度，对应平台规则 RL-102、RL-107、RL-112：

1. **成色虚标**——把 B 级（9成新，正常使用痕迹，允许极轻微外观瑕疵）标成 A 级（95新，轻微使用痕迹，无功能缺陷，无拆修），是最常见的驳回原因。成色判定标准见《商品分级标准》，发布时逐条对照。
2. **图片与实物不符**——用网图、官方宣传图替代实拍图，或图片经过美化滤镜导致色差明显。平台要求商品主图必须为实拍，且能清晰展示瑕疵部位。
3. **描述遗漏关键瑕疵**——有磕碰、划痕、维修史但未在描述中披露。特别是拆修史，一旦隐瞒，后续纠纷处理会对卖家非常不利。
4. **类目错放**——手机、平板电脑、笔记本电脑、相机与镜头、智能手表与穿戴、游戏主机与游戏、奢侈品箱包、腕表、黄金珠宝这九类必须走验货流程（规则 RL-105），错放到非验货类目会被直接驳回。
5. **标题或描述含违禁词**——如"全新未拆"用于已拆封商品、"官方正品"但无授权凭证等。标题撰写规则见《标题撰写规则》。

## 常见问题

**Q1：我标了95新，但审核说我虚标，凭什么？**
A：95新（A级）要求"无拆修"，如果你的机器有维修史，哪怕只是换过电池，也只能标到 B 级或更低。拆修史是硬门槛，不是看外观新旧。

**Q2：我拍了实拍图，但审核说图片不清晰，怎么办？**
A：在自然光下拍摄，对焦清晰，瑕疵部位单独拍特写。图片被压缩后模糊的，检查原图分辨率是否达标，重新上传原图。

**Q3：手机类目必须验货，我不想验货能卖吗？**
A：不能。手机属于强制验货类目，发布时系统会引导你选择验货服务。不走验货流程，商品无法通过审核。

**Q4：我改了三次还是被驳回，是不是被针对了？**
A：不会。连续驳回通常是同一个根本问题没解决。建议联系「我的-客服中心-在线客服」，把驳回记录发给客服，让审核同事帮你指出具体卡点。

**Q5：描述里写了"轻微使用痕迹"，但没写具体哪里有划痕，算违规吗？**
A：算。描述必须具体到瑕疵位置和程度，例如"屏幕左上角有一道长约1cm的细划痕，亮屏可见"。笼统描述会被视为披露不充分。

## 风险与避坑

1. **成色往低了标，别往高了标**——拿不准是 A 还是 B 时，按更低的成色发布。宁可买家收货觉得"比描述好"，也不要因为虚标被驳回、被投诉。
2. **保留修改前的原始素材**——每次被驳回后，把原图、原描述存一份。万一后续产生"你卖的是不是这台的争议"，这些素材是证明商品状态的重要依据。
3. **拆修史主动披露，别赌运气**——验货流程会拆机检测，隐瞒维修史在验货环节必然暴露，届时不仅驳回，还可能触发信用分扣减。
4. **留意驳回通知里的时限**——部分驳回原因需要在规定时间内修改并重新提交，超时后商品链接可能被关闭，需重新走发布流程。
5. **同类目多学多问**——连续两次因同一原因被驳回，先翻《标题关键词技巧》和《支持验货设置》自查，别急着改一两个字就重交。
