# 学生卖家政策

## 什么时候看这篇
你是在校学生，想在 RAGreflow 上把闲置手机、平板、相机或球鞋卖掉换点生活费，但不确定学生身份能不能开店、要不要交保证金、费率跟普通卖家有没有区别——这篇就是给你看的。

## 操作步骤
1. 确认在校身份。准备好学生证（含注册章或本学期注册记录）或在读证明（学校教务处盖章），照片要拍清楚姓名、学校、有效期三处信息。
2. 注册账号并进入卖家中心。App 路径：打开 RAGreflow →「我的」→「卖家中心」→「入驻申请」，选择「个人卖家」身份入口。
3. 提交学生认证材料。在入驻申请页上传学生证或在读证明照片，填写学校全称、学号、预计毕业年份。平台会在 1-2 个工作日内完成审核，结果通过站内信通知。
4. 完成实名认证与银行卡绑定。学生卖家同样需要实名认证，绑定本人储蓄卡用于后续结算提现。路径：「我的」-「账户与安全」-「实名认证」。
5. 阅读并勾选《学生卖家承诺函》。承诺所售商品来源合法、非盗抢非赃物、不涉及批量代购转售，然后提交入驻申请。
6. 审核通过后即可上架商品。上架路径：「卖家中心」-「发布商品」，按提示选择品类、填写成色（参考 N/S/A/B/C/D 分级）、上传实拍图、设置价格。

## 关键规则
- 保证金：学生卖家按个人卖家标准执行，保证金为 0 元（RL-102 卖家保证金制度）。无需缴纳 500 元专业卖家保证金即可开店。
- 平台服务费率：按商品实际所属品类计费，费率从 1% 到 3% 不等。手机数码类 1%，电脑办公类 1.5%，相机影音类 2%，奢侈品（箱包/腕表/黄金珠宝）3%，服饰鞋包 2%，图书 1%，家居家电 1.5%，其他品类 2%。单笔最低收取 0.1 元（RL-201 平台服务费标准）。
- 结算周期：交易完成后 T+1 结算，提现到账 T+1（RL-203 资金结算规则）。
- 强制质检品类：手机、平板电脑、笔记本电脑、相机与镜头、智能手表与穿戴、游戏主机与游戏、奢侈品箱包、腕表、黄金珠宝——这些品类学生卖家发布时必须选择平台质检服务，质检报告出具时限为 48 小时（RL-301 商品质检规范）。
- 非强制质检品类：台式机与配件、无线耳机与音频、运动鞋服、图书、小家电等，可自愿选择是否送检（RL-301）。
- 发货时限：买家付款后 48 小时内必须发货（RL-401 交易时效规范）。超时未发货将计入物流履约分。
- 信用分体系：学生卖家初始信用分 800 分，范围 350-950 分。扣分周期 365 天，累计 48 分永久封禁（RL-501 卖家信用分规则）。

## 常见问题

1. 学生认证没通过怎么办？检查上传的学生证是否在有效期内、注册章是否清晰。材料没问题的话，联系客服人工复核，通常 1-2 个工作日内有结果。

2. 寒暑假回家，发货会受影响吗？发货时限照常执行，买家付款后 48 小时内必须发货。假期离校前建议把商品交给家人代发，或直接在商品页注明预计发货时间。

3. 毕业之后学生卖家身份还有效吗？毕业即失去学生卖家资格，届时按个人卖家标准重新核验。保证金政策不变，仍是 0 元。

4. 学生能卖教材和笔记吗？可以，图书类目费率 1%，且不强制质检。但盗版复印教材、他人笔记复印件不能卖，涉及版权问题会直接处罚。

## 风险与避坑

- 卖手机、电脑前先退出个人账号、恢复出厂设置，清除所有个人信息。照片和视频里别拍到快递单、学生证号等隐私。
- 强制质检品类别图省事跳过送检。一旦买家收货后对成色有争议，质检报告是平台仲裁时对你最有利的凭证。
- 注意 15 天售后窗口期。卖出后别急着把钱花掉，若商品出现描述不符的问题，平台可能从你的结算款中划扣退款。
- 别用学生身份帮别人代卖批量商品。平台对批量代购转售是零容忍，一旦判定会直接扣信用分，严重时永久封禁。
- 同校线下交易可以走面对面，但务必在平台内完成下单和付款，别私下转账，否则纠纷不受平台保护。
