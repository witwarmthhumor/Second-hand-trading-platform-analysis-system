# 保证金赔付

## 什么时候看这篇

你收到平台通知，说要从保证金里扣钱赔给买家，或者你正打算申诉一笔赔付——先别急着上火，这篇告诉你钱从哪扣、扣多少、怎么拦。

## 操作步骤

1. 打开「我的-卖家中心-保证金」，查看当前保证金余额与冻结明细。赔付触发后，平台会先从可用余额划扣，余额不足时进入欠款状态。
2. 收到赔付通知后，在「我的-客服中心-赔付申诉」提交异议。上传证据时勾选订单快照、商品图片视频、聊天记录、物流凭证、质检报告、付款凭证中与你案件相关的类型。
3. 平台在收到申诉后进入复核，复杂案件处理周期以平台页面公示为准。申诉通过则退回已扣款项，不通过则维持原判。
4. 若保证金被扣至影响正常售卖，系统会提示你补足。个人卖家保证金为 0 元，专业卖家保证金为 500 元——补缴入口在「卖家中心-保证金-充值」。

## 关键规则

- 赔付金额优先从订单货款中抵扣，不足部分再从保证金划扣。货款结算为 T+1，提现到账同样为 T+1。
- 触发赔付的典型场景：卖家未在 48 小时内发货、商品与描述严重不符、售后期 15 天内出现非人为故障且卖家拒绝处理。
- 平台介入时效：首次响应 3 分钟内，常规介入处理 72 小时内给出结论，复杂案件延长至 5 个工作日。
- 赔付记录会计入店铺纠纷率，纠纷率是店铺评分四个维度之一（商品质量分、服务态度分、物流履约分、纠纷率）。
- 信用分初始 800 分，范围 350-950 分。赔付确认后按规则扣分，扣分节点与对应处置以平台页面公示为准。
- 需送检品类（手机、平板电脑、笔记本电脑、相机与镜头、智能手表与穿戴、游戏主机与游戏、奢侈品箱包、腕表、黄金珠宝）若因隐瞒瑕疵引发赔付，卖家还需承担检测相关费用。

## 常见问题

- **"我没发货是因为买家一直不回复，凭什么扣我保证金？"**
  发货时效从订单支付成功起算 48 小时，买家不回复不构成延迟发货的免责理由。建议到点前先发站内消息催确认，并保留已尽告知义务的截图。

- **"买家自己把手机摔了，回头说质量问题要赔，我冤不冤？"**
  你可以申诉。提供发货前的完整验机视频和物流包装照片，证明瑕疵非发货时存在。平台会结合质检报告和物流凭证判断责任方。

- **"保证金扣完了会怎么样？"**
  余额不足时订单会被限制发布，专业卖家需补足 500 元保证金才能恢复。欠款状态下新订单无法结算，直到补足。

- **"赔付金额怎么算的？是按我卖价全额赔吗？"**
  赔付以买家实际损失为限，不必然等于全额货款。平台会根据质检报告、维修报价单等核定损失金额，具体计算方式以平台页面公示为准。

- **"我申诉成功了，钱什么时候退回来？"**
  申诉通过后，已划扣的保证金原路退回至卖家保证金账户，可即时用于后续订单，提现仍按 T+1 到账。

## 风险与避坑

- **别把保证金当"押金"看**。专业卖家的 500 元保证金是持续冻结的，不是一次性费用；赔付扣款后不及时补足，欠款状态会卡住新订单结算，拖得越久损失越大。
- **发货前留足证据链**。带序列号或 IMEI 的实拍图、验机视频、打包封箱视频各存一份，至少保留到售后期 15 天结束。二手商品成色争议高发，没有发货前证据，申诉时口说无凭。
- **48 小时发货时效是硬杠杠**。哪怕差几分钟超时，赔付照扣。建议开启系统自动提醒，别赌"买家不催就没事"。
- **赔付申诉别只传一张截图**。把订单快照、聊天记录、物流轨迹、质检报告按时间线整理成组上传，证据之间能互相印证比单张图片有用得多。
- **看清扣分节点再决定是否申诉**。信用分累计扣到一定分值会触发限流或封禁，如果事实清楚、胜算不大，硬申诉拖过 72 小时平台介入期反而拉长纠纷时长，影响店铺评分。
