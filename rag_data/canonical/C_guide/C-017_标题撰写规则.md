# 标题撰写规则

## 什么时候看这篇

你刚通过「发布入口与流程」建好商品草稿，准备给手机、镜头或一只腕表起标题，却发现怎么写都差点意思——要么搜不到自己，要么被平台判违规。这篇就是给你对照着改的。

## 操作步骤

1. 打开「我的-卖家中心-发布商品」，进入标题输入框。标题限 30 个汉字以内，超过会被系统截断，截断部分不参与搜索匹配。
2. 先写核心词：品牌 + 具体型号 + 品类词。例：`iPhone 13 Pro 手机`，而不是`苹果手机`。买家搜"iPhone 13 Pro 屏幕"时，只有型号完整才可能命中。
3. 再补状态与卖点词：成色等级（N/S/A/B/C/D 之一，见平台成色标准）、是否国行、内存/尺寸等关键参数。例：`iPhone 13 Pro 手机 国行 128G A级 无拆修`。
4. 对照「违禁词排查」清单过一遍，确认没有极限词、承诺词（如"绝对正品""全网最低"）后提交。
5. 提交后 48 小时内留意审核结果（对应验货报告出具时限的同一窗口）。被驳回时，按提示修改标题，不要直接重复提交同一文案。

## 关键规则

**正确做法 vs 错误做法**，逐对看：

- **对：型号写全。** `索尼 A7M4 相机与镜头 全画幅微单 A级`。**错：只写"索尼微单"**——买家搜"A7M4"时你完全隐形，曝光量趋近于零。后果：商品无人问津，14 天后自动下架。
- **对：成色等级按平台标准写。** 轻微使用痕迹写 A 级（95新），明显磕碰写 C 级（8成新）。**错：把 C 级写成"几乎全新"**——买家收货后发起纠纷，平台介入时以订单快照和商品图片视频为准，你不仅要退款，纠纷率维度还会拖低店铺评分。
- **对：把验货信息放进标题。** 手机、平板、笔记本电脑、相机与镜头等类目强制验货，标题可写`支持验货`。**错：不写**——买家不知道有验货服务，可能转向别家。验货通过时买家承担寄回运费，这是你的卖点，别藏起来。
- **对：按实际品类匹配费率组。** 标题里的品类词要和发布类目一致，比如游戏主机归手机数码费率组。**错：标题写"游戏机"，发布在"台式机与配件"**——跨品类发布触发审核，轻则驳回重填，重则计入违规扣分。平台按商品实际所属品类取费率，不是按你标题怎么起。

标题里禁止堆砌与商品无关的热搜词（如给手机加"相机"），系统判定为关键词作弊，直接降权。具体阈值以平台页面公示为准。

## 常见问题

**"标题里写'全网最低价'会被拦吗？"**
会。极限词、承诺词属于违禁词，轻则驳回，重则计入违规扣分。卖点靠成色和验货说话，不靠喊价。

**"我卖的是港版手机，标题要不要写？"**
要写。版本（国行/港版/美版）直接影响买家决策，不写清楚，买家收货后以"版本不符"发起纠纷，你大概率要承担退货运费。

**"标题字数超了会被截断，那重要信息放前面还是后面？"**
放前面。系统从后往前截断，品牌、型号、成色这些核心词必须在前 30 个字内写完，卖点词往后放。

**"同一个商品，标题能隔几天改一次吗？"**
能改，但别频繁。每次修改都会重新进入审核队列，审核期间曝光会暂时受限。建议一次改到位，别挤牙膏。

## 风险与避坑

- **型号差一个字母，纠纷翻一倍。** `iPhone 13` 和 `iPhone 13 Pro` 是两个商品，`A7M4` 和 `A7C` 也不是一回事。发布前对着机身或包装核对型号，拍下商品图片视频留证，别凭记忆写。
- **成色往好了写，等于给自己埋雷。** C 级写成 A 级，买家收到货一验就知道。验货报告和订单快照都在平台手里，纠纷介入时你没有任何辩解空间，店铺评分里的商品质量分和纠纷率双输。
- **别蹭别人的型号。** 给二手安卓机标题加"iPhone 同款手感"这类词，属于关键词作弊，系统降权不说，买家搜到也觉得货不对板，转化率反而更低。
- **标题和实物描述不一致，验货会卡住。** 标题写"无拆修"，验货发现主板动过，报告会如实记录，买家看到报告直接退款，你还得承担来回运费。标题怎么写，商品就怎么是。
- **留意审核时限。** 标题驳回后修改重提，审核窗口和验货报告一样是 48 小时内出结果，别卡着上架时间反复试错，留足余量。
