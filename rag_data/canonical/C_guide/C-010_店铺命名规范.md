# 店铺命名规范

## 什么时候看这篇

你刚提交完个人卖家资料，正准备给自己的二手店铺起名，结果发现系统提示"名称含违规词"——别急着换名字硬试，先花三分钟把这篇看完，能帮你少走好几轮审核驳回的弯路。

## 操作步骤

1. 登录 RAGreflow 卖家端，进入「我的-店铺管理-店铺资料」页面，点击"店铺名称"旁的"修改"按钮。首次入驻时，该入口会在资质审核通过后自动开放。
2. 在命名输入框中填写你拟定的店铺名，系统会实时检测字符长度与敏感词。检测通过后点击"保存"，进入人工审核队列。
3. 等待平台审核结果，通常在 1-2 个工作日内通过站内信通知。若审核不通过，站内信会注明具体违规原因，你可在「店铺管理-命名记录」中查看驳回历史并重新提交。
4. 审核通过后，店铺名即锁定生效。如需再次修改，同一自然年内仅支持有限次数的自助修改，超出后需联系客服人工处理，具体次数以平台页面公示为准。
5. 修改完成后，建议立即检查店铺首页、商品详情页及分享卡片中的店铺名展示是否同步更新，避免出现旧名称缓存。

## 关键规则

店铺命名遵循"真实、可辨识、不误导"三项底线。你的店铺名必须能反映实际经营内容，不得使用与平台官方名称（如"回流二手""RAGreflow"）相同或近似的表述，也不得包含"旗舰店""官方店""唯一授权"等暗示平台背书的字样（来源制度编号 RL-102）。

命名中禁止出现以下内容：色情低俗、暴力恐怖、赌博博彩、政治敏感词汇；与其他已注册店铺名称构成混淆的近似名；包含未经授权的品牌名、商标或名人姓名。若你计划销售奢侈品箱包、腕表、黄金珠宝等品类，店铺名中不得出现"专柜""原单""代购"等易引发货源争议的表述——这些品类在平台规则中属于强制送检类目（来源制度编号 RL-207），命名时的审慎程度应相应提高。

店铺名长度建议控制在 4-20 个字符之间，支持中英文、数字及部分符号（如"-"、空格），不支持纯符号或纯数字。名称中若包含品类词，应与实际主营类目一致。例如你主要卖手机与平板电脑，店铺名可含"数码"但不宜含"家具"。跨品类经营时，名称应使用"闲置""二手""好物"等中性词，避免类目绑定过窄（来源制度编号 RL-103）。

涉及二手商品成色描述的命名，如"九成新""几乎全新"等，须与实际商品分级一致。平台成色分级从 N（全新）到 D（7成新及以下）共七档（来源制度编号 RL-301），店铺名中若承诺了某一成色等级，店内所有商品均不得低于该等级，否则将被判定为描述不符，影响店铺信用分中的"商品质量分"维度。

## 常见问题

"店铺名叫'XX潮品数码'，但我偶尔也卖几件衣服，要紧吗？"——要紧。名称含品类词时须与主营类目一致，偶尔卖衣服不影响，但若服饰类商品占比过高，建议改用"闲置""好物"等中性词，避免审核驳回。

"我提交的店名被驳回了，但站内信只写'含违规词'，没说是哪个词，怎么办？"——在「店铺管理-命名记录」中查看驳回历史，逐字核对是否触碰敏感词、品牌词或平台官方近似名。仍无法定位时，联系在线客服索取具体命中词条。

"店铺名审核通过后还能改吗？"——可以，但同一自然年内自助修改次数有限，超出后需联系客服人工处理。每次修改都会重新进入审核流程，建议一次定稿，别把修改额度浪费在试探性命名上。

"我卖的是奢侈品箱包，店名里能带'中古'吗？"——可以，但"专柜""原单""代购"等词禁用。中古本身是二手行业的正常描述，前提是你确实经营该品类且商品走强制送检流程。

## 风险与避坑

- **别蹭品牌名**。店名里带"Apple 优选""Nike 折扣"这类组合，审核必驳，严重时会被记为一次命名违规。卖品牌商品没问题，但店名不能让人误以为你是官方渠道。
- **成色承诺是给自己挖坑**。店名叫"九成新数码"，结果上架了一台 C 级（8成新）的手机，买家收货后一投诉，商品质量分直接受影响。命名时宁可留余地，别把成色承诺写死。
- **改名要趁交易少的时候**。店铺名锁定后，老链接、聊天记录、订单快照里都留着旧名。若你已有在途订单，改名可能让买家在售后时认不出店铺，建议清完在途单再操作。
- **保留命名审核截图**。人工审核存在一定主观性，若你因同一名称被反复驳回且理由前后矛盾，截图存档可作为申诉依据。平台信用分体系下，申诉通道对证据完整度要求较高，别等要用时才发现记录早被清掉了。
