# 运费争议

## 什么时候看这篇

买家申请退款，运费归属谈不拢，订单卡在售后流程里动不了——这篇给你一张判责底表，照着对就行。

## 运费判责底表

| 争议情形 | 运费承担 | 说明 |
| 商品与描述不符 | 卖家 | 描述瑕疵未披露，责任在卖家 |
| 质检报告与卖家描述不符 | 卖家 | 以质检报告为准 |
| 无理由退货 | 买家 | 买家原因退回，来回运费买家承担 |
| 买家收到后发现拍错 | 买家 | 卖家可协助协商，无责任 |
| 物流运输破损 | 按保价与物流责任 | 先向物流索赔，平台协助举证 |
| 验货通过后寄回买家 | 买家 | 平台现行口径（来源：inspection.buyer_bear_shipping_when_pass） |

## 操作步骤

1. 收到退款申请先别急着拒绝，对照上表判断责任归属；
2. 责任在你：同意退货退款，主动承担运费，纠纷率比运费值钱；
3. 责任在买家：礼貌说明判责依据，给出退货地址，等买家寄回；
4. 谈不拢不扯皮：让买家申请平台介入，仲裁按证据判，3 分钟内会有首响（来源：arbitration.first_response_minutes）。

## 关键规则

- 确认收货后 15 天内买家可发起售后，过了窗口的运费争议不再受理（来源：trade.after_sale_window_days，RL-A-047）；
- 举证材料认：订单快照、商品图片视频、聊天记录、物流凭证、质检报告、付款凭证（来源：arbitration.evidence_types）；
- 发货前你自己拍的打包影像，是物流破损争议里最关键的证据。

## 常见问题

问：买家不愿出退货运费怎么办？把判责底表发给他，再不行就平台介入，不要私聊扯皮超过一轮。

问：保价费该谁出？高价值商品建议卖家发货时保价，这笔钱是卖家自己的物流成本。

问：买家寄回用的是到付怎么办？事先约定运费承担方，未约定的到付可以拒收，但要在聊天里留痕。

## 风险与避坑

- 运费是小钱，纠纷率是大钱：店铺分里的纠纷率直接影响曝光；
- 别用"运费我出一半"的口头承诺糊弄，承诺了就写进订单备注；
- 贵重商品退回必须保价，丢件了卖家自己吃损失。
