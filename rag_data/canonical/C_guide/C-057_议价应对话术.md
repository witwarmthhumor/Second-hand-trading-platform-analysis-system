# 议价应对话术

## 什么时候看这篇

买家在「商品详情页-聊天窗口」发起砍价，你拿不准怎么接、怎么让、怎么守住底线的时候，看这篇。

## 操作步骤

1. **先看买家出价，再决定回法**。打开聊天窗口，点买家头像看对方信用分与交易记录。信用分低于 350 或近期有纠纷记录的账号，砍价话术再诚恳也不急着松口，先按正常节奏回复。出价低于你心理价位 20% 以上的，不必当场答应，先发一句"我看看，稍等"给自己留出判断时间。

2. **分三档回应砍价**。第一档，买家小刀（低于标价 5% 以内）：直接答应或象征性还一口价，爽快成交能攒服务态度分。第二档，买家大刀（低于标价 10%-20%）：用"我查下同类在售行情"回应，别急着拒绝，也别立刻让步。第三档，屠龙刀（低于标价 30% 以上）：礼貌说明底价依据，把对话引导回商品价值本身，不纠缠。

3. **让步要一次比一次小**。首次让价幅度控制在可接受范围内的一半，第二次让价幅度减半，第三次明确告知"这是底价了"。让步节奏一旦乱掉，买家会继续试探，拖长整个议价周期。

4. **把议价引向成交动作**。价格谈拢后，立刻发一句"按这个价给您改，您确认下收货地址"，然后走「订单管理-改价操作」完成改价。改价完成后提醒买家在 24 小时内完成付款，超时未付订单会被系统自动取消。

5. **谈不拢就体面收尾**。发一句"理解您的预算，这个价确实做不了，您再看看别的"，然后停止主动跟进。不拉黑、不嘲讽，留个后续复购的可能。

## 关键规则

- 商品若属于手机、平板电脑、笔记本电脑、相机与镜头、智能手表与穿戴、游戏主机与游戏、奢侈品箱包、腕表、黄金珠宝这些类目，必须走平台质检流程，成交价里包含的质检环节不可因议价而省略（来源制度 RL-103）。
- 卖家发货时限为 48 小时，从买家付款成功那一刻起算。议价过程拖太久，可能导致付款后发货时间紧张（来源制度 RL-201）。
- 平台服务费按成交价向卖家收取，费率按品类划分：手机数码 1%、电脑办公 1.5%、相机影音 2%、奢侈品 3%、服饰鞋包 2%、图书音像 1%、家居家电 1.5%、其他 2%。你给买家让价的每一块钱，都是税后净收入减少，算账时要把费率算进去（来源制度 RL-302）。
- 个人卖家保证金为 0 元，专业卖家保证金为 500 元。议价不涉及保证金调整，但恶意改价后不发货会被记入信用分扣减（来源制度 RL-401）。
- 信用分初始 800 分，最低 350 分，最高 950 分。议价过程中言语辱骂或诱导线下交易，一经核实将触发扣分（来源制度 RL-401）。

## 常见问题

**"你这价格能少点吗？我诚心要。"**
回："诚心要的话您出个价，我看看能差多少。"让买家先报价，你才知道对方的心理区间。

**"别人家同款比你便宜 200，你降不降？"**
回："您把链接发我看看，如果确实同成色同配置，我跟进一下。"要求对方举证，别被空口比价带节奏。

**"我学生，没什么钱，便宜点呗？"**
回："理解，价格上我可以适当让一点，但质检和运费这部分是平台固定的，实在动不了。"用规则当挡箭牌，不伤和气。

**"你直说底价多少，行我就拍。"**

## 风险与避坑

- **别被"马上拍"催昏头**。买家口头承诺"底价就拍"不构成订单，改价前先确认对方已拍下未付款，避免改完价对方消失、商品详情页却挂着低价记录。
- **型号与成色先对齐再谈价**。议价中随口承诺"跟新的差不多"容易埋雷，成交后买家按质检报告挑毛病，纠纷率上升会拖累店铺评分。
- **聊天记录就是证据**。砍价过程中谈定的价格、赠品、发货时间，都在平台聊天窗口里确认，别转微信聊，出纠纷时平台只认站内记录。
- **让价别碰质检底线**。部分类目强制走质检，议价时别答应"免质检直接发"这类要求，一旦绕过流程，后续售后责任全在卖家。
