# 申诉材料准备

## 什么时候看这篇

你卖了一台标价 4200 元的 95 新笔记本电脑，买家签收后第 6 天发起退货，理由是"开机有异响，与描述不符"。你心里清楚发货前刚做过检测，风扇声音正常。平台介入了，客服让你 72 小时内提交申诉材料——这时候你手边有什么能证明自己清白的？这篇就是告诉你，材料怎么备、备什么、怎么交才不被驳回。

## 操作步骤

1. 先别急着反驳，把订单号、商品名称、买家留言逐字截图存下来。在「我的-订单管理-售后详情」里找到这笔订单的售后编号，所有后续申诉都挂在这个编号下。
2. 打开「我的-客服中心-申诉入口」，确认当前申诉阶段和截止时间。平台介入后一般给 72 小时（以页面倒计时为准），超时未提交视为放弃，系统自动按买家方案处理。把截止时间设个手机闹钟，别指望自己记得。
3. 按证据类型逐项上传。每张图片不超过 10MB，视频不超过 3 分钟，支持 jpg/png/mp4 格式。一次传不齐没关系，在截止前可以补充，但每次补充都会重置审核计时，别拖到最后 1 小时才动手。
4. 上传完成后点「确认提交」，系统会生成一份申诉回执单。截图保存回执编号，后续追问进度时直接报这个号，客服不用再让你重复描述一遍事情经过。
5. 如果平台判定需要进一步核实，你会收到补充材料通知。按通知里列出的缺失项逐条补齐，不要自作主张传一堆无关截图——审核员看的是对应关系，不是数量。

## 关键规则

平台认可的申诉证据类型有六类：订单快照、商品图片视频、聊天记录、物流凭证、质检报告、付款凭证（RL-2026-售后纠纷类）。订单快照在「订单详情-查看快照」里直接生成，包含下单时的商品描述、成色等级、价格，是你主张"描述一致"的底稿。

成色等级是判责的核心依据。平台把成色分为 N（全新）、S（99新）、A（95新）、B（9成新）、C（8成新）、D（7成新及以下）六档，你发布时选的等级和买家收到的实物是否匹配，决定了纠纷走向。如果你卖的是手机、平板电脑、笔记本电脑、相机与镜头、智能手表与穿戴、游戏主机与游戏、奢侈品箱包、腕表、黄金珠宝这类强制送检品类，平台出具的质检报告是最有力的证据——报告上写了什么，基本就按什么判。

质检报告出具时限为 48 小时，如果你对报告结论不认可，可以在收到后 72 小时内申请复检（RL-2026-质检规则）。复检通过后买家需承担相应运费，这个规则在你申诉时可以引用。

物流凭证方面，发货时填写的运单号和揽收记录能证明你 48 小时内发出了货；买家签收后的物流轨迹则用于核对"签收时间 vs 问题反馈时间"的时间差。付款凭证用于证明交易金额和结算路径，一般只在涉及退款金额争议时用到。

聊天记录要注意：只有平台站内聊天记录被直接采信，微信、QQ 等外部聊天截图证明力很弱，审核员无法核实真伪。如果关键沟通发生在站外，你需要配合提供完整的上下文截图，并在申诉说明里解释为什么没有走站内沟通。

## 常见问题

"截图传上去好几天了，怎么还没动静？"申诉提交后审核需要时间，复杂案件通常 5 个工作日内出结果，你可以在申诉详情页看实时进度，不用反复催客服。

"买家说我卖的是翻新机，可我确实不知道啊。"如果你能提供进货凭证或上一手购买记录，并证明发货前成色描述属实，平台会按实际证据判责，不会只听买家单方面说法。

"质检报告说我商品有问题，但我发货前刚测过，能翻盘吗？"可以，收到报告后 72 小时内申请复检，复检通过后运费由买家承担。

## 风险与避坑

- 站外聊天截图证明力弱，关键沟通务必引导回站内，或录屏保留完整上下文。
- 发货前给商品序列号、外观瑕疵、功能测试各拍一段视频，存到云端别只留手机里——手机丢了证据就没了。
- 别在截止前最后一小时才传材料，一次传不齐可补充，但每次补充都会重置审核计时，拖越晚越被动。
- 申诉理由写清楚"商品与描述一致"的具体对应点，别写情绪化长文，审核员看的是对应关系。
