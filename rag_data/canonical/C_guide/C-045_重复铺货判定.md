# 重复铺货判定

## 什么时候看这篇
你准备上架多件同型号商品，或发现店铺里已有几条相似链接拿不准该不该保留——先读这篇，搞清楚哪些算重复铺货、哪些不算，以及踩线之后会怎样。

## 操作步骤

1. 登录卖家后台，进入「商品管理-发布商品」页面，先检索自己店铺内已在线商品。搜型号、搜品牌、搜关键参数，确认同款是否已经在售。
2. 若同款已在售，判断是否属于同一商品实体。判定维度有三个：品牌+型号完全一致、核心参数（存储容量/颜色/尺寸）一致、外观品相等级一致。三个维度全部命中，即视为同一商品实体。
3. 同一商品实体只允许保留一条在售链接。多余链接在「商品管理-下架管理」中自行下架，不要直接删除——下架后库存与历史评价仍保留，删除则不可恢复。
4. 若你确实有多件同型号商品要卖，正确做法是在同一条链接里增加库存数量，而不是再发一条新链接。库存数量修改路径：「商品管理-在售商品-编辑-库存」。
5. 若同型号但品相差异大（例如一台是 N 级全新未拆封、另一台是 C 级明显磕碰），允许分两条链接发布，但两条链接的主图、标题、描述必须能一眼区分等级差异，标题中须明确标注品相等级代码（N/S/A/B/C/D，见 RL-203 成色分级标准）。
6. 发布完成后，回到「商品管理-在售商品」列表做一次自查，确认没有同型号同品相的多条链接并存。

## 关键规则

- 同一商品实体（品牌+型号+核心参数+品相等级均一致）只允许一条在售链接，重复发布即构成重复铺货。规则来源：RL-201 商品发布规范。
- 重复铺货被系统识别或买家举报成立后，按违规次数累计扣信用分。信用分初始 800 分，最低 350 分，最高 950 分；扣分节点与处罚对应关系以平台页面公示为准，但累计扣分达到 24 分时触发流量限制 7 天，达到 36 分时店铺冻结 30 天，达到 48 分时永久封禁。规则来源：RL-210 信用分与处罚体系。
- 处罚按 365 天为一个计分周期滚动计算，不跨周期累计。规则来源：RL-210。
- 同型号不同品相等级分两条链接发布，不视为重复铺货，但必须在标题与主图中显著区分等级差异。
- 不同型号、不同容量版本（如 128G 与 256G）、不同颜色且主图能明显区分的，不视为重复铺货。
- 平台对重复铺货的判定以系统算法为主、人工审核为辅，具体识别阈值以平台页面公示为准。

## 常见问题

- 我有一台手机和一个平板，型号不一样，算重复铺货吗？——不算。品牌、型号、核心参数任一不同，就不属于同一商品实体。
- 同型号同品相，但一台自用一台帮朋友代卖，能发两条链接吗？——不能。平台不看货源归属，只看商品实体是否一致。
- 我先把旧链接下架了，再发一条新链接，这样行吗？——不行。下架后再发同款仍会被识别为重复铺货，正确做法是在原链接上改库存。
- 同型号两台，一台有磕碰一台完好，怎么发？——品相等级不同允许分两条，但标题必须写明等级代码，主图要能明显区分。
- 被误判了怎么办？——在「商品管理-违规记录」中提交申诉，附上商品实拍图与序列号照片，平台会在收到后尽快复核。

## 风险与避坑

- 别图省事批量复制链接再改价格。系统比对的是品牌、型号、参数和品相，价格不同不影响判定结果。
- 同型号不同品相分两条发时，主图别用同一张。买家投诉"图文不符"会连带触发商品质量分扣减，比重复铺货更麻烦。
- 下架不等于删除，但下架链接若长期无销量，系统仍会计入在售商品池。定期清理真正不再卖的链接，别攒着。
- 库存数量别一次加太多。二手商品一机一况，同链接挂 50 台库存但实际只有 3 台现货，发货超时会被判物流违约，规则见 RL-205。
- 收到违规通知后先看计分周期。365 天滚动计算，若上一周期快结束，可先确认本次扣分是否落在新周期，再决定申诉策略。
