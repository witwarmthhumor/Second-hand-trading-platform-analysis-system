# 店铺转让规则

## 什么时候看这篇
你打算把整个店铺连同信用分、在售商品一起过户给其他人，而不是单件转卖。店铺转让涉及主体变更、保证金承接和信用记录迁移，跟普通卖货完全是两套流程，先读完这篇再动手。

## 操作步骤

1. 确认转让资格。登录卖家端，进入「我的-店铺管理-店铺设置」，页面底部找到「店铺转让」入口。系统会先校验你当前是否有未完结订单、未出质检报告的商品或进行中的售后纠纷。任一条件不满足，入口置灰并提示原因。

2. 发起转让申请。点击「店铺转让」后，按页面提示填写受让方手机号。受让方必须是未在回流二手注册过店铺的自然人或企业主体。若受让方已有个人卖家账号，需先注销原店铺或放弃该账号，一个实名主体只能持有一家店铺。

3. 受让方完成入驻认证。系统会向受让方手机号发送邀请链接，对方需在 48 小时内完成入驻流程。个人卖家转让给个人，受让方需提交身份证与银行卡信息；转让给企业，则需额外提交营业执照并完成对公账户验证。认证通过前，转让流程暂停。

4. 签署转让协议并缴纳保证金。双方在线签署《店铺转让协议》，协议内容包含店铺信用分、在售商品清单、待结算货款归属三项核心条款。受让方按店铺类型缴纳保证金——个人卖家 0 元保证金，专业卖家 500 元保证金，该金额以平台页面公示为准。原卖家缴纳的保证金在转让完成后原路退回。

5. 平台审核与公示。提交后平台在 3 个工作日内完成审核，审核期间店铺正常运营但不可新增商品。审核通过后进入 7 天公示期，公示期内原卖家可就未披露的债务或纠纷提出异议。

6. 完成交割。公示期满无异议，系统自动完成主体变更。受让方获得店铺全部权限，原卖家账号解除绑定。店铺信用分、处罚记录、历史订单数据整体迁移至受让方名下。

## 关键规则

- 店铺转让后信用分完整继承，包括扣分记录。若原店铺当前处于限流期或封禁期，转让申请将被驳回，需等待处罚期满方可发起（处罚规则编号 RL-P03）。
- 在售商品随店铺一并转移，已生成的订单仍由原卖家履行发货义务。原卖家须在订单生成后 48 小时内发货，超时将计入物流履约分（规则编号 RL-T02）。
- 待结算货款默认归属原卖家，双方可在转让协议中另行约定。货款结算周期为 T+1，提现到账也为 T+1（费率与结算规则编号 RL-F01）。
- 店铺转让不改变商品所属品类的费率标准。受让方后续发布商品，仍按商品实际所属品类收取费率，手机数码 1%、电脑办公 1.5%、相机影音 2%、奢侈品 3%、服饰鞋包 2%、图书音像 1%、家居家电 1.5%、其他 2%，单笔最低 0.1 元（规则编号 RL-F02）。
- 受让方在转让完成后 15 天内不得再次发起店铺转让，防止频繁倒手规避平台监管。

## 常见问题

- 转让后我的信用分还能保留吗？——不能，信用分、处罚记录、历史订单整体迁到受让方名下，你的账号不再关联这家店。
- 受让方需要交多少保证金？——按店铺类型来，个人卖家 0 元，专业卖家 500 元，具体以平台页面公示为准。
- 在售商品还没卖完能转让吗？——能，商品随店铺一起过户，但已生成的订单仍由你发货，别漏了 48 小时发货时限。
- 公示期有人提异议怎么办？——异议成立则转让中止，处理完纠纷后才能重新发起。

## 风险与避坑

- 转让前先自查处罚状态。店铺若在限流期或封禁期，申请会被直接驳回，白等审核时间。
- 公示期内别放松发货。已生成订单仍算在你头上，超时发货扣的是你的物流履约分，不是受让方的。
- 待结算货款默认归你，但建议在协议里写明金额和到账时间，避免交割后扯皮。
- 受让方 15 天内不能再转手，选人时想清楚，别找个过桥的。
- 转让完成后原账号若还想卖货，得重新走入驻流程，原有店铺数据回不来。
