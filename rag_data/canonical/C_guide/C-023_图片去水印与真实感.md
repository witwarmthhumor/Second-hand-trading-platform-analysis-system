# 图片去水印与真实感

## 什么时候看这篇

准备发布商品、但手上图片带着别家平台水印或网图痕迹的时候。买家在回流二手（RAGreflow）上买的是"这件具体的东西"，不是你从详情页搬运来的宣传图——图片不真实，后面验货、售后全是坑。

## 操作步骤

1. 拍摄前先清洁商品表面，选自然光或白光环境，避免黄光导致色偏。手机摄像头擦干净，这是最容易被忽略的一步。
2. 拍摄时覆盖六个面：正面、背面、两侧、顶部/底部，外加一张能拍到序列号或唯一标识的特写。功能瑕疵（如屏幕划痕、镜头霉点）必须单独拍局部大图，不要指望文字描述能代替。
3. 检查原图是否带水印。凡是从其他平台、品牌官网、搜索引擎下载的图片，一律不得直接上传——先裁剪掉水印区域，再重新拍摄同角度实拍图替代。裁不掉的，弃用。
4. 使用平台内置编辑工具做基础调整：旋转校正、亮度微调、裁剪多余背景。工具路径为「发布商品-图片上传-编辑」，只允许调亮度、对比度、色温，禁止使用滤镜、美颜、虚化背景等改变真实观感的功能。
5. 上传顺序按"主图-细节图-瑕疵图"排列。主图放最能体现整体成色的正面照，瑕疵图必须放在买家无需翻页就能看到的位置（前四张以内）。
6. 提交前逐张自查：有没有漏掉的水印角标、有没有过度后期导致颜色失真、瑕疵是否全部入镜。拿不准的，重新拍，不要赌。

## 关键规则

- 全平台禁止上传带第三方平台水印、Logo、网址的图片，一经发现按违规图片处理，来源制度编号 RL-102。
- 图片必须真实反映商品当前状态。成色等级 N（全新）到 D（7成新及以下）均有对应描述标准，图片展示的磨损程度不得低于文字描述等级，来源制度编号 RL-087。
- 手机、平板电脑、笔记本电脑、相机与镜头、智能手表与穿戴、游戏主机与游戏、奢侈品箱包、腕表、黄金珠宝这九类强制走验货流程，验货报告出具时限为 48 小时。图片与实物不符的，验货不通过，来回折腾的是你自己。
- 使用他人实拍图、官方渲染图冒充实拍，属于严重违规，按信用分扣减处理，具体阈值以平台页面公示为准。
- 图片存储与展示规则、分辨率要求，以平台页面公示为准。

## 常见问题

**"我直接从京东详情页存了几张图，裁掉水印能用吗？"**
不能用。裁掉水印的图依然是网图，不是你这件商品的实拍。买家收到货一对比就穿帮，纠纷率直接拉高。重新拍，十分钟的事。

**"手机有点划痕，但拍照看不太出来，能不能不传瑕疵图？"**
不能。验货环节会拍高清细节图，划痕必然暴露。你隐瞒瑕疵，买家收货后发起售后，15 天售后窗口期内你都得接着。主动披露反而显得诚实，成交更顺。

**"用美图秀秀调了下颜色，算违规吗？"**
算。任何改变商品真实观感的后期处理都不允许。你调亮了觉得好看，买家拿到手觉得色差大，纠纷就是这么来的。只用平台内置编辑做亮度微调即可。

**"背景有点乱，能不能用虚化功能把后面模糊掉？"**
不能。虚化背景属于改变图片信息的行为，可能掩盖商品周边环境线索（比如是否在烟灰缸旁边、是否有宠物毛）。保持背景干净即可，不用虚化。

**"验货报告里的图和我上传的图不一样，以哪个为准？"**
以验货报告为准。验货机构会独立拍摄留档，这份报告是后续仲裁的关键证据。所以你自己上传的图越真实，报告和你的图越一致，对你就越有利。

## 风险与避坑

- 别只盯着水印。真正让买家退货的，往往是那些你"觉得无所谓"的细节——充电口磨损、镜头进灰、按键松垮。拍之前把机器翻来覆去摸一遍，发现问题就拍进去。
- 序列号特写别省。验货不过、买家扯皮时，唯一能证明"这就是你那台"的只有序列号。图省事跳过这张，后面举证你拿不出东西。
- 上传前数一遍图片数量。平台对图片张数有下限要求，少传一张就发布失败一次，反复提交还容易被误判为异常操作。以平台页面公示为准，别卡着线传。
- 二手交易讲证据。聊天记录里承诺的成色、瑕疵，最后都会变成仲裁依据。图片拍得越全，你越少废话。
