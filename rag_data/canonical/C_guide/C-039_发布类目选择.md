# 发布类目选择

## 什么时候看这篇

你手上有一台闲置手机或一只二手包，准备在 RAGreflow（回流二手）上架，但拿不准该放进哪个类目、选错会有什么后果。这篇帮你把类目、费率和验货要求一次理清。

## 操作步骤

1. 打开 App 进入「发布商品-选择类目」，系统会先让你选一级类目（手机数码、电脑办公、相机影音、奢侈品、服饰鞋包、图书音像、家居家电、其他），再逐级下钻到叶子类目。以一台 iPhone 为例：手机数码 → 手机，而不是走"其他"。
2. 对照实物确认叶子类目是否命中验货清单。目前强制验货的类目包括：手机、平板电脑、笔记本电脑、相机与镜头、智能手表与穿戴、游戏主机与游戏、奢侈品箱包、腕表、黄金珠宝。如果你的商品属于这些类目，发布流程会自动带入验货环节，无法跳过。
3. 选完类目后核对页面展示的预估费率和服务费说明，确认无误再进入下一步填写商品信息。提交前系统会做一次类目与商品标题、图片的匹配校验，若明显不符会弹出提示，按提示修改即可。

## 关键规则

**费率按叶子类目归属的费率组收取，由卖家承担。** 手机数码费率 1%，电脑办公 1.5%，相机影音 2%，奢侈品 3%，服饰鞋包 2%，图书音像 1%，家居家电 1.5%，其他 2%；单笔服务费最低 0.1 元，结算与提现均为 T+1 到账（制度编号 RL-FEE-2024-01）。

**类目选错会直接影响验货义务和费率。** 举例：一台笔记本电脑若误选入"台式机与配件"，费率从 1.5% 变为 1.5% 不变，但"台式机与配件"不强制验货，而笔记本电脑强制验货——类目选错可能导致本应验货的商品跳过验货，后续产生纠纷时卖家承担不利后果。同理，智能手表与穿戴属于手机数码费率组（1%），但强制验货；无线耳机与音频同属手机数码费率组却不强制验货，两者义务完全不同。

**跨品类通用类目仅用于确实无法归入现有叶子类目的商品**，费率按商品实际所属品类取对应费率组，不享受任何类目特定优惠。能用标准类目描述的商品，不建议走通用类目。

**强制验货类目的验货报告出具时限为 48 小时**，卖家对报告有异议可在 72 小时内申请复检；验货通过后买家承担寄出运费（制度编号 RL-INSPECT-2024-03）。非强制验货类目，卖家可自愿选择是否开启验货服务。

**类目与成色描述必须一致。** 成色分级从 N（全新）到 D（7成新及以下）共六档，D 档（较重磨损或局部功能瑕疵）必须在描述中显著披露。选错类目导致成色标准适用错误，按商品描述不符处理。

## 常见问题

**我卖的是手机壳，该选哪个类目？**

手机壳不属于强制验货类目，选"手机数码"下对应配件叶子类目即可，费率按手机数码 1% 收取。拿不准时用类目搜索框输入"手机壳"，系统会给出匹配项。

**选错类目已经发布了，还能改吗？**

商品未售出前可在「我的-在售商品-编辑」里修改类目，但改到强制验货类目会重新触发验货流程。已成交的订单不能改类目，只能按原类目履约。

**同一件商品既能放"手机"也能放"其他"，放哪边更划算？**

能归入标准类目就不要走"其他"。跨品类通用类目费率按实际品类取，不享受任何优惠，且系统匹配校验更容易拦截。

**验货不通过会被收费吗？**

验货环节的费用规则以平台页面公示为准。验货通过后买家承担寄出运费；若因卖家隐瞒瑕疵导致验货不通过，相关费用由卖家承担。

## 风险与避坑

- **类目决定验货义务，别只盯着费率。** 智能手表费率低但强制验货，无线耳机不强制验货——两者义务完全不同。选类目前先对照强制验货清单，再比较费率。
- **成色描述要和类目匹配。** 强制验货类目走验货报告定级；非强制类目靠自述，D 档瑕疵必须显著披露，否则按描述不符处理，纠纷时卖家吃亏。
- **保留选类目时的页面截图。** 若后续因类目归属产生争议，截图能证明你当时按系统指引操作，是有效的申诉证据。
- **跨品类通用类目是兜底不是捷径。** 频繁使用会被系统标记，影响商品质量分。能归入标准叶子类目的商品，别图省事走通用。
