# 提现失败处理

## 什么时候看这篇

点了提现，钱没到账，页面还弹了失败提示——这篇按失败原因带你逐项排查，多数情况自己就能解决。

## 操作步骤

1. 看「卖家中心-账单」确认可提现余额确实足够，扣除中的技术服务费不参与提现（来源：RL-A-062）；
2. 核对收款银行卡：户名必须与实名认证一致，卡号逐位核对，二类户与异常状态的卡会直接退回；
3. 查结算节奏：确认收货后货款 T+1 入账，提现到账 T+1，节假日顺延（来源：fee.settlement、fee.withdraw_arrive，RL-A-063、RL-A-066）；
4. 以上都正常仍失败的，走「卖家中心-客服中心」提交工单，写明提现单号。

## 常见失败原因对照

| 提示 | 原因 | 处理 |
| 账户信息不一致 | 实名与收款卡户名不符 | 改绑本人银行卡后重试 |
| 余额不足 | 可提现余额低于提现金额 | 等待在途货款入账 |
| 银行退回 | 银行卡状态异常或超限 | 联系发卡行后重试 |
| 系统处理中 | 节假日或高峰期 | T+1 后查看，超时再报工单 |

## 关键规则

- 货款结算与提现到账都是 T+1，不是实时到账（来源：fee.settlement、fee.withdraw_arrive）；
- 保证金是保证金，货款是货款，专业卖家的 500 元保证金不混入可提现余额（来源：fee.deposit_yuan.pro_seller，RL-A-073）；
- 提现失败的金额原路回到可提现余额，不会丢失。

## 常见问题

问：显示成功但银行卡没到账怎么办？先等 T+1，超过到账时限仍未见款的，凭提现单号报工单。

问：换银行卡要重新认证吗？换绑本人新卡即可，户名必须与实名一致。

问：提现有手续费吗？按平台公示的提现规则执行，页面在确认前会展示费用明细。

## 风险与避坑

- 不要轻信"加急到账"的第三方服务，提现只有官方通道；
- 对账以「账单明细」为准，学会用《对账方法》里的口径自查；
- 账单差异先自己拉流水核对，再报工单，沟通成本最低。
