# 个人与专业卖家区别

## 什么时候看这篇

你刚注册完账号，在「卖家中心-身份选择」页面卡住了：一边是"个人卖家"，一边是"专业卖家"，不知道选哪个更划算、门槛更低。这篇帮你把两条路的差别摊开讲清楚。

## 操作步骤

1. 打开 App，进入「我的-卖家中心-身份选择」，先别急着点。系统会展示两种身份的权益对比表，仔细看费率、保证金、可发布类目三栏。
2. 对照自己手头的货：只卖一两件闲置手机、旧相机，选「个人卖家」；打算长期收售游戏主机、奢侈品箱包，选「专业卖家」。选完提交实名认证，个人卖家需绑定本人银行卡，专业卖家额外要求上传营业执照（个体工商户或企业均可）。
3. 专业卖家按页面提示缴纳保证金，金额以平台页面公示为准，目前标准为 500 元，支持支付宝或对公转账；个人卖家保证金为 0 元，无需任何资金冻结。
4. 缴纳完成后回到「卖家中心-资质管理」，确认身份标识已点亮。个人卖家标识为"个人"，专业卖家标识为"专业"，会展示在商品详情页店铺信息栏。
5. 之后想升级身份，路径是「卖家中心-身份选择-升级为专业卖家」，补齐资质和保证金即可；想从专业降回个人，需先清空在售商品并结清所有订单，再联系客服处理。

## 关键规则

**费率差异是核心分水岭。** 平台向卖家收取技术服务费，费率按商品实际所属品类计取（来源 RL-FEE-03）：手机数码 1%、电脑办公 1.5%、相机影音 2%、奢侈品 3%、服饰鞋包 2%、图书音像 1%、家居家电 1.5%、其他 2%，单笔最低 0.1 元。个人卖家与专业卖家执行同一套费率表，没有身份折扣——差别不在费率，而在保证金与可发布类目。

**保证金规则（来源 RL-ACC-07）：** 个人卖家保证金 0 元，专业卖家保证金 500 元。保证金用于覆盖交易纠纷垫赔，身份降级或注销时可申请退还，前提是无未完结纠纷。

**可发布类目差异（来源 RL-ACC-08）：** 个人卖家仅可发布非强制质检类目下的闲置商品，例如无线耳机与音频、运动鞋服、图书、小家电、台式机与配件；手机、平板电脑、笔记本电脑、相机与镜头、智能手表与穿戴、游戏主机与游戏、奢侈品箱包、腕表、黄金珠宝等强制质检类目，仅专业卖家可发布。个人卖家若想卖手机，必须先升级为专业卖家。

**结算规则（来源 RL-TRD-05）：** 两种身份均适用 T+1 结算，买家确认收货后次日资金可提现，提现到账也为 T+1。个人卖家无店铺评分展示，专业卖家展示店铺评分，包含商品质量分、服务态度分、物流履约分、纠纷率四个维度。

## 常见问题

**"我就卖一部旧手机，选个人卖家行不行？"**
不行。手机属于强制质检类目，只有专业卖家能发布。想卖手机就得升级，这是类目门槛，不是费率问题。

**"个人卖家是不是费率更低？"**
不是。两种身份共用同一张费率表，按品类计取，谁卖都一样。个人卖家省的是那笔 500 元保证金，不是手续费。

**"先选个人卖家，以后货多了再升级，麻烦吗？"**
不麻烦。路径是「卖家中心-身份选择-升级为专业卖家」，补齐营业执照和保证金即可，在售商品不受影响。反过来降级才麻烦，得先清空在售、结清订单。

**"专业卖家保证金什么时候能退？"**
无未完结纠纷的前提下，身份降级或注销时可申请退还。有纠纷在走流程的话，会先冻结到结案。

## 风险与避坑

- **别拿个人身份挂强制质检类目。** 有人想绕过门槛，把手机挂在"无线耳机与音频"这类非强制类目下碰运气。平台按商品实际品类核验，一旦查出，轻则下架扣分，重则限制发布权限，保证金白交。
- **升级前先算账。** 500 元保证金不是成本，是可退押金，但如果你只打算卖一两件闲置，为单件商品冻结这笔钱未必划算。先想清楚出货频率再点升级。
- **降级不是点一下按钮的事。** 从专业降回个人要清空在售、结清订单，处理周期不短。决定降级前，把在途订单和售后窗口都过一遍，别留尾巴。
- **费率按实际品类走，别被"其他"误导。** 发布时选错类目，结算时按实际品类补扣费率差。发布前对照费率表核一遍，省得事后对账才发现少赚了。
