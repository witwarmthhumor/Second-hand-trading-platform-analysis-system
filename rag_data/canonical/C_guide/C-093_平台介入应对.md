# 平台介入应对

## 什么时候看这篇

买家申请退款后你们没谈拢，订单进入平台介入流程。此时你需要在 72 小时内配合平台裁决，超过时限平台将按已有材料直接判。这篇教你撑过这 72 小时，以及更早的 3 分钟黄金窗口。

## 操作步骤

1. 收到介入通知后，先别急着写小作文。打开订单详情页，点「纠纷详情」，把买家申请理由、上传的凭证逐条截图存档。平台介入的举证期从通知发出起算，以页面倒计时为准。
2. 在「纠纷详情-我的举证」里按类目上传材料。平台认六类证据：订单快照、商品图片视频、聊天记录、物流凭证、质检报告、付款凭证。图片单张别超过 10MB，视频用 mp4 格式，聊天记录截图要包含双方头像和完整时间线，只截对自己有利的半句话会被认定为无效举证。
3. 举证期内可以发起一次「补充说明」，把时间线捋清楚：什么时候发货、买家什么时候说有问题、你什么时候回复的。平台客服介入后通常会在 72 小时内给出判定，复杂案件（涉及质检复核、多方责任认定）延长至 5 个工作日。
4. 对判定结果不满，在结果页点「申请复核」。复核申请需在判定后 72 小时内提交，超时入口关闭。复核只接受新证据，老话重提不会被受理。
5. 若判定你需要退款，按页面提示操作。涉及质检的订单，若质检报告判定商品本身无问题，买家需承担送检运费，你不用垫付。

## 关键规则

- 平台首次响应介入请求的目标时限为 3 分钟——这不是给你的时限，是平台客服的响应标准，但意味着你的举证材料越早越全，越可能被优先审阅。
- 平台介入整体裁决时限为 72 小时（自介入受理起算），复杂案件延长至 5 个工作日（RL-310）。
- 信用分初始 800 分，纠纷率是店铺评分的四个维度之一。若平台判定你有过错，将按情节扣减信用分；扣满 12 分触发警告，24 分限流 7 天，36 分封店 30 天，48 分永久封禁（RL-210）。
- 举证期内你与买家的每一次沟通都会留痕。平台调取聊天记录时，你承诺过但没做到的话（比如"我保证没修过"但质检报告显示拆修），会作为不利证据。
- 各环节具体倒计时、可补充举证的次数上限，以平台页面公示为准。

## 常见问题

- "买家说东西是坏的，但我发货前明明测过，怎么办？"
  上传发货前的测试视频或照片，附上聊天记录里买家确认收货的对话。若商品属于强制质检类目（手机、平板、笔记本电脑、相机与镜头、智能手表与穿戴、游戏主机与游戏、奢侈品箱包、腕表、黄金珠宝），以质检报告为准。
- "平台判我输了，但我真没坑人，还能翻盘吗？"
  可以，在结果页 72 小时内申请复核，只接受新证据。比如买家后来自己修过机器的维修单、物流公司开的破损证明。
- "买家一直不退货，平台却让我先退款，合理吗？"
  按平台规则走，退款后保留好订单号和聊天记录。若买家超时未退货，可另行发起投诉追偿，以平台页面公示的流程为准。
- "我和买家私下谈好了，怎么撤销介入？"
  在纠纷详情页点「双方和解」，需买卖双方都确认。和解后平台不再介入，已提交的举证材料不会影响你的信用分。
- "质检报告说没问题，但买家不认，非要平台判。"
  质检报告是平台采信度最高的证据类型。若报告判定商品无问题，买家坚持送检产生的费用由买家承担（RL-310 质检规则）。

## 风险与避坑

- 举证期别拖到最后一天。平台倒计时走完，补充入口直接关闭，你手里再有新证据也递不上去，只能走复核，而复核只认新证据。
- 聊天记录别只截对自己有利的。平台调取的是完整记录，你截掉的那半句若被买家补传，反而坐实你刻意隐瞒。
- 口头承诺要慎重。"我保证全原装"这类话在纠纷里会被逐字比对，与质检报告矛盾时直接成为不利证据。
- 判定退款后及时操作，别赌买家不退货。拖过平台给的退货期限，后续追偿流程会更被动，具体时限以页面倒计时为准。
