# iPad Air交易遭遇ID锁无法退出，平台支持全额退款

## 案情时间线

1. 第 2 天，无锡买家在平台拍下一台 iPad Air，成交价 3200 元。卖家描述为"自用国行，无锁无修"，随附开机视频与爱思助手截图。买家收货后开机，系统正常，遂确认收货。
2. 第 3 天，买家尝试用自己的 Apple ID 登录 App Store，系统提示"此设备已与另一个 Apple ID 关联"。买家随即在"我的-客服中心-售后申请"提交退货退款申请，理由勾选"商品与描述不符"。
3. 第 4 天，卖家拒绝退款，坚称发货前已退出 iCloud，怀疑买家自行登录他人账号导致锁机。买家再次发起申诉，并上传当日录制的完整开机视频，视频中设置页顶部明确显示"无法验证此设备的所有权"。
4. 第 10 天，平台客服介入，要求买家在"订单详情-举证中心"补充材料。买家上传了订单快照、开机视频、Apple 官网序列号查询结果（显示该机仍处于他人账户激活状态），以及连续三天尝试重置密码被拒的截图。
5. 第 11 天，卖家补充提交发货前退出 iCloud 的录屏、顺丰寄出时的验机照片，并留言"买家签收后隔天才报问题，怀疑掉包"。
6. 第 12 天，平台将双方材料移交质检复核，要求买家将设备寄回平台指定检测点，运费由平台先行垫付。
7. 第 14 天，质检报告出具：设备序列号与订单快照一致，未拆修，但激活锁状态为"开启"，且绑定的 Apple ID 邮箱前缀与卖家注册手机号不符。检测点尝试联系原机主解绑，未获响应。

## 争议焦点

设备在签收次日被证实存在无法退出的 ID 锁，卖家是否构成描述不符；买家隔天申报是否影响责任认定。

## 双方举证

1. 买家提交订单快照、开机视频、官网序列号查询结果（仍处他人账户激活状态）及重置密码被拒截图。
2. 卖家提交退出 iCloud 录屏和验机照片，主张买家隔天申报、怀疑掉包。
3. 质检确认序列号与订单一致、未拆修，排除掉包与拆机。

## 平台判定

1. 激活锁为"开启"，绑定 ID 邮箱前缀与卖家手机号不符，说明发货前未真正退出账号。
2. 序列号一致且未拆修，"掉包"不成立，隔天申报不影响交付瑕疵认定。
3. 以质检结论为准，认定卖家描述不符、承担全责。

## 处理结果

1. 平台支持全额退货退款，3200 元原路退回买家，iPad Air 寄回卖家，运费由平台垫付后向卖家结算。
2. 卖家 ID 锁类纠纷计入商品质量分，并被要求苹果设备上架前关闭"查找"、退出 iCloud。

## 复盘提示

1. 买苹果设备当场查看激活锁与"查找"状态，别只看能否开机。
2. 官网序列号查询并截图，是证明 ID 锁的权威依据。
3. 序列号一致、未拆修即可排除掉包质疑，保留好原机包装。
