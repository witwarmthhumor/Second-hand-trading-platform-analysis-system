# 4K显示器出现ID锁无法退出：验货拦截后原路退款全过程

## 案情时间线

1. 第 1 天，济南买家在平台拍下一台 4K 显示器，成交价 1899 元。卖家发货前提供了开机视频，画面正常，无任何账号提示。
2. 第 2 天，物流显示包裹已签收。买家当晚通电测试，屏幕亮起后直接卡在 ID 锁激活界面，无法进入系统，多次重启无效。
3. 第 5 天，买家在订单页发起退货退款申请，理由勾选"商品与描述不符"，并上传两张照片：一张为显示器背面序列号特写，另一张为 ID 锁界面的完整画面。
4. 第 6 天，卖家拒绝退货，坚称发货前已测试，怀疑买家自行操作导致锁机。买家随即申请平台介入，补充提交了开箱全程录像。
5. 第 9 天，平台客服查看双方凭证后，要求买家将显示器寄回平台合作的质检仓进行验货拦截。买家当天打包寄出，物流单号同步回传至售后页面。
6. 第 11 天，质检仓签收。工程师通电检测，确认设备开机即进入 ID 锁激活界面，无法跳过，且该 ID 与买家账号无任何关联。
7. 第 13 天，质检报告出具，结论为"设备存在非买家原因的账号锁定问题"。平台依据报告判定退货退款成立。

## 争议焦点

显示器在签收后出现 ID 锁无法退出，究竟是卖家发货前已存在，还是买家操作所致。

## 双方举证

1. 买家提交：开箱通电录像（连续无剪辑，覆盖从拆箱到出现 ID 锁全过程）、ID 锁界面照片、订单快照、退货物流凭证。
2. 卖家提交：发货前开机视频、聊天记录截图（主张买家未按指引操作）、拒绝退货的说明文字。
3. 平台调取：质检仓验货报告，含设备序列号比对记录。

## 平台判定

1. 质检仓通电确认设备开机即进入 ID 锁界面、无法跳过，锁定 ID 与买家账号无关联，排除买家自行锁机。
2. 买家开箱录像连续无剪辑，覆盖从拆箱到出现 ID 锁全过程，可证明签收时缺陷已存在。
3. 卖家发货前视频未展示退出账号的完整流程，无法证明交付时无锁，故认定账号锁定问题在发货前已存在，卖家全责。

## 处理结果

1. 平台支持全额退货退款，1899 元货款原路退回买家，显示器退回卖家，来回运费由卖家承担。
2. 卖家账号锁定类描述不符计入商品质量分纠纷记录，被要求上架前必须退出并解除全部账号绑定。

## 复盘提示

1. 买带账号体系的数码设备，收货第一时间通电验证能否正常激活、有无残留 ID 锁。
2. 开箱到出现问题全程录像不中断，是排除"买家自己锁机"的关键。
3. 卖家发货前要恢复出厂、退出全部账号并录下完整过程，避免交付后说不清。
4. 双方都无法自证时，申请寄回质检仓检测，以序列号和锁定账号比对定责。
