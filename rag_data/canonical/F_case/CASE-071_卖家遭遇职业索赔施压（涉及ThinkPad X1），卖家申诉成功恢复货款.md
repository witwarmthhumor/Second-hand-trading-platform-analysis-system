# 卖家遭遇职业索赔施压（涉及ThinkPad X1），卖家申诉成功恢复货款

## 案情时间线

第1天，青岛卖家在平台挂出一台ThinkPad X1，标价4280元。买家拍下后未多问配置，仅确认"能开机、无拆修"即完成付款。卖家当天发货，物流轨迹正常。

第2天，买家签收。当晚发来消息，称电脑屏幕有亮点，要求退部分款项作为"补偿"，否则申请退货。卖家回复愿走正常退货流程，买家未再回应。

第7天，买家突然发起仅退款申请，理由为"商品与描述不符——屏幕存在维修痕迹"，并附上一张屏幕边框特写。卖家在后台看到该照片光线角度刻意，边框缝隙疑似被放大拍摄。

第9天，平台介入，买家补充提交一段开机视频，声称"第3秒可见屏幕闪烁"。卖家随即在申诉通道上传原始订单快照、发货前拍摄的整机多角度视频（含开机画面）、以及顺丰物流签收凭证。

第10天，买家在聊天窗口施压，称"我是做这行的，懂规则，你最好私了"，并发送一段模糊的所谓"质检报告"截图。卖家未妥协，继续补充提交该型号ThinkPad X1出厂序列号查询结果，显示无官方维修记录。

第13天，平台要求双方补充材料。卖家提交与买家的完整聊天记录，其中第2天买家主动提出"退点钱就算了"的对话被高亮标注，并附上买家账号近半年内多条仅退款记录截图。

第14天，平台作出判定，支持卖家，货款4280元全额解冻至卖家账户。

## 争议焦点

买家主张商品存在维修痕迹与屏幕闪烁，要求仅退款；卖家主张商品完好，买家系以瑕疵为由施压谋取部分退款。

## 双方举证

买家提交了屏幕边框特写照片、一段自称显示屏幕闪烁的开机视频、一份来源不明的"质检报告"截图。卖家提交了发货前多角度开机视频、订单快照、官方序列号查询无维修记录页面、完整聊天记录，以及买家账号的历史退款记录。

## 平台判定

平台比对证据后认定：买家主张维修痕迹与屏幕闪烁，但边框特写无法对应具体故障、闪烁视频未连续展示开机全过程，所谓"质检报告"来源不明、无机构资质，证明力不足；卖家提交发货前多角度开机视频、官方序列号无维修记录页面、订单快照与完整聊天记录，证据链完整，买家账号还存在多条仅退款记录。综合判断买家主张缺乏有效证据，对其仅退款诉求不予支持。

## 处理结果

1. 支持卖家，订单款 4280 元全额解冻至卖家账户，驳回买家仅退款申请。
2. 商品由买家继续受领，不产生退货运费。
3. 买家异常仅退款行为记录在案，若被认定恶意施压将影响其售后权益，以平台规则页公示为准。

## 复盘提示

1. 主张屏幕闪烁、维修痕迹要有连续完整的开机视频和有资质的检测报告，来源不明的截图不被采信。
2. 官方序列号查询、卖家发货多角度视频都是强证据，下单前可要求卖家提供。
3. "仅退款不退货"门槛较高，需证明商品根本无法使用，轻微争议更适合退货退款。
4. 频繁仅退款会形成账号记录，维权应基于真实证据。
