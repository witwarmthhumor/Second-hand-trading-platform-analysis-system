# WiFi6路由器交易遭遇ID锁无法退出，验货拦截后原路退款

## 案情时间线

第 3 天，合肥买家在平台拍下一台 WiFi6 路由器，成交价 450 元。卖家在商品页标注"自用无锁"，买家下单前也通过聊天确认过"能正常初始化"。当天卖家发货，物流轨迹正常更新。

第 6 天，包裹到达买家所在城市。买家当面拆包，通电后尝试进入管理后台做初始化设置，页面弹出该设备绑定的平台账号 ID 锁，无法退出。买家随即在收货页发起"验货拦截"，并上传开机视频，视频里能清晰看到 ID 锁登录界面和路由器机身序列号。

第 10 天，平台客服介入，要求卖家提供该设备的解绑记录或原始购买凭证。卖家回复称路由器是朋友转手给的，自己从未绑定过，手里只有一张手写收据。

第 11 天，买家按客服指引将设备寄回平台质检仓，物流签收。第 12 天，质检仓完成检测，确认设备存在无法绕过的 ID 锁，属于"功能受限"情形。

第 13 天，平台将检测结论同步给卖家，并开放退货退款入口。第 14 天，卖家未对结论提出异议，平台执行原路退款，450 元全额退回买家付款账户。

## 争议焦点

路由器存在无法退出的 ID 锁，是否属于卖家应知而未披露的功能瑕疵，买家能否在验货环节直接拦截并退款。

## 双方举证

买家提交了订单快照、开机视频（含 ID 锁界面与序列号）、物流签收记录，以及下单前与卖家确认"能正常初始化"的聊天记录截图。卖家提交了商品上架时的实拍图片和一张手写收据，主张自己不知情、非故意隐瞒。

## 平台判定

平台引用 RL-204 二手数码设备功能披露标准，核心规则是：凡影响设备正常初始化、绑定或使用的账号锁类问题，卖家必须在发布页显著披露；未披露即视为隐瞒。买家在验货环节发现 ID 锁并当场拦截，举证链完整——视频、序列号、聊天记录三者能互相印证。卖家仅凭手写收据无法证明设备来源合规，也无法证明其已尽到合理查验义务。质检仓复测结论与买家描述一致，故判定责任在卖家。

## 处理结果

第一条 平台判定卖家未按约定时效发货，构成违约。

第二条 买家已支付货款全额原路退回，退款到账时效以平台页面公示为准。

第三条 卖家店铺记违规一次，限制发布新品，限制时长以平台处罚通知为准。

第四条 该笔订单关闭，不再进入物流履约流程。

## 复盘提示

第五条 卖家上架商品前须确认库存与发货能力，无货商品不得挂售。

第六条 买家下单后超过平台规定时效未收到发货通知，可直接发起催单或申请退款，无需等待卖家主动联系。

第七条 涉及金额较大的订单，建议买家在付款前通过平台聊天窗口与卖家确认发货时间，留存沟通记录作为争议凭证。

第八条 卖家因不可抗力无法按时发货的，应在平台规定时效内主动联系买家协商取消或延期，避免被动判定违约。
